## 摘要
未来预测如何影响上下文相关的机器人控制？我们提出 PonderPounce-WM，在 PonderPounce 基础上扩展了三个未来 token，并以预测视觉特征变化为监督目标。其预训练的多模态大语言模型（MLLM）Ponder 将历史与演示整合为连续认知，供动作模型 Pounce 使用。我们研究 token 的顺序与传递方式，以区分预测性监督与直接的未来条件化。在 RoboMME 上，认知优先排序并仅传递认知，将成功率从 60.83% 提升至 67.42%。在相同排序下，直接传递未来 token 的成功率为 64.00%。探针显示，认知中的未来信息增加，而所测试的过去事件属性仍基本可解码。在四个真实机器人任务中，PonderPounce-WM 在异步执行下取得 67.44% 的平均成功率，而 PonderPounce 为 60.98%。这些结果表明，未来预测可通过辅助监督改善上下文相关控制，而无需将未来 token 传递给动作模型。

## Abstract
How does future prediction affect context-dependent robot control? We introduce PonderPounce-WM, extending PonderPounce with three future tokens supervised to predict visual-feature changes. Its pretrained MLLM, Ponder, integrates history and demonstrations into continuous cognition for the action model, Pounce. We investigate token ordering and delivery to distinguish predictive supervision from direct future conditioning. On RoboMME, cognition-first ordering with cognition-only delivery improves success from 60.83% to 67.42%. With the same ordering, direct future-token delivery yields 64.00% success. Probes show increased future information in cognition while the tested past-event attributes remain largely decodable. Across four real-robot tasks, PonderPounce-WM achieves 67.44% mean success under asynchronous execution, compared with 60.98% for PonderPounce. These results suggest that future prediction can improve context-dependent control through auxiliary supervision without delivering future tokens to the action model.

# PonderPounce-WM 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：上下文相关的机器人控制（context-dependent robot control）要求机器人保留已经无法直接观测到的过去事件（例如隐藏容器位置、已完成的重复次数），并利用演示（demonstration）来解释当前任务。
- **既有做法**：先前工作通常将观测历史/显式记忆与未来预测结合用于控制；PonderPounce 则把预训练 MLLM 的原生因果上下文当作"情节记忆"（episode memory），并输出一个连续上下文表示——**cognition（认知）**。
- **核心疑问**：未来预测究竟以何种方式帮助控制？是作为**辅助监督**去塑造 cognition 表示，还是必须把未来信息**直接条件化**给动作模型才有效？作者指出，预测视觉变化所需的信息，未必等同于动作决策所需的信息。
- **论文定位**：不引入视频生成骨干做像素级预测，而是把"世界模型"落实为**基于情节上下文对未来视觉特征变化做辅助预测**，并系统区分"预测性监督"与"直接未来条件化"两种作用路径。

## 2. 方法论

### 2.1 基础双系统架构（PonderPounce）

- **PONDER**（预训练 MLLM，Qwen3.5-9B）：把任务指令、演示、执行历史保存在原生因果上下文中；在查询时刻 $t$ 追加当前观测 $O_t$、可选子目标文本，以及一个可学习的 **cognition token**，其末层隐状态 $c_t \in \mathbb{R}^H$ 即为传给动作模型的连续上下文表示。
- **POUNCE**（π0.5 动作模型）：在第 $j$ 次调用时，将自身观测、本体感受、任务与前缀 $[e_{\Delta(j)}, W_c e_{c_j}]$ 结合，预测动作块（action chunk）。其中 $W_c$ 把最新就绪的 cognition 投影到动作模型宽度，$e_{\Delta(j)}$ 编码该 cognition 相对源观测的"年龄"。
- **异步执行**：POUNCE 在新 cognition 就绪前复用旧状态，实现松耦合的异步推理。
- **端到端训练**：动作 flow-matching 损失经前缀反传到 PONDER（梯度缩放 0.5），grounding token 交叉熵经 LM head 进入，总损失为 $\mathcal{L} = \mathcal{L}_{fm} + 0.1\mathcal{L}_{ground} + 5\mathcal{L}_{fut}$。

### 2.2 未来预测（核心新增）

- 新增 **3 个可学习未来 token** $F_1, F_2, F_3$，连同 cognition 共 $K=4$ 个 token。
- 每个 slot 对应一个预测时域：仿真中 $(h_1,h_2,h_3)=(0.5,1,2)$ 秒，真机为 $(1,2,3)$ 秒。
- **预测目标**为视觉特征的变化量而非绝对像素：
  $$\Delta_{t,h} = \mathrm{pool}_{4\times4}\,\phi(I_{t+h}) - \mathrm{pool}_{4\times4}\,\phi(I_t)$$
  其中 $\phi$ 为 **冻结的 SigLIP 编码器**，4×4 池化保留 16 个空间特征，输出维度 $\mathbb{R}^{16\times1152}$。
- 共享线性头把 slot $F_i$ 的隐状态 $f_{t,i}$ 映射为预测 $\hat{\Delta}_{t,h_i}$；辅助损失 $\mathcal{L}_{fut}$ 为有效"查询–时域"对上的均方误差，并排除超出情节结束的目标。
- **关键机制**：未来损失梯度会更新 PONDER 共享参数，并在未来 token 关注 cognition 时**流经 cognition**，因此预测监督可以在**不把未来 token 交给 POUNCE** 的前提下塑造 cognition；预测头在动作生成时完全不需要。

### 2.3 两个实验轴：顺序与传递

- **Token 顺序**：
  - `cog-first`：$[\text{cog}, F_1, F_2, F_3]$，因果注意力下 cognition **看不到**同一查询的未来 token；
  - `fut-first`：$[F_1, F_2, F_3, \text{cog}]$，cognition 可读取同查询未来 token。
  - 两者都保留此前查询的全部 token。
- **传递方式**：POUNCE 只接收 cognition，或通过共享 $W_c$ 接收全部 4 个隐状态。
- 组合成 4 种配置，用以解耦"预测作为辅助监督"与"未来作为直接条件"。

## 7. 局限性

- **训练随机性未覆盖**：单一种子 + 仅对评测槽做 bootstrap，无法区分配置间差异中有多少来自训练噪声；对区间含零的结论只能表述为"未被分辨"，不能断言等价。
- **基线非配对复现**：K=1、FrameSamp+Modul、MemER 均为引用数值或不同配方下的结果，缺少同数据、同调度、同评测次数的重跑，绝对增益的归因强度有限。
- **真机证据为弱因果**：不同模型在不同场次评测，cognition 新鲜度、操作者判定、场景顺序均未完全对齐；每任务 14–16 试次使任务级结论的方差较大。
- **未来监督的超参未系统扫描**：3 个 slot、固定时域 $(0.5,1,2)$ / $(1,2,3)$ 秒、损失权重 5、SigLIP + 4×4 池化的目标设计均为一次性设定，缺少对 slot 数、时域跨度、特征粒度、损失权重的消融，无法判断当前配置是否接近最优。
- **任务覆盖偏窄**：16 个仿真任务与 4 个真机任务均集中在桌面操作与短时程记忆（秒级），未验证长时程（分钟级）、多阶段任务或需要精细空间推理的任务。
- **未与视频生成式世界模型直接对比**：论文的定位是"轻量特征级预测"，但没有与像素级/潜空间视频预测骨干在同条件下比较，因此"特征变化预测优于生成式预测"这一隐含主张缺少直接证据。
- **梯度路径未做隔离实验**：论文论证未来损失"可经 cognition 回流"，但未通过 stop-gradient 或冻结 cognition 的对照来量化该路径的实际贡献比例。

## 8. 关键启示与开放问题

- **核心启示**：对未来视觉变化的预测，其价值主要在于**正则化上下文表示**，而非提供额外的决策输入；把未来 token 直接喂给动作模型会引入与动作无关的信息，反而稀释 cognition 的信号。这一结论对"世界模型 = 必须条件化未来"的默认假设构成了有价值的反例。
- **顺序即信息流**：因果注意力下的 token 排列决定了"谁监督谁"。`cog-first` 使 cognition 成为纯粹的预测起点，`fut-first` 则让 cognition 吸收未来 token 的表征——前者更好，说明**预测应当塑造表示，而不是被表示读取**。
- **开放问题**：
  1. 预测时域与任务时间尺度如何自适应（而非固定三档）？
  2. 特征级预测目标（SigLIP 变化量）是否是唯一有效选择，动作空间预测或本体感受预测是否更贴合控制？
  3. 未来监督带来的过去事件记忆轻微损失（容器位置 −1.5~−4.5 pt）是否存在容量竞争，能否通过解耦 token 或分离损失权重缓解？
  4. 在长时程、多阶段任务上，cognition 的"情节记忆"容量与 131K 上下文上限如何共同成为瓶颈？
  5. 单种子结论能否在多种子下复现，尤其是 Reference 族"基本不变"与若干单任务负增益（MoveCube −10 pt、PickHighlight −9 pt）是否稳健？

## 9. 总体评价

- **贡献清晰**：论文把一个模糊的问题——"未来预测如何帮助控制"——拆解为可实验分离的两个轴（监督 vs 条件化），并用 4 组配置 + 2 个对照给出了方向明确的答案，方法设计（共享预测头、cognition 中介、异步双系统）与问题拆解高度自洽。
- **证据强度中等偏上**：仿真规模（每配置约 2,400 次闭环评测、3 次重复、bootstrap 区间）在同类工作中属扎实；K=4 无未来损失对照是关键的实验设计亮点。但单种子、非配对基线、真机弱因果三点限制了结论的强度上限。
- **写作与透明度**：主动报告负增益单任务、明确区分"未分辨"与"等价"、把真机结果定位为支持性证据，均体现了较好的报告规范；算力与训练细节基本完整，仅缺墙钟时长与真机 GPU 具体配置。
- **定位**：这是一篇**以机制辨析为核心**的工作，其最大价值不在于刷新 SOTA，而在于给出"预测性监督优于直接未来条件化"这一可复用、可检验的设计原则，并为后续世界模型与机器人记忆系统的结合提供了明确的实验范式。
