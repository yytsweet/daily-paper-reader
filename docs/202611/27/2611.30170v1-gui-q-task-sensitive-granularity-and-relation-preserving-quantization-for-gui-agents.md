## 摘要
图形用户界面（GUI）智能体能够实现对移动端、Web和桌面界面的自动化交互。然而，其较大的内存占用和重复的模型调用阻碍了在资源受限设备上的部署，这推动了无需完整重训练的训练后量化（PTQ）。量化可能降低GUI响应准确率，并扭曲GUI目标选择所需的指令—视觉亲和性和局部空间关系。较小的坐标误差可能导致点击遗漏，而早期动作错误可能改变后续界面状态并破坏任务执行。仅靠局部重建误差无法直接评估这些响应和关系是否得到保持。我们提出GUI-Q，一种以响应和关系保持为目标的PTQ框架，采用4位权重和16位激活（W4A16）。任务敏感粒度分配（TSGA）在尺度字节预算下，结合响应敏感性与测得的激活加权失真降低量，分配更细的分组。关系保持对称性选择（RPSS）随后选择对称或非对称网格，以保持GUI中的指令—视觉亲和性和局部空间关系。在三个具备GUI能力的模型上，GUI-Q相比评估中最强的4位配置，将平均grounding TargetHit提高8.04至12.55点，同时相对于bfloat16（BF16）将静态峰值图形处理器（GPU）内存降低49.9%至56.2%。采用打包4位执行的固定输出重放可提供1.7至2.8倍的模型调用加速。代码将发布。

## Abstract
Graphical user interface (GUI) agents enable automated interactions with mobile, web, and desktop interfaces. However, their large memory footprint and repeated model calls hinder deployment on resource-constrained devices, motivating post-training quantization (PTQ) without full retraining. Quantization can degrade GUI response accuracy and distort the instruction-vision affinities and local spatial relations needed for GUI target selection. Small coordinate errors can cause missed clicks, while early action errors can alter subsequent interface states and disrupt task execution. Local reconstruction error alone does not directly assess whether these responses and relations are preserved. We propose GUI-Q, a PTQ framework that targets response and relation preservation with 4-bit weights and 16-bit activations (W4A16). Task-Sensitive Granularity Allocation (TSGA) allocates finer groups under a scale-byte budget by combining response sensitivity with the measured reduction in activation-weighted distortion. Relation-Preserving Symmetry Selection (RPSS) then selects symmetric or asymmetric grids to preserve instruction-vision affinities and local spatial relations in GUIs. Across three GUI-capable models, GUI-Q improves mean grounding TargetHit by 8.04 to 12.55 points over the strongest evaluated 4-bit configurations, while reducing static peak graphics processing unit (GPU) memory by 49.9% to 56.2% relative to bfloat16 (BF16). Fixed-output replay with packed 4-bit execution provides 1.7 to 2.8 times model-call speedups. The code will be released.

# GUI-Q 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：GUI 智能体（移动端、Web、桌面端）依赖大型视觉语言模型，通过"截图 + 指令 → 动作"完成自动化交互，需要精准定位目标并正确生成动作参数。
- **核心痛点**：
  - 7–8B 模型 FP32 权重约需 26–30 GiB 内存；即便 BF16，静态峰值 GPU 显存也达 15.75–16.67 GiB，难以部署到手机等边缘设备。
  - 智能体需重复调用模型，推理开销大。
- **量化带来的风险**：训练后量化（PTQ）虽可免重训降低存储，但会降低 GUI 响应准确率，并扭曲目标选择所需的**指令—视觉亲和性**与**局部空间关系**。小坐标误差即导致点错；早期动作错误会改变后续界面状态、破坏任务执行。
- **现有方法不足**：AWQ、GPTQ、AutoRound、VLM-PTQ、GuidedQuant、QVLA、ActQuant 等提供敏感度或动作信号，但"识别敏感模块"并不等于"知道哪里分配更细分组最划算"；局部重建误差也不能直接衡量指令—目标关系和空间关系是否保持。
- **论文主张**：GUI 量化应同时做**响应保持**（在有限 scale 字节预算下）与**关系保持**（指令—视觉亲和 + 局部空间关系），并据此指导粒度与对称性两个决策。

## 2. 方法论

### 2.1 总体框架

- 采用 **W4A16** 设置：所有目标线性权重（decoder 的 q/k/v/o 与 gate/up/down）量化为 4-bit，激活与未目标组件保持 BF16。
- 每个模块 $l$ 的量化配置为 $c_l=(4, g_l, a_l)$，其中 $g_l\in\{64,128\}$ 为分组大小，$a_l\in\{\text{sym},\text{asym}\}$ 为网格对称性。
- 两阶段解耦决策：**TSGA 先定粒度**（在 scale 字节预算 $B_{\text{scale}}$ 下），**RPSS 再定对称性**（在固定粒度上，从冻结的注意力投影池 $C$ 中选至多 $K_{\text{asym}}$ 个非对称模块）。最后用统一舍入后端校准导出。

### 2.2 任务敏感粒度分配（TSGA）

- **动机**：G64 比 G128 范围更局部，但 scale 元数据从 0.125 bit/weight 增至 0.25 bit/weight，需按模块收益分配。
- **响应敏感度估计**：
  - 用冻结模型贪婪生成参考响应 $y_n^*$，按原生 chat 模板 teacher-forcing 得到逐 token 损失。
  - 构造三类掩码：序列全部位置、含 Unicode 十进制数字的 token（约占 17.15–20.85%）、其余 token；空掩码回退到全序列。
  - 固定权重 $(p_{\text{seq}},p_{\text{num}},p_{\text{non}})=(0.30,0.50,0.20)$，先做百分位归一化再加权得模块敏感度 $S_l^+$。
  - 敏感度用因子化代理 $\hat E_{l,t}=\frac1N\sum_n \text{mean}(H_{l,n}^{\odot2})\cdot\text{mean}(U_{l,t,n}^{\odot2})$ 估计（仅保留响应行，属响应受限的秩代理）。
- **失真收益**：对每个候选粒度计算激活加权相对失真 $D_{l,g}$，定义目标 $J_l(g)=S_l^+\cdot D_{l,g}$，G64 相对 G128 的预测收益 $b_l=[J_l(128)-J_l(64)]^+$。
- **预算约束下的选择**：将问题建模为 0-1 背包——最大化 $\sum_l b_l x_l$，约束为额外 scale 字节 $\sum_l[C_l(64)-C_l(128)]x_l\le B_{\text{scale}}$；对整数代价约简后用动态规划求解（DP 仅需 0.138 秒）。

### 2.3 关系保持对称性选择（RPSS）

- **动机**：对称网格把范围绑定到最大绝对值，非对称网格增加零点以适配偏移范围；二者会改变指令与竞争目标之间的相对亲和，需按关系保持效果选择。
- **候选池**：冻结的 16 模块注意力池（早期 q 投影 + 三个深度的 k/v/o 投影），控制 profiling 成本。
- **关系度量**：
  - 取 block $b$ 注意力+残差后、MLP 前的特征并做 $\ell_2$ 归一化；文本仅用用户指令位置，视觉用可见截图 token，位置为源 patch 的归一化质心。
  - **指令—视觉亲和**：归一化点积 $A^r_{a,n,ij}=\langle T^r,V^r\rangle/\tau$，经 LogSinkhorn 得最优传输耦合 $P^r$，跨模态差异用 KL 型散度 $\mathcal L^{\text{cm}}$ 衡量。
  - **局部空间关系**：$G^r_{ij}=\langle V^r_i,V^r_j\rangle\cdot\exp(-\|\rho_i-\rho_j\|^2/2\sigma^2)$，空间差异用相对 Frobenius 误差 $\mathcal L^{\text{sp}}$。
  - 综合分数 $R=\mathcal L^{\text{cm}}+\gamma\mathcal L^{\text{sp}}$，边际增益 $\Delta_a=\frac1N\sum_n[R(\text{sym})-R(\text{asym})]$，选 $\Delta_a>0$ 的前 $K_{\text{asym}}$ 个模块。
- **超参**：$\tau=0.1$、$\sigma=0.25$、$\gamma=1$、$\epsilon_D=\epsilon_G=10^{-8}$。
- **最终舍入校准**：仅优化零初始化的舍入偏移（$[-1,1]$），50 步 Adam、FP32、直通舍入，权重/scale/零点/常量组固定。

### 2.4 算法流程（文字版）

1. 用冻结模型对 128 个无标签校准样本贪婪生成响应，构造三类掩码；
2. teacher-forcing 缓存各模块输入 $H_{l,n}$ 与损失梯度 $U_{l,t,n}$；
3. 计算敏感度代理并做全局百分位归一化与加权；
4. 计算各模块 $D_{l,64}$、$D_{l,128}$、收益 $b_l$ 与两种 scale 代价；
5. 用代价归一化 DP 求解背包，得到粒度分配 $\{g_l\}$；
6. 在固定粒度下，用 RPSS 对 16 模块池逐一评估对称/非对称边际关系保持分数，选至多 $K_{\text{asym}}$ 个非对称模块；
7. 冻结两项决策，用统一后端校准舍入偏移并导出打包 4-bit checkpoint。
