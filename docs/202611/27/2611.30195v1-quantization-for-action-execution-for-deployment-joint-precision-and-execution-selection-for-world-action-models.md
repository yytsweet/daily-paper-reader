## 摘要
世界动作模型通过预测动作的影响或根据观测生成指令来引导机器人。模型在行动前可能会比较数百个候选未来，并反复读取必须能装入设备内存的权重。训练后量化减少了存储预训练权重所用的比特数，但更小的模型未必可部署：临时张量可能超出图形处理器（GPU）内存限制，而即使很小的预测误差也可能改变所选动作。这带来了两个耦合的挑战：识别能保持任务性能的比特分配，并确定其中哪些满足真实执行约束，同时不耗尽昂贵的任务试验。我们提出 PTQ4WAM，一个用于在内存、延迟和任务评估预算下选择逐层比特分配与执行路线的框架。校准测量引导候选方案的提出，可选地借助语言模型智能体。在针对可行分配方案消耗任务试验之前，我们先在 GPU 上剖析全模型路线。融合分组重缩放并原地读取视觉历史，可使原本不可行的分配方案变得可部署。在来自四个模型家族的 15 个工作负载上，任务得分中位数为对应 32 位浮点（FP32）得分的 99.2%。在固定 GPU 回放中，相对于 FP32 的中位加速比为 2.36 倍，峰值分配内存的中位降低幅度为 71.5%。代码即将发布。

## Abstract
World action models guide robots by predicting the effects of actions or generating commands from observations. A model may compare hundreds of candidate futures before acting, repeatedly reading weights that must fit in device memory. Post-training quantization reduces the number of bits used to store pretrained weights, but a smaller model is not necessarily a deployable one: temporary tensors can exceed graphics processing unit (GPU) memory limits, while even small prediction errors can change the selected action. This creates two coupled challenges: identifying bit assignments that preserve task performance and determining which of them meet real execution constraints, without exhausting costly task trials. We present PTQ4WAM, a framework for choosing layer-wise bit assignments and execution routes under memory, latency and task-evaluation budgets. Calibration measurements guide candidate proposals, optionally with a language model agent. We profile full-model routes on the GPU before spending task trials on feasible assignments. Fusing group rescaling and reading visual history in place can make an otherwise infeasible assignment deployable. Across 15 workloads from four model families, the median task score is 99.2% of the corresponding 32-bit floating-point (FP32) score. On fixed GPU replays, the median speedup over FP32 is 2.36 times and the median reduction in peak allocated memory is 71.5%. The code will be released soon.

# PTQ4WAM 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAM）通过预测动作后果来指导机器人决策。这类模型在行动前往往要比较数百个候选未来（如 V-JEPA 2-AC 用 300M 参数预测器在 RTX 4090 上比较 800 个动作候选、耗时 16 秒），并反复读取必须装入设备内存的权重。
- **痛点一：压缩不等于可部署**。训练后量化（PTQ）能减少权重比特数，但临时张量（如分组重缩放的中间结果、视觉历史的连续化拷贝）仍可能超出 GPU 显存；同时单个 kernel 的速度或权重文件大小无法判断整次调用是否同时满足内存与延迟限制。
- **痛点二：平均重建误差不可靠**。两条候选轨迹的预测终点可能距目标几乎相同，微小的特征误差即可交换二者排序、改变最终动作；而整体平移的较大误差反而可能不改变决策。因此逐层比特分配不能用重建误差来指导。
- **痛点三：任务评估昂贵**。测试一个完整精度分配需要从多个初始状态运行控制器直到终止，每次试验代价高；若把试验浪费在不可行方案上，就挤占了本可用于可行方案的评估预算。
- **核心问题**：在有限的内存、延迟与任务评估预算下，如何联合选择逐层比特分配与 GPU 执行路线，使 WAM 既保持控制性能又可真正部署？

## 2. 方法论

### 2.1 核心思想
把“精度选择”与“执行路线选择”视为一个联合决策问题：先在 GPU 上剖析全模型路线、筛掉不可行方案，再用原始任务得分在可行方案中挑选，避免把昂贵的任务试验花在无法部署的模型上。

### 2.2 设备约束下的精度选择
- **文件大小匹配**：对工作负载 $w$，精度图 $c$ 给每个组件 $i$ 分配 $b_i \in \{4,8\}$ 比特，总文件大小 $S_w(c)=\sum_i \lceil n_i b_i/8\rceil + S^{aux}_w(c)$，需满足硬字节上限 $B_w$（或相对偏差 $\le 10^{-3}$ 的等大小比较）。
- **可行实现集合**：对每个候选对 $(c,r)$（精度图 + 执行路线），测量峰值进程内存 $P_{cr}$ 与整次调用的 p95 延迟 $L_{cr}$，定义 $\mathcal{F}_w=\{(c,r)\in\mathcal{V}_w: P_{cr}\le \bar{P}_w,\ L_{cr}\le \bar{L}_w\}$。对每张图先固定其最快的可行路线再观察任务结果。
- **按任务结果选择**：每个源 $j$ 内的多次执行先取平均 $v(c,r,Z_j)\in[0,1]$，开发集得分为 $\hat{Q}_{dev}(c,r)=100\cdot\frac{1}{n}\sum_j v(c,r,Z_j)$，最终 $(\hat c,\hat r)\in\arg\max_{(c,r)\in E_K}\hat{Q}_{dev}$，并列时依次按延迟、内存、候选顺序打破。

### 2.3 校准引导的候选提出
- **合法图池**：在等大小组件间交换 W4/W8 保持总比特数不变，去重、校验文件大小，所有策略共享同一候选池。
- **可选 LLM 代理**：接收组件形状、层间连接、校准统计、允许格式与存储预算，输出对 W4 数量的约束；由确定性生成器强制执行并校验打包文件，同时要求候选间汉明距离 $d_H(c,c')\ge d_{min}$ 以保持多样性。
- **试验分配**：分阶段评估——所有候选先在同一批初始源上测试，仅较优者进入后续阶段；总访问次数 $N_{eval}=\sum_{s=1}^{S}K_s(n_s-n_{s-1})$，每个新增源仍跑完整规划时域。
- **理论保证**：在源独立同分布、效用有界于 $[0,1]$ 的假设下，有限池选择满足 $q(c^\star)-q(c_T)\le \min\{1, 2\eta_K\}$，$\eta_K=\sqrt{\log(2K/\delta)/(2n)}$；候选收缩另给出覆盖损失 $\rho_A$ 的分解界（Corollary 1）。

### 2.4 低内存执行
- **融合分组重缩放（FGR）**：量化线性层对每个输入通道组 $g$ 形成整数部分积 $p_{ijg}$，在产生处直接乘以激活尺度 $s^a_{ig}$ 与权重尺度 $s^w_{jg}$ 再累加：$y_{ij}=\sum_g s^a_{ig}s^w_{jg}p_{ijg}+\beta_j$，避免把中间张量写回显存再读回；需保证整数部分积不溢出，且需与量化参考做数值校验（浮点加法顺序变化仍可能改变舍入结果）。
- **直接历史读取（DHR）**：把逻辑拼接 $X$ 的第 $p$ 个位置映射回所属分段 $X_j[p-o_{j-1}]$（$o_{j-1}\le p<o_j$），避免连续化拷贝；要求各段不可变、消费者不依赖连续地址、注意力使用全局归一化而非分段归一化。
- **峰值判据**：局部节省不一定降低全局峰值。设改动阶段原分配 $A$、净节省 $d_{save}$、其余阶段最大分配 $C$，则 $\Delta M_{peak}=\max(A,C)-\max(A-d_{save},C)$；更一般地，完整活跃集核算给出 $P-P'=\min_t(g_t+d_t)$（Theorem 2），只有每个事件处净节省都超过原有余量，峰值才真正下降。

## 6. 主要结果与发现

- **精度选择：任务得分比重建误差更可靠**。在相同候选池与评估预算下，以原始任务得分排序的规则总体优于重建误差、Hessian 与对角 Hessian 规则；后三者可能选中“平均误差更小但会交换候选动作排序”的精度图。该结果与论文动机一致：WAM 的控制性能取决于决策边界附近的排序稳定性，而非特征的整体逼近程度。
- **候选提出：结构化候选优于纯随机/固定候选**。Sensitivity、Agent 与 Broad 候选池在有限评估预算下更容易命中较优精度图；其中 LLM 代理的作用主要是缩小 W4 数量约束的搜索空间，最终仍由确定性生成器与文件大小校验保证合法性。候选间最小汉明距离有助于避免评估预算被近似重复方案消耗。
- **搜索策略：分阶段搜索在质量与成本间取得较好折中**。质量优先策略容易把预算花在不可行方案上；约束贝叶斯优化在离散、非平滑的任务得分上优势有限；Pareto-48 覆盖全池但成本高；PTQ4WAM-12 与分阶段搜索先筛可行路线、再逐阶段扩大评估源，在保持选择质量的同时显著降低准备时间（如 Fast-WAM Long 的准备耗时约减半）。
- **执行侧：FGR 与 DHR 分别降低中间张量与历史拷贝开销**。融合分组重缩放避免分组重缩放中间结果写回显存再读回，直接历史读取避免视觉历史连续化拷贝；二者联合时在多个工作负载上降低峰值显存与回放延迟。但论文同时强调，局部节省不必然降低全局峰值，需按完整活跃集核算；只有当每个事件处的净节省都超过原有余量时，峰值才真正下降。
- **端到端：可行性与控制性能需同时满足**。在内存与延迟硬约束下，PTQ4WAM 选出的精度图与执行路线能够在多数工作负载上保持接近全精度的任务得分，同时满足部署约束；而仅按文件大小、单 kernel 速度或平均重建误差选择的方案，存在“看似压缩成功、实际整次调用超限”或“误差更小但控制变差”的风险。
- **分布偏移与跨任务迁移**：论文报告了分布偏移与跨任务迁移专项实验，用于检验所选精度图是否只在开发源上有效。总体结论倾向于：任务得分选择在偏移条件下仍比重建误差规则稳健，但性能差距会随任务与偏移强度变化，不能保证无条件迁移。
- **机制验证**：在 LeWM Wall 上通过匹配噪声、敏感层恢复、随机恢复与精度置换等干预，将“误差大小”与“决策改变”分离。结果支持“微小但位于决策边界附近的误差可能改变动作排序”的解释，也说明单纯压低逐层重建误差并不等价于保持控制性能。

## 7. 局限与需谨慎之处

- **硬件与规模有限**：全部测量基于单张 RTX 4090，未报告多卡、不同 GPU 架构或真实机器人部署结果；峰值内存与延迟结论对其他设备不一定可直接迁移。
- **任务域以模拟器为主**：Fast-WAM、LeWM、DINO-WM 与 V-JEPA 2-AC 的评估覆盖多个基准，但仍以受控模拟任务和记录数据为主，真实世界感知噪声、执行器延迟与安全约束可能改变精度选择结果。
- **量化格式较窄**：逐组件主要在 W4/W8 间选择，未系统覆盖 W3、混合浮点、激活量化或更激进的稀疏化；文件大小匹配也只考虑有限组件与辅助项。
- **任务评估成本仍高**：虽然分阶段搜索降低了准备时间，但完整搜索仍需大量任务反馈；在任务回合长、模拟器慢或真实试验昂贵的场景中，选择成本可能成为实际瓶颈。
- **理论保证依赖假设**：有限池选择的界依赖源独立同分布、效用有界等假设；候选收缩的覆盖损失分解也需要候选池覆盖性质。实际任务源存在相关性，理论界应理解为方向性保证而非精确预测。
- **执行优化的适用条件**：FGR 需保证整数部分积不溢出，并需与量化参考做数值校验；DHR 要求各历史段不可变、消费者不依赖连续地址、注意力使用全局归一化。若模型实现不满足这些条件，优化可能不可用或需改写消费者。
- **峰值判据需完整核算**：局部内存节省不一定转化为全局峰值下降；若缺少完整活跃集与事件级核算，容易高估优化收益。
- **部分实验结论的统计稳健性**：如 Wall 上量化超过 FP32 等观察，可能受有限评估源与任务随机性影响；应结合置信区间与重复实验解读，避免过度泛化。

## 8. 结论与启示

论文的核心贡献不是提出单一量化算法，而是把**逐层比特分配**与**GPU 执行路线选择**统一到“设备约束下的可行集 + 任务得分选择”框架中：先剖析全模型路线并筛除不可行方案，再用原始任务得分在可行方案中挑选，从而避免把昂贵任务试验浪费在不可部署模型上。其方法论启示包括：

1. **压缩指标应与最终决策对齐**：对 WAM 这类“比较候选未来”的模型，平均重建误差不是可靠代理，任务得分或决策排序稳定性更关键。
2. **部署约束要按整次调用核算**：文件大小、单 kernel 速度与局部峰值节省都不足以判断可部署性，需同时测量峰值进程内存与 p95 延迟。
3. **执行优化与精度选择应联合考虑**：FGR、DHR 等低内存执行路线会改变可行集，精度图的最优性依赖于所选路线。
4. **评估预算应分阶段分配**：先在同一批源上粗筛，再让较优候选进入后续阶段，可在有限任务反馈下扩大有效搜索范围。
5. **理论保证与工程校验并重**：有限池选择界提供方向性保证，但数值舍入、溢出、活跃集核算与消费者约束仍需工程级校验。

总体而言，PTQ4WAM 在“可部署的 WAM 后训练量化”问题上给出了较完整的系统化流程与较广泛的实验对照；其主要价值在于揭示了“压缩—执行—任务性能”三者之间的耦合关系，并为后续在更多硬件、更激进量化格式与真实机器人场景中的验证提供了可复用的实验框架。
