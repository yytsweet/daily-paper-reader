## 摘要
量化是缩小大语言模型的标准方法，通常用困惑度和任务准确率来评判。我们提出一个不同的问题：量化之后，模型究竟还能说出哪些词？当一个 token 无法通过任何隐藏状态成为输出层的首选时，它就是沉默的，因此贪心解码器永远无法生成它。我们给出一种简单且可扩展的方法，用来估计量化输出头会使多少 token 沉默，该方法结合三项检查：一个能让 token 胜出的方向（因此它是安全的）、一个上界（刻画 token 对应的行有多接近被其他行困住），以及一个证明 token 永远无法胜出的精确匹配。因此每个计数都是一个可认证区间：精确匹配给出其下界，被标记的 token 只能提高其上界。在我们报告的几乎所有设置中，低至 3 bit 时两端重合，因此计数是精确的。在三个开源模型上，我们发现量化会使 token 沉默：在大词表模型上，8 bit 精度时就已经出现，在 10 亿参数模型上最多涉及数百个此前可达的 token，并且随着精度下降而增加；而小词表模型直到 3 bit 才出现。这种损失在不同语言间远非均匀：在多语言词表上，被沉默的 token 绝大多数是非拉丁文字（韩语、中文、泰语、阿拉伯语和希伯来语），尽管拉丁 token 在词表中占主导。因此，沉默是一种可测量、对语言敏感的副作用，标准平均指标会忽略它，应当与这些指标一并报告。

## Abstract
Quantization is the standard way to shrink large language models, and it is usually judged by perplexity and task accuracy. We ask a different question: after quantization, which words can the model still say at all? A token is silenced when no hidden state can make it the top choice of the output layer, so a greedy decoder can never produce it. We give a simple, scalable way to estimate how many tokens a quantized output head silences, combining three checks: a direction that lets a token win (so it is safe), an upper bound on how close a token's row is to being trapped inside the others, and an exact match that proves a token can never win. Each count is therefore a certified range: exact matches give its lower end and flagged tokens can only raise its upper end. In nearly all settings we report down to 3 bits the two ends coincide, so the counts are exact. Across three open models we find that quantization silences tokens: on large-vocabulary models it already appears at 8-bit precision, up to a few hundred previously reachable tokens on a 1B-parameter model, and grows as precision drops, while a small-vocabulary model resists until 3 bits. The loss is far from uniform across languages: on a multilingual vocabulary the silenced tokens are overwhelmingly non-Latin (Korean, Chinese, Thai, Arabic and Hebrew), even though Latin tokens dominate the vocabulary. Silencing is thus a measurable, language-sensitive side effect that standard averages miss, and it should be reported alongside them.

# 《Estimating Silenced Tokens in Quantized LLMs》论文总结

## 1. 核心问题与研究动机

- **背景**：后训练量化是压缩 LLM 的主流手段，其代价几乎总用“平均值”衡量——困惑度（PPL）差距、benchmark 准确率下降、权重空间误差。
- **被忽略的失效模式**：平均指标对“全有或全无”的失败是盲的。量化后，某些 token 可能**永远无法成为输出层的最高分**，即无论隐藏状态如何都无法胜出，贪心解码器永远无法生成它。作者称之为 **unargmaxable / silenced（被沉默）token**。
- **关键区分**：结构性“沉默”（任何输入都无法输出）不同于“某语料上恰好没出现”，论文全程严格区分二者。
- **现实意义**：量化 checkpoint 使用广泛且随模型增大而增多（Qwen2.5 家族量化下载占比从 8% 升至 20%，GPT-2 近乎为零；约 40% 为会量化输出头的 GGUF）。模型可能在英文 benchmark 上表现健康，却悄悄失去生成某些韩语/泰语 token 的能力。

## 2. 方法论

### 核心思想
- 输出头为矩阵 \(W \in \mathbb{R}^{V\times d}\)，每行 \(w_t\) 对应一个 token，得分为 \(z=Wh\)。
- token \(t\) 可被 argmax 当且仅当存在 \(h\) 使 \(w_t^\top h > w_j^\top h\)（对所有 \(j\neq t\)）；否则被沉默。
- **几何判据**：\(t\) 被沉默 ⇔ 其行 \(w_t\) 落在其他行的**凸包内部**（Grivas et al., 2022）。量化把行映射到共享网格上，可能把边界行推入内部。

### 三重单边检验（输出为可认证区间）
1. **获胜方向（判为安全）**：为绝大多数 token 找到一个使其严格胜出的隐藏状态 \(h\)，存为 winning direction，验证仅需一次矩阵乘法。全程要求**严格不等式**，避免把并列（如数字 token）误判为可达。
2. **困住上界（flagged）**：定义 \(d_t=\max_{\|h\|\le1}\min_{j\neq t}(w_t-w_j)^\top h\)，即 \(w_t\) 到其他行凸包的距离，它控制该 token 能取得的最大 margin。若 \(d_t\le u\)，则任何 \(h\) 下的胜出 margin 不超过 \(u\|h\|\)。此类 token 标为 flagged，计入**上界**（不确定端）。
3. **精确匹配（证明沉默）**：若 \(w_t\) 与其他行（实践中是逐 bit 与某一行）完全重合，则证明其永远无法严格胜出。量化把不同行映射到同一网格点即产生此类碰撞，构成**下界**。

### 计算流程与稳定性
- **两阶段、data-free、纯 GPU 批量矩阵运算**：先评估候选方向，快速解决大部分词表；未解决者做一阶投影近似凸组合以收紧上界，残差收敛到零则测试逐 bit 碰撞。
- 全 152k 词表在某模型/位宽/方案下，**单张消费级 GPU 数分钟到数小时**完成。
- 对退化行簇（如 Qwen2.5-0.5B 约 1400 个近邻距离 \(10^{-5}\)–\(10^{-4}\) 的欠训练行），改报**连续 margin 上界**而非二分类，并与共享的全精度基线做受控差分比较。

## 6. 主要结论与发现

- **沉默出现得早**：Llama-3.2-1B 全精度零沉默，8-bit 各方案即沉默 **160–284** 个 token，随位宽下降增长；Llama-3.1-70B 同样 8-bit 沉默 **221–287** 个（254/287 为保留特殊 token），说明效应不随规模消失。
- **小词表更抗压但终会破**：GPT-2 到 4-bit 仍零沉默，3-bit per-tensor 沉默 **175** 个（全部精确碰撞，其中 **70 个为数字 token**）。
- **沉默是结构化的**：Llama 以保留/欠训练“glitch” token 为主；GPT-2 3-bit 以数字词表为主；Qwen 以非拉丁文字为主。
- **语言严重偏斜**：Qwen 的 3827 个语言相关沉默 token 中仅 **266 个拉丁**，韩语 964、中文 603、泰语 578、希伯来 382、阿拉伯/波斯 370；相对词表规模，Qwen 失去 **27% 韩语、23% 泰语、12% 希伯来语，仅 0.3% 拉丁**。英文中心的 GPT-2/Llama 则主要损失拉丁 token。
- **机制**：欠训练 token 行范数低、彼此靠近、处于凸包内部；Qwen 中沉默 token 行范数中位数 0.31 vs 其余 0.46（Llama 0.55 vs 0.99），低范数几乎完美区分沉默（AUC 0.99/1.00）；GPT-2 例外（AUC 0.63），由数字行网格碰撞驱动。
- **与平均质量解耦**：GPT-2 4-bit 困惑度爆炸却零沉默；Llama/Qwen 8-bit 沉默数百 token 但准确率仍在 3 点内——二者互不预测。
- **实际危害**：GPT-2 3-bit 下 400 篇文档中有 **52 个位置**（含多位数共 120 个）全精度能正确生成数字而量化模型**结构上不可能**生成；但 8-bit 在 3200 万位置上沉默 token 从未是正确下一 token，属**潜在风险**而非立即可见错误。
- **部署建议**：应报告“证明沉默下界 + flagged 上界”的区间及 script 分解；保持输出头高精度可避免新增沉默，但不能挽回全精度已无法输出的 token；多语言部署尤其需要此检查。

## 7. 优点

- **视角新颖**：把量化评估从“平均质量”转向“结构可达性”，提出独立于语料与解码器的可检查属性。
- **方法严谨且廉价**：三重单边检验给出**可认证区间**，严格不等式处理边界，data-free、单卡可跑，适合作为量化后的例行检查。
- **可扩展性强**：验证到 70B 模型与 152k 词表，并覆盖 per-group、GPTQ、AWQ、bitsandbytes 等多种实际方案。
- **语言分解有洞察力**：揭示平均指标完全掩盖的 script 级不均衡，对多语言部署有直接实践价值。
- **诚实的实验报告**：明确区分“证明沉默”与“flagged”，标注退化簇的不稳定性，并区分结构性沉默与语料级观测。

## 8. 不足与局限

- **部分计数不精确**：2-bit 坍缩头、Qwen 全精度欠训练簇、Qwen2.5-7B 的 GPTQ 头中仍有 flagged token，无法给出精确值。
- **仅保证贪心解码**：沉默 token 仍保有非零概率，采样解码下仍可能被生成；结论不覆盖采样场景。
- **仅分析输出头**：对“token 能否胜出”是精确的，但对“完整网络在真实输入上是否实现”只是上界；且不同部署流程是否量化输出头差异很大。
- **量化器覆盖有限**：GPTQ/AWQ 仅 4 个模型，SmoothQuant、QuaRot、SpinQuant 等未测。
- **多语言证据单一**：仅基于 Qwen 一个多语言词表（三个规模共享），结论需在其他多语言头上确认；Unicode script 到语言只是代理，存在跨语言共享文字（如汉字）的偏差风险。
- **任务影响证据有限**：仅语料检查与 0.5B 模型上的 Belebele，缺乏完整下游评测；Belebele 结果显示准确率变化并不随沉默数变化，说明危害具有条件性。
- **退化簇二分类本质不稳定**：近重复行场景下 safe/flagged 判定受舍入尺度影响，只能报告 margin 上界。
