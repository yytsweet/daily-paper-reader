# Estimating Silenced Tokens in Quantized LLMs 

Giuseppe Pappalardo 

University of Enna “Kore”, Italy 

giuseppe.pappalardo@unikore.it 

Abstract 

Quantization is the standard way to shrink large language models, and it is usually judged by perplexity and task accuracy. We ask a different question: after quantization, which words can the model still say at all? A token is silenced 

when no hidden state can make it the top choice of the output layer, so a greedy decoder can never produce it. We give a simple, scalable way to estimate how many tokens a quantized output head silences, combining three checks: a direction that lets a token win (so it is safe), an upper bound on how close a token’s row is to being trapped inside the others, and an ex-act match that proves a token can never win. Each count is therefore a certified range: exact matches give its lower end and flagged tokens can only raise its upper end. In nearly all set-tings we report down to 3 bits the two ends coincide, so the counts are exact. Across three open models we find that quantization silences tokens: on large-vocabulary models it already appears at 8-bit precision—up to a few hundred previously reachable tokens on a 1B-parameter model—and grows as precision drops, while a small-vocabulary model resists until 3 bits. The loss is far from uniform across languages: on a multilingual vocabulary the silenced tokens are overwhelmingly non-Latin (Korean, Chinese, Thai, Arabic and Hebrew), even though Latin tokens dominate the vocabulary. Silencing is thus a measurable, language-sensitive side ef-fect that standard averages miss, and it should be reported alongside them. 1

1 Introduction 

Post-training quantization is the default way to fit a large language model (LLM) into a tight memory and latency budget (Gholami et al., 2021). Its cost is almost always summarized by an average : a perplexity gap, a drop in benchmark accuracy, or a weight-space error. These averages, however, are

blind to an all-or-nothing failure: after quantization some tokens simply can no longer be said. No matter what the network computes, they never win the output layer, so a greedy decoder can never emit them. We call such tokens unargmaxable (Grivas et al., 2022), or silenced .Whether a token can win the output layer de-pends only on the geometry of the output head— the final weight matrix that turns a hidden state into one score per token. Quantization changes that ma-trix, and with it the set of tokens that can still win. Our goal is to estimate how large the silenced set becomes, and which tokens fall into it. Silencing is a structural property: a silenced token cannot be output for any input. This differs from a token that simply does not appear in the output on a given corpus, which can happen for many reasons; we keep the two notions separate throughout. Measuring this exactly over a full vocabulary is expensive, so we estimate it with cheap, one-sided checks (Section 3): a token is declared safe as soon as we find a hidden state that makes it win; a token is flagged when its row is provably close to being trapped inside the others; and it is proven silenced when its row exactly coincides with a combination of the rest. This yields bounds: tokens proven si-lenced by exact collision give the lower bound, and flagged tokens can only add to the upper bound. Down to 3 bits almost every silenced token is an exact collision, so the two bounds essentially coin-cide. The flagged tokens that remain sit in degener-ate clusters of under-trained rows or in collapsed 2-bit heads, where resolving them exactly would cost much more computation for little insight. We apply the method to three open models— GPT-2, Llama-3.2-1B and Qwen2.5-0.5B—under standard round-to-nearest (RTN) quantization. Our findings are: • Silencing appears early. Intuitively, if a row is surrounded by the others, every direction that raises its score raises some competitor’s score at least as much (Figure 1). This is the structural counterpart of the “stolen probability” effect, where rare tokens are crowded out of the probability simplex (Demeter et al., 2020), and it is tied to the low-rank softmax bot-tleneck (Yang et al., 2018) that also lets one re-cover hidden geometry through an API (Finlayson et al., 2024). Prior work studies this geometry in full-precision models (Grivas et al., 2022; Deme-ter et al., 2020; Yang et al., 2018). We ask how quantization reshapes it. Because argmaxability depends on W alone, analysing the head in isolation is exact for this question: a token that no hidden state can push to a win is unreachable for any input the rest of the network could produce. The converse does not hold: a token we call safe has a hidden state that makes it win, but the model may never produce that hidden state for any real input. So a safe token is not guaranteed to be reachable in practice, while a silenced token is unreachable for sure under greedy decoding. Our silenced counts are therefore con-servative: the true number of tokens the model can never output can only be larger. 

3 Estimating the silenced set 

Enumerating the silenced tokens exactly means solving one geometry problem per token over a vo-cabulary of tens or hundreds of thousands of rows, which does not scale. We instead estimate the set with three one-sided checks that are computation-ally lightweight on a single consumer-grade GPU, each carrying explicit geometric semantics. 

A winning direction (safe). For the vast majority of tokens, we identify a hidden state h that makes the token the strict winner of the output layer. We store this state as a winning direction : verifying its validity requires only a single matrix multipli-cation, a direct numerical check that the token is not silenced. We require strict inequalities through-out our checks; accepting ties would incorrectly classify boundary cases, such as digit tokens, as reachable. As an example, consider two tokens with the same row, wa = wb = (1 , 0) . Every hid-den state gives them the same score, so neither can ever be the unique top choice: they can only tie for it. With non-strict inequalities both would count as reachable; with strict ones both are silenced. A decoder that breaks ties by token index could still emit the lower-index one, but that outcome is fixed by the tie rule, not by the model, so we count both as silenced. Quantization creates exactly this case for GPT-2’s digit rows at 3 bits. In our counts such ties concern at most one token per group of identical rows: at most 42 of the 175 tokens GPT-2 silences at 3 bits, 33 of Llama’s 264 and 5 of Qwen’s 834 at 8 bits.

An exact match (proven silenced). In the strongest case the token’s row coincides exactly with a combination of the others—in practice, bit-for-bit with a single other row. Then the token is provably silenced: no strict win exists. Quanti-zation creates such exact collisions when it maps distinct rows onto the same grid point. The output is therefore a range: a lower end from tokens proven silenced by exact collision, and an upper end that also includes flagged tokens whose status is not certain. We report both, which is why we speak of estimating the silenced set rather than counting it. 

Computational pipeline and scalability. Our estimation framework operates as a data-free, two-stage pipeline executed entirely via batched GPU matrix operations on the stored weight matrix. In the first stage, we evaluate a curated set of candi-date directions; identifying a strictly positive mar-gin immediately classifies the token as safe, rapidly resolving most of the vocabulary. For unresolved tokens, we run a first-order projection to approxi-mate wt as a convex combination of surrounding rows, thereby tightening the upper bound on dt. If the residual converges to zero, we test for a bit-for-bit exact collision. Because the computational footprint is dominated by standard matrix multi-plications, evaluating a full 152 k-token vocabulary across a specific model, bit-width, and quantization scheme completes in minutes to a couple of hours on a single consumer GPU. Code and per-token measures are available at https://github. com/gpappalardo/EACL2027Paper .

Stability on degenerate row clusters. Because our geometric checks evaluate static weight ma-trices directly, a binary classification into safe or flagged tokens can become ill-conditioned when rows are densely clustered. For example, Qwen2.5-0.5B contains a degenerate cluster of roughly 1,400 

under-trained rows with nearest-neighbour dis-tances of 10 −5 to 10 −4. At such scales, a stan-dard rounding step is comparable to the inter-row separation, making binary reachability classifica-tions intrinsically unstable under quantization. To address these dense regimes, we report the continu-ous margin bounds from Eq. (1) rather than binary classifications, and we consistently evaluate quan-tized heads against a shared full-precision baseline to ensure a controlled differential comparison. 

4 Setup 

Models. We study GPT-2 (124M, 50k vocab-ulary), Llama-3.2-1B (128k vocabulary) and Qwen2.5-0.5B (152k multilingual vocabulary), spanning small vs. large and English-centric vs. multilingual vocabularies. To check whether the re-sults hold across model size, we also use Qwen2.5-1.5B and Qwen2.5-7B, which share Qwen2.5-0.5B’s vocabulary, and Llama-3.1-70B, which shares Llama-3.2-1B’s (Sections 5 and 6). 

Quantization. We use round-to-nearest (RTN) fake quantization of all linear weights (attention and MLP projections and the output head; embed-dings, normalization and biases are left in full preci-sion), at {8, 4, 3, 2} bits, symmetric or asymmetric, per-tensor or per-channel. RTN is the simplest and most widely used scheme and is a clean stress test; stronger quantizers (Frantar et al., 2023; Lin et al., 2024; Dettmers et al., 2022, 2023) start from the same rounding step. 

What we measure. For every model, scheme and bitwidth we run the estimator of Section 3 on the output head and count the tokens that become silenced relative to full precision. We treat symmet-ric per-channel RTN as the controlled stress test (a single scale per row), asymmetric per-channel as the closer proxy for realistic deployment, and we report per-tensor variants as well because they be-have differently: a shared per-tensor scale rounds every row against the same grid, which can either protect or expose tokens depending on how the rows are distributed. For reference we also record perplexity (WikiText-2) and ARC-Easy accuracy so that silencing can be read next to standard qual-ity numbers. 

5 Quantization silences tokens 

Figure 2 shows, for each model, how many tokens become silenced relative to full precision as preci-sion drops. Two regimes stand out. 

Large vocabularies silence tokens already at 8 bits. Llama-3.2-1B is the cleanest case: in full precision its head silences no token, yet every 8-bit scheme silences between 160 and 284 tokens, rising through 4 bits and below. The effect does not fade with scale: Llama-3.1-70B, which shares Llama-3.2-1B’s vocabulary, also silences no token in full precision and 221–287 tokens at 8 bits, all exact collisions and again mostly reserved special tokens (254 of 287). Qwen2.5-0.5B, whose full-precision head already has a large cluster of near-duplicate under-trained rows, silences a further 830 to 834 tokens at 8 bits. The effect is present be-fore any visible quality loss: at 8 bits both models stay within three accuracy points of full precision (Table 3). 

Small vocabularies resist longer, then break. 

GPT-2 silences no token down to 4 bits, then at 3-bit per-tensor silences 175 tokens, all proven si-lenced by exact collision: the 3-bit grid maps their rows onto identical vectors. Crucially, 70 of them are numeric tokens (single digits, years, round num-bers). 

Which tokens fall silent. The silenced sets are structured (Figure 3). On Llama they are domi-nated by reserved special tokens and known under-trained “glitch” tokens; on GPT-2 at 3 bits by the numeric vocabulary; on Qwen by non-Latin-script tokens. The composition matters for whether si-lencing does any harm: losing a deep-tail reserved token is harmless, losing digits is not. 

Group-wise scaling does not prevent silencing. 

It is natural to ask whether increasing scale gran-ularity avoids structural silencing. Our measure-ments show it does not: repeating the sweep with per-group scales along the rows (groups of 32 and 128, the granularity of popular k-quant formats) leaves the pattern essentially unchanged—at 4 bits with groups of 32, Llama-3.2-1B still silences 258 –

289 tokens (versus 290 for plain per-channel) and Qwen2.5-0.5B reaches 2232 –2234 in total (versus 

2236 –2238 ). Silencing is a property of rounding rows onto a shared grid, not an artifact of coarse scaling. 

Calibrated quantizers. We repeated the mea-surement with GPTQ (Frantar et al., 2023) and AWQ (Lin et al., 2024) on Llama-3.2-1B and Qwen2.5-0.5B, 1.5B and 7B. AWQ keeps the out-put head in 16 bits and introduces no new silenced token relative to full precision. Against an fp16 copy of the head, Qwen2.5-0.5B shows 75 new silenced tokens, but all 75 come from the cast to fp16, not from AWQ quantization itself. GPTQ, as implemented in GPTQModel, quantizes the head to 8 bits with groups of 32 by default. With this head Qwen2.5-0.5B silences 180 new tokens (134 when the rest of the model is at 4 bits), all exact collisions, while Llama-3.2-1B and Qwen2.5-1.5B silence none. When the head is quantized to 4, 3 or 2 bits, GPTQ silences 91, 135 and 259 new tokens on Llama-3.2-1B and 796, 817 and 834 on Qwen2.5-0.5B, again all exact collisions. On Qwen2.5-7B, GPTQ applied to the head alone si-lences 281–285 new tokens, flagged rather than proven. Calibration thus reduces silencing at the default 8-bit head, but does not prevent it once the head is quantized to fewer bits. 

A note on deployment quantizers. Production kernels such as 8-bit and NF4 (Dettmers et al., 2022, 2023) often leave the output head in higher precision, so they do not silence tokens struc-turally. They can still change decisions: on a 500-document corpus (WikiText-103), bitsandbytes 4-bit quantization (its default FP4 format) flips 29 .4% 

of Qwen2.5-0.5B’s greedy choices, and 1842 to-ken types reached in half precision (fp16) are not reached under it ( 1793 of them Latin). This is a corpus-level observation, not structural silencing, and we keep the two notions separate throughout: our counts concern what the head can ever produce, not what it happens to produce on a given corpus. 

Silencing is a separate axis from average quality. 

Table 3 shows that the two do not move together. GPT-2 at 4 bits silences no token yet its perplex-ity has already exploded by orders of magnitude: average quality can collapse with the reachable vocabulary fully intact. Conversely, Llama and Qwen at 8 bits silence hundreds of tokens while staying within three accuracy points and a few perplexity points of full precision: the vocabulary shrinks before any average moves much. Neither number predicts the other, so silencing is not a re-statement of perplexity—it is an independent prop-erty that a quality average can hide in both direc-tions. The same holds language by language. We measured accuracy on Belebele (Bandarkar et al., 2024), a reading-comprehension benchmark, in ten languages for Qwen2.5-0.5B with its head quan-tized to 8 bits. Although this head silences 550 of the 2550 Thai tokens, Thai accuracy does not drop (32.1% in full precision, 35.3% quantized; Ta-ble 2), and in no language does the change follow the number of silenced tokens.

Why non-Latin tokens. The pattern has a nat-ural explanation: under-trained tokens (Land and Bartolo, 2024). A multilingual tokenizer spends most of its vocabulary on the dominant script (here Latin), while tokens that are rare in training keep short rows that sit very close together, near the in-terior of the hull. In Qwen’s full-precision head about 1400 such rows already form a tight clus-ter. At 8 bits, rounding merges the rows next to that cluster with it: every token newly silenced by Qwen2.5-0.5B at 8 bits has a row of norm about 

0.30 , the same as the cluster, and ends up identi-cal to cluster rows. These under-trained tokens are not spread evenly across scripts. Over the whole vocabulary, the median row norm is 0.30 for Thai against 0.46 overall, while Korean ( 0.42 ), Hebrew (0.40 ), Arabic ( 0.45 ) and Chinese ( 0.47 ) are close to the global value. Thai is therefore under-trained as a whole, whereas in the other scripts only a tail of tokens is. Relative to vocabulary size the loss is still large: across all configurations Qwen loses

GPT-2 is the instructive exception (AUC 0.63 ): there silencing is driven not by rarity but by the exact grid colli-sions of the digit rows at 3 bits. 

7 When does it matter? 

Silencing a deep-tail reserved token that no input ever needs is harmless; silencing a token the model must produce is not. The clearest harmful case is GPT-2 at 3 bits. There, digit rows collide exactly, so the digits are proven silenced. On 400 WikiText-103 documents we find 52 positions where the full-precision model greedily decodes the correct digit (120 including multi-digit numeric tokens such as years) but the quantized model cannot produce it at all—the outcome is impossible by construction, before any other degradation is considered. This shows that silencing is not a purely theo-retical curiosity: when it lands on task-relevant to-kens, it removes correct outputs outright. Whether it matters therefore depends on which tokens are silenced—exactly the composition that Figures 3 and 4 make visible.

8 Related work 

Output-layer geometry. Unargmaxable tokens were introduced by Grivas et al. (2022) as a prop-erty of trained output heads: rows inside the convex hull of the others can never win the argmax. Quantization. Weight-only post-training quanti-zation ranges from error-correcting and activation-aware rounding (Frantar et al., 2023; Lin et al., 2024) to calibrated schemes (Shao et al., 2024) and equivalence-preserving transforms such as smooth-ing and learned rotations (Xiao et al., 2023; Ashk-boos et al., 2024; Liu et al., 2025). All of them op-timize average reconstruction error or downstream loss; none targets reachability, and the rounding step they share is precisely what silences tokens. Deployment kernels (Dettmers et al., 2022, 2023) often leave the head in higher precision and so avoid structural silencing, at the cost of a larger model. 

Fidelity and reachability. Token-level fidelity metrics compare the outputs of a quantized and a full-precision model (Nikoli´ c et al., 2026), and lexical-reachability scores ask which words a de-coder can produce under a given sampling filter (Awad et al., 2026). Both are complementary to our question: the former compares distributions on a corpus and the latter concerns the decoding procedure, whereas we characterize, independently of any corpus or decoder, which tokens the model 

could ever produce. To our knowledge this struc-tural, language-resolved view of quantization is new. 

9 Discussion 

Our findings yield three practical implications. First, silencing is cheap to measure : the estima-tor runs on the output head alone, in minutes to hours on a single GPU, and needs no data. It can be run as a routine check whenever a model is quantized, next to the usual perplexity pass. Sec-ond, the right thing to report is not a single number but a range with a script breakdown : the proven-silenced count (exact collisions) as a lower end, that count plus the flagged tokens as an upper end, and the per-language composition that tells a prac-titioner whether the loss lands on tokens they care about. Third, our stress test uses plain RTN, but the mechanism—rounding rows onto a shared grid until marginal ones fall inside the hull—is generic; stronger quantizers change how quickly it happens, not whether it can. Quantizing a model to 8 bits is often assumed to be lossless. For practitioners, the main point is to check the precision of the model’s output head. Quantizing the head to 8 bits already silences hun-dreds of tokens on large-vocabulary models: re-served tokens on Llama, mostly non-Latin tokens on Qwen. Whether this happens depends on the deployment format: bitsandbytes and the public GPTQ checkpoints we inspected keep the head in 16 bits, whereas llama.cpp’s GGUF formats quan-tize it (for example to Q6_K). Keeping the head in higher precision prevents new silencing, but not the loss of tokens that a full-precision head already cannot emit. The clearest recommendation is for multilingual deployment. A 4-bit model that keeps its English scores can still have silenced a meaningful slice of a low-resource script, and no English-only evaluation will reveal it. A script-level silenced-token count is a small, direct safeguard against deploying a model that has quietly lost the ability to generate text in some of the languages it was trained to serve. 

10 Conclusion 

Quantization can make tokens impossible to pro-duce. We gave a simple, scalable way to estimate how many tokens a quantized output head silences, with a clear meaning for each classification, and showed that silencing appears already at 8 bits on large-vocabulary models and falls disproportion-ately on non-Latin scripts. Because a single per-plexity or accuracy number hides this, we argue that silenced-token counts—and especially their language breakdown—should be reported along-side standard metrics when quantizing multilingual models. 

Limitations 

Our classifications are relative to the stored weight matrix; on clusters of near-duplicate rows the flagged/safe classification is intrinsically unstable, and we report margin bounds rather than a binary answer there. The guarantee concerns greedy de-coding: a silenced token keeps a nonzero probabil-ity and can still be emitted under sampling. The analysis is of the output head alone: it is exact for whether a token can win, but it is an upper bound on what the full network actually realizes on real inputs, and deployment pipelines differ in whether they quantize the head at all. Besides RTN, we test GPTQ and AWQ on four models only; smooth-ing, rotation-based and other quantizers (Xiao et al., 2023; Ashkboos et al., 2024; Liu et al., 2025; Zhang et al., 2024) remain untested. The mapping from Unicode script to language is a proxy, not a lan-guage identifier, and our multilingual evidence rests on a single multilingual vocabulary, shared by the three Qwen2.5 models; the pattern remains to be confirmed on other multilingual heads. Not every count is exact: flagged tokens remain in collapsed 2-bit heads, in Qwen’s full-precision cluster and in the GPTQ head of Qwen2.5-7B. Finally, our evi-dence on task impact is limited to corpus checks and to Belebele on a 0.5B model; a full downstream evaluation is left to future work.
