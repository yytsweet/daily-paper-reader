## 摘要
实时机载机器人控制需要轻量级视觉-语言-动作（VLA）模型，但缩小骨干网络会降低推理时的深思能力。思维链解码、双系统架构和更大的骨干网络可以恢复这种推理能力，但会重新引入促使模型小型化的延迟和内存开销。循环动作头通过在潜在空间中迭代后再输出动作，提供了一种更轻量的替代方案，但现有设计仅细化一个未分化的单一状态，该状态必须同时编码缓慢演变的任务上下文和快速变化的电机指令。我们提出分层推理动作头（HR-AH），它维护两个以不同频率更新的潜在状态：一个快速更新的低层状态，以动作 token 和本体感觉为基础；以及一个缓慢更新的高层状态，以视觉理解和由指令信息引导的低层状态为基础。两个状态通过嵌套推理循环交换信息。由于所有迭代都在单次骨干网络前向传播后于紧凑动作头内进行，HR-AH 在不增加骨干网络规模的情况下增加了分层推理。在相同骨干网络上，HR-AH 的动作头具有 2250 万参数，比 RD-VLA 和 VLA-Adapter 的动作头小 3–4.3 倍；其在 LIBERO 上达到 97.0% 的成功率，在 CALVIN ABC→D 上达到 4.40 的平均链长，并在对比方法中具有最低延迟。我们表明，这种分层结构相比参数匹配的单状态动作头提升了性能，并且将不同模态路由到各自层级可进一步提升准确率并降低推理成本。

## Abstract
Real-time onboard robot control calls for a lightweight vision-language-action (VLA) model, yet shrinking the backbone leaves less capacity for deliberation at inference time. Chain-of-thought decoding, dual-system architectures, and larger backbones can restore deliberation but reintroduce the latency and memory costs that motivated going small. Recurrent action heads offer a lighter alternative by iterating in latent space before committing to an action, but existing designs refine a single undifferentiated state that must simultaneously encode slowly evolving task context and rapidly changing motor commands. We propose the Hierarchical Reasoning Action Head (HR-AH), which maintains two latent states updated at different frequencies: a low-level state that updates fast, grounded in action tokens and proprioception, and a high-level state that updates slowly, grounded in visual understanding and the instruction-informed low-level state. The two states exchange information through nested reasoning cycles. Because all iteration occurs in the compact head after a single backbone pass, HR-AH adds hierarchical reasoning without increasing the backbone size. With a 22.5M-parameter head, 3-4.3x smaller than those of RD-VLA and VLA-Adapter on the same backbone, HR-AH reaches 97.0% success rate on LIBERO and a 4.40 average chain length on CALVIN ABC->D, at the lowest latency among compared methods. We show that this hierarchy improves performance over a parameter-matched single-state head, and that routing distinct modalities to each level yields further gains in both accuracy and inference cost.

## 1. 核心问题与研究动机

- **背景**：机载实时机器人控制要求 VLA 模型轻量化，因此需要把视觉-语言骨干（backbone）压缩到很小（如 0.5B 级）。但缩小骨干会显著削弱推理时的“深思”（deliberation）能力。
- **现有补救方案的代价**：
  - 思维链（CoT）解码（3–8.5B 参数）、双系统架构（把模态分给两个大 VLM 子系统）、更大骨干，都能恢复推理能力，但重新引入促使模型小型化的延迟与内存开销。
  - 循环动作头（recurrent action head）在潜在空间中迭代后再输出动作，是更轻量的替代方案。
- **关键缺口**：现有循环头（如 RD-VLA）只细化**单一、未分化的潜在状态**，该状态必须同时编码“缓慢演变的任务上下文”和“快速变化的电机指令”，相当于“以伺服频率运行任务规划器”，二者时间尺度冲突。
- **核心研究问题**：能否在**不增加骨干计算负担**的前提下，显式分离这两种过程，从而同时提升循环计算的有效性与效率？
- **整体含义**：论文提出分层推理动作头（HR-AH），把分层结构完全放入单次骨干前向之后的紧凑动作头内部，为微型 VLA 提供低成本的结构化推理路径。

## 2. 方法论

### 2.1 核心思想
- 将潜在状态拆为两个以不同频率更新的分量：
  - **低层动作状态** \(z_L \in \mathbb{R}^{N_{act}\times D}\)：快速更新，以动作 token 与本体感觉（proprioception）为基础，表示演化中的电机指令。
  - **高层规划状态** \(z_H \in \mathbb{R}^{N_{plan}\times D}\)：慢速更新，以视觉 token 与“经指令条件化的 \(z_L\)”为基础，编码任务相关视觉上下文。
- 该路由是有意为之：动作 token 紧凑且已含指令信息，适合高频接地；视觉 token 数量大、变化慢，放到慢速路径可把昂贵视觉注意力成本**摊销**到多次快速执行器更新上。

### 2.2 特征提取
- 骨干只前向一次，从深层（倒数第二层）取视觉 token \(h_{viz}\) 与动作查询 token \(h_a\)；语言 token 不直接取出（因果 VLA 中动作查询已关注前置语言 token）。
- 额外从**嵌入层**取视觉特征 \(h^{emb}_{viz}\)，经学习到的 sigmoid 门控 \(\sigma(g)\odot F^{(0)}\) 注入，门控初值接近 0，使模型从深层特征起步、逐步学习引入浅层细粒度空间信息。
- 本体感觉 \(p\) 经线性层投影到维度 \(D\)。

### 2.3 统一桥接注意力块（UBAttn）
- 将 VLA-Adapter 的 Bridge Attention 推广到任意上下文集合：把查询源 \(X\) 与上下文 \(C_1..C_m\) 拼接为一个序列，做**单次 softmax** 联合注意力；加入 RoPE 编码拼接序列内的 token 顺序；去掉视觉注意力分数上的可学习门控，使模块**与输入来源无关**。
- 因此同一套块定义可分别充当执行器 \(f_L\)、规划器 \(f_H\)、精炼模块 \(f_R\)，只是上下文输入不同；块内为 RMSNorm 预归一化 + SwiGLU FFN 的残差结构。

### 2.4 三个模块与嵌套循环（算法流程）
- **低层执行器**：\(z'_L = f_L(z_L, \{h_a, p\})\)，每步都接地于动作 token 与本体感觉。
- **高层规划器**：\(z'_H = f_H(z_H, \{h_{viz}, h^{emb}_{viz}, z'_L\})\)，慢速运行，集中全部视觉注意力，并由 \(z'_L\) 引导关注与当前电机指令相关的特征。
- **自顶向下精炼**：\(z''_L = f_R(z'_L, \{z'_H\})\)，把更新后的规划显式注入低层状态，闭合双向回路。
- **段与循环结构**：整体分 \(S\) 个段（segment），每段含 \(K_H\) 个分层推理循环；每个循环先做 \(K_L\) 次低层执行器迭代，再做 1 次高层规划器更新，最后做 1 次精炼；每段结束对两状态施加 RMSNorm 稳定幅度。
- **输出**：最终低层状态经 RMSNorm 与线性投影得到动作块 \(\hat{A} \in \mathbb{R}^{N_{act}\times 7}\)（末端平移、轴角旋转增量与夹爪状态）。

### 2.5 训练与推理技巧
- **单步梯度近似**（借自 HRM）：每段内只有最后一个推理循环可微，之前循环全部 detach，避免缓存所有中间激活；段间也 detach。
- **深度监督**：每段都产生动作预测，对真值动作块施加 \(\ell_1\) 损失，按段索引线性加权；训练时展开固定 \(S_{total}=8\) 段。
- **免训练自适应停止**：每段后计算相邻预测的相对变化 \(\delta_s = \|\hat{A}_s-\hat{A}_{s-1}\|_\infty/(\|\hat{A}_s\|_\infty+\epsilon)\)，当 \(\delta_s<\tau\) 连续 \(P\) 次即停止，受最小段数 \(S_{min}\) 与最大段数 \(S_{max}\) 约束，使推理深度随任务难度变化。

### 2.6 关键超参
- \(D=896\)、\(N_{act}=8\)、\(N_q=64\)、\(N_{plan}=32\)、\(N_{viz}=512\)、\(K_L=2\)、\(K_H=1\)、\(S_{total}=8\)；推理时 \(S_{min}=2\)、\(S_{max}=8\)、\(\tau=0.01\)、\(P=1\)。

## 6. 主要结论与发现

- **性能**：22.5M 参数动作头在 **LIBERO 平均 97.0%**（Spatial 98.0、Object 99.6、Goal 97.4、Long 93.0），为对比方法中最高；**CALVIN ABC→D 平均链长 4.40**，与 VLA-Adapter 持平，显著优于 RD-VLA（3.39）与 OpenVLA（3.27），5 任务链成功率 74.0% vs RD-VLA 45.3%。
- **效率**：动作头比 VLA-Adapter（97M）小约 4 倍、比 RD-VLA（72.3M）小约 3 倍；在对比方法中**延迟最低**（49.63 ms/块）。
- **真实机器人**：平均成功率 78.8% vs RD-VLA 66.3%，且任务执行更快。
- **消融结论**：
  - 引入第二个循环状态（即使输入相同）带来 **+9.4 个百分点**，平均推理段数从 7.44 降到 5.71——**分层状态分离

本身即是主要增益来源**：即便两个循环状态接收相同输入，只要保留“快更新/慢更新”两种时间尺度，模型就能把任务上下文维持与电机指令细化解耦，从而减少无效循环并提升成功率。进一步加入模态路由（视觉 token 进入慢速规划路径，动作 token 与本体感觉进入快速执行路径）后，性能继续提升，说明“时间尺度分离”和“输入分工”是互补的；而去掉学习到的状态初始化会带来明显退化，表明可学习的初始潜在状态对冷启动和少样本真实任务较为关键。

- **推理效率结论**：固定段数越多并非总是越好；自适应停止在较严格阈值下能用更少平均段数达到接近甚至优于固定 8 段的精度，说明“按任务难度分配推理深度”有效。延迟–精度权衡图中，HR-AH 位于较优的帕累托前沿：在相近或更低延迟下取得更高成功率，优于 CoT 类大模型和同骨干循环基线。
- **定性观察**：随着推理段推进，规划状态对任务相关视觉区域的注意力趋于锐化，低层动作状态则更快收敛到稳定动作块；真实机器人 rollout 中，HR-AH 的任务完成速度优于 RD-VLA，说明分层循环不仅提升成功率，也改善了执行节律。

## 7. 局限性与可改进方向

- **真实实验统计强度有限**：每任务仅 20 条示教、20 次 rollout，未报告多次随机种子、置信区间或显著性检验，真实场景结论应视为初步证据。
- **效率比较的公平性需补充**：延迟数据未完整交代测量硬件、批处理大小、是否含骨干前向与通信开销；跨方法延迟对比的严格可比性有限。
- **超参敏感性覆盖不足**：主要报告了停止阈值 \(\tau\) 的两档设置，对 \(K_L\)、\(K_H\)、段数 \(S\)、规划 token 数 \(N_{plan}\)、状态维度等缺少系统扫描，实际部署时调参成本不明确。
- **路由与更新频率为手工设计**：快/慢路径的输入分配和更新次数是固定结构，未验证学习式路由、可学习更新频率或动态段长是否更优。
- **验证范围较窄**：骨干仅覆盖 0.5B 级 MiniVLA，任务以桌面操作和 LIBERO/CALVIN 为主；对更长程、多物体、移动操作或更高自由度场景的泛化性尚不清楚。
- **训练近似的影响**：单步梯度近似降低了显存与计算开销，但可能限制深层循环的信用分配；其与完整反传之间的性能差距未充分量化。

**可改进方向**：引入可学习的快慢调度或门控路由；在更多骨干规模与真实任务上验证；报告多种子均值与方差；统一延迟测量协议；分析循环深度、状态维度与停止策略的敏感性；探索将分层动作头与更大规模预训练或在线自适应结合。

## 8. 总体评价与启发

- **核心贡献**：论文把“分层推理”从骨干级或双系统级下沉到轻量动作头内部，在不增加骨干前向次数的前提下，用快/慢双状态和嵌套循环实现结构化 deliberation，兼顾了微型 VLA 的精度与实时性。
- **方法启发性**：将“规划—执行”的时间尺度冲突显式建模为状态分离与路由问题，并用统一桥接注意力块复用模块，设计简洁、参数效率高；自适应停止使推理成本随任务难度变化，符合机器人部署的实际需求。
- **实验说服力**：仿真基准、消融和真实机器人形成较完整的证据链，尤其是参数匹配与同输入双状态消融较好隔离了分层与路由的贡献；但真实实验规模、延迟测量规范和超参敏感性仍需加强。
- **适用边界**：当前证据支持 HR-AH 在 0.5B 级 VLA 与桌面操作任务上的有效性；对更大骨干、更复杂长程任务和跨 embodiment 的收益仍需进一步验证。
- **实践意义**：对于机载/边缘端实时机器人控制，HR-AH 提供了一条“不换大骨干、只改动作头”的低成本升级路径，具有较高的工程参考价值。
