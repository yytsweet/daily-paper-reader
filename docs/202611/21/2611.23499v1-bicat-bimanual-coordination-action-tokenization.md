## 摘要
自回归视觉-语言-动作（VLA）模型利用其视觉-语言主干的下一标记预测目标来预测离散动作标记，因此动作标记器定义了策略与机器人之间的接口。在双臂操作中，两条手臂共享一套运动库，但通过互补角色进行协调，因此动作表示应同时刻画这两个方面。然而，大多数现有标记器将双臂编码为单个拼接的动作向量，其中两臂共有的运动模式未被共享，跨臂依赖关系仍纠缠在每个标记内部。因此，策略必须隐式地学习这两个方面。我们提出双臂协调动作标记化（BiCAT），它在双臂间共享一个运动表示，同时通过对称跨臂注意力和联合解码器，使每条手臂的标记以另一条手臂为条件。随后，策略并行预测每条手臂的所有标记，先生成左臂，再以左臂为条件生成右臂。在十个 RoboTwin 2.0 任务和三种机器人本体上的六个真实世界任务中，BiCAT 在所比较的标记器中取得了最高成功率。在仿真中，相较于八个基线中最强的一个，它将平均成功率提高了 17.6 个百分点，在需要双臂紧密协调的任务上提升最大，同时每个动作块仅需 40.5 ms。这些结果表明，动作标记器是建模双臂协调的自然切入点。

## Abstract
Autoregressive vision-language-action (VLA) models predict discrete action tokens with the next-token objective of their vision-language backbone, so the action tokenizer defines the interface between the policy and the robot. In bimanual manipulation, the two arms share a repertoire of movements yet coordinate through complementary roles, and an action representation should capture both. However, most existing tokenizers encode both arms as a single concatenated action vector, in which motion patterns common to the two arms are not shared and cross-arm dependencies remain entangled within each token. The policy must therefore learn both aspects implicitly. We propose Bimanual Coordination Action Tokenization (BiCAT), which shares one motion representation across arms while conditioning each arm's tokens on its partner through symmetric cross-arm attention and a joint decoder. The policy then predicts all tokens of each arm in parallel, generating the left arm first and the right arm conditioned on it. Across ten RoboTwin 2.0 tasks and six real-world tasks on three embodiments, BiCAT achieves the highest success among the compared tokenizers. In simulation, it improves mean success by 17.6 percentage points over the strongest of eight baselines, with the largest gains on tasks that require close coordination between the arms, while requiring only 40.5 ms per action chunk. These results suggest that the action tokenizer is a natural place to model bimanual coordination.

# BiCAT: Bimanual Coordination Action Tokenization 论文总结

## 1. 核心问题与研究动机

- **背景**：自回归 VLA（视觉-语言-动作）模型沿用视觉语言主干的 next-token 预测目标，需要先用**动作标记器（action tokenizer）** 把连续动作块离散化为 token。因此标记器实质上定义了"策略 ↔ 机器人"的接口，决定了策略学什么、误差如何传导。
- **现有做法的缺陷**：
  - **联合标记化（joint tokenization）**：把双臂动作拼接成单个扁平向量统一编码。跨臂依赖虽可被捕捉，但两臂共有的运动模式未被共享，且左右臂信息在每个 token 内纠缠，策略须隐式学习"共享运动库"与"跨臂协调"两方面。
  - **逐臂标记化（per-arm tokenization，如 M2Tok）**：按臂切分、独立编码，得到臂索引 token，但**丢失了伙伴臂上下文**；实验显示其表现并不优于最强联合标记器（M2Tok 仅 40.5%）。
- **核心问题**：当双臂被 token 化为独立流之后，这两个流应如何交互，才能为双臂策略提供更好的接口？
- **核心洞察**：臂索引 token 不必是臂独立的——每条臂的 token 可以在**访问伙伴臂信息**的前提下计算，同时两条流仍保持分离。由此提出 **BiCAT**，设计原则为"**双臂共享运动表示，同时让离散化以伙伴臂为条件**"。

## 2. 方法论

### 2.1 总体框架
- 输入双臂动作块 `A = [A_L ‖ A_R] ∈ R^{H×2d_a}`，输出两条臂索引 token 流 `(y_L, y_R) = T(A_L, A_R)`，反标记器 `T^{-1}` 重建 `Â`。
- 流程：**镜像规范化 → 共享因果编码器 → 对称交叉臂注意力 → 共享 FSQ → 联合解码器**，仅用重建损失训练。

### 2.2 关键技术细节
- **规范动作空间（canonicalization, C）**：
  - 利用双臂镜像安装特性，用本体相关的符号向量 `s ∈ {−1,+1}^{d_a}` 把右臂翻转到左臂约定（如 RoboTwin/YAM 用 `s=(−1,1,1,1,−1,−1,1)`；G1、SO-101 各有自己的 `s`），使镜像运动共享同一规范轨迹。
  - **共享归一化**：不是各臂独立归一化，而是把两臂对应通道池化后得到统一上下界 `ℓ, u`，再逐元素归一化，保证相同关节值在两臂映射一致。
- **共享编码器 `E_φ`**：线性投影 + 两层因果卷积（核 5/3，步长 2/2，left-only padding），把 `H=32` 步压缩为 `M=8` 个隐位置；配 Mish + LayerNorm、正弦位置编码、共享的预归一化因果自注意力，得 `S_L, S_R`。潜在位置 `i` 只依赖前 `4i` 步动作。
- **对称因果交叉臂注意力**：
  - `C_L = S_L + CA(S_L, S_R)`，`C_R = S_R + CA(S_R, S_L)`；
  - 两方向都读取**原始** `S_L, S_R`，query `i` 只能看伙伴位置 `j ≤ i`（因果性）；残差保证自身特征直通。
  - 交换两条规范输入流会交换其协调特征（对称性），但输出流仍保留显式臂索引。
- **共享 FSQ 量化**：共享线性投影到 `d_z=4` 维，层级 `(8,8,6,5)`，词表 `K=1920`；双臂共享投影与网格，故同一符号在两流中映射到同一量化向量。token 序列化为 `y = (y^L_1..y^L_M, y^R_1..y^R_M)`，形成两个臂索引块。
- **联合解码器 `D_θ`**：每个隐位置拼接双臂去量化向量，线性投影成 `M` 个配对记忆槽；6 层 Transformer 解码器以 `H` 个零初始化 query 读取（query 自注意力因果、交叉注意力访问完整配对记忆），**并行**重建整段 `H` 步动作，再做逆归一化与右臂符号逆变换。
- **训练目标**：共享归一化空间上的重建 MSE（式 9），联合训练编码器、交叉注意力、量化投影与解码器；FSQ 无码本、无 commitment loss。

### 2.3 策略侧：半自回归块预测
- 冻结 BiCAT，用其 token 监督预训练 VLM（仿真用 PaliGemma 2-3B，真机用 Molmo2-ER），词表扩充 `K` 个动作符号 + 1 个 mask token。
- 分解为 `p(y|o) = p(y_L|o)·p(y_R|o, y_L)`：每臂内 `M=8` 个 token **并行**预测，右臂块以完整左臂块为条件；训练时用块因果注意力，两块的交叉熵等权、一次前向完成；推理时两次块解码 + 贪心解码。

  - **Decoder-only coupling / Encoder-only coupling**：仅在解码端或仅在编码端引入跨臂信息，均退化到最强基线（NAC）水平附近，说明耦合必须发生在**离散化之前**，且编码端的条件化不可由解码端补偿；
  - **Independent arms**（等价于逐臂标记化）：跌至约 40.5%，与 M2Tok 持平，直接复现了"丢失伙伴上下文"的代价；
  - **Single-block prediction**：损失 18.2 个点（约 51.1%），证明两块半自回归调度与标记器设计是互补的——标记器提供了臂索引流，调度才得以利用它；
  - **Right-first prediction**：略低于左臂优先，差距不大但一致，说明性能主要来自"分块条件化"这一结构而非某一固定顺序；作者亦承认左臂优先属经验选择。
- **FSQ 网格消融**：词表从 240 扩到 4375，成功率变化在数个点内，且未呈单调趋势，说明方法对量化粒度不敏感，增益不来自"更大的有效词表"。
- **相关性分析**：重建 MSE 与 token 准确率**不能**预测闭环成功率（甚至方向相反）；与成功率更一致的是"对执行误差的容忍度""重规划一致性""块边界跳变"等闭环可用性指标，提示标记器评价标准应从"压缩保真"转向"策略友好"。
- **表征分析**：t-SNE 与 MMD 显示 BiCAT 的左右臂潜在/token 分布在共享空间中高度重叠（MMD 显著低于逐臂基线），而输出仍保持显式臂索引，即"共享而不混淆"在表征层面得到验证。

## 7. 局限与讨论

- **本体假设较强**：规范化依赖双臂镜像安装与手工设定的符号向量 `s`，对非镜像布局、自由度不对称或异构双臂（如人形 + 夹爪混合）不直接适用，需逐本体设计。
- **共享的前提是维度对称**：`A_L` 与 `A_R` 需同维（`d_a` 相同），异构臂需先做动作空间对齐或填充，论文未讨论该情形。
- **调度顺序固定**：半自回归固定"左臂块 → 右臂块"，缺少自适应顺序或真正的联合块解码；虽消融显示顺序影响不大，但在强非对称任务中未必最优。
- **评价覆盖有限**：仿真仅取 50 个任务中的 10 个，真机每任务 25 次试验且仅两个基线，统计功效与外部效度受限；相关性分析样本少且含大量自方法变体，作者自述为描述性。
- **算力披露不足**：未报告 GPU 数量与总训练时长，复现成本难以评估。
- **任务域较窄**：集中于桌面级双臂操作，未涉及长时序、移动底盘或人机交互场景。

## 8. 启示与总体评价

- **概念贡献大于工程贡献**：论文把"动作标记器即策略—机器人接口"这一视角显式化，并给出可操作的设计准则——**共享运动表示 + 以伙伴臂为条件的离散化**，这比单纯提升重建精度更有迁移价值。
- **设计模式可复用**：镜像规范化、共享因果编码器、对称交叉臂注意力、共享 FSQ、联合解码器的组合，构成一套对双臂乃至多末端协调任务的通用模板；"耦合必须前置于量化"是可被其他工作直接引用的结论。
- **评价范式的提醒**：重建误差与 token 准确率与闭环成功率脱钩，提示后续标记器研究应默认报告闭环指标与闭环相关性质，而非仅报告压缩指标。
- **总体判断**：方法简洁（参数量在对比中最小）、增益显著且随耦合度递增、在三种真实本体上一致复现，实验设计与消融逻辑严密；主要不足在于本体假设的通用性、真机规模与算力透明度。作为"接口层"研究，其结论对该方向的后续工作具有较好的指导意义。
