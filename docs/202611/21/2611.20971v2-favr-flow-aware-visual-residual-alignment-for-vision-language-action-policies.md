## 摘要
预训练视频表征为机器人操作提供了丰富的时间信息，但将其有效集成到现有视觉-语言-动作（VLA）策略中仍具挑战性。我们提出流感知视觉残差对齐（FAVR），一个用于冻结VLA策略的流感知视觉条件化的轻量级框架。FAVR通过线性测试时训练（TTT）维护紧凑的时间视觉状态，并在基于流的动作生成过程中检索动作条件视觉特征。通过利用冻结动作头的仿射结构，我们显式刻画注入的视觉特征如何影响预测的动作速度，并将流感知通道选择建模为盒约束优化问题。我们开发了基于FISTA的联合门控优化求解器，并通过对角化与重缩放推导出高效的闭式近似。仅需1.74–2.19M可训练参数和5,000步适配，FAVR在多个基准上提升了预训练VLA策略。在RoboTwin 2.0上，FAVR在干净条件下将LingBot-VLA从87.12%提升至90.04%，在随机化条件下从86.88%提升至89.38%。在五个RoboTwin任务上的受控消融进一步表明，流感知门控将平均成功率从跨流步共享门控时的72.0%提高到82.0%，证明了在动作生成全过程中自适应视觉条件化的收益。

## Abstract
Pretrained video representations provide rich temporal information for robotic manipulation, yet effectively integrating them into existing vision-language-action (VLA) policies remains challenging. We present Flow-Aware Visual Residual Alignment (FAVR), a lightweight framework for flow-aware visual conditioning of frozen VLA policies. FAVR maintains a compact temporal visual state through linear Test-Time Training (TTT) and retrieves action-conditioned visual features throughout flow-based action generation. By exploiting the affine structure of the frozen action head, we explicitly characterize how injected visual features influence predicted action velocities and formulate flow-aware channel selection as a box-constrained optimization problem. We develop a FISTA-based solver for joint gate optimization and derive an efficient closed-form approximation through diagonalization and rescaling. With only 1.74-2.19M trainable parameters and 5,000 adaptation steps, FAVR improves pretrained VLA policies across benchmarks. On RoboTwin 2.0, FAVR improves LingBot-VLA from 87.12% to 90.04% under clean conditions and from 86.88% to 89.38% under randomized conditions. A controlled ablation on five RoboTwin tasks further shows that flow-aware gating increases average success from 72.0% with a gate shared across flow steps to 82.0%, demonstrating the benefit of adapting visual conditioning throughout action generation.

## 2. 方法论

### 2.1 总体架构

- 冻结的流式 VLA 策略 πθ（VLM 主干 + 流匹配动作专家 + 冻结仿射动作头）与冻结的 V-JEPA 2.1 ViT-B 视频编码器。
- 仅训练两个轻量模块：**时序视觉接口**（线性 TTT + 检索投影）与**速度残差预测器** Rϕ。
- 视觉残差经门控后在**动作头之前**以残差连接注入。

### 2.2 时序视觉状态构建与检索（线性 TTT）

- 冻结 V-JEPA 提取时空 token Z，学习投影 fK、fV 生成键 K 与值 V。
- 维护状态 S ∈ R^{p×p}（p=128），对键到值的映射做一步梯度拟合：
  - S ← S − (η/n)·Kᵀ(KS − V)，η = sigmoid(ηraw)
- 每个 episode 用学习到的 S0 初始化；动作生成期间状态固定，新观测到来时再更新。
- 每个流步以当前动作特征 hτ 为查询：
  - qτ = norm(P_Qᵀ LN(hτ))
  - x̃τ = P_Oᵀ S_tᵀ qτ + bO
- 幅度约束（ρ=0.1，stop-gradient 防止退化）：
  - xτ = x̃τ · clip[0,1]( ρ·sg(‖hτ‖₂) / (‖x̃τ‖₂ + ε) )

### 2.3 流感知视觉残差对齐

- 训练目标速度为 u，残差 rτ = u − v0_τ（v0_τ 为冻结策略速度）。
- 推理时 u 不可得，故用轻量 MLP 预测器从 (hτ, xτ, Wxτ, 流时间嵌入 e(τ)) 估计 µτ；训练时对 detached 残差做 valid-coordinate MSE。
- 门控注入与冻结仿射头给出精确的线性映射：
  - ehτ = hτ + gτ ⊙ xτ
  - vτ = W·ehτ + b = v0_τ + Qτ gτ，其中 Qτ = W·diag(xτ)
- 通道选择建模为盒约束最小二乘：
  - min_{g∈[0,1]^d} ½‖Qτ g − µτ‖₂²

### 2.4 求解器

- **FISTA 联合优化（FAVR）**：
  - 梯度 ∇F(g) = Bg − s = x ⊙ Wᵀ[W(x ⊙ g) − µ]，不显式构造 B=QᵀQ。
  - 步长 L ≥ ‖Q‖₂²；每步做 clip[0,1] 投影 + Nesterov 动量；若加速候选使目标上升则回退到可行点。
  - 迭代次数：LIBERO 8 次，LIBERO-Plus 与 RoboTwin 128 次；复杂度 O(N_iter·m·d)。
- **闭式近似（FAVR-CF）**：
  - 对角近似 D = diag(B)，D_jj = ‖Q_:j‖₂²，得 gD_j = clip(s_j / D_jj)。
  - 解析标量重缩放：gCF = α*·gD，α* = clip(µᵀcD / (‖cD‖₂² + ε))，cD = Q·gD。
  - 复杂度 O(m·d) 算术、O(d+m) 额外空间（缓存动作头列范数）。
  - 提供与通道耦合强度相关的误差界：0 ≤ F(gCF) − F(g*) ≤ ‖E·gD‖₁ + ε/2 ≤ d‖E‖₂ + ε/2，E 为 B 的非对角部分。
- **训练流程**：残差损失更新 ϕ（输入 detached）；动作损失固定 ϕ，梯度穿过预测器输入与求解器迭代步反传至视觉接口。
