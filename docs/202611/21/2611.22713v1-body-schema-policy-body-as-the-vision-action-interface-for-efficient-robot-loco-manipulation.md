## 摘要
目前，机器人可以通过规模化来学习全身移动操作：最强的策略拥有数十亿参数，却仍需针对具体任务进行微调。人类的信息处理能力有限，却能借助一种组织其所见与所动的身体图式，高效地学习和行动。我们提出身体图式策略（Body Schema Policy, BSP），一种将此类图式构建到视觉-动作接口中的模仿学习策略。其潜在身体图式将关节与连杆 token 置于机器人的运动学树上，由学习得到的螺旋运动在连杆之间传递特征。通过身体查询式视觉，每个身体部位检索自身的视觉证据，并以此作为其动作去噪的条件。凭借这一归纳偏置，BSP 返回动作块的速度快于我们所比较的任何策略。无需空间监督，紧凑且针对具体身体部位的视觉读出也会自然涌现：操作指令强烈依赖于任务物体，而移动指令则对场景做出更广泛的响应。在九个仿真 Unitree G1 全身任务上，BSP 以少 75 倍的参数量媲美 Ψ0 人形基础模型，并将 Diffusion Policy 的成功率提升近一倍。在真实 G1 和 Fetch 移动操作机器人上同样如此。

## Abstract
Currently, robots can learn whole-body loco-manipulation through scale: the strongest policies have billions of parameters and still need task-specific fine-tuning. Humans have limited processing capacity, yet learn and act efficiently through a body schema that organizes what they see and how they move. We introduce Body Schema Policy (BSP), an imitation learning policy that builds such a schema into the vision-action interface. Its latent body schema places joint and link tokens on the robot's kinematic tree, where learned screw motions carry features between links. Through body-queried vision, each body part retrieves its own visual evidence, which conditions the denoising of its actions. With this inductive bias, BSP returns an action chunk faster than any policy we compare. Compact, body-specific visual readouts also emerge without spatial supervision: manipulation commands depend strongly on task objects, while locomotion commands respond more broadly to the scene. On nine simulated Unitree G1 whole-body tasks, BSP matches the $Ψ_0$ humanoid foundation model with $75\times$ fewer parameters and nearly doubles Diffusion Policy's success. The same holds on a real G1 and a Fetch mobile manipulator.

## 1. 核心问题与整体含义

- **研究背景**：全身移动操作（loco-manipulation）要求机器人同时协调移动与精细操作。当前主流路线是扩大模型与数据规模，例如 VLA、WAM 和 humanoid foundation model，最强策略可达数十亿参数，但仍需针对每个任务用示范数据微调。
- **核心问题**：人类处理能力和注意力有限，却能借助“身体图式”（body schema）高效组织感知与动作。论文追问：**视觉运动策略能否像人类一样，以身体结构为归纳偏置，高效学习全身技能？**
- **问题根源**：常见策略把动作表示为扁平坐标向量，把图像表示为全局池化特征，导致“哪些关节如何协同运动”“图像中哪部分对应哪个身体部位”等结构信息被隐藏，只能从示范中隐式学习。
- **整体含义**：论文提出 **Body Schema Policy（BSP）**，把机器人身体图式嵌入视觉–动作接口，以紧凑参数和任务示范实现高效全身移动操作，探索“结构归纳偏置”而非单纯“规模扩张”的互补路线。

## 2. 方法论

### 2.1 核心思想

- 将机器人建模为根节点运动学树，把关节 token、连杆 token 和全局 token 组织成**潜在身体图式**。
- 用学习得到的**螺旋运动（screw motion）**在运动树上传递连杆特征，使特征传播方式与正向运动学的复合结构一致。
- 每个身体部位用自己的 token 查询图像 patch 特征，检索与自身相关的视觉证据，并条件化自身动作坐标的去噪。
- 动作去噪不是基于一个全局共享视觉向量，而是基于“身体图式 + 身体查询视觉”的逐坐标条件。

### 2.2 关键表示与公式流程

- **问题设定**：策略将第一视角图像 \(I_t\) 和本体状态 \(s_t\) 映射为动作块 \(a_t\in\mathbb{R}^{H\times A}\)；以扩散去噪器 \(\epsilon_\phi(x_t^{(k)},k,s_t,V)\) 实现，其中 \(x_t^{(k)}\) 是第 \(k\) 步动作假设，\(V\) 是图像 patch token。
- **动作空间划分**：\(a_t=[a_t^{on},a_t^{off}]\)，前者为运动树上的关节目标，后者为基座速度等离树控制器命令。
- **身体图式**：\(\mathcal{S}=(J,L,g;G)\)。\(J\) 为关节 token，\(L\) 为连杆 token（每个连杆含 \(C\) 个无限制 \(4\times4\) 特征通道），\(g\) 为全局 token；\(G\) 为连通运动子树。
- **初始化**：由当前动作假设、去噪步嵌入和本体状态经仿射映射初始化 \(J,L,g\)，因此每个去噪步都会重建图式。
- **Neural Screw Block**：
  - 每个关节 token 预测潜在坐标 \(\vartheta_d=w_\theta^\top J_d\)。
  - 父连杆特征通过右乘/左乘学习螺旋变换传递到子连杆：
    \[
    \tilde L_c=\sum_{r=1}^{R}\alpha_r(L_pG_r(\vartheta))+\sum_{r=R+1}^{2R}\alpha_r(G_r(\vartheta)L_p)
    \]
    其中 \(G_r(\vartheta)=\exp(\vartheta\hat\xi_r)\)，\(\alpha_r\) 为通道混合矩阵。
  - 更新连杆：\(L\leftarrow \mathrm{LN}(L+\tilde L)\)；更新关节：\(J_d\leftarrow J_d+W_d\mathrm{vec}(L_{c(d)})\)。
  - 周期性加入身体自注意力，混合连杆与全局 token。
- **身体查询式视觉**：
  - 用预训练 DINOv2 提取 patch token，加位置嵌入并投影为视觉记忆 \(\bar V\)。
  - 关节查询由 \([J_d;\mathrm{vec}L_{p(d)}]\) 构成，全局 token 提供全身查询；关节和全局查询共享多头注意力参数但使用独立输入/输出投影。
  - 视觉证据通过后续螺旋传递和自注意力在图式中分发；最后一个交叉注意力阶段直接条件化对应动作坐标。
- **身体感知动作去噪**：
  - 每个动作坐标获得一个条件：
    \[
    c_n=
    \begin{cases}
    W_c[J_n;\mathrm{vec}L_{p(n)}], & n\le D\\
    c_g+b_n, & n>D
    \end{cases}
    \]
  - 共享时序解码器 \(f_\phi\)（FiLM 条件化 Conv1D 残差块）逐列预测噪声：
    \[
    \hat\epsilon=[f_\phi(x_n,c_n,k)]_{n=1}^{A}
    \]
  - 语言指令经冻结文本编码器（如 CLIP）嵌入，并在每个 block 后调制关节和全局 token。
- **训练与推理**：采用 DDPM 噪声预测目标，最小化 \(\mathrm{MSE}(\epsilon,\hat\epsilon)\)；推理时执行完整动作块；缓存视觉 key/value，并用 CUDA graph 加速去噪器调用。
