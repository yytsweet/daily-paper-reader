## 摘要
任务规定了世界应如何变化，而策略规定了机器人应做什么。我们提出进度预测策略（PPP），它通过由其微分诱导出的指令来学习语言条件标量场。我们通过将潜在进度场与共享世界模型组合来获得动作条件化，并在固定参考指令处读取其动作梯度。连续指令通过学习到的正增益缩放该梯度，而离散指令则使用同一标量的有限差分。由此得到一种混合策略，无需单独的动作头或迭代搜索。仅拟合示范进度值并不能保证动作梯度与专家指令对齐。PPP 通过模仿训练诱导指令，并对连续梯度读出使用双重反向传播，以塑造该场的局部控制几何。示范时序无需额外标注即可在观测状态上校准场值。连续读出在没有进度标签时仍可学习，但这些由时序导出的目标支持执行过程中的进度监测。在仿真和真实机器人操作中的实验表明，在共享架构下 PPP 优于行为克隆。

## Abstract
A task specifies how the world should change, while a policy specifies what the robot should do. We introduce Progress Predicts Policy (PPP), which learns a language-conditioned scalar field through the commands induced by its differential. We obtain action conditioning by composing a latent progress field with a shared world model and read its action gradient at a fixed reference command. Continuous commands scale this gradient by a learned positive gain, while discrete commands use finite differences of the same scalar. This yields a hybrid policy without a separate action head or iterative search. Fitting demonstration progress values alone does not ensure that action gradients align with expert commands. PPP trains the induced commands by imitation and uses double backpropagation for the continuous gradient readout to shape the field's local control geometry. Demonstration timing calibrates field values on observed states without additional annotation. The continuous readout remains learnable without progress labels but these timing-derived targets support progress monitoring during execution. Experiments in simulated and real robot manipulation show that PPP outperforms behavioral cloning under a shared architecture.

## 1. 核心问题与研究动机

- **任务与策略的语义分离**：论文开篇指出，“任务”规定世界应当如何变化（例如“碗应最终位于盘子上”），而“策略”规定机器人应执行什么动作。二者的决定因素不同：任务由目标语义决定，动作则由机器人动力学决定。主流模仿学习（扩散策略、VLA 模型等）把二者压缩进一个“从观测+指令到动作”的映射中，导致任务语义与具体本体/动力学相互纠缠。
- **核心问题**：能否用一个**学习得到的标量任务评估器**（进度场）同时提供：
  1. 对观测状态的进度估计；
  2. 由该标量场的**微分**直接读出控制指令。
- **关键观察（论文最重要的动机）**：仅拟合示范进度值**不足以保证**动作梯度与专家命令对齐。进度标签只约束示范状态上的函数值；在这些状态上取值相同的函数，其附近导数可以完全不同。实验（图 4）显示：仅用进度监督的场对训练状态排序几乎完美（Spearman ρ≈0.999），但动作梯度与专家命令的平均余弦仅约 0.22–0.25；而动作模仿训练后可达 0.995。因此，真正要学的是“**控制对齐的进度场（control-aligned progress field）**”，而不仅是准确的进度估计器。
- **另一个缺口**：在场上做有限命令的全局搜索（最大化 Q）既不能恢复示范行为，实验中几乎全部失败，因此读出应是**局部**的梯度读出而非迭代搜索。

## 2. 方法论：PPP 的核心思想与技术细节

### 2.1 总体框架
- 用视觉编码器 E 将观测 o 映射为潜状态 z=E(o)，指令编码为 ℓ。
- 学习一个语言条件标量势场 pθ(z, ℓ)，称为**任务场（task field）**。
- 用一个**共享世界模型**的动作条件查询 f(z, a) 把候选命令 a 映射到潜空间，构造复合标量：
  - **Q_{z,ℓ}(a) = pθ(f(z, a), ℓ)**，即在候选命令下评估的任务场值。
- 策略从 Q 的**微分**读出动作，而非单独的 action head 或采样搜索。

### 2.2 动作条件化与局部控制几何
- 在固定参考命令 a0（归一化零，对应语料中位命令）处，记 z̄ = f(z, a0)、J_f = ∂f/∂a|_{a0}，链式法则给出：
  - **g_a := ∇_a Q_{z,ℓ}(a0) = J_fᵀ ∇_z pθ(z̄, ℓ)**
- 该式把“任务敏感度”∇_z pθ 与“查询映射的局部潜响应”J_f 结合：g_aᵀδa = ∇_z pθᵀ(J_f δa)。一次反向传播即可精确计算，无需显式构造雅可比。
- 作者指出：控制查询分支与世界模型预测分支共享权重，但使用**独立的归一化统计量**（固定于候选动作，避免 BatchNorm 跨样本耦合），从而保证 Q 关于候选动作的导数正确。

### 2.3 混合动作读出（连续 + 离散）
- **连续位姿命令**（6 维平移+轴角增量）：
  - **π(z, ℓ) = a0 + η_ϕ(z̄) · g_a**
  - η_ϕ = softplus(MLP(sg z̄)) + ε_η，为**学习到的正增益**（stop-gradient 输入、无语言输入），只缩放幅值、不能旋转方向。
  - 因此一阶上 Q 的增量为 η_ϕ‖g_a‖² ≥ 0，方向完全由场梯度决定；语言只通过 pθ 进入。
- **离散夹爪命令**（开/合）：
  - b = Q_{z,ℓ}(u0, c_alt) − Q_{z,ℓ}(u0, c_h)，若 b > ε_g 则切换，否则保持。
  - 与连续读出共享同一参考点与同一标量场，构成**局部混合控制器**，每次决策仅需 1 次梯度评估 + 2 次势函数评估。
- 双臂扩展：12 维联合位姿梯度 + 每个夹爪一个有限差分，离散查询数随夹爪数线性增长。

### 2.4 训练目标：两种监督，同一个场
- **进度校准损失 L_p**（无需额外标注，仅用示范时序）：
  - 归一化相位目标 p* = ρ − 1（ρ∈[0,1] 为示范内归一化时间）；或绝对剩余时间 p* = −(T−t)/T_u。
  - 值损失 L_val、增量损失 L_inc（成对 i<j）、时序排序损失 L_rank、终端边界损失 L_bd、指令对比损失 L_lang（真实指令得分高于错配指令）。
- **动作模仿损失 L_act**：
  - L_act = λ_vec/6 · ‖u − ū_E‖² + λ_dir · (1 − cos(u, ū_E))，把诱导出的位姿命令与专家块均值命令比较。
  - **关键：保留 ∇_u Q 的计算图，用双重反向传播**把梯度穿过梯度读出，回传到势场（经 ∇_z pθ）、世界模型与编码器（经 J_f 与 z̄），从而**塑造场的局部控制几何**。
- **夹爪切换损失 L_grip**：对切换窗口二分类标签 y，温度缩放 logistic 损失作用于 b；仅更新 pθ（潜变量 detach）。
- **联合训练**：L = L_p + λ_act L_act + λ_grip L_grip + λ_WM L_WM；先预热（仅 L_p，编码器/动力学冻结），再联合优化；世界模型用更低学习率。

3. **进度标签对连续控制是可选的**：No Lp 仍能学到有效策略（38.6%，与 PPP-GH 的 43.5% 差距不大，且显著优于 BC 的 38.1% 区间），说明真正驱动控制的是**动作梯度对齐监督**，进度损失主要起正则化与可解释性作用；作者进一步用"分支调度"实验说明该结论不能简单归因于训练日程差异。
4. **冻结世界模型会破坏控制几何**：冻结编码器/动力学后成功率从 43.5% 跌至 5.0%，说明 PPP 依赖世界模型与势场**协同塑形**——若 J_f 固定且与任务无关，则 ∇_z pθ 必须独自承担全部对齐压力，梯度读出失效。
5. **局部梯度读出优于全局搜索**：CEM 在 Q 上的一步/四步搜索与 CEM-Goal 潜空间规划几乎全部失败；用真动力学做梯度上升也只有 1.5%（对比 PPP 的 66.0%）。这支持了论文的核心论断——Q 的可微局部结构才是可用的控制信号，而非其全局极大值。
6. **显式 pθ∘f 分解是必要的**：Direct-AP（直接在动作空间定义标量）与 PPP 差异不显著但未见优势，且失去"任务场可单独解释/可视化"的性质；PPP-AH（场读夹爪 + action head 读位姿）与 PPP-GH 的对照则表明夹爪的势差读出与学习头性能相当，但前者更简洁、参数更少。
7. **骨干可迁移性**：把 LeWM 换成 Seer 骨干后，Seer-AC-PPP 相对 Seer-AC 仍有稳定增益，说明 PPP 是一种**与具体世界模型解耦的读出范式**，而非特定架构的偶然产物。
8. **闭环进度可用于在线监控**：用势场值对 2,000 条 rollout 做成功/失败判别，AUROC 显著高于随机，说明学到的场不仅驱动控制，还可作为**运行时进度信号**（可用于早停、重试、数据筛选）。
9. **双臂任务暴露边界**：两台 xArm7 倒鸡蛋仅 5 次试验、成功率 1/5，作者如实承认高维联合位姿 + 精细接触任务仍具挑战，未将其包装为成功案例。

## 7. 贡献与创新点定位

- **概念层面**：把"任务"与"策略"的分离形式化为"标量任务场 + 动作条件查询 + 微分读出"，提出"控制对齐的进度场"这一明确的学习目标，而非笼统的"进度估计 + 策略头"。
- **技术层面**：
  - 用**共享世界模型的动作条件分支**构造 Q，使一次反向传播即得精确梯度，避免显式雅可比或采样；
  - **混合读出**（连续位姿用梯度、离散夹爪用势差）在同一标量场上统一，决策开销极小（1 次梯度 + 2 次势评估）；
  - **双重反向传播**穿过梯度读出，把动作模仿信号回传到势场与世界模型，这是让"值函数"具备"控制几何"的关键工程手段；
  - 进度损失的五项分解（值/增量/排序/边界/语言对比）为无额外标注的时序自监督提供了较完整的配方。
- **相对已有范式的差异**：
  - 与扩散策略 / VLA 的"观测→动作"直接映射相比，PPP 把动作生成变成**对学到的任务标量的求导**，天然具备可解释性与可组合性；
  - 与能量模型 / EBM 相比，PPP 不依赖 MCMC 或迭代优化，而是取**一阶局部梯度**，规避了全局搜索的失败模式；
  - 与 RL 价值函数相比，PPP 的标量由示范时序自监督（进度）而非奖励塑造，且读出方式被显式设计为梯度。

## 8. 局限性与作者承认的不足

- **理论保证缺失**：论文只给出"一阶上 Q 沿梯度方向增加"的局部论证，未刻画场的全局形状、收敛性或多模态下的行为；局部性实验（r 从 0.03 到 4）显示一阶拟合比随步长增大而退化，说明读出本质上是**小步长控制器**。
- **对世界模型的依赖**：冻结即崩（5.0%）表明方法对动力学质量敏感，世界模型预训练成本与误差会直接传导到控制。
- **进度标签的边际价值不明确**：No Lp 与完整 PPP 差距不大，削弱了"进度"作为核心卖点的说服力，作者未给出何时必须用进度监督的判据。
- **实验覆盖有限**：以 LIBERO 与桌面操作（抓放、翻正、倒蛋）为主，缺少移动操作、长时序多阶段、多物体交互与跨本体迁移的系统证据；真实试验次数少，统计功效不足。
- **超参数与工程细节较重**：增益网络 η_ϕ、夹爪阈值 ε_g、切换窗口、预热阶段、独立归一化统计等均需调校，论文未给出敏感性分析。
- **算力与复现信息不完整**：GPU 数量/型号/总时长未系统披露，限制了成本评估与独立复现。

## 9. 启示与可复现性评估

- **对后续研究的启示**：
  1. "值函数准确 ≠ 梯度可用"是一个可迁移的诊断视角，可推广到任何以标量场驱动控制的框架（如基于价值的规划、世界模型 MPC）；
  2. 把离散决策（夹爪）与连续决策（位姿）统一到**同一标量场的不同读出方式**，是一种简洁的多模态动作接口设计；
  3. 势场值可作为**免费的过程奖励/监控信号**，用于数据筛选、失败检测与在线重规划。
- **可复现性**：论文提供了架构（LeWM ViT + Transformer 动力学 + FiLM 残差 MLP）、训练 epoch、batch size、学习率与主要损失形式，方法层面可复现性尚可；但算力清单、完整超参表、真实机器人试验协议细节与代码/数据开放情况在总结所覆盖的范围内不够明确，独立复现仍有门槛。

## 10. 总体评价

PPP 是一篇**问题意识清晰、诊断实验扎实**的工作：它没有停留在"再做一个更强的策略头"，而是先指出模仿学习中"任务语义与动作动力学纠缠"的结构性问题，再用一个精心设计的诊断实验（进度拟合近乎完美但梯度余弦仅 0.22）证明"准确的值函数并不自动可用"，最后给出"控制对齐的进度场 + 微分读出"这一自洽的解法。其优势在于概念优雅、读出开销低、消融充分且对不利结果如实报告；其短板在于理论刻画薄弱、对世界模型质量高度依赖、真实机器人证据量偏少，以及"进度标签"这一名义核心在消融中显得并非必需。总体而言，论文的最大贡献可能不是某个具体指标，而是**把"标量场必须控制对齐"这一要求显式化**，并为后续在世界模型上构建可解释控制器提供了一个可复用的范式与诊断工具。
