## 摘要
视觉-语言-动作（VLA）规划器从预训练视觉-语言模型中继承语义知识，但其推理很少以三维场景结构及其随时间演化为依据。我们提出 GeoVLDrive，一个面向三维时空推理与规划的几何锚定 VLA 框架。来自三维基础模型的多层特征通过门控交叉注意力增强视觉-语言主干。结构化的潜在思维链（CoT）将未来场景几何、关键智能体运动与元动作组织为有序且分别监督的潜在状态。动作专家根据这些状态和多层场景特征生成轨迹候选，并使用场景锚定的交互式评分 token 对其进行排序。我们还提出 NAVSIM 3DQA，用于训练和评估度量化的三维空间与运动理解。GeoVLDrive 在 NAVSIM v1 上达到 91.8 PDMS，在 NAVSIM v2 上达到 90.9 EPDMS。在 NAVSIM 3DQA 上，几何锚定主干总体得分为 89.2%，比微调后的 Qwen3-VL-2B 基线高 4.6 个百分点。在 LingoQA 上，该主干达到 68.6% 的 Lingo-Judge 准确率。

## Abstract
Vision-language-action (VLA) planners inherit semantic knowledge from pretrained vision-language models, but their reasoning is rarely grounded in 3D scene structure and its evolution over time. We introduce GeoVLDrive, a geometry-grounded VLA framework for 3D spatiotemporal reasoning and planning. Multi-layer features from a 3D foundation model augment the vision-language backbone through gated cross-attention. A structured latent chain of thought (CoT) organizes future scene geometry, key-agent motion, and meta-actions into ordered, separately supervised latent states. An action expert generates trajectory proposals from these states and multi-layer scene features, and ranks them using scene-grounded, interacting score tokens. We also introduce NAVSIM 3DQA to train and evaluate metric 3D spatial and motion understanding. GeoVLDrive achieves 91.8 PDMS on NAVSIM v1 and 90.9 EPDMS on NAVSIM v2. On NAVSIM 3DQA, the geometry-grounded backbone scores 89.2% overall, 4.6 percentage points above the fine-tuned Qwen3-VL-2B baseline. On LingoQA, the backbone achieves 68.6% Lingo-Judge accuracy.

- `g_m` 为可学习标量门，`φ_m` 为投影到解码器宽度；query 来自解码器隐状态，因此视觉、文本、潜在推理 token 均可访问几何流。

**(2) 空间对齐**
- 对归一化图像坐标 `(u,v)` 使用**共享 2D 正弦位置编码**，分别加到视觉 query 与几何 key/value 上，为不同分辨率的特征网格提供统一图像平面参考。

**(3) 结构化潜在 CoT（三类状态组）**
- **未来场景几何**：预测 2 s（K=4 个 0.5 s 时域），保留当前多层几何特征作稠密参考，时间条件残差解码器更新：`∆G_ℓk = R(G_ℓ, F_k, t_k)`，输出未来深度 `ẑ_k` 与置信度 `c_k`；损失 `L_world = Σ(L_depth + L_conf + L_grad)`（深度回归 + 置信度加权 + 多尺度梯度一致性）。
- **关键智能体运动**：10 个 token 表示类别、当前位置、8 个未来偏移（4 s，J=8）；`p̂_0 = g_0(d_0)`，`p̂_j = p̂_0 + g_∆(d_j)`；损失 `L_agent = λ_cls L_CE + λ_pos L_SmoothL1 + λ_dir L_cos`（方向损失对近静止目标降权，η=0.25 m）。
- **元动作**：2 个 token 表示纵向/横向意图，交叉熵监督 `L_meta`。
- **有向注意力掩码**（图 3）：运动状态可读几何状态，元动作可读两者，**反向阻断**；几何 token 只读自身及更早时域；未来运动 token 之间双向。

**(4) 动作专家**
- 4 个 refinement stage，每 stage 4 个独立参数化注意力块，对应 Qwen3-VL 读出层 [8, 16, 22, −1]；
- 维护 **R=64 个轨迹候选**，每个由 J=8 个 action token + 1 个 score token 表示；
- 多深度 Qwen 特征经 attention pooling 压缩为 64 token；**VLM 输入全部 detach**，阻断规划梯度回传 VLM；
- **因果联合注意力掩码**：推理 → 动作 → 评分单向流动，组内双向；
- 轨迹监督：阶段折扣的 **winner-takes-all** 回归损失（公式 7）；
- **场景锚定跨候选评分**：score token 直接注意对应 proposal 的 action，score token 之间互相注意以交换候选信息；MLP 输出标量分数，以模拟器分数 `q_r` 为软标签做 BCE 监督；推理时选最高分。

**(5) 训练目标与流程**
- 总损失：`L = L_traj + Σ_{q∈{world,agent,meta,cot,score}} λ_q L_q + Σ λ_aux L_aux`；
- **四阶段训练**：① 语义-几何对齐（3 epoch）→ ② 未来几何与关键智能体运动预测（5 epoch）→ ③ 监督潜在链（10 epoch）→ ④ 链 + 动作专家联合训练（30 epoch）。

## 六、主要结论与发现

- **规划性能**：2B 主干、单前视相机、纯监督训练下，NAVSIM v1 **91.8 PDMS**，NAVSIM v2 **90.9 EPDMS**；v1 上超过 SGDrive(SFT) +4.4、CoWorld-VLA +1.8、DriveWorld-VLA +0.5、RL 训练的 LaST-VLA-2B +0.7，与 iPad（91.7）和 GeoWorldAD（91.0）相当或更优。
- **几何理解**：NAVSIM 3DQA 总体 **89.2%**，比同条件微调基线（84.6%）高 **4.6 个百分点**，主要来自度量位置（66.8→76.7）与运动（85.8→91.0）。
- **语言问答**：LingoQA **68.6%**，略高于微调基线 67.0%。
- **消融结论**：
  - 几何注入使 3DQA 从 84.6→87.5，加 UV 位置对齐再升至 89.2；LingoQA 67.0→67.6→68.6；
  - 潜在 CoT 逐组加入使 PDMS 90.1→90.5→90.7→91.0，再加几何注入达 **91.8**（EP 提升最大，+2.1）；
  - **有向掩码**（91.8）显著优于双向掩码（90.8），说明因果依赖顺序重要；
  - **跨候选交互评分 token** 相比 MLP 读出提升 **1.6 PDMS**（90.2→91.8），验证候选间相互比较的价值。
- **中层预测质量**：关键智能体类别 98.4%、ADE 0.
