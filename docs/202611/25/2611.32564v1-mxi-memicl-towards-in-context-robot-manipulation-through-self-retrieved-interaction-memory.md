## 摘要
上下文学习（ICL）为机器人提供了一种无需参数更新即可从单次演示中获取新技能的方法。然而，现有的机器人ICL方法要么依赖受稀缺且昂贵的机器人交互数据制约的大规模预训练，要么需要额外标注却难以跨任务泛化。为弥补这一差距，我们提出MXI-MemICL，一个面向视觉-语言-动作（VLA）模型的记忆引导ICL框架。通过将演示视为可检索记忆，MXI-MemICL无需额外大规模预训练或专门标注即可实现上下文操作。具体而言，视觉-动作因果编码器将演示和已完成交互中的动作及其观测效果转化为可复用记忆，以指导执行。为检索适合即将执行的经验，意图预测器预测下一阶段的意图，并用其查询记忆。检索到的经验通过经验标记前缀和门控交叉注意力对语言主干进行条件化，并通过学习到的门控调节其影响来指导动作生成。MXI-MemICL在RoboCasa365和RoboTwin 2.0上相较基线分别将成功率提升+8.2%和+14.4%。真实机器人实验显示+9.0%的提升，其中演示在已见任务上带来+5.0%、在未见任务上带来+16.7%的增益。代码将公开。

## Abstract
In-context learning (ICL) offers robots a way to acquire new skills from a single demonstration without parameter updates. However, existing robotic ICL methods either rely on large-scale pretraining constrained by scarce, costly robot interaction data or require additional annotations yet struggle to generalize across tasks. To bridge this gap, we propose MXI-MemICL, a framework for memory-guided ICL in vision-language-action (VLA) models. By treating demonstrations as retrievable memory, MXI-MemICL enables in-context manipulation without additional large-scale pretraining or specialized annotations. Specifically, a visual-action causal encoder turns actions and their observed effects in demonstrations and completed interactions into reusable memory to guide execution. To retrieve experience suited to upcoming execution, an intention predictor forecasts the next stage's intent and uses it to query memory. The retrieved experience conditions the language backbone through experience-token prefixes and gated cross-attention, guiding action generation with a learned gate that regulates its influence. MXI-MemICL improves success over the baseline by +8.2% and +14.4% on RoboCasa365 and RoboTwin 2.0. Real-robot experiments show a +9.0% gain, with demonstrations adding +5.0% on seen and +16.7% on unseen tasks. The code will be made publicly available.

- **背景**：VLA（视觉-语言-动作）模型与 WAM（世界-动作模型）在多种操作任务上表现强劲，但面对新目标、新物体、新环境时仍需“适配”。论文将现有适配策略归纳为三类（图1a）：
  - **任务特定后训练**：需反复采集新数据并更新策略参数；
  - **测试时训练（TTT）**：部署时仍需梯度优化，产生在线计算开销；
  - **上下文学习（ICL）**：从演示中适配、不更新参数，是更理想的路径。
- **现有机器人 ICL 的瓶颈**：
  - 一类方法沿用 GPT-3 范式，依赖大规模多样化物理交互数据预训练，而机器人交互数据稀缺、采集昂贵，难以扩展；
  - 另一类方法依赖自动生成的语义/运动标注来暴露演示结构，但对更难的未见任务泛化仍不足。
- **核心主张**：把“演示”当作**可检索的外部记忆**，让冻结的 VLA 在新任务上通过“检索—注入”复用已有经验，从而**无需额外大规模预训练、无需专门标注、部署时无参数更新、无在线梯度优化**。
- **整体含义**：将机器人 ICL 从“靠预训练涌现”转向“靠记忆组织与检索”，为 VLA 提供一种轻量、可插拔的测试时适配接口。

## 2. 方法论

### 2.1 核心思想
以 π0.5 为基座并冻结其参数，构建“**阶段编码 → 意图引导检索 → 双流经验注入 → 动作生成 + 下一步意图预测**”的闭环：把已完成交互（及可选的成功演示）编码为带检索键的记忆，用“当前阶段 + 预测的下一步意图”作为查询，取回相关经验并以经验令牌前缀与门控交叉注意力条件化语言主干。

### 2.2 关键模块与技术细节

- **问题形式化**：策略 π 在观测 ot、指令 ℓ、记忆库 Bt、先验意图 rt 条件下生成动作块 At；整体分解为“查询形成 → 经验检索 → 动作生成”三层概率（式1）。
- **阶段嵌入**：主干特征 Ht = Fθ(ot, ℓ)，均值池化得 ht；意图解码器输出归一化阶段嵌入 st = norm(ut + fcur(ht))，其中 ut 为 ht 的固定归一化投影（语义锚），fcur 为残差 MLP。
- **视觉-动作因果编码器**（借鉴 BehaviorVLA 的三流因果结构）：视觉流、动作流、交互状态流，GRU 时间混合器 + 同时间步跨流注意力；将执行的动作、执行前后观测、视觉变化、动作摘要融合为记忆 mt；检索键 kt 由 MLP 从 (ht, zt) 生成。记忆窗口含 4 个转移、每个转移 4 个控制，隐藏宽度 256，效果/检索表示宽度 128。
- **记忆库组织**：容量 64 对键-记忆；按新近度分为**短期记忆**（最近 n 条，表征正在进行的执行上下文）与**长期记忆**（其余）；FIFO 淘汰。
- **意图引导的门控查询**：qt = norm(st + αt(rt − st))，αt 为 sigmoid 学习门；q0 = s0。
- **n 槽软检索**：每个槽加一个学习偏移 dr，用余弦相似度匹配投影查询与键，温度 τ = 0.1 做 softmax；每槽检索后按 br+1,i = max(1e−6, br,i(1 − wr,i)) 衰减可用性，抑制重复命中、促进互补检索；无效记录掩码。
- **演示即记忆**：演示 D 与目标执行 E 来自同任务的不同源轨迹，分别由因果编码器编码；完整演示构成**只读**记忆库 BD，候选集 Ct = BD ∪ (BE<t \ Bshort)，与在线记忆共用同一检索与注入机制（算法1）。
- **双流经验注入**：
  - n 个学习查询（以 qt 为条件）分别对短期上下文与检索经验做注意力，拼接、融合、投影为经验令牌 Mt；
  - Mt 作为**前缀**拼接到观测/指令令牌之前；
  - 同时在 18 层主干的第 0/3/6/9/12/15 层施加**门控交叉注意力**：H′ = H + tanh(γl)·Attn(RMSNorm(H), Mt)，γl 初始化为 0，由学习决定注入强度。
- **下一步意图预测**：rt+1 = norm(qt + fnext(ĥt, qt))，ĥt 为经验令牌前缀位置的池化读出。
- **动作生成**：动作专家基于经验条件化的 KV 缓存，用流匹配采样动作块（每次预测 50 个控制，执行前 16 个）。

### 2.3 三阶段训练策略
- **Phase 1（交互编码）**：训练因果编码器预测执行动作与后续视觉特征，并加同任务对比、相位正则、效果监督等辅助目标；之后**冻结**，作为共享交互表示。
- **Phase 2（经验条件控制）**：冻结基座策略，联合优化意图建模与检索/融合/注入；损失 L = L_FM + λI·L_intent + λA·L_anchor（λI=0.1，λA=0.01）；意图损失对齐预测的 rt+1 与下一步语义锚 ut+1（余弦、stop-gradient），锚损失把查询 qt 锚定在当前观测上。
- **Phase 3（演示引导适配）**：从 Phase 2 权重出发，使用同任务的“演示–执行”配对；主干与编码器冻结，仅意图与记忆相关参数继续学习；未来执行观测只提供意图标签，检索/恢复/动作先验等辅助项关闭。
- **推理**：全部参数冻结；演示预编码为只读库；每次决策执行一次主干前向 + 检索 + 注入，输出动作块并提交完成的交互到在线记忆。

## 6. 主要结论与发现

- **成功率提升**：RoboTwin 2.0 Hard 上 51.9% vs π0.5 37.5%（+14.4），且在每个列出任务上优于所有 baseline；RoboCasa365 上 78.6% vs 70.4%（+8.2），优于 Xiaomi-Robotics-1（70.8%）与同基座复现的 Zeva（75.2%）；LIBERO 平均 98.1%（LIBERO-10 97.0% 为所列方法最高）。
- **真机**：平均 69.0% vs π0.5 60.0%（+9.0），五个任务全部第一；提升集中在电池插入（30→45）、积木归纳（85→95）、叠衣（60→70）等需要跟踪接触/进度/形变的任务。
- **演示的上下文增益**：已见任务 69.0%→74.0%（+5.0）；未见任务 25.0%→41.7%（+16

+16.7）个百分点。该结果说明：演示记忆对未见任务的相对增益更明显，但绝对成功率仍偏低，方法更多是在缓解“任务结构可识别、执行细节不稳定”的分布偏移，尚不能替代对新技能或新接触动力学的学习；已见任务增益较小（+5.0），则表明记忆接口在熟悉任务上的收益趋于饱和。

- **关键机制归因**：消融整体支持“时间多尺度 + 双流注入 + 意图引导检索”的组合必要性。短期记忆与长期记忆分别承担“当前执行上下文”和“可复用经验”的角色，单路配置均不及组合；令牌前缀与门控交叉注意力两条注入路径存在互补性，双路优于任一单路；以“当前阶段 + 预测下一步意图”为查询，优于仅用当前阶段查询或当前特征 top-k 检索；移除意图损失不仅削弱检索相关性，也会影响下一步意图预测质量。
- **效率与行为特征**：推理阶段每次决策仅执行一次主干前向、一次检索与注入，无在线梯度更新；延迟随记忆规模增长但整体可控。任务完成时间与成功率同步改善，说明增益并非来自“更慢、更保守”的执行策略。遮挡式视觉敏感性分析则显示性能会下降，表明记忆不能完全补偿关键感知线索缺失，方法仍依赖对当前观测的有效编码。
- **跨 benchmark 一致性**：RoboTwin 2.0、RoboCasa365、LIBERO 与真机平台均呈正向收益，说明“演示/经验即记忆”的即插即用接口具有一定跨域泛化性；但增益幅度随任务难度、演示相关性和基座表征质量变化，Hard 设置与长时任务上的提升更依赖记忆对进度和接触状态的跟踪。

## 7. 局限性与风险

- **性能上限受冻结基座约束**：方法不更新 π0.5 主干与动作专家，因而无法纠正基座表征或动作先验中的系统性错误；当新任务需要全新技能或显著不同的接触动力学时，记忆检索只能提供条件化线索，难以替代参数适配。
- **记忆组织与检索的级联风险**：阶段嵌入是检索键的核心组成，若阶段发现或下一步意图预测偏差较大，可能检索到语义相近但执行不适配的经验；FIFO 淘汰也可能冲刷掉低频但关键的长尾经验。
- **演示依赖与迁移边界**：演示需与目标任务同源，跨任务、跨本体或失败演示的利用尚未系统验证；Phase 3 仅继续学习意图与记忆相关参数，可能存在欠拟合或对演示质量敏感的问题。
- **评估统计功效有限**：真机每任务 20 次试验、部分仿真 baseline 直接取自 leaderboard，跨方法比较存在训练/评测设置不一致风险；部分增益的显著性证据偏弱，且消融主要集中于 RoboCasa365 的少量任务，跨 benchmark 的机制归因仍不充分。
- **工程与安全维度**：记忆库随任务与交互增长带来存储和检索开销，长期部署中的记忆污染、错误经验复用、隐私与安全约束尚未讨论；多臂协调、动态环境与开放世界长尾场景的验证仍有限。

## 8. 学术价值与启示

- **问题重构价值**：将机器人上下文学习从“依赖大规模交互预训练涌现”转向“对已有经验进行结构化记忆与检索”，为数据稀缺条件下的 VLA 测试时适配提供了新视角。
- **方法可插拔性**：冻结主干、仅学习意图与记忆接口的设计，使方法可作为轻量适配层叠加到现有 VLA/WAM 上，具备较好的工程复用潜力。
- **中间表征的可解释性**：阶段嵌入与下一步意图预测构成了介于语言指令与低层动作之间的可解释变量，为检索、进度跟踪和失败诊断提供了抓手。
- **统一离线演示与在线经验**：“演示即记忆”把示范数据与部署中产生的交互经验纳入同一检索—注入机制，为持续学习式的机器人操作提供了一种不更新参数的替代路径。

## 9. 总体评价

MXI-MemICL 的核心贡献不在于提出新的端到端 VLA 架构，而在于为冻结 VLA 设计了一套“阶段编码—意图引导检索—双流经验注入”的测试时记忆接口。实验覆盖仿真与真机、多任务与多 benchmark，主结果和消融总体支持其有效性；但绝对性能、统计显著性与跨任务迁移边界仍需更严格的统一复现和更大规模真机验证。总体而言，这是一项问题切入清晰、工程可复用性强、但证据强度仍可进一步加强的机器人 ICL 工作。
