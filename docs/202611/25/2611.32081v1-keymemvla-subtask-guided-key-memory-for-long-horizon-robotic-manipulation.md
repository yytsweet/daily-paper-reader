tldr: 长时程机器人操作需在有限记忆预算下保留能消解阶段歧义的历史。KeyMemVLA 用子任务引导关键记忆：两级标注选取满足进度指示或决策证据保留的子任务，将其末帧作为关键帧监督在线记忆写入，并由共享视觉-语言骨干联合学习子任务、动作与关键帧预测。推理时先推断当前子任务，再据此预测动作和未来记忆写入位置；在 RMBench-M(n)、RoboTwin-MeM、KMBench 及真实任务上平均成功率优于基线。该工作表明稀疏关键记忆与在线进度推断结合，可提升历史依赖控制。

## 摘要
依赖记忆的长时程操作要求视觉-语言-动作（VLA）策略推断任务进度，并回忆当前观测中缺失的证据。在有限记忆预算下，挑战在于保留能够消除阶段歧义并支持后续决策的历史信息。我们提出 KeyMemVLA，一种基于进度指示和决策证据保留的子任务引导关键记忆框架。两级标注过程选择满足任一条件的子任务，并将其最终帧标注为关键帧，以监督在线记忆写入。共享的视觉-语言主干联合学习子任务、动作和关键帧预测。在推理时，策略首先根据指令、视觉上下文和记忆预测当前子任务，然后利用该语义条件预测动作和未来记忆写入位置。执行过程中，在选定的时刻保留实际观测。我们引入 KMBench 来评估跨子任务决策中的主动记忆保留。在 RMBench-$M(n)$、RoboTwin-MeM、KMBench 和真实世界操作任务上的评估显示，相比对比基线具有更高的平均成功率。消融研究和表示分析支持关键记忆与显式任务进度语义的作用。这些结果突出了将稀疏关键记忆与在线进度推断相结合对于依赖历史的控制的价值。

## Abstract
Memory-dependent long-horizon manipulation requires vision-language-action (VLA) policies to infer task progress and recall evidence absent from current observations. Under a limited memory budget, the challenge is to retain history that resolves stage ambiguity and supports subsequent decisions. We present KeyMemVLA, a subtask-guided key memory framework based on progress indication and decision-evidence retention. A two-level annotation process selects subtasks satisfying either criterion and labels their final frames as keyframes to supervise online memory writes. A shared vision-language backbone jointly learns subtask, action, and keyframe prediction. At inference, the policy first predicts the current subtask from the instruction, visual context, and memory, then uses this semantic condition to predict actions and future memory-write positions. Actual observations are retained at the selected times during execution. We introduce KMBench to evaluate active memory retention for decisions across subtasks. Evaluations on RMBench-$M(n)$, RoboTwin-MeM, KMBench, and real-world manipulation tasks show higher average success rates than the compared baselines. Ablation studies and representation analysis support the roles of key memory and explicit task-progress semantics. These results highlight the value of coupling sparse key memory with online progress inference for history-dependent control.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型已能将预训练视觉/语言知识迁移到机器人控制，但**依赖记忆的长时程操作**还要求策略处理当前观测中缺失的信息。
- **核心矛盾**：以 "Find Heaviest" 为例，机器人依次称重四个盒子并放回原位，工作区外观在每次测量后重复出现，但秤的读数会消失。策略必须同时完成两件事：
  - **推断任务进度**：区分当前处于哪个阶段（哪些盒子已称过）；
  - **回忆历史证据**：在阶段已知的情况下，仍需调取早期读数以做比较决策。
- **现有方法的权衡**：观测序列、层次记忆、压缩隐状态、视觉记忆、稀疏记忆（KEMO、EventVLA、KeyframeChaining VLA）以及进度建模（TaskAnchor、ChainVLA、TFP、EventSync）各有覆盖，但**长历史带来高成本，压缩/稀疏选择又可能丢失后续所需的短暂线索**。
- **论文主张**：在有限记忆预算下，保留的观测应能提供"进度线索"或"决策证据"；需要把这种**任务相关的选择准则显式化**，并与阶段推断、动作生成协同起来。

## 2. 方法论

### 2.1 核心思想
- 记忆的价值取决于**子任务确立了哪些信息**以及**后续决策需要哪些信息**，据此提出两条选择准则：
  - **进度指示（Progress Indication）**：保留能区分外观相似阶段的线索；
  - **决策证据保留（Decision-Evidence Retention）**：即使阶段已知，也保留当前或后续决策所需的证据。
- 用**稀疏、按时间排序的关键帧记忆** $M_t$ 近似全历史最优策略：
  $$\pi^\star(\cdot \mid H_t, g) \approx \bar{\pi}(\cdot \mid VA_t, M_t, g),\quad C(M_t)\le B$$
  其中 $VA_t=(o_0,o_{\tau_1},\dots,o_{\tau_K},o_t)$ 为视觉锚点（初始帧 + K 个近期帧 + 当前帧），$B$ 为记忆预算。

### 2.2 两级标注与关键帧构造
- **第一级（关键子任务选择）**：满足任一准则的子任务被选为关键子任务（如"称重"入选，"放回"不入选）。
- **第二级（关键帧提取）**：仅将关键子任务的**最后一帧**标为关键帧，必要时细化子任务边界，使末帧捕获可观测结果或瞬态证据（如盒子+读数）。
- 关键帧时间戳 $K=\{e_k \mid k\in J\}$，$e_k$ 为关键子任务结束时刻。
- **半自动流程**：标注者依据代表性示范定义分割/选择规则 → 写成任务专用脚本 → 批量标注其余示范。
- **三种记忆模式**：`Image`（仅关键帧图像）、`ImageAndText`（图像+子任务描述）、`Text`（仅描述）；主方法采用 `Image`。

### 2.3 策略架构（Qwen-OFT，骨干 Qwen3-VL）
- **共享视觉-语言骨干**同时支撑三个头：
  - **子任务预测头（SPH）**：复用语言生成头，训练时用标注子任务文本做教师强制；
  - **动作头**：MLP 将动作查询表示 $Q_t=\mathcal{F}^\text{qry}_\theta(C_t,\ell_t)$ 映射为长度 $L$ 的连续动作块；
  - **关键帧预测头（KPH）**：以 $Q_t$ 为 query、当前主视图视觉嵌入 $O_t$ 为 key/value 做交叉注意力，经门控残差融合：
    $$\gamma_t=\mathrm{CA}(\mathrm{LN}_q(Q_t),\mathrm{LN}_o(O_t)),\ \alpha_t=\sigma([Q_t;\gamma_t]w_g+b_g),\ Q'_t=Q_t+\alpha_t\odot\gamma_t$$
    再由 MLP 输出每个未来位置的写入分数 $p_{t,j}$。
- **软目标监督**：以到最近标注关键帧的时间距离 $d_{t,j}$ 构造余弦软标签
  $$y_{t,j}=\frac{1+\cos(\pi d_{t,j}/r)}{2}\ (d_{t,j}\le r),\quad 0\ (d_{t,j}>r)$$
- **联合损失**：$\mathcal{L}=\lambda_\text{act}\mathcal{L}_\text{act}+\lambda_\text{sph}\mathcal{L}_\text{sph}+\lambda_\text{kph}\mathcal{L}_\text{kph}$，分别为 L1 动作回归、token 交叉熵、带正类权重 $\beta$ 的二元交叉熵。

### 2.4 在线推理流程
1. 每回合从空记忆 $M_0$ 开始；
2. SPH 自回归生成当前子任务 $\hat\ell_t$；
3. 以 $\hat\ell_t$ 为条件，动作头与 KPH 分别预测动作块 $A_t$ 与写入分数 $p_t$；
4. 若动作块内最高分超过写入阈值，则在实际执行到该时刻时保留观测写入记忆；
5. 时间过滤抑制邻近重复写入；按时间顺序保留，超预算时淘汰最旧条目；
6. **当前子任务文本每个决策周期重新预测，视觉关键记忆跨重规划持续保留**；重规划若替换未执行部分，则取消对应待写入事件。

  - **不足**：真实世界每任务仅 10 次试验，样本量偏小，任务间差异的统计显著性难以确立，论文也未报告置信区间或多种子方差；仿真虽每任务 100 次试验，但未说明随机种子数量与方差；缺少对记忆预算 $B$、写入阈值、软标签半径 $r$ 等关键超参的敏感性分析；缺少与"全历史但不加选择"的上界对照，因而难以量化稀疏化本身带来的信息损失；未报告标注关键帧的人工成本或标注一致性。

## 6. 主要结果与结论

- **KMBench**：KeyMemVLA 在四类记忆需求上整体取得最高或接近最高的平均成功率，尤其在"证据推理"（Calibrated Sort、Battery Charge）与"计数记忆"任务上优势更明显——这类任务的共同点是关键证据只在某一瞬间可见，验证了"保留决策证据"准则的必要性。相比之下，依赖稠密历史或压缩隐状态的方法在长时程下出现证据稀释，依赖稀疏/事件触发的方法则容易漏掉非事件性的短暂读数。
- **RoboTwin-MeM**：在需要保留交互中出现、随后消失的视觉证据的任务上优于 MemoryVLA、EventVLA、Mem-0 等记忆基线，说明"子任务末帧作为关键帧"的构造方式能较稳定地捕获瞬态证据。
- **RMBench**：在 M(n)（需多阶段记忆）任务上提升明显，在 M(1) 任务上与强基线持平或略优，表明方法未以牺牲短时程性能为代价换取长时程能力。
- **真实世界**：在 Find Heaviest、Press Button 等依赖历史读数/历史交互的任务上成功率高于对比方法；结合效率结果，说明方法在实机上以较小的延迟与显存增量换取了记忆能力。
- **消融**：
  - 去掉 **KPH** 后退化最大，说明"由动作查询驱动、预测何时写入"的学习式写入策略是性能关键，固定间隔或事件触发式写入无法替代；
  - 去掉 **SPH** 后性能下降，且线性探针显示动作查询表示对归一化时间进度的 MAE 明显变大，说明子任务预测不仅提供语义条件，还实质上帮助策略编码"任务进行到哪一步"；
  - **记忆模式**：`Image` 与 `ImageAndText` 接近且优于 `Text`，表明关键帧的视觉内容（读数、颜色、状态）是主要信息载体，文本描述只能部分替代；主方法选择 `Image` 是在性能与 token 成本间的折中。
- **效率**：由于记忆规模受预算 $B$ 约束且按时间淘汰，推理延迟与显存随回合长度增长基本可控，优于保留全历史的方法。

## 7. 优势、局限与讨论

- **主要优势**：
  1. **准则显式化**：把"该记什么"从隐式学习变为两条可陈述的准则（进度指示、决策证据），使记忆设计可解释、可复用；
  2. **两级标注 + 半自动流程**：先用少量示范定义规则、再脚本化批量标注，在标注成本与监督质量之间取得平衡；
  3. **写入策略学习化**：KPH 以动作查询为 query 预测未来写入位置，使"记什么"与"要做什么"耦合，而非独立于策略的启发式；
  4. **软目标监督**：余弦软标签缓解了关键帧稀疏导致的监督信号过少问题，让模型在关键帧邻域内也能获得梯度；
  5. **与阶段推断协同**：SPH 与记忆共享骨干，子任务文本既作为动作条件又作为记忆检索的语义锚点，二者互相增强。
- **局限与可讨论之处**：
  1. **依赖任务专用标注脚本**：第一级"关键子任务"的选择仍由人依据任务语义定义，跨任务泛化到全新任务类型时需要重新设计规则，自动化程度有限；
  2. **"末帧即证据"的启发式**：对证据在子任务中途出现、或需要保留多个时刻（如连续读数序列）的任务，单帧表示可能不足；
  3. **固定预算淘汰最旧条目**：在超长时程任务中，早期但关键的证据可能被淘汰，缺少基于重要性的淘汰机制；
  4. **实验统计强度**：真实世界试验次数少、未报告方差与显著性检验，结论的稳健性有待更强证据；
  5. **算力透明度不足**：未报告训练 GPU 数量与总时长，复现成本难以估计；
  6. **未讨论失败模式分类**：缺少对失败案例的定性分析（如写入时机错误、证据误选、阶段误判），不利于后续改进定位。

## 8. 总结与启示

KeyMemVLA 的核心贡献不在于提出新的记忆结构，而在于把"长时程操作中应当保留什么"这一模糊问题拆解为两条可操作准则，并通过"两级标注构造关键帧 + 动作查询驱动的写入预测 + 子任务预测头协同"将其落地为一个预算受限的稀疏记忆策略。实验在仿真与真实平台上覆盖了四类记忆需求，消融与线性探针共同支持了"KPH 决定写入时机、SPH 帮助进度编码"的机制解释。

对后续研究的启示在于：记忆选择准则与策略的阶段推断应当联合设计而非彼此独立；记忆的监督信号可以从示范中半自动提取，从而避免昂贵的人工逐帧标注；评价记忆方法时，除端到端成功率外，应补充表征层面的探针分析与预算/阈值敏感性分析，以区分"记住了"与"用上了"。
