## 摘要
训练后量化（PTQ）通过在小数据集上校准量化参数、无需重新训练来压缩大型视觉语言模型（LVLM）。然而，尽管校准策略日益复杂，现有方法在低位权重—激活量化下仍会出现显著性能下降。为理解这种性能下降，我们定位量化误差集中的位置，并考察相应的权重与激活分布。我们观察到，少数离群值主导了逐通道（PC）权重与逐令牌（PT）激活所共享的范围，导致大多数数值的分辨率不足，并将其中许多值映射为零。这些发现促使我们将关注点从校准细化转向底层的量化表示。因此，我们提出旋转与细化量化（Rotate-and-Refine Quantization，RRQ），作为一种简单而有效的 LVLM PTQ 基线，它结合了局部 Hadamard 变换、分组量化以及高效的组感知执行。在 8 个多模态任务和多种量化设置下，RRQ 显著优于基线，同时降低推理时间和内存占用。在 W4A4 下，它在 8B 模型上保留了超过 96% 的全精度性能，在 32B 模型上保留超过 99%，而这些基线不到 8%。源代码已公开于 https://github.com/kmc3661/RRQ。

## Abstract
Post-training quantization (PTQ) compresses large vision-language models (LVLMs) by calibrating quantization parameters on a small dataset without retraining. However, despite increasingly sophisticated calibration strategies, prior methods suffer substantial performance degradation under low-bit weight--activation quantization. To understand this degradation, we locate where quantization error is concentrated and examine the corresponding weight and activation distributions. We observe that a few outliers dominate the ranges shared by per-channel (PC) weights and per-token (PT) activations, leaving insufficient resolution for most values and mapping many of them to zero. These findings motivate a shift in focus from calibration refinement to the underlying quantization representation. We therefore present Rotate-and-Refine Quantization (RRQ) as a simple, effective baseline for LVLM PTQ, combining local Hadamard transforms with group quantization and efficient group-aware execution. Across 8 multimodal tasks and diverse quantization settings, RRQ substantially outperforms baselines while reducing inference time and memory usage. At W4A4, it retains over 96\% of full-precision performance on 8B models and over 99\% on a 32B model, compared with less than 8\% for these baselines. The source code is publicly available at https://github.com/kmc3661/RRQ

## 1. 核心问题与研究动机

- **背景**：大型视觉语言模型（LVLM）通过视觉编码器连接语言模型，在视觉问答、图像描述、多模态推理等任务上表现优异，但计算与内存开销巨大。训练后量化（PTQ）因无需重训练、仅需小规模校准集即可压缩模型，成为实用路径。
- **核心问题**：现有 LVLM PTQ 方法（MBQ、QIG、MASQuant、BFQ 等）不断细化“模态感知校准策略”，但在低比特权重—激活量化（尤其 W4A4）下仍出现**近乎灾难性的性能崩溃**（基线保留率不足 8%）。
- **关键诊断**：作者将误差定位到量化敏感模块（尤其是 down 投影），并观察其权重/激活分布，发现：
  - 同一权重通道内、同一 token 激活内，**极少数离群值**幅值远大于其余值（97.7%–99.99% 的值落在最大绝对值 10% 以内）；
  - 逐通道（PC）权重 / 逐 token（PT）激活量化让整条通道或整个 token **共享同一量化范围**，离群值撑大范围，导致主体值分辨率不足；
  - 在 4-bit 下，Qwen3-VL 示例中 **98.27% 的权重、99.71%/99.98% 的视觉/文本激活被映射为零**（zero-bin collapse）。
- **整体含义**：论文主张把研究重心从“校准策略精细化”转向**底层量化表示本身**——当大量数值已共享同一量化码时，仅调整其相对重要性无法恢复区分度。

## 2. 方法论：Rotate-and-Refine Quantization（RRQ）

### 2.1 核心思想
用**局部 Hadamard 变换**打散离群值主导的范围，再用**分组量化**为残余范围差异提供组专属尺度，最后通过**组感知高效执行**把额外表示开销压回可接受水平；校准仅用简单的均匀通道均衡（CWE）尺度搜索。

### 2.2 关键技术细节

- **预备：通道均衡（CWE）**
  - 对线性层激活 X 与权重 W 施加对角缩放 D：`XD = XD⁻¹`、`WD = WD`，保持 `XWᵀ` 不变但改变量化误差。
  - 候选 D 由通道平均绝对激活的归一化幂次构成（指数在 [0,1] 均匀取 20 个），按输出重建 MAE 最小选取：
    `D* = argmin_D MAE(QA(XD)QW(WD)ᵀ, XWᵀ)`。

- **局部 Hadamard 变换**
  - 对每 h 个输入特征组成的块施加正交旋转 `H_h`，输出 `x̃ⱼ = (1/√h) Σₖ sₖⱼ xₖ`，`sₖⱼ ∈ {−1,+1}`；每个输入以 ±xₖ/√h 扩散到块内所有输出。
  - 对缩放后的两个操作数同时施加 `R = diag(H_h, …, H_h)`，由 `XD R` 与 `WD R` 计算量化尺度；正交性保证 `(XD R)(WD R)ᵀ = XWᵀ`，**无需逆变换**。

- **分组量化**
  - 将变换后的权重行与激活 token 按 G 个特征分组，每组独立尺度。
  - 激活（对称）：`Δg = max_{k∈g}|zk| / Qa`，`qk = clip(round(zk/Δg), −2^{ba−1}, Qa)`，`ẑk = Δg qk`。
  - 权重（组仿射）：`uk = clip(round(wk/sg)+zg, 0, 2^{bw}−1)`，`ŵk = sg(uk − zg)`。

- **高效组感知执行**
  - 将 Hadamard 变换、分组激活量化与打包**融合为单一 kernel**，避免中间缓冲反复读写。
  - 专用 decode GEMV kernel：把组修正**融入整数累加**。采用 QServe 风格权重编码 + token 锚定激活尺度：
    `ŵok = co(mog uok + bog)`，`x̂tk = αt μtg qtk`；
    组内码点积 `Ptog = Σ qtk uok`、激活码和 `Stg = Σ qtk`；
    修正贡献 `Atog = μtg(mog Ptog + bog Stg)`，输出 `ŷto = αt co Σg Atog`。
  - 补充材料进一步给出：20 个均匀指数候选、离线权重重拟合（3 次交替更新、仅在误差下降时接受）、组乘子上限 8 以平衡精度与 INT32 累加范围。

## 6. 主要结论与发现

- **诊断结论**：LVLM 低比特 PTQ 崩溃的主因是**离群值主导的 PC/PT 共享量化范围**，导致大量主体值分辨率不足甚至被量化为零；down 投影是 W4A4 下的主要误差来源（单独恢复可回收 90% 以上 NLL 增量）。
- **方法结论**：Hadamard 变换 + 分组量化 + 高效执行可在**简单均匀 CWE 校准**下大幅恢复性能；一旦表示改善，复杂模态感知校准不再带来一致收益（表 5）。
- **性能结论**：
  - W4A4 下 8B 模型保留 **96.55%–98.16%**，32B 模型保留 **99.06%**，而基线不足 8%；
  - 32B 在 W4A6 下达到 **100%** 保留；
  - W4A8 下 8B 模型保留 99.23%–99.55%。
- **效率结论**：推理生成时间降低约 **32%–33%**、峰值内存降低约 **57%–59%**（相对 BF16），校准时间减少 40–91%，与优化后的 PC/PT 运行时开销相当。
- **总体主张**：LVLM 低比特 PTQ 应优先改进**量化表示与执行**，而非继续堆叠校准复杂度。

## 9. 启示与可拓展方向

- **研究范式的转移**：论文提示 LVLM 低比特 PTQ 的瓶颈已从“校准策略”转移到“量化表示容量”——当 98% 以上的数值被映射到同一量化码（zero-bin collapse）时，任何基于重要性的加权都无法恢复信息。这一诊断对多模态之外的其他大模型压缩（如长上下文 LLM、语音—文本模型）同样具有迁移价值。
- **旋转类方法与分组量化的组合潜力**：局部 Hadamard 与分组量化在本文中是互补而非替代关系（前者打散离群、后者吸收残余范围差异），这一“先旋转后分组”的范式可与 GPTQ/AWQ 类误差补偿、或与 QuaRot 的全局旋转做叠加研究，探索更优的旋转基（如学习式正交变换、Kronecker 分解）。
- **校准成本与表示质量的权衡**：既然简单均匀 CWE 搜索已足够，未来可研究“校准预算—表示自由度”的定量关系，甚至探索免校准（data-free）的旋转+分组方案，进一步降低部署门槛。
- **向 KV cache 与视觉编码器延伸**：down 投影被识别为主要敏感模块，提示视觉—语言投影层与 FFN 中间层应获得差异化比特分配；将该诊断方法（逐模块 NLL 恢复实验）推广到 KV cache 与视觉塔，可能带来新的压缩空间。
- **系统—算法协同设计**：本文的融合 kernel 与整数累加修正方案说明，量化算法的可行域受硬件累加位宽约束；未来可将组大小、组乘子上限等纳入与硬件协同的联合搜索，而非事后约束。

## 10. 总体评价

论文以扎实的误差诊断切入，指出 LVLM 低比特 PTQ 崩溃的根因在于逐通道/逐 token 共享量化范围导致的表示塌缩，而非校准策略不足；据此提出以局部 Hadamard 旋转 + 分组量化 + 组感知高效执行为核心的 RRQ，在仅使用简单均匀通道均衡校准的前提下，将 W4A4 下的性能保留率从基线不足 8% 提升至 96.55%–99.06%，同时在生成时间、峰值内存与校准时间上均取得实质收益。方法简洁、可检验性强、工程落地性突出，主要局限在于校准数据单一、硬件依赖较强与部分复现信息缺失。整体而言，这是一篇**问题诊断与工程实现俱佳、并带有明确方法论主张**的量化研究论文。
