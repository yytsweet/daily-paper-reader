## 摘要
低位量化可降低大型语言模型（LLM）的内存占用与推理成本，但精确的FP4量化仍颇具挑战。MXFP4、NVFP4和HiF4等实用格式将4位浮点载荷与分块或分层尺度码配对，使得精度对每个局部分布的缩放方式高度敏感。默认的最大绝对值缩放虽保留了动态范围，却可能将稀缺的FP4级别耗费在极少被占据的离群区域上，并导致稠密张量值的分辨率不佳。现有尺度搜索方法最小化局部逐元素重建误差，优化的是张量保真度而非层输出保真度。我们提出SoScale，一种用于分层FP4量化的二阶权重尺度码搜索方法。SoScale在Hessian感知的层重建目标下搜索硬件有效的尺度码，并将该搜索与GPTQ风格的误差恢复相结合，依据尺度对层输出的影响来选择尺度。在Qwen3系列模型上，SoScale在MXFP4、NVFP4和HiF4下均能持续降低下游量化退化。

## Abstract
Low-bit quantization reduces the memory footprint and inference cost of large language models (LLMs), yet accurate FP4 quantization remains challenging. Practical formats such as MXFP4, NVFP4, and HiF4 pair a 4-bit floating-point payload with block-wise or hierarchical scale codes, making accuracy highly sensitive to how each local distribution is scaled. Default maximum-absolute-value scaling preserves dynamic range, but can spend scarce FP4 levels on rarely occupied outlier regions and leave dense tensor values poorly resolved. Existing scale-search methods minimize local element-wise reconstruction error, optimizing tensor fidelity rather than layer-output fidelity. We propose SoScale, a second-order weight scale-code search method for hierarchical FP4 quantization. SoScale searches hardware-valid scale codes under a Hessian-aware layer reconstruction objective and couples this search with GPTQ-style error recovery, selecting scales by their impact on layer outputs. Across Qwen3 models, SoScale consistently reduces downstream quantization degradation under MXFP4, NVFP4, and HiF4.

## 1. 核心问题与研究动机

- **背景**：LLM 部署受显存与推理成本制约，训练后量化（PTQ）是主流压缩手段。FP4 因每值仅 4 bit、保留指数动态范围且可硬件加速而受关注；MXFP4、NVFP4、HiF4 等实用格式进一步引入**分块或分层 scale 码**来适配 LLM 权重/激活的非均匀分布。
- **核心痛点**：FP4 载荷只有 16 个可表示值，block scale 决定这些量化等级落在实数轴的何处，因此精度对 scale 码选择高度敏感。
  - 默认 **max-abs 缩放**为覆盖最大幅值而扩张网格，可能把稀缺等级耗费在极少占据的离群区域，导致零附近稠密值分辨率不足。
  - 论文在真实 Qwen3-8B 的 MXFP4 权重块上展示：默认缩放下最外两个可表示等级**没有任何赋值**（离群值被舍入到次内层），而搜索得到的 scale 将网格收缩到占据区域；排序后两端绝对误差几乎不变，中间（近零）区域误差显著下降。
- **现有方法局限**：分布重塑（SmoothQuant、QuaRot、SpinQuant、Block Rotation）、误差补偿（GPTQ、ARCQuant）、FP4 专用 scale 启发式（Four Over Six、ScaleSearch）大多以**局部块重建误差/MSE** 为 scale 选择目标，优化的是张量保真度而非**层输出保真度**。论文图 1c 显示：降低局部逐元素误差并不必然降低困惑度。
- **研究含义**：应把 scale 码选择视为**层重建问题**而非局部张量拟合问题，在硬件合法码空间内按其对层输出的影响来选码。

## 2. 方法论

### 2.1 核心思想
- 在目标 FP4 格式的**合法 scale 码集合**内搜索，用 **Hessian 加权的层重建损失**评分，并与 **GPTQ 式二阶误差恢复**交错执行；权重离线量化，推理阶段无搜索、完全保留原 FP4 编码。

### 2.2 关键技术细节
- **层重建目标**：对线性层 $Y=XW^\top$，量化权重 $\hat W$ 的误差为
  $L(W,\hat W)=\|XW^\top-X\hat W^\top\|_F^2=\sum_i e_i^\top H e_i$，其中 $H=X^\top X$ 为校准激活的经验 Hessian。对层输出影响大的权重误差受更大惩罚。
- **格式统一抽象**：每行沿输入维分块，块量化写作 $\hat w_{i,b}(c)=Q_F(w_{i,b};c)$，$c\in C_F$ 为合法 scale 配置；payload 仍按格式标准舍入/裁剪，SoScale 只改 scale 码。
  - MXFP4：E2M1 payload + E8M0 块指数，$s(c)=2^c$，$\hat w=s(c)\Pi_{\text{E2M1}}(w/s(c))$。
  - NVFP4：搜索 E4M3 块 scale 码，FP32 张量 scale 固定。
  - HiF4：搜索 E6M2 scale 码并派生 E1 scales。
- **块局部二阶代理**：取 Hessian 子矩阵 $H_b=H_{I_b,I_b}$，块误差 $e_{i,b}(c)=w_{i,b}-\hat w_{i,b}(c)$，评分
  $\ell_{i,b}(c)=e_{i,b}(c)^\top H_b e_{i,b}(c)$。
  若 $H_b=I$ 即退化为局部平方误差；用经验 Hessian 则按校准激活对误差及其相关性加权。逐行-块取 $c^\star_{i,b}=\arg\min_{c\in C_{i,b}}\ell_{i,b}(c)$，候选集 $C_{i,b}$ 为默认 scale 码附近的**小偏移窗口**（如 $c_0-2$ 至 $c_0+2$）并裁剪到合法范围，避免组合爆炸。
- **二阶误差恢复**：计算阻尼逆 Hessian 的上三角因子 $U^\top U=(H+\lambda I)^{-1}$。设当前块列索引 $Q$、未来列 $F$：
  1. 在补偿权重上搜索 $c^\star_Q=\arg\min_{c_Q\in C_Q}\ell_Q(c_Q)$；
  2. 提交 $\hat W_{:,Q}=Q_F(\tilde W_{:,Q};c^\star_Q)$；
  3. 块误差 $E_Q=\tilde W_{:,Q}-\hat W_{:,Q}$；
  4. 回代传播 $\tilde W_{:,F}\leftarrow\tilde W_{:,F}-E_Q U^{-1}_{Q,Q}U_{Q,F}$。
  已提交块固定，仅更新工作副本，使后续块的 scale 搜索发生在**已含补偿的参数空间**中。
- **激活侧**：在线动态 per-token FP4，$c^{act}_{t,b}=D_F(x_{t,b})$，用逐元素 MSE 轻量选码，与权重搜索解耦。
- **整体流程**：估计 Hessian →（可选）预处理变换 $W\leftarrow WR,\ H\leftarrow R^\top HR$ → 计算 $U$ → 按 FP4 块顺序执行"搜索—提交—传播"→ 输出 FP4 payload 与合法 scale 码。推理仅需存储的 payload、scale 码与逐 token 激活 scale。

## 6. 主要结果（定性归纳）

- **整体趋势**：在 W4A4 下，SoScale 在 MXFP4、NVFP4、HiF4 三种格式、两个模型规模上普遍优于 RTN、GPTQ 与 ScaleSearch，任务平均分更接近 BF16；相对 BF16 的保留比例在三种格式间较为稳定，说明方法不依赖某一特定 scale 编码。
- **与局部 MSE 方法的分野**：ScaleSearch 以块内平方误差选码，论文结果显示其局部误差更低但下游任务未必更好，呼应图 1c "局部保真度 ≠ 层输出保真度"的论点；SoScale 用 Hessian 加权把误差按其对层输出的敏感度重新排序，因而在相同 payload 约束下取得更好的端到端表现。
- **与分布重塑的兼容性**：与 block Hadamard（`w/ Had.`）组合时，SoScale 通常仍带来额外增益，说明"预处理改变分布"与"在合法码空间内按层目标选码"是正交的两类手段，可叠加使用。
- **direct-activation 设置**：当激活退化为直接 RTN 后，方法间差距的构成发生变化，SoScale 相对基线的优势主要来自权重侧选码，验证了权重 scale 搜索的独立贡献，而非仅由激活侧在线规则带来。
- **格式差异**：HiF4 因分层 scale 结构（E6M2 派生 E1）码空间更大，搜索收益的发挥空间也更大；NVFP4 的 E4M3 块 scale 码空间较粗，收益更多体现在近零区域分辨率与离群块处理上；MXFP4 的 E8M0 指数码为 2 的幂，搜索主要表现为整体网格的收缩/平移。

## 7. 机制分析与消融要点

- **scale 码的偏移方向**：搜索得到的码普遍偏离 max-abs 默认值，向"收缩网格以覆盖稠密占据区"的方向移动；这与图 1 中"外层等级空置、近零区误差下降、两端误差基本不变"的现象一致，说明收益来自等级利用率的重分配而非简单扩大动态范围。
- **Hessian 加权的作用**：将 $H_b$ 替换为单位矩阵即退化为块内 MSE 选码；论文的对比用于论证"按层输出敏感度加权"是性能提升的关键，而非仅靠候选窗口搜索本身。
- **二阶误差恢复的必要性**：去掉"搜索—提交—传播"交错、改为逐块独立选码后再统一补偿，会削弱后续块在已补偿参数空间中选码的优势；该消融用于分离"选码目标"与"误差回代"两个来源的贡献。
- **候选窗口的敏感性**：窗口过窄可能错过更优码，过宽则增加搜索成本且受块局部代理近似误差影响；论文以 $c_0\pm2$ 一类小窗口在效果与组合复杂度之间折中。
- **块局部代理的合理性**：用 $H_b$ 近似全层 Hessian 的对角块，忽略了跨块耦合；交错回代在一定程度上补偿了这一近似，但仍是方法的主要误差来源之一。

## 8. 结论

- 论文主张：FP4 量化的 block scale 码选择应被建模为**层重建问题**，在目标格式的合法码空间内、以 Hessian 加权的层输出损失为目标进行搜索，并可与 GPTQ 式二阶误差恢复交错执行。
- 方法仅改动 scale 码、不改 payload 编码规则，推理阶段零额外开销，因而对 MXFP4/NVFP4/HiF4 等不同 scale 编码具有较好的可移植性。
- 实验表明该视角在 W4A4 下优于以局部 MSE 为目标的 scale 搜索与常规 PTQ 基线，并能与旋转类预处理叠加。
