## 摘要
近期为提升多模态大语言模型（MLLMs）效率的研究探索了视觉 token 剪枝、量化和特征压缩。然而，决定变换后的视觉 token 是否仍能被冻结解码器使用的性质尚未得到充分刻画。我们提出 TIVS（Token Identity Versus Statistics），一个无需训练的干预框架，在受控条件下分别研究序列置换、token 保留、数值精度和统计替换。在 192 个 POPE 问题上，三种 token 置换平均仅使 TinyLLaVA 准确率变化 -0.17 个百分点，却改变了 4.69% 的个体预测。在相同子集上，对角替换和秩为 64 的高斯替换分别使准确率下降 25.0 和 28.1 个百分点。结合精确矩约束、量化误差、token 保留以及其他视觉任务的进一步实验，揭示了这些效应在多大程度上依赖原始特征值和评估设置。这些发现为评估冻结 MLLMs 中的视觉 token 变换以及设计更可靠的多模态接口提供了经验基础。

## Abstract
Recent efforts to improve the efficiency of multimodal large language models (MLLMs) have explored visual token pruning, quantization, and feature compression. However, the properties that determine whether transformed visual tokens remain usable by a frozen decoder are not well characterized. We introduce \textbf{TIVS (Token Identity Versus Statistics)}, a training-free intervention framework that separately studies sequence permutation, token retention, numerical precision, and statistical replacement under controlled conditions. On 192 POPE questions, three token permutations change TinyLLaVA accuracy by only $-0.17$ percentage points on average, while changing 4.69\% of individual predictions. Diagonal and rank-64 Gaussian replacements decrease accuracy by 25.0 and 28.1 points on the same subset. Further experiments with exact moment constraints, quantization error, token retention, and additional visual tasks reveal how strongly the effects depend on the original feature values and the evaluation setting. These findings provide an empirical basis for assessing visual token transformations in frozen MLLMs and designing more reliable multimodal interfaces.
