## 摘要
视觉-语言模型（VLM）中高效的思维链（CoT）推理需要同时减少中间推理步骤及其执行开销。潜在CoT方法将文本推理依据压缩为连续思维，但其全精度（FP）模型仍保留大量存储和计算开销。降低数值精度可以减少这些剩余开销，但直接量化会严重降低推理准确率，尤其是在4比特权重和激活下。算子与扰动分析揭示了连续思维误差的关键敏感性及方向依赖的预测效应，这促使我们超越重建精度，保持信息检索与后续推理。因此，我们提出QL-VLM，一种面向视觉-语言模型（VLM）高效潜在推理的动态感知量化框架。首先，动态引导量化（DGQ）使用保持旋转键结构的非均匀码本，减轻视觉-语言信息检索中量化引起的失真。其次，动态保持蒸馏（DPD）将连续思维、潜在查询读出和预测与全精度教师对齐，从而在后续低精度推理中保持预测一致性。在ScienceQA-IMG上，使用Qwen2-VL-2B-Instruct，4比特QL-VLM达到90.43%的准确率，较基线提升40.33%，与显式CoT相比，比特运算量减少为原来的1/16.64，实测延迟降低为原来的1/6.40。

## Abstract
Efficient chain-of-thought (CoT) reasoning in vision-language models (VLMs) requires reducing both intermediate reasoning steps and their execution cost. Latent CoT methods compress textual rationales into continuous thoughts, yet their full-precision (FP) models retain substantial storage and computation costs. Lowering numerical precision could reduce these remaining costs, yet direct quantization severely degrades reasoning accuracy, particularly with 4-bit weights and activations. Operator and perturbation analyses reveal key sensitivity and direction-dependent predictive effects of continuous-thought errors, motivating preservation of information retrieval and subsequent reasoning beyond reconstruction accuracy. We therefore introduce QL-VLM, a dynamics-aware Quantization framework for efficient Latent reasoning in Vision-Language Models (VLMs). First, Dynamics-Guided Quantization (DGQ) uses nonuniform codebooks that preserve rotary-key structure, mitigating quantization-induced distortion in vision-language information retrieval. Second, Dynamics-Preserving Distillation (DPD) aligns continuous thoughts, latent-query readouts, and predictions with a full-precision teacher, maintaining predictive consistency through subsequent low-precision reasoning. On ScienceQA-IMG with Qwen2-VL-2B-Instruct, 4-bit QL-VLM achieves 90.43% accuracy and improves baseline by 40.33%, with 16.64x fewer bit-operations and 6.40x lower measured latency than explicit CoT.

## 1. 核心问题与研究动机

- **背景**：多模态思维链（CoT）让 VLM 通过中间推理依据整合视觉证据与文本知识，但推理成本沿两个方向增长：
  - **解码步数**：显式 CoT 在 MMStar 上用 Qwen3-VL-8B 生成 142.1 个推理 token 需 7.24 s，而编码输入仅 0.47 s；thinking 类模型单样本输出可达数千 token（Kimi-VL-Thinking 约 4.4K）。
  - **每步成本**：每个 token / 思维都要经过数十亿参数骨干网络的前向计算，权重、激活、注意力历史均以全精度存储与读写。
- **已有工作的割裂**：token 剪枝、简洁推理目标、潜在 CoT（latent CoT，如 CODI）只压缩第一轴（步数）；低比特量化（PTQ/QAT）只压缩第二轴（每步成本）。二者**并非可加性叠加**。
- **关键现象（本文的出发点）**：在 ScienceQA 上用 Qwen2-VL-2B，全精度潜在 CoT 把生成从 56.28 token 压到 6 个思维 + 6 个答案 token，但模型仍占 4.89 GB，理论单答案算力只降 8%（223.10 → 205.65 TBitOps）；而把潜在 CoT 量化到 W4A4，准确率从 **79.97% 崩到 11.16%**，即便量化感知训练（QAT）也只恢复到 **50.10%**。
- **原因解释**：显式 CoT 中量化误差只扰动单个 token，且立刻被重新编码为离散符号；潜在 CoT 中连续思维被**回灌为下一步输入嵌入**，其缓存的 key 又持续可被后续 query 访问，误差因此沿后续推理链传播并影响答案。
- **两项诊断性分析**（决定方法设计）：
  - **算子敏感性**：Linear-only 量化 73.49%，Attention 操作数量化 40.16%，两者同时量化 11.16%。固定 Linear 为 W4A4 后，仅把 **K** 从 4 bit 提到 8 bit 即从 11.16% 升到 **70.35%**，而 Q / V / P 分别只有 18.74% / 17.65% / 33.41% → **key 精度是主瓶颈**。
  - **扰动敏感性**：用答案 logits 的总 Jacobian 构造预测 Fisher 度量，发现同等范数扰动引起的 KL 差异中位达 **2.82 倍**；方向感知估计与实测 KL 的 Spearman 相关为 **0.999**，而仅按幅度排序只有 **0.270** → **预测影响取决于方向而非仅幅度**，因此"重建误差"是错误的优化目标，应保留的是后续步骤所检索的信息与消费这些信息的推理过程。

## 2. 方法论：QL-VLM

### 2.1 总体框架
- 在 CODI 式的视觉-语言潜在推理基础上做低比特量化：显式 CoT 与隐式 CoT 分支共享全精度参数，隐式分支用 T 个连续思维替代文本推理，由可学习 `<bot>` / `<eot>` 界定；每个思维经两层 MLP + LayerNorm 投影后作为下一步输入嵌入。
- 两个组件分别对应上述两项诊断：**DGQ**（动态引导量化，保 key 结构与检索）+ **DPD**（动态保持蒸馏，保后续推理轨迹）。

### 2.2 动态引导量化（DGQ）
- **分组**：码本组 $g=(l,\kappa,a,\xi)$，即语言层、KV 头、M-RoPE 轴（temporal / height / width）、key 来源（text / image / latent$_1$…latent$_T$）。latent 来源按 key **被创建时的推理步**标记，与其后被哪个 query 读取无关。
- **预测敏感度量**：对每组用采样到的原始 key 对的 Fisher 块平均，加迹缩放的各向同性阻尼，再用**统一迹归一化因子**除以所有组（保留组间相对敏感性），得到正定度量 $H_g$。因旋转保持长度但不保度量各向同性，需在原始坐标下用 $F(k)=R(\phi)^\top F(\tilde k)R(\phi)$。
- **极坐标非均匀码本**：按 token 与 KV 头做尺度归一 $\gamma_j=\max_d\|k_{j,d}\|_2$（下限 $10^{-8}$），$\bar k=k/\gamma$；每组学习半径项 $\rho_{g,\mu}\in[0,1]$ 与相位项 $\psi_{g,\nu}\in[-\pi,\pi)$，码字 $C_g(\mu,\nu)=\rho_{g,\mu}(\cos\psi_{g,\nu},\sin\psi_{g,\nu})^\top$，其中一个半径项固定为 0。
- **码字选择**：最小化 Mahalanobis 失真 $(\bar k - C_g(\mu,\nu))^\top H_g(\bar k - C_g(\mu,\nu))$；重建 $\hat k=\gamma_j C_g(\mu^\star,\nu^\star)$ 后施加真实 M-RoPE 旋转得到注意力 key 操作数。尺度因子 $\gamma_j^2$ 对所有候选失真等比例，故在分配时抵消，但在拟合共享码本时保留。
- **校准**：交替进行码字分配、半径闭式更新、周期性相位优化。
- **QAT 损失**：$L_{key}=\tfrac12 \mathbb{E}_{call}[\mathbb{E}_{k|call}[(\hat k-k)^\top H_g(\hat k-k)]]$，$H_g$ 固定，也用于推理期码字选择，不需要来自未来 query 的梯度。
- **配置**：主配置 b=4，一对 key 用 8 个逻辑索引比特（每个原始分量 4 bit），不对特定组提精度；4-bit 用 16×16 码字的**分块联合搜索**，8-bit 用坐标搜索。

### 2.3 动态保持蒸馏（DPD）
- 教师为全精度潜在 CoT（含其适配器与推理投影），训练中冻结于 eval 模式。
- **潜在查询读出对齐**：对学生/教师按层 $l$、头 $h$、推理步 $i$、来源 $s\in\{\text{image},\text{history}\}$ 计算读出 $r=\sum_{j\in J_{i,s}}\hat P \hat V$ 与 $r^\star=\sum P^\star V^\star$，用按 $\|r^\star\|_2^2/D$ 归一化的 Smooth-L1 惩罚，并按 $w_i=\mathrm{tr}(G_i)/Z_F$ 加权（$Z_F=\max(\tfrac1T\sum_i \mathrm{tr}(G_i),10^{-20})$）。Softmax 在概率量化之前、在完整可见历史上做来源选择，不做分来源重归一化。
- **敏感性加权思维对齐**：$L_{roll}=\frac{1}{2TZ_F}\sum_{i=1}^T (z_i-z_i^\star)^\top G_i (z_i-z_i^\star)$，$G_i$ 为 $F(z_i^\star)$ 的对角校准估计，作为固定的局部近似，不保证最终预测 KL 单调下降。
- **答案级监督**：改造后的 $\tilde L_{ans}=L_O+\lambda_p L_P+\lambda_e L_E$（分别对应选项 token、答案模板、终止 token 的位移预测位），加温度 $\tau$（默认 1）的全词表 KD：$\tau^2/|O|\sum_{n\in O}\mathrm{DKL}[\mathrm{sg}(\mathrm{softmax}(u^\star_n/\tau))\|\mathrm{softmax}(u^Q_n/\tau)]$；保留显式 CoT 交叉熵 $L_{cot}$ 与边界对齐 $L_{bd}$（对教师显式 CoT 边界激活做参考标准差归一化的 Smooth-L1）。显式推理依据仅用于该训练分支。
- **总目标**：$L=L_{CODI}+\lambda_{KD}L_{KD}+\alpha_m[\lambda_{key}L_{key}+\chi M_{ref}(\lambda_{read}L_{read}+\lambda_{roll}L_{roll})]$；$\alpha_m$ 逐步激活辅助监督，$\chi\sim\mathrm{Bernoulli}(1/M_{ref})$ 做微批采样以降低开销，乘 $M_{ref}$ 保持期望贡献不变。
