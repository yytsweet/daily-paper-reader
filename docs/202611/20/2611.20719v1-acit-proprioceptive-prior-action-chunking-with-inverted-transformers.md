## 摘要
视觉运动策略将动作预测条件化于视觉和本体感觉观测。历史本体感觉序列蕴含丰富的动力学先验，但当前方法将其与高维视觉同等对待，导致本体感觉信号被淹没。为识别等条件融合中丢失的信息，我们分析本体感觉数据，发现强关节间耦合是决定动作的关键结构。这一发现与神经感觉运动环路一致：本体感觉先形成以身体为中心的先验，视觉随后通过顶叶重映射进行校准。受此启发，我们提出 ACiT（Proprioceptive-Prior Action Chunking with Inverted Transformers），将历史关节耦合强化为主要条件，并以视觉作为后续校准。该设计通过三个模块实现：Inverted State Encoding 通过逐关节 token 和关节间自注意力构建本体感觉先验；State-Visual Grounding 使关节 token 查询视觉证据，使视觉仅用于目标和校准；Inverted Action Chunking 独立解码逐关节轨迹。ACiT 在大多数 LIBERO、RoboTwin 2.0 和真实世界任务上提高了成功率，在需要动力学和协调的任务上增益最大。将相同条件设计迁移到 VLA 主干 pi_0-ACiT，在更好执行效率下取得显著增益。

## Abstract
Visuomotor policies condition action prediction on visual and proprioceptive observations. While historical proprioceptive sequences carry rich dynamic priors, current methods treat them as equal to high-dimensional vision, causing the proprioceptive signal to be overwhelmed. To identify what is lost in equal-conditioning fusion, we analyze proprioceptive data and find that strong inter-joint coupling is the key action-determining structure. This finding aligns with the neural sensorimotor loop, in which proprioception first forms a body-centered prior and vision is later calibrated via parietal remapping. Inspired by this, we propose ACiT, Proprioceptive-Prior Action Chunking with Inverted Transformers, which reinforces historical joint-coupling as the primary condition with vision as a later calibration. This design is instantiated through three modules: Inverted State Encoding builds a proprioceptive prior via per-joint tokens and inter-joint self-attention. State-Visual Grounding lets joint tokens query visual evidence, making vision goal- and calibration-only. Inverted Action Chunking decodes per-joint trajectories independently. ACiT improves success rates on most LIBERO, RoboTwin 2.0, and real-world tasks, with the largest gains on those that require dynamics and coordination. The same conditioning design transferred to the VLA backbone pi_0-ACiT yields significant gains with better execution efficiency.
