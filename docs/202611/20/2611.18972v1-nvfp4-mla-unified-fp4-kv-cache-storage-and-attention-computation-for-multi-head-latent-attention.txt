NVFP4-MLA: Unified FP4 KV-Cache Storage and Attention
Computation for Multi-Head Latent Attention
Chao Ni1, Qi Zhang1, Xiao Wang1, Zongfei Jing1, Mingyang Hao1, Binghan Chen1, Kefeng Duan1, Yu-Jung Chen1, Mengdi
Wang1, Tijmen Blankevoort1 and Jun Yang1

Long-context reasoning and agentic workloads make key-value (KV) cache capacity and attention computation the dominant
costs of serving frontier large language models. We present NVFP4-MLA, the first design to push both KV-cache storage
and attention computation of multi-head latent attention (MLA) to FP4. NVFP4-MLA co-designs the quantization algorithm
with the attention kernel and the cache system. Selective residual compensation preserves model accuracy by adding NVFP4
residuals only to the quantization-sensitive channels. Two-dimensional quantization blocks make the shared latent cache
compatible with the different reduction directions of the two attention batched matrix multiplications (BMMs), removing
requantization between them. On DeepSeek-R1 and Kimi-K3, NVFP4-MLA matches BF16 MLA average accuracy across
nine benchmarks while compressing the MLA KV cache by 3.20× and 3.05× relative to BF16 MLA. On NVIDIA Rubin
GPUs, NVFP4-MLA speeds up the attention kernel over FP8 MLA by up to 2.82× on DeepSeek-R1 and 2.71× on Kimi-K3,
and lowers p90 time to first token in agentic multi-turn serving by up to 3.5× and 2.1×, respectively. In disaggregated
DeepSeek-R1 serving, it also raises per-GPU throughput by up to 2.30×.
1. Introduction
Multi-head latent attention (MLA) represents keys and values in a shared low-rank latent space and is the common attention
pattern of several popular open-source large language models, including DeepSeek-V3 (DeepSeek-AI, 2024b), DeepSeek-
R1 (Guo et al., 2025), Kimi-K2.6, Kimi-K3 (Kimi Team, 2026), and LongCat-Flash (Meituan LongCat Team, 2025), which
use MLA in all or part of their attention layers. The low-rank latent shrinks the key-value (KV) cache, but the cache still grows
with sequence length and serving concurrency, and every decoding step reads all of it, which puts pressure on both memory
capacity and bandwidth. Agentic workloads sustain this pressure across turns and tool calls because they preserve and reuse
growing contexts, which keeps the KV cache resident for longer. When GPU memory cannot hold these caches, the server
evicts them and recomputes the prefix in the next turn, which increases time to first token. A smaller cache allows longer
contexts, keeps more tokens and requests in GPU memory, reduces cache eviction and recomputation, and increases serving
concurrency.
Beyond memory, computation can also be under pressure. In grouped-query attention (GQA), each KV head serves only
the few query heads in its group, whereas all MLA heads share the latent cache during decoding, so MLA performs more
computation per cached byte (Appendix B). Model-native multi-token prediction (MTP) verifies several queries against the
same latent cache. Reusing the cache across these queries raises arithmetic intensity further and makes MLA decoding
compute-bound (Section 4.4.2), so math throughput matters as much as cache bytes. Together, these pressures motivate us
to apply NVFP4, a 4-bit format that recent NVIDIA Tensor Cores support natively, to both KV-cache storage and attention
computation in MLA, so that MLA benefits from smaller storage and higher math throughput.
We introduce NVFP4-MLA, which brings unified NVFP4 storage and attention computation to MLA. Its design addresses the
challenges of applying FP4 quantization directly to MLA. First, direct FP4 quantization degrades accuracy. Outliers in the
MLA cache concentrate in the last few channels, so selective residual compensation adds an NVFP4 residual only to these
channels and keeps all elements in FP4 (Section 4.2.2). Second, MLA shares one latent representation between keys and
values. Default block-wise quantization groups this latent along channels, which matches the channel reduction of the first
batched matrix multiplication (BMM1) but not the token reduction of BMM2. NVFP4-MLA introduces two-dimensional
quantization blocks that are compatible with both reduction dimensions and therefore remove the need to requantize the shared
latent cache for the second BMM (Section 3.3). Third, the higher arithmetic intensity makes math throughput a bottleneck.
NVFP4-MLA therefore also quantizes queries and softmax scores online, so both BMMs run on native FP4 Tensor Cores
and exploit the higher FP4 math throughput. A corresponding cache system and kernel pipeline implement this design, and

Our main contributions are:
1. We design selective residual compensation, which keeps model accuracy by adding NVFP4 residuals to quantization-
sensitive channels without mixed precision.
2. We design two-dimensional quantization blocks and a corresponding cache system that let the shared quantized
representation serve both BMMs without requantization.
3. We build an efficient kernel pipeline. The pipeline quantizes queries and softmax scores online, so both BMMs benefit
from the higher throughput of FP4 Tensor Cores.
We evaluate NVFP4-MLA on two frontier open MLA models, DeepSeek-R1 and Kimi-K3, across nine benchmarks that
span reasoning, coding, instruction following, long context, and agentic tool use. NVFP4-MLA matches BF16 MLA average
accuracy on both models while reducing the MLA KV cache by 3.20× and 3.05× relative to BF16 MLA. On NVIDIA
Rubin GPUs, NVFP4-MLA speeds up the attention kernel over FP8 MLA by up to 2.82× on DeepSeek-R1 and 2.71× on
Kimi-K3. In the AgentX benchmark, the smaller cache lowers p90 time to first token by up to 3.5× and 2.1×, respectively. In
disaggregated DeepSeek-R1 serving on the MLPerf and 8K/16K Reasoning workloads, per-GPU throughput reaches up to
2.30× that of FP8 MLA, and is 26.7% and 39.9% higher on average, respectively.

quantization blocks, and the corresponding cache system and kernel pipeline. Section 4 evaluates the accuracy, memory

2.1. Multi-head latent attention

The shared latent is involved in both BMMs. The first, BMM1 (QK), reduces over latent channels to generate attention logits,
and the second, BMM2 (PV), reduces over cached tokens to generate the output. The same cached values are therefore reduced
along two directions, so their block scales must serve both BMMs.
As Appendix B shows, MLA performs more computation per cached byte than a grouped-query attention (GQA) reference.
Matrix absorption reduces cache traffic and reuses the latent cache for every query head. Model-native MTP raises arithmetic
intensity further when the kernel reuses the cache across several query positions. MLA decoding therefore tends to be
compute-bound.
2.1.2. NoPE and RoPE channels serve different roles: Applying rotary position encoding (RoPE) (Su et al., 2024) directly
to the compressed keys would break matrix absorption, because the rotation depends on each token’s position (DeepSeek-AI,
2024a). MLA therefore carries RoPE on a decoupled path, with additional per-head queries and a single key shared by all
heads. Each cached token thus holds a 𝑑𝑐= 512-channel compressed latent, which we call NoPE, and a 𝑑R = 64-channel
decoupled key, which we call RoPE. In BMM1, each head adds the NoPE and RoPE dot products to form its attention logit,
whereas BMM2 aggregates only the NoPE latent. Kimi-K3 keeps this decoupled layout but applies no positional encoding to
either path (Kimi Team, 2026); we still call its decoupled channels RoPE.
2.2. NVFP4 format and KV-cache quantization
KV-cache quantization reduces per-token storage by encoding cached values with fewer bits (Liu et al., 2024). To keep
accuracy, prior methods redistribute large outliers through rotations, preserve selected outliers separately, or assign different
bit widths across tensors and layers (Hooper et al., 2024; Li et al., 2025; Su et al., 2025; Zandieh et al., 2026). Beyond
accuracy, using the quantized cache directly in low-precision BMMs requires a compatible hardware format. We therefore use
block-scaled NVFP4 for both cache storage and attention computation.
NVFP4 and MXFP4 both encode values in 4-bit E2M1 and attach a shared scale to each block (Rouhani et al., 2023; NVIDIA,
2025). NVFP4 uses an E4M3 scale per 16 values, whereas MXFP4 uses an E8M0 power-of-two scale per 32 values. NVFP4’s
smaller blocks and non-power-of-two scales give finer control over local value ranges.
These formats have mostly been studied for weight and activation quantization (Egiazarian et al., 2026). For KV caches, their
use also depends on how attention consumes the quantized values. When compute precision differs from storage precision,
attention needs an extra dequantization step. Computing directly on the stored values avoids this step, but each BMM then
requires the quantized values and scales in a compatible layout. This requirement links the block layout to the reduction axes of
the attention BMMs. In GQA, separate key and value caches can adopt independent block layouts. In MLA, by contrast, both
BMMs reduce the same latent cache along different axes, which couples their block layouts. A shared MLA cache intended for
native FP4 computation therefore requires quantization blocks that support both reduction directions.
3. Methodology
NVFP4-MLA makes the shared latent a direct operand of both FP4 attention BMMs. Selective residual compensation reduces
quantization error without mixed precision, two-dimensional quantization blocks align quantization with both reduction axes,
the efficient kernel pipeline handles online quantization, and the corresponding cache system supports end-to-end integration.

3.2. Selective residual compensation
FP4 quantization error in the MLA cache is disproportionately large in the RoPE partition (Section 4.2.2). NVFP4-MLA
therefore keeps a single NVFP4 component for NoPE but adds a second NVFP4 component only for the RoPE quantization
error. Because the RoPE partition holds 64 of the 576 latent channels, the residual adds little storage and computation;
Section 4.2 evaluates the accuracy of NVFP4-MLA.
The native kernel packs RoPE and its quantization error separately with independent NVFP4 block scales, logically concatenates
them along the reduction dimension of BMM1, and duplicates the corresponding channels. The compensated logits, which
replace 𝑆in Equation 2, therefore take a single BMM1 reduction, without merging base and residual into a high-precision
tensor.
3.3. Two-dimensional quantization blocks for shared keys and values
As Section 2 shows, the shared MLA latent requires scales that work in both reduction directions. A conventional one-
dimensional layout aligns its blocks with BMM1 but not with native NVFP4 BMM2 (Figure 2a). Converting this layout requires
dequantizing the cached E2M1 values, transposing them, and requantizing them into BMM2-aligned blocks. Requantization
introduces additional quantization error. It also adds overhead such as memory traffic, a scale reduction, and synchronization
before BMM2.
NVFP4-MLA therefore quantizes the shared NoPE latent in two-dimensional 16 × 16 blocks over tokens and channels
(Figure 2b). One scale covers every 16-element row and column segment of a block, so the block is valid in either reduction
direction: both BMMs share the same NVFP4 values and scales without a high-precision intermediate or a requantization pass.

Balancing FP4 score construction and accumulator rescaling. Fusion shortens the logit-to-score path, but this stage
still carries more non-matrix work than its FP8 MLA counterpart. Rather than dedicate separate warp groups to FP4 score
construction and online-softmax accumulator rescaling, we partition each logit tile across the warp groups. Each group
constructs the FP4 score operand for its logit partition and also rescales a complementary partition of the resident BMM2
accumulator when the running maximum changes. This mixed assignment keeps the logit-to-score stage from serializing the
pipeline.
Reusing FP4 score operands across BMM2 output tiles. Each packed FP4 score slice contributes to multiple BMM2 output
tiles. The kernel uses the Tensor Core operand-reuse mechanism to retain thiŝ︀𝑃operand of BMM2 across these tiles instead
of reloading it for each tile, so more execution bandwidth remains for FP4 score construction.
Shape-adaptive CTA scheduling. With MTP, each request has more queries, so the kernel can use larger matrix multiply-
accumulate (MMA) tiles. It gives each cluster of thread blocks (cooperative thread arrays, CTAs) the packed query rows of one
request; the CTAs of a cluster split the KV tiles, exchange the FP4 scores through distributed shared memory, and use the same
FP4 operands and softmax. At long KV lengths, the kernel also splits the KV of a request into pieces that run on idle streaming
multiprocessors (Figure 1c) and merges them with a reduction kernel.
3.5. End-to-end integration
For end-to-end integration, we adapt the cache system to be compatible with two-dimensional quantization blocks, the NVFP4
attention kernel, paged KV caches, and speculative decoding (Figure 1d). During prefill, a fused quantize-and-scatter kernel
writes completed NVFP4 blocks into paged storage, which decode reads without requantization. Disaggregated serving
transfers only these pages, namely the E2M1 values and their scales, plus the BF16 tail of the incomplete last block. During
decode, a fused pre-attention kernel applies RoPE where the model uses it, updates a 16-token BF16 ring, quantizes the
operands, and writes the cache. Each request owns a stable slot in the ring, and the runtime refreshes the active NVFP4 block
from BF16 values and finalizes the block once it fills. It therefore never has to dequantize a block, append newly generated
tokens, and requantize it, which would introduce additional quantization error. For speculative decoding such as MTP, the
runtime snapshots the BF16 ring before speculative writes, commits accepted candidates, and restores locations overwritten
by rejected candidates. Completed NVFP4 pages remain unchanged during rollback, so rejected tokens cannot contaminate
persistent state. NVFP4-MLA has been integrated into TensorRT-LLM (NVIDIA, 2026).

4.1. Experimental setup
Accuracy. Both models use the same nine tasks, spanning reasoning, coding, instruction following, long context, and agentic
tool use (Table 1). RULER and MRCR use a 128K-token context. We compare NVFP4-MLA with BF16 MLA, FP8 MLA,
and vanilla NVFP4 MLA. BF16 MLA keeps the KV cache and attention BMM computation in BF16. FP8 MLA quantizes
the KV cache and attention BMM computation to E4M3. Vanilla NVFP4 MLA quantizes them directly to NVFP4 without
residual compensation.
Storage. We count the stored MLA cache. DeepSeek-R1 uses NVFP4 in all 61 MLA layers. Kimi-K3 uses NVFP4 in 22 of its
24 MLA layers and FP8 in the final two; the count excludes the recurrent state of its 69 Kimi Delta Attention (KDA) layers.
Performance. All performance experiments run on NVIDIA Rubin GPUs, and serving runs use TensorRT-LLM with the same

5. Related work
KV-cache quantization. Most previous work focuses on quantizing the KV cache to reduce its footprint and memory traffic.
KIVI (Liu et al., 2024) quantizes keys per channel and values per token, keeping the most recent tokens in full precision.
KVQuant (Hooper et al., 2024) quantizes keys per channel before RoPE and keeps outliers in a sparse format. KVTuner (Li
9


NVFP4-MLA: Unified FP4 KV-Cache Storage and Attention Computation for Multi-Head Latent Attention
et al., 2025) searches layer-wise mixed precision for keys and values. RotateKV (Su et al., 2025) and TurboQuant (Zandieh
et al., 2026) rotate cached vectors to spread outliers before low-bit quantization. Serving systems such as Atom (Zhao et al.,
2024) and QServe (Lin et al., 2025) also store 4-bit KV caches alongside low-bit weights and activations. These methods
target separate key and value caches rather than MLA’s shared latent representation. They also execute the attention BMMs at
higher precision, which adds dequantization overhead for the cached values and limits MLA decoding once MTP makes it
compute-bound (Section 4.4.2). NVFP4-MLA instead stores a shared MLA cache in NVFP4 whose scale blocks match both
reduction directions, so both BMMs read it in FP4 without dequantization and run at FP4 Tensor Core throughput.
Quantized attention kernels. Low-precision attention kernels quantize attention operands to run the attention BMMs on faster
low-precision Tensor Cores. SageAttention (Zhang et al., 2025b) quantizes queries and keys to INT8 for the 𝑄𝐾⊤BMM and
keeps the 𝑃𝑉BMM mostly in FP16. SageAttention3 (Zhang et al., 2025a) runs both BMMs in NVFP4, quantizing FP16
queries, keys, and values inside each attention call, and mainly targets image and video generation. SnapMLA (Zhang et al.,
2026) pushes MLA computation to FP8 with a per-token FP8 latent cache and keeps the RoPE channels in BF16. NVFP4-MLA
pushes it further to FP4 and combines low-precision storage and computation: both BMMs consume the persistent NVFP4
MLA cache without dequantization, and the RoPE channels are quantized to NVFP4 with residual compensation rather than
kept in high precision.
Evaluation scope. Prior KV-cache quantization studies evaluate non-MLA models of limited size, mostly with perplexity,
short-generation tasks, or long-context retrieval (Liu et al., 2024; Hooper et al., 2024; Li et al., 2025). These settings do not
test long reasoning traces or multi-turn agentic sessions, where quantization error can accumulate over thousands of generated
tokens. We instead evaluate large MLA reasoning models with a broader set of tests, spanning downstream accuracy on
reasoning and agentic tasks, cache footprint, and kernel and end-to-end serving performance, to understand how NVFP4-MLA
affects both model quality and efficiency.
6. Conclusion
We have presented NVFP4-MLA, which shows that NVFP4 can serve as both the storage format and the compute format
of MLA. Selective residual compensation targets quantization outliers and greatly reduces the accuracy drop of direct FP4
quantization, and two-dimensional quantization blocks let one shared latent cache supply both BMMs. We also design
a corresponding cache system and an efficient kernel pipeline. NVFP4-MLA matches BF16 MLA average accuracy on
DeepSeek-R1 and Kimi-K3, speeds up the attention kernel over FP8 MLA by up to 2.82× and 2.71×, lowers p90 time to first
token in agentic multi-turn serving by up to 3.5× and 2.1×, and raises per-GPU throughput in disaggregated DeepSeek-R1
serving by 26.7% and 39.9% on average on two workloads and by up to 2.30×. By computing attention in FP4 while preserving
accuracy, NVFP4-MLA turns KV-cache compression into real inference speedups.
