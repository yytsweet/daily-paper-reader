## 摘要
现有智能体式操作系统将预训练的视觉-语言-动作（VLA）策略视为不透明的、仅支持语言的原语：当策略调用在陌生指令或场景扰动下失败时，智能体无法引导其行为，只能进行无效重试或代价高昂的人工接管。我们提出InteractVLA，一个通过与视觉-语言智能体的双向几何接口，将预训练的基于流的VLA转化为可几何引导且可检查的工具的框架。在前向方向上，测试时几何引导通过可微的命令到位姿映射，将智能体指定的末端执行器目标经由动作专家转化为输入梯度；而软时间目标对齐将到达时间视为潜在执行索引，以匹配目标位姿，同时不扭曲策略的接近运动。在反向方向上，动作信息驱动的智能体式细化将生成的动作块和校准后的相机重投影暴露给智能体，使其能够诊断空间差异、为后续VLA调用修正目标，或在引导轨迹之上局部调整运动片段。使VLA可控不仅提升了在线智能体式工具使用，还解锁了有效的递归自我改进（RSI），在LIBERO-Plus上达到99.4%、在RoboDojo上达到48.62%、在RoboCasa365上达到89.4%的最先进性能。项目页面：https://lingwupro.github.io/InteractVLA/。

## Abstract
Existing agentic manipulation systems treat pretrained vision-language-action (VLA) policies as opaque, language-only primitives: when a policy call fails under unfamiliar instructions or scene perturbations, the agent cannot steer its behavior and is forced into futile retries or costly manual takeover. We present InteractVLA, a framework that turns pretrained flow-based VLAs into geometrically steerable and inspectable tools through a bidirectional geometric interface with vision-language agents. In the forward direction, test-time geometric guidance translates an agent-specified end-effector target into input gradients through the action expert via a differentiable command-to-pose mapping, while soft-time target alignment treats arrival time as a latent execution index to match the target pose without distorting the policy's approach motion. In the reverse direction, action-informed agentic refinement exposes generated action chunks and calibrated camera reprojections back to the agent, allowing it to diagnose spatial discrepancies, revise targets for subsequent VLA calls, or locally adjust motion segments on top of the guided trajectory. Making the VLA controllable not only boosts online agentic tool use, but also unlocks effective recursive self-improvement (RSI), achieving state-of-the-art performance of 99.4\% on LIBERO-Plus, 48.62\% on RoboDojo, and 89.4\% on RoboCasa365. ## 1. 核心问题与研究动机

- **背景**：智能体式机器人操作通常采用"分工"范式——视觉语言智能体（VLM/LLM Agent）负责长程推理与任务分解，预训练 VLA 策略负责生成时序连贯的底层动作。
- **核心痛点**：现有系统把 VLA 当作**不透明、仅接受语言指令的黑箱原语**，智能体无法干预策略"如何执行"。
  - 失败后简单重试几乎无效，因为相同观测下策略会生成几乎相同的动作；
  - 改写语言指令往往把 VLA 推出分布，成功率反而骤降（图1）；
  - 结果智能体只能退化为"兜底监督者"，被迫人工接管底层控制。
- **关键洞察**：即使语言指令或场景布局导致 VLA 无法定位正确目标，其预训练的空间感知与运动先验（平滑接近轨迹、协调旋转、抓取时机）依然有效。只要显式地把末端执行器引导到正确目标，同一策略就能完成任务。
- **整体含义**：需要从"仅语言调用"升级为**双向几何接口**——智能体能下发显式空间目标来引导动作生成，也能反过来检查动作提案以修正后续执行。

## 2. 方法论

### 2.1 核心思想
将基于流匹配（flow-matching）的预训练 VLA 改造为**可几何操控、可检查**的在线工具，VLA 本身保持冻结，全部在测试时完成：
- **前向（Agent → VLA）**：智能体给出稀疏目标位姿 \(G_k=(p^*,R^*,w^*)\)（位置、朝向、夹爪状态），通过可微映射转为去噪过程的输入梯度。
- **反向（VLA → Agent）**：把生成的动作块、已执行前缀、剩余动作与标定重投影回传给智能体，用于诊断与局部修正。

### 2.2 测试时几何引导（前向）
- 由单步干净动作估计 \(m_t = x_t + (1-t)v_\theta(x_t,t;c_k)\)，经**可微命令到位姿映射** \(C_{ok}\) 得到命令位姿。
- 完整位姿误差 \(E_h\) 聚合归一化的位置、旋转、夹爪差异（双臂在共享索引上求和）。
- 引导梯度 \(g_t = \nabla_{x_t} L_t(C_{ok}(m_t), G_k)\)，更新式：
  \[
  x_{t+\Delta t} = \mathrm{sg}\left[x_t + \Delta t\,(v_\theta - B_t(g_t))\right]
  \]
  其中 \(B_t\) 缩放并限幅梯度（相对原生速度）、限定在内部活动窗口；`sg[·]` 停止梯度使每步只对当前专家求导。
- **低置信度提前拒绝**：置信度 \(C_t=\exp(-\max(r_t/r_0,\,d_t/d_0))\)，若首步后 \(C_t<e^{-1}\) 则终止生成、交还智能体重规划，避免不兼容目标扭曲生成。

### 2.3 软时间目标对齐
- 问题：固定步惩罚会强行假设到达时刻；对所有步均匀惩罚会把接近轨迹整体拉向目标（"过早匹配"破坏接近运动）。
- 方案：把到达时间视为**潜在执行索引**，令 \(\tau=1-t,\ \beta_t=t^2/\tau^2\)，用 log-sum-exp 聚合：
  \[
  L_{\text{soft}}(t)=-\tau^2\log\!\Big(\tfrac{1}{H}\sum_{h=1}^{H}\exp[-\beta_t E_h]\Big)
  \]
- 梯度得到时间分配 \(q_h(t)=\mathrm{softmax}_h(-\beta_t E_h)\)，最终引导为
  \[
  L_{\text{guide}}(t)=\tfrac{\tau}{t}L_{\text{soft}}(t),\quad
  g_t=t\tau\sum_h q_h(t)\nabla_{x_t}E_h
  \]
- 位置/朝向/夹爪误差共享同一时间权重 \(q_h(t)\)，保证在**统一步骤**匹配完整位姿；随去噪推进 \(\beta_t\) 增大，\(q_h\) 在最佳匹配步上锐化，到达时刻自然浮现。

### 2.4 动作信息驱动的智能体式细化（反向）
- 不只回传二值成败，而是暴露完整动作块、已执行前缀、剩余动作与观测历史。
- 通过**标定相机重投影**把预测命令位姿映射到相机帧，与观测物体位置、历史像素运动、RGB-D 反投影对比，区分"目标偏移"与"执行滑移/过早抓取"。
- 两条轻量恢复路径：
  1. 目标本身不准 → 修正 \(G_k\)，重新调用引导 VLA 生成全局一致的新动作块；
  2. 轨迹结构已正确 → 复用提案，用机器人控制工具做局部调整（接近偏移、抬升高度、夹爪释放时机）。
- 结合低置信度拒绝，形成闭环：几何目标引导生成，生成提案指导下一步修正。

## 3. 实验设计

- **骨干模型**：MR-0（Meituan-Robotics-0）作为统一的预训练流式 VLA。
- **智能体模型**：GPT-6 Astra（推理更强、API 更贵）用于 RoboDojo / RoboCasa365 的 RSI；GPT-6.1 Sol（更经济）用于在线工具使用与 LIBERO-Plus。
- **Benchmark（仿真）**：
  - **LIBERO-Plus**：6 类扰动（背景、光照、语言、噪声、布局、相机、机器人初始位姿）+ 总体。
  - **RoboDojo**：双臂操作，5 维度（泛化、精度、长程、记忆、开放式）。
  - **RoboCasa365**：大规模家庭操作，Atomic-Seen / Composite-Seen / Composite-Unseen。
- **真实世界**：Dexmal 平台 4 个任务（桌面整理、竖立瓶子、倒水、移动方块），每任务 50 条演示训练 MR-0 骨干，每方法 30 次试验。
- **三种引导模式**：GT 引导（训练数据参考位姿）、离线引导（复用固定智能体预测目标）、在线引导（迭代更新目标 + 运动细化）。
- **对比方法**：
  - 独立 VLA：MR-0、OpenVLA-OFT、π0、π0-FAST、RIPT-VLA、Meituan-Robotics-0；
  - 智能体/VLA 系统：HarnessVLA、RV-ICL、PhysicalRSI、WorldScape-R2SI、HexaShell-Preview、HexaShell 1.5、GPT-6 Astra（纯 Agent）。
- **消融**：
  - 时间对齐 4 种变体（固定末步、全步均匀、硬最小、软时间）；
  - 反馈设计 3 档（仅观测、+生成动作、+重投影）；
  - 推理效率对比（Agent+VLA、Agent+InteractVLA、Agent Only）。

## 6. 主要结论与发现

- **SOTA 性能**：LIBERO-Plus **99.4%**、RoboDojo **48.62%**、RoboCasa365 **89.4%**，均超过独立 VLA 与现有 Agent+VLA 系统。
- **几何引导即可解锁潜在能力**：即使不做在线重规划，仅用显式位姿目标引导独立 VLA，LIBERO-Plus 从 88.5% 提升至 91.3%（GT）/94.5%（离线 Sol）。
- **在线闭环收益最大**：LIBERO-Plus 上语言-only Agent+VLA 93.1% → InteractVLA 98.3%，布局扰动 89.5%→98.4%、相机扰动 87.6%→98.4%；RoboDojo 18.0%→26.0%。
- **软时间对齐是关键**：消融中软时间在三个 benchmark 全面最优（99.4/48.6/89.4），显著优于固定末步（96.8/39.1/83.0）与全步均匀（95.6/34.7/79.8）。
- **动作反馈 + 重投影必要**：仅观测 → +动作块 → +重投影，RoboDojo 40.3→44.8→48.6，RoboCasa365 84.1→87.0→89.4。
- **RSI 有效**：智能体通过实践 rollout 诊断失败、固化可复用策略并迁移到未见评测场景；随经验积累，执行步数与 token 增长放缓、成功率上升。
- **真实世界全面提升**：如桌面整理 65.5→92.5 分且 API 调用减半；移动方块 97.6 分、执行时间降 59
