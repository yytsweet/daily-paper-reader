## 摘要
视觉-语言-动作模型（VLA）通过在机器人示范数据上微调预训练的视觉-语言模型（VLM）得到，从而能够根据视觉观察和语言指令进行动作预测。然而，这种微调会引发灾难性遗忘，显著削弱原始 VLM 的语义与视觉 grounding 能力。我们通过在不重新训练任一模型的情况下合并 VLM 与其 VLA 衍生模型的参数来解决这一问题。具体而言，我们提取任务向量（VLA 与 VLM 权重之差），并通过奇异值分解对其进行分解。对于每个分量，我们学习一个标量混合系数，控制保留多少 VLA 适配，并以同时保持动作预测和视觉-语言能力为目标进行优化。实验表明，我们的合并模型在两个维度上同时表现良好，持续优于已有的合并基线。

## Abstract
Vision-Language-Action models (VLAs) are obtained by fine-tuning pre-trained Vision-Language Models (VLMs) on robot demonstration data, enabling action prediction from visual observations and language instructions. However, this fine-tuning induces catastrophic forgetting, substantially degrading the semantic and visual grounding capabilities of the original VLM. We address this by merging the parameters of a VLM and its VLA derivative without retraining either model. Concretely, we extract the task vector (the difference between VLA and VLM weights) and decompose it via Singular Value Decomposition. For each component, we learn a scalar mixing coefficient controlling how much of the VLA adaptation is retained, optimised to jointly preserve action prediction and vision-language capabilities. Experiments show that our merged model performs well on both axes simultaneously, consistently outperforming established merging baselines.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作模型（VLA）通常由预训练 VLM（如 PaliGemma-3B）在机器人示范数据上微调得到，从而能根据视觉观察与语言指令直接输出低层动作。这类模型是构建通用机器人智能体的重要基础。
- **核心矛盾**：微调会引发**灾难性遗忘**——动作目标逐步覆盖编码视觉-语言理解的权重方向，使 VLA 在低层控制上很强，却丧失语义推理与视觉 grounding 能力（例如面对“描述场景”的提示只能输出碎片化词串或乱码）。
- **现有方案的不足**：
  - 冻结 VLM、只训练轻量动作模块：限制表征对具身控制的充分适配；
  - 训练时混入文本任务 / 对齐动作与语言表征（co-training）：需大规模联合训练，成本高，且难以事后应用于已微调好的 VLA；
  - 模型合并（Model Soup、SLERP、DARE、AdaMerging 等）：成本低，但**朴素均匀混合对所有参数一视同仁**，忽视不同权重矩阵在两种能力中的异质角色，导致语言与动作的折衷次优（实验中多数基线在动作上直接崩到 0%）。
- **论文目标**：在**不重训任一源模型**的前提下，通过参数合并同时恢复 VLM 的视觉-语言理解并保留 VLA 的动作预测能力，即"让语言回归动作"。

## 2. 方法论

### 2.1 核心思想
把 VLM→VLA 的微调视为一个**任务向量**，并将其按奇异值分解为若干正交的“适配方向”，对**每个方向单独学习一个标量混合系数**，从而在比“全局标量”或“逐层标量”更细的粒度上，区分哪些方向承载语言能力、哪些承载动作能力。

### 2.2 关键技术细节（文字化流程）
1. **提取任务向量**：对每个共享层 $l$，$\Delta^{(l)} = \theta^{(l)}_{VLA} - \theta^{(l)}_{VLM}$；合并模型等价于 $\theta^{(l)}_{merged} = \theta^{(l)}_{VLM} + \alpha^{(l)}\Delta^{(l)}$，即对任务向量做缩放。
2. **SVD 分解**：$\Delta^{(l)} = \sum_{k=1}^{r^{(l)}} \sigma_k^{(l)} u_k^{(l)} v_k^{(l)\top}$，每个奇异三元组代表一个独立的适配方向；可按秩 $r$ 截断，只保留前 $r$ 个分量。
3. **逐分量系数**：将单一 $\alpha^{(l)}$ 替换为 $\alpha_k^{(l)} \in [0,1]$，最终合并式为
   $\theta^{(l)}_{merged} = \theta^{(l)}_{VLM} + \sum_k \alpha_k^{(l)} \sigma_k^{(l)} u_k^{(l)} v_k^{(l)\top}$。
   - 所有 $\alpha_k=0$ → 退化为纯 VLM；所有 $\alpha_k=1$ → 完全恢复 VLA；全部相等则退化为全局标量合并（Model Soup 的特例）。
   - VLA 特有部件（动作头）不参与合并，直接继承。
4. **优化目标**（仅 $\alpha$ 可训练，两源模型与 SVD 全部冻结）：
   $L(\alpha) = \lambda_1 L_{text} + \lambda_2 D_{KL}(\pi_\alpha \| \pi_{VLM}) + \lambda_3 L_{act} + \lambda_4 D_{KL}(\pi_\alpha \| \pi_{VLA})$
   - $L_{text}$：语言数据集上的负对数似然；
   - $L_{act}$：自回归 VLA 用动作 token 的 NLL，flow-matching VLA 用条件流匹配损失；
   - 两个 KL 项分别把合并模型锚定到 VLM 分布与 VLA 分布（flow-matching 侧用高斯近似速度场，采样 16 个噪声，闭式 KL）。
5. **训练配置**：Adam，学习率 0.01 + 余弦衰减，20,000 步，batch size 2，$\alpha$ 以 Uniform(0,1) 初始化，SVD 幂迭代 4 次。

### 2.3 理论/实证解释
论文给出一个重要的**尺度不对称性**洞见：语言相关方向集中在少数主导奇异方向上，动作相关方向则弥散在大量弱分量中——这解释了为何均匀合并能部分恢复语言却在动作上崩溃。

## 6. 主要结论与发现

- **主结果**：合并模型是唯一在三轴（语言、具身推理、动作）上同时不崩的方法。
  - Ours$_{\pi0.5}$：ROUGE-L 29.5 / BERTScore 87.8 / VQAv2 48.7（VLM 上界 33.6 / 88.9 / 53.8），LIBERO 成功率 89.3 / 88.1 / 93.3（纯 VLA 88 / 90 / 96），几乎无损地保住了动作能力。
  - Ours$_{\pi0FAST}$：18.6 / 82.1 / 28.9，LIBERO 61.2 / 73.1 / 79.8（纯 VLA 70 / 82 / 88），恢复程度弱于 π0.5，作者归因于自回归头中语言与动作 token 共享、相互纠缠。
  - 所有固定系数基线（Model Soup、DARE、SLERP）在 LIBERO 上基本崩到 0%，AdaMerging 虽恢复语言（28.1 ROUGE-L）但动作几乎全失（6.2 / 2.9 / 3.7）。
- **粒度是决定性因素**：逐分量 $\alpha$ 在 $L_{text}$、$L_{act}$ 与两个 KL 上全面优于逐层 $\alpha$（动作侧差距约一个数量级），说明单层内的语言方向与动作方向纠缠，粗粒度无法解耦。
- **秩的不对称性（核心科学发现）**：语言恢复在 $r=16$ 即饱和（ROUGE-L ≈30），而动作保持需 $r \ge 1024$ 才超过 90% 成功率；$r=1024$ 仅需 269,443 个参数。即**语言能力集中于少数主导方向，动作适配弥散于大量弱分量**。
- **$\alpha$ 分布佐证**：主导方向（$k$ 小）的平均 $\alpha$ 接近 0（π0.5 在 $k<200$ 时严格为 0），随秩索引单调上升至约 0.65–0.8，两种骨干一致。
- **损失项作用**：去掉 $L_{act}$ → 动作 0%；去掉 $KL_{VLM}$ → 语言崩至 7.9 ROUGE-L（该 KL 是语言保持的主要锚点，$L_{text}$ 单独不足）；去掉 $KL_{VLA}$ → 动作降至 71.5%；四项互补，完整目标取得最佳联合折衷。
- **权重空间定位**：合并模型在全部 602 层上同时比两源模型彼此更接近（余弦相似度高于 VLM–VLA 基线），且始终更靠近 VLA，说明它不是简单插值，而是找到了一个“同时邻近两个源”的位置。

## 7. 优点

- **方法轻量且真正 post-hoc**：两源模型完全冻结，只优化约 3.8×10⁵ 个标量，3 小时单卡可完成，可直接用于已微调好的 VLA，无需架构改动或混合数据共训。
- **粒度设计的动机清晰**：从“全局标量 → 逐层 → 逐奇异分量”的递进逻辑自然，且用消融与 $\alpha$ 分布双重证据证明细粒度的必要性，而非仅凭最终指标。
- **跨动作解码范式验证**：同时在自回归（π0-FAST）与 flow-matching（π0.5）上验证，并为后者专门设计了基于高斯速度场近似的 KL 估计，工程细节较扎实（语言/动作子词表分别 mask 后计算 KL）。
- **基线设置较为克制公平**：AdaMerging 复用完全相同的目标函数，从而把差异归因于粒度；随机方法报告 10 种子方差。
- **提供了可解释的结构性洞见**：秩不对称性与 $\alpha$ 随奇异谱的单调上升，不仅解释了自身方法为何有效

，也给出了一个关于“语言能力与动作能力在参数空间中的分布形态”的可迁移假设，对后续任务向量编辑、VLA 训练正则化都有参考价值。

## 8. 局限与不足

- **语言恢复并非无损**：即便最好的 Ours$_{\pi0.5}$，在 COCO captioning 与 VQAv2 上仍落后纯 VLM 约 4–5 个点（如 VQAv2 48.7 vs 53.8，ROUGE-L 29.5 vs 33.6），EQA 上也存在个别子项被 AdaMerging 反超（Object State 32.3 vs 43.4）。论文的定位是"找回大部分能力"而非"完全恢复"，但正文对这一残差的来源缺少专门分析。
- **自回归骨干上效果明显偏弱**：π0-FAST 侧动作成功率下降 9–13 个点（如 Object 79.8 vs 88），作者将其归因于动作 token 与语言 token 共享词表、表征纠缠，但这只是定性解释，未给出权重层面的证据（如 π0-FAST 的 α 分布与 π0.5 是否真的不同）。
- **依赖"源模型自生成数据"**：$D_{act}$ 与 $D_{text}$ 分别由 VLA 和 VLM 自身产出，本质上是自蒸馏闭环。这意味着合并目标对齐的是两个源模型各自的输出分布，而非人类标注的真实分布；若源模型在某类场景上系统性出错，合并模型可能继承该偏差，而评测集（LIBERO/LeRobot 同源）难以暴露这一点。
- **秩 $r$ 是需要调的超参**：实验显示语言在 $r=16$ 饱和、动作需 $r\ge1024$，但论文未给出在**未知下游任务**上选择 $r$ 的原则（例如是否需要针对每个新机器人平台重跑一次秩扫描），实际部署时的自动化程度受限。
- **算力报告不完整**：只报告了 α 优化的成本（1×H100、3 小时），VLA 微调、SVD 分解、数据生成推理、10 种子重复实验的总开销均未量化，难以评估端到端性价比。
- **任务域偏窄**：动作评估集中在桌面操作（LIBERO 三套件 + RoboCasa 三个厨房任务），未涉及移动操作、双臂、长程多阶段任务；语言评估用 COCO/VQAv2/EQA 等通用 benchmark，与机器人场景的指令理解（如指代消解、空间关系）尚有距离。
- **理论层面以实证洞见为主**："语言集中于主导奇异方向、动作弥散于弱分量"目前是从 α 分布与秩敏感性曲线反推的经验规律，缺少形式化论证（例如为何微调动力学会导致这种谱结构），其普适性仍需在更多 VLM/VLA 组合上验证。
- **对比基线覆盖不均**：学习型基线 AdaMerging 只在 π0.5 上跑；Model Soup 仅取 4 个离散 α，未做细粒度折衷曲线或最优 α 搜索，基线的"崩到 0%"可能部分源于搜索不足而非方法本身的极限。

## 9. 启发与可延伸方向

- **把"任务向量 SVD + 逐分量门控"推广为通用的能力编辑工具**：该框架不依赖机器人领域，原则上可用于任意"基座模型 + 微调模型"对（如通用 LLM 的指令微调、安全对齐微调），用于在保留新能力的同时回收旧能力。
- **将秩结构洞见反哺训练**：既然动作适配弥散在弱奇异方向上，可考虑在 VLA 微调阶段加入**谱正则**（如惩罚主导方向的更新、鼓励能量分布在尾部），从源头缓解灾难性遗忘，而不是事后补救。
- **自适应秩选择**：可探索用验证集上的语言/动作双指标曲线自动确定 $r$，或对不同层使用不同秩（论文已显示逐层 α 不如逐分量，逐层秩可能同样有价值）。
- **与数据侧方法结合**：本文是纯参数侧方法，若与少量混合数据共训或 LoRA 式适配器结合，或可进一步缩小与纯 VLM 的残差。
- **扩展到更多模态与更复杂动作空间**：验证在扩散策略、分层策略、多模态输入（触觉、本体感知历史）下该谱结构是否依然成立。

## 10. 总体评价

本文针对 VLA 微调中的灾难性遗忘提出了一种**极轻量、即插即用的事后参数合并方案**：将 VLM→VLA 的任务向量做 SVD，在奇异分量级别学习混合系数，仅优化约 3.8×10⁵ 个标量、单卡 3 小时即可完成。其核心贡献不只是"三轴同时不崩"的实验结果，更在于揭示了**语言能力与动作能力在权重空间中的谱分布不对称性**这一可解释的结构性规律，并用消融（粒度、损失、秩）与 α 分布分析形成相互印证的证据链。方法设计克制、基线比较相对公平、跨两种动作解码范式的验证增强了说服力。主要短板在于语言恢复仍有残差、自回归骨干上效果偏弱、数据自生成带来的闭环偏置、以及算力与超参选择的报告不够完整。总体而言，这是一篇问题清晰、方法优雅、洞见有价值的工作，其"谱粒度合并"思路与"能力分布不对称"假设均有较强的外溢潜力。
