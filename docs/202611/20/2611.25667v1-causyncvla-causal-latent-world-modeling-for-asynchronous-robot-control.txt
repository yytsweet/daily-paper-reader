Abstract
Vision–Language–Action (VLA) policies must react while visual inference is still running. Overlapping
computation and execution reduces waiting, yet leaves perceptual memory stale and successive action
chunks disconnected. We present CauSyncVLA, an asynchronous dual-system controller that aligns
perceptual-memory prediction and trajectory correction with actual robot execution. Rather than forecasting
pixels or physical states, a Causal Latent World Model predicts current perceptual memory from delayed
visual anchors and executed state–action history, supervised through action-sensitive distillation to retain the
frozen expert’s control response. Conditioned on this updated memory, Predictive Flow Warm-Starting
(PFWS) aligns the unexecuted action horizon for single-step flow correction without extra training. On
LIBERO-10, CauSyncVLA reaches 93.8% success at 5.04× inference throughput, improving closed-loop
robustness and robot motion smoothness.

1 Introduction
Vision–Language–Action (VLA) policies transfer pretrained multimodal knowledge to robotic manipula-
tion [9, 17, 44]. They pair foundation backbones with generative action heads to synthesize continuous
motion [2, 3, 6]. During physical deployment, however, the environment does not pause for model
inference. Approaching, grasping, and placing continuously alter the robot–scene configuration and
demand timely closed-loop decisions grounded in the evolving physical state.
Meeting this requirement is difficult because heavy visual encoding cannot match the rate of fast physical
execution, stalling synchronous closed-loop feedback.
Action chunking [6, 42] and asynchronous
execution [4, 33] amortize this latency by overlapping inference with ongoing motion, yet leave perception
and action temporally misaligned because replaying open-loop tails or stitching boundaries keeps
intermediate queries conditioned on delayed perceptual memory when contacts shift mid-chunk. Existing

reconcile reactivity, perceptual freshness, and trajectory continuity across mismatched sensing and control

To resolve this misalignment, we observe that actual robot execution supplies a shared temporal reference
to align perception and action. Observed state transitions and applied commands record physical evolution
since the latest visual frame, while the unexecuted tail of the preceding plan provides a structured motion
prior. Rather than predicting pixels or physical states independently of control, we formulate asynchronous
control as coupled perceptual-memory prediction and trajectory correction under one physical clock,
updating prefix key–value (KV) memory from execution history before refining remaining actions.
We instantiate this principle in CauSyncVLA, an asynchronous dual-system controller [15]. A slow visual
stream periodically publishes KV memory anchors from observed images, while a fast control stream
predicts current perceptual memory and refines subsequent actions. Specifically, a Causal Latent World
Model predicts current KV memory from the latest delayed anchor and executed state–action history
under action-sensitive distillation. Conditioned on this predicted memory, Predictive Flow Warm-Starting
(PFWS) aligns the unexecuted action horizon to the current step and refines it in one flow step. Training only
the lightweight predictor keeps the backbone and action expert frozen, retaining pretrained competence
while supporting rapid closed-loop replanning between visual updates.
On LIBERO-10, CauSyncVLA raises task success from 91.2% to 93.8% over the ten-step synchronous
policy while delivering 5.04× higher model replanning capacity on a shared GPU. Ablations, perturbation
tests, and physical trials isolate the complementary roles of causal perceptual-memory prediction and
trajectory correction. Our principal technical contributions are organized around three axes.
• Execution-grounded asynchronous control.
We formulate asynchronous control as coupled
perceptual-memory prediction and trajectory correction, evaluating execution-aligned replanning
across simulation and physical trials, reducing feedback latency with frozen VLAs.
• Causal, action-relevant latent world modeling. We propagate delayed KV anchors along realized
state–action history in latent prefix space, supervising residual updates via action-sensitive distillation,
which recovers control-relevant perceptual conditioning.
• Training-free predictive trajectory correction. We propose PFWS to reuse unexecuted action
horizons as intermediate flow priors, refining trajectories in one frozen-expert Euler step, which
suppresses boundary mode switching across perturbed trials.

2 Related Works
Asynchronous Vision–Language–Action Execution.
Generalist policies pair multimodal pretraining
in RT-1 [5], RT-2 [44], OpenVLA [17], and Octo [9] with generative control in 𝜋0 [3], 𝜋0.5 [2], and
CogACT [18]. Later works extend this paradigm through spatial grounding [29], mobile manipulation [36],
and reinforcement learning [26]. For higher closed-loop speed, OpenVLA-OFT [16] accelerates decoding,
while EfficientVLA and HBVLA reduce model cost through compression and low-bit quantization [38, 39].
Action chunking [6, 42] further amortizes computation across fixed horizons or adaptive horizons in
AAC [20]. SmolVLA [33] overlaps prediction with execution, whereas RTC [4] and Acting While
Understanding [37] reconcile chunk boundaries via action inpainting or time-misalignment training. Still,
overlapping or stitching chunks leaves intermediate queries conditioned on stale anchors between visual
passes, requiring execution-grounded updates over frozen backbones.
Latent World Models for Visuomotor Control.
Compensating for delayed perception links asyn-
chronous VLAs to latent dynamics models in DreamerV3 [11] and TD-MPC [12], later extended to
manipulation and whole-body control in ManiGaussian [27] and SuperMimic [21]. Within VLAs,
MAP-VLA [19] injects execution memory, Latent Bridge [25] predicts inter-pass feature or KV deltas,
and EagleVLA [40] forecasts future representations for asynchronous inference. Action-informed belief
learning also links latent memory to control through an inverse-dynamics objective [35]. Our Causal
Latent World Model advances delayed KV memory anchors along realized state–action transitions inside
prefix cache space, supervised through the frozen flow expert via action-sensitive distillation to maintain
control fidelity.
Trajectory Priors and Fast Flow Sampling.
Even with refreshed perceptual memory, resampling
trajectories from Gaussian noise at each cycle risks cross-chunk mode switching and multi-step overhead in
diffusion [6] and flow [1, 22] policies. Prior speedups rely on Consistency Policy [31] distillation, real-time
iteration [7] warm-starts, history-informed initialization in A2A [14], history transport in Δ-flow [45],
or adaptive tail reuse in VLA-Rolling [13]. Building on trajectory reuse, PFWS keeps expert weights
fixed, shifts the unexecuted horizon past consumed commands, rebases state-relative coordinates to the
3


latest proprioceptive state, and applies one Euler refinement under causally predicted memory to improve
alignment and continuity across successive chunks.
3 Method
Overlapping visual encoding with physical actuation mitigates inference stalls, yet still leaves perceptual
conditioning stale and consecutive action chunks spatially misaligned.
To address this challenge,
CauSyncVLA couples perceptual-memory prediction and trajectory correction around the frozen visual–
language backbone 𝐵𝜙and action expert 𝑣𝜓[2, 3] (Figure 2a). At each replanning boundary, our Causal
Latent World Model 𝑊𝜃integrates the latest visual anchor with realized state–action history to predict
current KV memory. Predictive Flow Warm-Starting then refines the prior plan’s unexecuted tail under
this memory in one frozen-expert Euler step, while action-sensitive distillation guides 𝑊𝜃.

4 Experiments
Our evaluation separates individual module contributions from whole-system asynchronous execution
while testing whether decoupled visual encoding accelerates closed-loop reaction without sacrificing
competence, whether causal latent prediction preserves conditioning between visual refreshes, and whether
PFWS sustains smoothness and robustness. We further ablate each component and training objective
within matched cohorts before validating closed-loop physical deployment on a Franka FR3 arm.
4.1 Experimental Setup
Built on a frozen 𝜋0.5 backbone and flow action expert, the Causal Latent World Model is a 24.27M-
parameter AdaLN transformer trained for 12k updates with simulation horizon 𝐻= 10, stride 𝐶= 5,
one Euler step, and PFWS factor 𝜌= 0.5, while baselines retain public weights and official inference
heads. Specifically, RTC and Latent Bridge R0 share the OpenPI 𝜋0.5 base at 𝐻/𝐶= 10/5, whereas
VLA-Rolling retains its LeRobot backbone at 𝐻/𝐶= 50/10. Full hyperparameters and training datasets
appear in Appendix A and Table 7.
Competence and robustness span 500 native starts on LIBERO-10 [23] and 2,519 paired perturbations
on LIBERO-Plus [8], while timed closed-loop execution evaluates 100 shared starts at 20 Hz under a
26 s budget on an exclusive RTX 5090 GPU alongside scheduling analyses in Appendix C.10. Physical
manipulation is evaluated on a 7-DoF Franka FR3 arm with dual D405 cameras at 𝐻/𝐶= 10/2 under a
100 Hz dispatch ceiling and live 30 Hz perception, deploying an offline timestamp-adapted updater trained
on 10 Hz demonstrations across altered cup stacking and held-out fruit placement and vegetable sorting
per the protocol and trial counts in Appendix C.9.

5 Conclusion
We presented CauSyncVLA, an execution-grounded asynchronous controller that reconciles perceptual
freshness with cross-chunk continuity around frozen VLA policies without retraining. Coupling history-
conditioned prefix KV prediction with single-step flow warm-starting keeps rapid trajectory revisions
aligned with actual robot motion and clarifies a continuity–adaptation boundary between local stabilization
and large exogenous shifts. Operating strictly through cached prefix KV memory and chunked flow priors
makes the design directly compatible with single-system flow VLAs, while multi-backbone hardware
validation, event-triggered visual refreshes, and exogenous prior resets in Appendix B.15 mark natural
next steps toward broad physical autonomy.

B Discussion, Analytical Scope, and Limitations
B.1 What Is Added Beyond Asynchronous Scheduling?
Asynchronous execution by itself can overlap perception and command supply, as demonstrated by RTC [4].
While feature or KV prediction has precedent in Latent Bridge [25] and tail reuse in VLA-Rolling [13],
our learned contribution conditions a published real visual anchor on ordered execution transitions
and supervises that update through the frozen expert’s action sensitivity, paired with training-free tail
continuation under PFWS. Writing the frozen one-step endpoint as 𝐹𝜓(Q, 𝑧) while suppressing fixed state,
20


noise, and restart time, adding and subtracting 𝐹𝜓(Q, 𝑧★) around reference inputs (Q★, 𝑧★) yields
𝐹𝜓(Q, ˆ𝑧) −𝐹𝜓(Q★, 𝑧★) = [𝐹𝜓(Q, ˆ𝑧) −𝐹𝜓(Q, 𝑧★)]
+ [𝐹𝜓(Q, 𝑧★) −𝐹𝜓(Q★, 𝑧★)].
(23)
The first term isolates the conditioning discrepancy targeted by action distillation at a shared initializer, and
the second captures the effect of the prior initializer under fixed conditioning, explaining why a smooth
prior cannot replace current memory and why KV reconstruction alone does not constrain boundary
sampling. Matched controls in Table 12 test module necessity within this implementation without claiming
additive task-success gains or superadditive interaction over a complete multi-factor runtime grid.
B.2 What Do the Theoretical Arguments Establish?
Appendix A.3 proves causal information flow, exact age-zero identity, and a conditional local action-error
bound. It does not prove task success, global stability, or universal transfer across control frequencies.
The history interventions are tests of a trained model, not separately trained reduced-input baselines. The
KV-only objective comparison, in contrast, changes supervision at a matched training budget.
B.3 Does PFWS Always Improve Performance?
No. Its synchronous paired success difference is not statistically decisive (𝑝= 0.1173), despite reduced
boundary reversals. Across the LIBERO-Plus perturbation catalog, PFWS raises synchronous success
from 78.36% to 80.15% and asynchronous success from 76.38% to 78.09%, leaving an asynchronous
deficit of 1.98 percentage points without reuse and 2.06 percentage points with reuse. Because that gap
already appears without PFWS, aggregate scores establish a within-controller benefit from trajectory reuse
alongside perturbation families where reuse hurts rather than greater absolute perturbation robustness
or disentangled memory-and-scheduling errors. Dense flow paths are already low-curvature in both
conditions, so PFWS shortens the correction interval rather than learning a new field or proving smaller
training-distribution shift. Full perturbation-family results and the matched flow-interval comparison are
retained below.
B.4 How Should Pretrained Comparisons Be Interpreted?
Public checkpoints retain their released action heads and inference budgets. Latent Bridge [25] is the
available R0 model, not an unreleased or retrained R1, while VLA-Rolling [13] retains its LeRobot
backbone and longer horizon alongside its paired backbone control. Native success has an action budget,
whereas paced success limits wall time under distinct hardware scopes. Model-only timing measures
resident-input forward latency (60.01, 36.00, 35.54, and 11.91 ms across ten-step, one-step, synchronous
PFWS, and shared-GPU CauSyncVLA), so fewer flow evaluations explain part of the 5.04× capacity ratio
and removing visual encoding from the fast path accounts for the remaining reduction while the world
model preserves conditioning rather than accelerating compute. By contrast, single-GPU timed execution
includes observation transport, co-located rendering, and executor guards, producing smaller realized gains
of 3.28/2.57 = 1.28 in replans/s and 16.60/13.02 = 1.27 in supplied actions/s. RTC’s separate-GPU
93/100 asynchronous evaluation appears in Table 24 outside the co-located single-GPU ranking, while
the teaser radar plot depicts qualitative trade-offs rather than normalized axis scores, isolating a 12.52×
speedup in Table 16.
B.5 Selection, Physical Transfer, and Failure Cases
The evaluation seed and updater recipe were chosen after earlier endpoint comparisons, and the selected
12k checkpoint follows a training-budget sweep, making reported uncertainty conditional on that selection.
Separately reset physical scenes are not exact outcome pairs, and offline timestamp-conditioned adaptation
from processed existing trajectories adjusts the updater rather than deploying an unchanged 10 Hz model.
Held-out task labels denote tasks unseen by the updater without certifying absence from backbone
pretraining. Successful duration ends at the operator verdict, HTTP dispatch does not verify actuator
21


consumption, and whole-system hardware comparisons co-vary realized dispatch frequency with controller
inference speed rather than isolating frequency-matched module effects.
B.6 Is This a General Dynamics or Future-Video Model?
No. The predictor estimates current frozen-expert conditioning rather than synthesizing future pixels,
predicting counterfactual rewards, or identifying physical contact dynamics. Temporal causality follows
the information filtration in Appendix A.3, and the indistinguishability bound in Appendix A.4 shows why
execution history alone cannot resolve exogenous scene changes without new visual anchors. Empirical
prediction quality between anchors is therefore evaluated rather than implied by causal measurability,
age-stratified curves reflect sampled history probes rather than live deployment age distributions, and
RGB-colored KV panels depict shared-basis PCA projections rather than reconstructed camera views.
B.7 Is Direct KV Prediction the Novelty?
Direct prediction alone is not the distinction: Latent Bridge already includes a 𝜋0.5 KV bridge [25].
Our proposed combination is an ordered record of executed transitions, prediction anchored at the latest
published real memory, and supervision through the unchanged action expert. The prior action chunk
Q𝑡initializes PFWS; it is not supplied as an unexecuted trajectory to the history encoder. The history
interventions and matched objective control isolate these design choices more directly than a comparison
of aggregate success across independently trained public checkpoints.
B.8 Could Extra Training or the Sampling Rule Explain the Gain?
The updater adds learned parameters and training data; freezing the backbone does not make the entire
controller training-free. Public-method comparisons do not equalize training budgets and do not imply
sample-efficiency advantages. Within our ablations, the same data, initialization, budget, and validation
pairs isolate the action-loss contribution, while inference-time module toggles keep the learned checkpoint
fixed. Every retained training row is eligible with stride one; 𝐶controls deployed chunk consumption and
cache shifting, not dataset subsampling. Validation splits and normalization stay separate from evaluation.
B.9 Does the Teacher Leak Future Evaluation Information?
Offline supervised pairs contain a real target encoding at the later recorded state. This target supplies a
detached label, like standard teacher supervision [32]; it is never available to the deployed updater. At
inference, only a completed real prefix and transitions already issued and observed are admissible. The
warm training prior comes from a previous fresh-teacher endpoint and therefore differs from recursive
deployment, an acknowledged training-distribution approximation rather than hidden online oracle access.
B.10 Why Not Simply Increase the Command Rate?
Higher-rate resending can repeat an unchanged target without computing a new plan, so distinct action-node
first dispatches are reported separately from plan adoption, model capacity, and response latency. Under
uninterrupted steady execution consuming 𝐶nodes per plan, realized replanning is bounded by both fast
computation capacity and node-consumption rate divided by 𝐶, alongside startup, gripper barriers, and
horizon exhaustion. Multi-plan overlap within one System 2 window is measured directly from monotonic
timestamps rather than inferred from latency ratios; in the archived 20-episode 𝐶= 1 simulation probe,
250 of 4,874 completed slow windows contain multiple fast plans first used in that window (5.13%),
demonstrating workload-dependent overlap without claiming multiple replans in every pass or identical
ratios at 𝐶= 5.
B.11 Does Timestamp Conditioning Make 10 Hz Data Native High-Rate Data?
No. The physical controller uses a separately adapted updater while preserving the original expert and
action units. Its 𝐾= 24, seven-state/seven-action base vector has 358 entries. The shared training/inference
encoder appends the 24 measured transition durations divided by 0.1 s and their sum on that same scale,
giving 383 inputs. These duration features expose irregular sampling; they neither create previously
22


unobserved contact events nor prove rate invariance. Offline processing of existing trajectories is not
equivalent to collecting independent 100 Hz measurements. The physical results establish performance for
the evaluated 100 Hz ceiling and actual measured rates, not for arbitrary 200 Hz or faster execution.
B.12 Could Synchronization, Smoothing, or Pair Selection Produce the Motion Result?
Both controllers share the pose-arrival and gripper-completion executor. During a gripper barrier, arm
progression and policy history/cache updates pause; resumption requires fresh observation and real
memory. Active-rate statistics remove those waits, whereas successful-trial duration retains them. These
are complementary quantities rather than interchangeable notions of speed. The speed-CV and acceleration-
RMS statistics use the same unsmoothed 100 ms EEF samples for all outcomes; display-only filtering does
not enter the numbers. The new illustration pairs are selected first by complete phase-path similarity and
then initial layout, without ranking the size of our advantage. Requiring complete grasp–place phases
restricts visual panels to that subset, while the 138-trial table covers all outcomes.

B.15 Limitations, Applicability to Single-System VLAs, and Future Directions
Adapting the memory predictor to another VLA requires a compatible cached prefix conditioning interface
and training against that policy’s frozen action expert, while PFWS as formulated requires a flow velocity
head. Other benchmarked backbones remain reference baselines without controller integration, leaving
cross-architecture transfer and alternative action heads untested.
In execution, the controller cold-starts at episode onset and clears prior tails with fresh anchors across
physical gripper barriers or upon exceeding history capacity, yet does not run a learned confidence test
against sudden viewpoint or scene shifts. Future extensions therefore include innovation- or entropy-
triggered visual refreshes for exogenous motion in Appendix A.4, adaptive flow interpolation 𝜌𝑡between
warm reuse and cold resets, and high-frequency visuo-tactile sensing during dexterous contact.

C.4.1 Frozen-Expert Flow Geometry
To examine the initializer used by PFWS, we visualize actual model ODE trajectories and velocity

and current real visual prefix are identical for both conditions. Native LIBERO-10 tasks 0, 4, and 8 supply
contexts at executed steps 20 and 40 under a ten-step reference policy. At each of these six contexts, eight
matched Gaussian seeds give 48 trajectories per condition. Each prior chunk has executed five commands
before shift-and-repeat builds Q𝑡.
We densely integrate cold starts from 1 to 0 and PFWS starts from 𝜌= 0.5 to 0, using Euler step size
0.025. The cold suffix from 0.5 to 0 provides a matched-interval reference. These dense paths diagnose
the field rather than change the deployed one-step method. All metrics use the 70 active normalized action
coordinates, excluding padding. We measure path length divided by endpoint chord, initial-to-endpoint
RMS distance, and the RMS discrepancy between a single Euler step and the corresponding dense endpoint.
Figure 5 shows the preselected task-0, step-20 context; the numerical summaries below average all six
contexts and eight seeds per context.
PFWS reduces mean initial-to-endpoint RMS distance from 1.115 to 0.550 and one-step endpoint error
from 0.03655 to 0.02937 (19.7%). The cold matched suffix has distance 0.550 and error 0.02970.
Path/chord ratios are 1.00182 for full cold, 1.00302 for its suffix, and 1.00301 for PFWS, showing that
PFWS shortens the integration interval along nearly straight frozen streamlines without reshaping the
underlying flow field. This diagnostic uses a shared GPU for trajectory visualization.

C.9 Real-Robot Training and Evaluation
Frozen expert and timestamp-conditioned updater.
The FR3 policy uses front/wrist images and seven-
dimensional end-effector/gripper state. Its original action expert, action magnitude, and normalization
remain fixed. Updater pretraining uses 205 demonstrations and 36 validation trajectories across screw
sorting, water pouring, marker sorting, cup stacking, and test-tube tidying. The existing filtered 10 Hz
dataset contains 35,198 training and 6,201 validation rows across 6k pretraining updates.
For variable-rate feedback, we augment the existing filtered trajectories with timestamped histories while
retaining every original action target. Actual collection timestamps determine interval duration. Continuous
states are interpolated only within gaps of at most 150 ms without gripper transitions; commands and
RGB observations use causal holds. The extra history states are synthetic augmentation, rather than newly
acquired high-rate measurements. Training samples use approximately 10/20/30 ms history intervals,
preserve command changes, and cap history at 24 nodes and 250 ms. The conditioner appends the 24
measured intervals and elapsed anchor time, scaled by 100 ms. Runtime supplies the same features from
actual state samples and dispatched commands.
We adapt only the updater for 4k additional updates on two L40S GPUs with global batch 32, AdamW,
learning rate 3×10−5, 200 warmup updates, and cosine decay. The new time-input weights start at zero.
The objective combines KV regression and action distillation with weights 1 and 2, respectively, and
gripper weight 0.1. Fixed validation on 600 pairs selects adaptation step 2,500, giving 8,500 cumulative
updater updates; the total optimization budget is 10,000. No new robot rollouts enter training. Cup
stacking is updater-trained; fruit placement and vegetable sorting are held out from updater training,
without assuming they are unseen by the supplied backbone.
Shared physical protocol.
Both controllers use the same FR3/Robotiq hardware, two D405 cameras,
RTX 5090, compiled inference, ten-action horizon, and two consumed actions per plan. Feedback is
read after the preceding action has been dispatched, with a 100 Hz sending ceiling. The baseline uses ten
30


denoising evaluations with dual prediction and PFWS disabled; CauSyncVLA uses one evaluation, the
timestamp-conditioned updater, and PFWS restart 𝜌= 0.5. A slow pass uses the newest image pair after
both camera sequences advance, up to the wrist camera’s 30 Hz limit, without an added slow-stream delay.
Before a gripper transition, the shared executor waits for the associated arm pose, then confirms fresh native
gripper completion. Both model streams pause during this interval. After completion, CauSyncVLA
builds a real anchor from new observations, clears the old action tail, and resumes from a cold plan. Both
controllers share workspace, force, freshness, and first-post-grasp action guards. Trials are collected in
controller blocks with manually reset objects and recorded initial images; they are not paired by identical
physical object poses or random noise.
