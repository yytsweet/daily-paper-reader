Abstract
Recent efforts to improve the efficiency of multimodal large
language models (MLLMs) have explored visual token prun-
ing, quantization, and feature compression. However, the
properties that determine whether transformed visual tokens
remain usable by a frozen decoder are not well character-
ized. We introduce TIVS (Token Identity Versus Statistics),
a training-free intervention framework that separately stud-
ies sequence permutation, token retention, numerical preci-
sion, and statistical replacement under controlled conditions.
On 192 POPE questions, three token permutations change
TinyLLaVA accuracy by only −0.17 percentage points on
average, while changing 4.69% of individual predictions.
Diagonal and rank-64 Gaussian replacements decrease ac-
curacy by 25.0 and 28.1 points on the same subset. Further
experiments with exact moment constraints, quantization
error, token retention, and additional visual tasks reveal how
strongly the effects depend on the original feature values and
the evaluation setting. These findings provide an empirical
basis for assessing visual token transformations in frozen
MLLMs and designing more reliable multimodal interfaces.

A visual token sequence contains information at multiple
levels. Individual token vectors encode specific numerical
features, while their aggregate statistics describe the over-
all feature distribution. These properties are not equivalent.
Two sequences may exhibit similar means and covariances
while containing different feature vectors. Conversely, token
permutation preserves the original vectors while changing
their positions. Understanding how these differences affect
downstream predictions is essential for identifying which
properties of visual representations support reliable multi-
modal inference.
We introduce TIVS (Token Identity Versus Statistics), a
training-free framework for controlled visual token interven-
tions. TIVS fixes the model and evaluation examples, varies
one intervention at a time, and measures both accuracy and
individual prediction changes. We study permutations, token
retention, feature quantization, and Gaussian replacements.
We also test exact finite-sample moment constraints and per-
turbations matched by magnitude. These controls connect
the properties of the transformed features to downstream
predictions.
Beyond aggregate accuracy, we examine how visual to-
ken transformations affect individual model decisions. Two
configurations can achieve identical accuracy while produc-
ing different predictions on the same questions. We therefore
evaluate prediction consistency and logit margins alongside
conventional accuracy. This paired analysis provides a more
detailed characterization of how visual token transformations
influence the behavior of frozen decoders.
Our experiments reveal a clear difference between trans-
formations that preserve the original token vectors and those
that replace their numerical content. On 192 POPE ques-
tions [9], token permutation changes TinyLLaVA accuracy
by only −0.17 percentage points on average, while diagonal
and rank-64 Gaussian replacements reduce accuracy by 25.0
and 28.1 points, respectively. Despite the small change in
aggregate accuracy, permutation still alters 4.69% of individ-
ual predictions. Further experiments with exact covariance
matching, numerical precision, token retention, and different
model backbones provide additional evidence of how visual
feature properties influence frozen MLLM behavior. Our
main contributions are summarized as follows:
• We introduce TIVS, a training-free framework that system-
atically investigates the effects of token order, retention,
numerical precision, and statistical properties on frozen
MLLMs.
• We establish a paired evaluation protocol that jointly mea-
sures prediction accuracy, decision consistency, and logit
margins, revealing changes in individual predictions that
aggregate accuracy can conceal.
• We provide systematic experimental evidence across to-
ken transformations, feature layers, and model backbones,
highlighting the importance of token-level numerical iden-
tity for reliable visual representations.
2. Related Work
Visual token selection.
Efficient MLLMs commonly re-
duce the number of visual tokens passed to the decoder.
FastV prunes tokens using attention signals [4]. ATP-LLaVA
adapts pruning decisions across inputs and layers [18]. Di-
vPrune emphasizes token diversity [1]. TopV considers infer-
ence compatibility [15]. VFlowOpt uses visual information
flow to guide pruning [17]. TransPrune analyzes represen-
tation transitions [8]. VisionZip compacts visual encoder
outputs [16]. These methods motivate our study of retention
budgets and selection strategies.
Feature compression and transformation.
Other meth-
ods modify visual representations to create shorter inputs.
LLaVA-PruMerge merges related visual features [11]. ApET
uses approximation error in compression [10]. CORE con-
solidates object-centric information [7]. Hybrid Token Com-
pression combines discrete and continuous representations

Visual token representations.
Recent analyses exam-

Prior work studies sparsity and redundancy in MLLMs [6].

their sequence assignments, and their empirical moments.

We further analyze the effects of token permutation and
quantization relative to the clean accuracy of each layer.
The native layer −2 gives the highest clean accuracy
among the four tested depths. The frozen projector processes
every layer with the same mapping. This exposes sensitivity
at the encoder–projector interface. Figure 12 measures each
intervention against the clean accuracy at its extraction depth.
Across the four extraction depths, permutation changes
accuracy by at most 6.3 points. Eight-bit quantization stays
within 4.2 points of each clean baseline. Diagonal Gaussian
replacement yields larger reductions at every depth, with the
largest drop of 35.4 points at layer −2.
At layer −4, 8-bit quantization increases accuracy by
4.2 points. The other three layers show zero or negative
changes.
6. Conclusion
We introduced TIVS, a controlled study of visual token trans-
formations in frozen MLLMs. Expanded POPE experiments,
paired margins, and exact statistical controls distinguish the
effects of changing token order from changing numerical
feature content. Precision and retention sweeps show how
accuracy depends on the magnitude and structure of a trans-
formation. Cross-task and backbone comparisons further
define the conditions under which these observations hold.
TIVS provides reproducible evidence and practical measure-
ments for designing reliable visual token interfaces. We also
plan to leverage these findings to develop adaptive visual
token compression methods in future work.
