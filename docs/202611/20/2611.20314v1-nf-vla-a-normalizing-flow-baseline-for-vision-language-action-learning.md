## 摘要
自回归归一化流（NF）为学习和采样连续机器人动作提供了可处理的密度。我们表明，单一的最大似然目标即可训练出在操作基准上与领先方法相竞争的视觉-语言-动作（VLA）策略。我们提出 NF-VLA，它将条件自回归归一化流与基于分数的动作细化相结合。其深层-浅层架构将视觉、语言和本体感觉的前缀条件集中于高容量深层模块，而无条件的浅层模块提供共享的可逆动作变换。视觉-语言骨干网络与流通过在高斯平滑动作块上的精确最大似然进行联合训练。同一学习到的密度在推理时提供一次基于分数的校正，对生成动作进行细化，以补偿训练时的平滑，而无需单独训练去噪器。在 LIBERO 上，基于预训练的视觉-语言骨干网络且未进行机器人预训练，NF-VLA 在四个标准套件上达到 98.35% 的成功率，并在相同检查点、无需进一步微调的情况下在 LIBERO-Plus 上达到 72.6%。消融实验表明，仅深层前缀条件与基于分数的细化均能提升闭环成功率。总之，这些结果确立了精心构建的自回归流作为 VLA 控制的一种有竞争力方法，其中单一学习到的密度支持策略训练、动作生成与细化。

## Abstract
Autoregressive normalizing flows (NFs) provide a tractable density for learning and sampling continuous robot actions. We show that a single maximum-likelihood objective can train vision--language--action (VLA) policies competitive with leading methods on manipulation benchmarks. We present NF-VLA, which combines conditional autoregressive normalizing flows with score-based action refinement. Its deep--shallow architecture concentrates visual, language, and proprioceptive prefix conditioning in a high-capacity deep block, while unconditioned shallow blocks provide a shared invertible action transformation. The vision--language backbone and flow are jointly trained by exact maximum likelihood on Gaussian-smoothed action chunks. The same learned density supplies a single score-based correction at inference, refining generated actions to account for training-time smoothing without a separately trained denoiser. Trained on LIBERO from a pretrained vision--language backbone without robot pretraining, NF-VLA achieves 98.35\% success across the four standard suites and 72.6\% on LIBERO-Plus using the same checkpoint without further fine-tuning. Ablations show that deep-only prefix conditioning and score-based refinement both improve closed-loop success. Together, these results establish carefully structured autoregressive flows as a competitive approach to VLA control, with one learned density supporting policy training, action generation, and refinement.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作）模型将预训练视觉-语言表征连接到机器人控制，其核心设计选择是**动作模型**——它决定观测如何条件化动作分布、以及如何产生可执行指令。现有路线包括离散 token 预测（RT-2、OpenVLA）、连续回归（OpenVLA-OFT）、扩散（Diffusion Policy）、流匹配（π0、SmolVLA）。
- **切入点**：归一化流（NF）用可逆变换同时定义连续密度与采样过程，其可处理的变化-of-变量似然支持**直接最大似然训练**；TARFlow、STARFlow 已证明 Transformer 自回归流在视觉/多模态生成上的潜力。近期 NinA、RoMAN-Flow、SERNF 已将 NF 用于机器人策略，但多依赖耦合流、优势加权离线 RL 或蒸馏等额外组件。
- **本文问题**：能否仅用**单一精确最大似然目标**训练出有竞争力的 VLA 策略？在此框架下应**在何处、以何种方式注入多模态条件**？采样后能否**复用同一学习密度的分数**改进动作，而无需单独训练去噪器？
- **整体含义**：作者将 NF-VLA 定位为"基线"研究，论证精心结构的自回归流是 VLA 控制的一条可行且简洁的技术路线：一个密度模型同时承担策略训练、动作生成与推理修正。

## 2. 方法论

### 2.1 核心思想
- 采用 TARFlow 的仿射自回归参数化 + STARFlow 的**深-浅架构**：高容量深层块接收视觉、语言、本体感觉的**前缀条件**；多个**无条件浅层块**提供动作坐标与中间隐变量之间的共享可逆变换。
- 训练：在**高斯平滑后的动作块**上做精确负对数似然（NLL），VLM 骨干、条件投影、流块**联合端到端优化**，无辅助预测损失或表征对齐损失。
- 推理：从标准高斯采样隐变量 → 逆流生成动作 → 用同一密度的**分数做一步 Tweedie 修正** → 反归一化。

### 2.2 关键技术细节
- **动作表示与条件构造**：输入多视角图像、语言指令、本体感觉 $q_t$；图像 resize 至 384×384，编码为 36 个视觉 token/图（2 图共 72），加 50 个指令 token 位置，得 122 个宽度 960 的特征；经线性投影后与本体感觉 token 拼接，形成 $C_t \in \mathbb{R}^{123\times1024}$ 的前缀上下文。
- **流结构**：动作头共 6 个仿射自回归块——5 个浅块（各 2 层 Transformer，无条件）+ 1 个深块（14 层，prefix 条件），宽度 1024、16 头、1D RoPE（base 10000）。块间用**交替顺序排列** $P_k$（奇数保持、偶数反转 token 序）。
- **注意力掩码**：上下文 token 在 prefix 内双向注意、不关注动作 token；动作 token 关注全部上下文、前序动作及自身，未来位置被掩码；仿射参数**右移一位并在首位补零**，保证 token $i$ 的系数只依赖前序 token（含首位恒等变换 $[b_1,s_1]=[0,1]$）。
- **数值稳定化**：$b_i=4\tanh(\beta_i/4)$，$s_i=\log[1+(e-1)\exp(4\tanh(\alpha_i/4))]$，保证尺度为正且有界；变换为 $v_i=(u_i-b_i)\oslash s_i$。
- **似然目标**：对角块为 $\mathrm{diag}(1/s_i^{(k)})$，排列绝对行列式为 1，故 $\log|\det J_{f_k}|=-\sum_{i,j}\log s^{(k)}_{i,j}$；损失为每标量动作维度的 NLL：$\mathcal{L}=\frac{1}{Hd_a}\mathbb{E}\left[\frac12\|Z\|_F^2+\sum_k\sum_{i,j}\log s^{(k)}_{i,j}\right]$。
- **高斯平滑**：$\tilde X_t=X_t+\sigma\epsilon$，$\sigma=0.05$（归一化动作空间），使密度在数据支撑外仍有定义、并支撑后续去噪修正。
- **推理与修正**：反向逐块求逆，深块先用上下文填充 KV cache，每块需 $H-1=9$ 次顺序 token 评估，总计 $K(H-1)=54$ 次；随后做一次 Tweedie 修正 $\hat X_t=\tilde X_t+\sigma^2\nabla_{\tilde X_t}\log q_\theta(\tilde X_t\mid C_t)$，该分数通过**额外一次似然评估并对采样动作求导**获得，无需独立分数网络。作者明确指出这是近似后验均值，而非干净分布的精确样本。
- **配置规模**：$H=10$，$d_a=7$（3 平移 + 3 旋转 + 1 夹爪），动作与本体感觉按训练集统计逐维归一化。

## 7. 局限、启示与批判性评估

### 7.1 作者自述或可推断的局限
- **仅仿真验证**：全部结果来自 LIBERO / LIBERO-Plus，无真实机器人部署，sim-to-real 的可行性（尤其对 74 ms 级延迟与单步修正的精度要求）未获证据。
- **单步修正的近似性**：Tweedie 步给出的是近似后验均值而非干净样本，作者已明确承认；未探索多步迭代修正或步数-精度的权衡曲线。
- **高斯平滑的固定性**：$\sigma=0.05$ 为固定超参，既决定训练密度的支撑范围，又决定推理修正强度，二者耦合，缺少敏感性分析。
- **统计强度不足**：单次运行、无种子方差，1–1.5 pp 的领先幅度在 2000 episodes 上的置信区间未被讨论。
- **对比的非受控性**：基线多为引用值，骨干规模（500M）显著小于部分对手，训练数据组织方式（联合 vs 分套件）构成潜在混杂。

### 7.2 方法论启示
- **"一个密度、三种用途"** 是本文最可迁移的思想：同一 NLL 训练出的密度同时充当策略（采样）、评分器（分数修正）与似然评估器，避免了扩散/流匹配路线中"策略网络 + 独立去噪器/价值网络"的多组件拼装。
- **深-浅架构的性价比** 提示 VLA 动作头的条件化应"集中"而非"铺开"：把条件预算花在少数深层块上，其余块保持无条件以维持可逆变换的廉价性与共享性。
- **交替排列 + 右移掩码 + 有界参数化** 构成一套可复用的自回归流工程配方，解决了自回归流在动作维度上的并行训练与数值稳定问题。
- **前缀注意 vs AdaLN** 的对照对多模态条件注入的通用设计有参考价值，不限于机器人策略。

### 7.3 证据强度评级
- **新颖性：中等偏上**——NF 用于 VLA 并非首次，但"纯最大似然、无辅助损失、分数复用"的组合较为干净，定位为强基线而非全新范式。
- **实验严谨性：中等**——benchmark 覆盖与消融设计合理，但缺方差、缺统一配方重训、缺真机。
- **实用价值：较高**——延迟、显存、参数量均有报告，303M 动作头 + 500M 骨干的规模对中等算力可复现。
- **可复现性：中等**——关键结构（块数、宽度、掩码、参数化）描述充分，但训练步数、时长、数据增强、超参搜索预算缺失，算力成本披露不完整。

## 8. 总体结论

NF-VLA 论证了一个简洁命题：**在 VLA 中，一个精心结构的自回归归一化流可以在单一精确最大似然目标下同时完成策略学习、动作生成与推理期修正**。其在 LIBERO 上 98.35% 的平均成功率与 LIBERO-Plus 上 72.6% 的零样本鲁棒性，为该路线提供了有竞争力的经验支持；消融进一步表明"深块条件化 + 浅块无条件共享变换"与"分数复用"是两个真正起作用的组件，而非结构性冗余。与此同时，单次运行、引用式基线对比、纯仿真验证与不完整的算力披露，使其结论更适合被读作"该路线可行且值得作为基线"而非"该路线已被确证优越"。后续工作最有价值的方向是：统一配方下与 NinA / RoMAN-Flow 的重训对比、多步 Tweedie 修正的精度-延迟曲线、$\sigma$ 的敏感性分析，以及真机部署验证。
