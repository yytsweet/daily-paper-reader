## 摘要
视觉-语言-动作（VLA）模型在多任务机器人操作中展现出强大能力。然而，在物体抓取、对齐和插入等关键操作阶段，它们在控制精度和执行稳定性方面仍存在局限。为将通用操作能力与任务特定的细粒度控制相结合，并在多阶段操作任务中实现通用策略与专用策略之间的有效协调，本文提出 MARS（模块化原子技能路由系统），一种面向基于强化学习的原子技能的动态路由框架。MARS 将冻结的通用 VLA 策略与多个独立训练的原子技能策略相集成。利用共享的 RL Token 状态表示和 VLA 的参考动作，针对不同关键操作阶段，通过强化学习优化专用控制策略。针对高层策略选择，我们开发了一种融合时间上下文与技能语义的动态路由器。该路由器采用基于 Mamba 的循环编码和历史特征窗口来捕捉操作过程中的状态演化。候选策略的技能描述被编码为语义查询，并利用注意力机制建立技能语义与时间状态特征之间的对应关系。实验结果表明，在固定轨迹评估下，MARS 在四个 LIBERO 任务套件上取得 90.47% 的平均 Macro-F1 分数，比基于 MLP 的路由器高出 7.08 个百分点。在模拟 Tube Transport 任务中，全任务成功率从 20.04% 提升至 85.67%。这些结果表明，阶段特定的强化学习和时间状态感知的动态策略路由能够改善多阶段机器人操作中的多策略协调与整体任务执行性能。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong capabilities in multi-task robotic manipulation. However, they still face limitations in control precision and execution stability during critical manipulation stages, such as object grasping, alignment and insertion. To combine general-purpose manipulation capabilities with task-specific fine-grained control, while enabling effective coordination between generalist and specialized policies throughout multi-stage manipulation tasks, this paper proposes MARS (Modular Atomic-skill Routing System), a dynamic routing framework for reinforcement learning-based atomic skills. MARS integrates a frozen generalist VLA policy with multiple independently trained atomic skill policies. Using a shared RL Token state representation and the reference action of VLA, specialized control policies are optimized through reinforcement learning for different cr`itical manipulation stages. For high-level policy selection, we develop a dynamic router that integrates temporal context and skill semantics. The router employs Mamba-based recurrent encoding and a historical feature window to capture state evolution during manipulation. Skill descriptions of candidate policies are encoded into semantic queries, and attention mechanisms are used to establish correspondences between skill semantics and temporal state features. Experimental results show that MARS achieves an average Macro-F1 score of 90.47% across four LIBERO task suites under fixed-trajectory evaluation, outperforming an MLP-based router by 7.08 percentage points. In the simulated Tube Transport task, the full-task success rate increases from 20.04% to 85.67%. These results demonstrate that stage-specific reinforcement learning and temporal state-aware dynamic policy routing can improve multi-policy coordination and overall task execution performance in multi-stage robotic manipulation.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作）模型（RT-1/RT-2、Octo、OpenVLA、π0、SmolVLA 等）通过大规模机器人数据预训练，已具备较强的多任务操作泛化能力，但在**抓取、对齐、插入**等对精度与稳定性要求高的关键阶段仍表现不足。
- **核心矛盾**：多阶段操作任务（如多物体抓放、试管搬运）中，不同阶段对控制策略的要求差异很大——运输、复位等阶段通用策略即可胜任，而对齐、插入则需要高精度专用控制。**单一策略难以同时兼顾通用性与关键阶段的精细控制**。
- **现有 RL 后训练方法的局限**：
  - 一类方法（VLA-RL、SimpleVLA-RL、iRe-VLA、π0.6）直接优化动作生成或模型参数；
  - 另一类（RL Token、PARTS、Object-Centric Residual RL、VLaRL）通过轻量模块/残差策略保留预训练能力；
  - 但**用单一策略优化整个多阶段任务**时，若只有“全任务成功/失败”的二元终端奖励，中间动作得不到反馈，价值估计与策略优化困难。
- **本文思路**：将关键阶段分解为**原子技能**并分别用 RL 优化（提供局部奖励），再由**动态路由器**在冻结的通用 VLA 与多个原子技能策略之间进行选择与切换，实现“通用能力 + 专用精细控制”的协同。

### 2.1 整体框架

- 解耦设计：**低层原子技能优化** 与 **高层策略选择（路由）** 分离。
- 状态表示：s_t = [z^RL_t ; q_t]，其中 z^RL_t 为共享 RL Token 特征，q_t 为归一化本体感知状态。
- 路由器 R_φ 依据状态历史 s_{1:t} 与技能描述集合 S 输出 K+1 类策略概率分布 p_t。

### 2.2 共享 RL Token 特征提取
- 冻结 VLA 主干 F_VLA 输出多模态特征序列 H_t；对有效 token 归一化并用二值掩码 m_t 标记。
- 加入位置嵌入与可学习聚合 token，经 Transformer 编码器 g_ψ 压缩为固定维度表示 z^RL_t。
- 训练时用解码器 g_η 重建归一化中间特征，损失为有效 token 上的**均方误差重建损失** L_rec；训练完成后丢弃解码器、冻结编码器，供所有原子技能与路由器共享。

### 2.3 原子技能策略学习（TD3 + 参考动作约束）
- VLA 生成动作序列，取前 C 个动作构成**参考动作块** A^ref_t；Actor 以 (s_t, A^ref_t) 为输入输出长度 C 的动作块。
- 每个技能维护独立回放缓冲区 D_j，内含 VLA 预热轨迹、在线交互轨迹与人工干预轨迹；采用**滑动窗口（步长 2、段长 C）** 抽取重叠片段提升数据利用率，终止标志 δ 表示局部目标达成或策略切换。

### 2.4 动态路由器（时序上下文 + 技能语义）
- **时序建模**：z^RL_t 经线性层、q_t 经 MLP 后归一化拼接为 x_t，送入 **2 个 Mamba 块**的因果时序编码器（带循环缓存 ξ_t），得到 h_t；维护长度 L 的**历史特征窗口** M_t，并加入可学习的相对时间嵌入 e_i。
- **技能语义查询**：用冻结的 **SigLIP 2（ViT-B/16）** 文本编码器编码技能描述，经 L2 归一化与共享线性投影得到查询向量 v_j（离线预计算缓存）。
- **注意力融合**：N_q 层模块中，先对技能查询做**自注意力**捕捉技能间关系，再以技能查询为 Q、历史窗口为 K/V 做**交叉注意力**，得到技能条件表示 f_{t,j}。
- **打分与路由**：共享评分网络 g_score 输出匹配分，Softmax 得路由概率 p_{t,j}。
- **路由训练**：采用**类别频率加权的交叉熵损失**（权重 w_j = N/((K+1)n_j)）缓解不同技能时长导致的类别不平衡。
- **动态切换机制**：仅当最优候选与当前策略不同、其概率 ≥ 阈值 τ、且连续 k 步满足条件时才切换；配合**动作队列 B**，切换时清空队列，队列空时由 VLA 生成新动作块或作为选中技能的参考，实现块级动作与逐步路由的协调。

### 2.5 闭环执行算法（Algorithm 1）

- **Q1 局部技能有效**：RL 原子技能在 4 项局部操作上全面优于冻结 VLA，插入任务提升最显著（Tube Transport 插入 69.57% → 96.85%，+27.28 个百分点；抓取 +15.20~+20.14 个百分点）。但作者指出局部提升不必然带来全任务提升。

- **Q4 真机验证**：真实 Tube Transport 全任务 SR 从 12.00% 提升至 **74.00%**（+62 个百分点），SCR 从 27.33% 升至 83.33%，抓取成功率 136/139 vs 66/94，插入 125/136 vs 41/66，成功回合平均耗时从 39.53 s 降至 31.96 s。
- **总体结论**：阶段专用 RL 优化可缓解长时程稀疏奖励难题（缩短奖励传播链），时序状态感知的动态路由能有效协调多策略，二者结合显著提升多阶段操作性能。

- **技能集合需人工预定义**：原子技能的目标、数量与技能描述文本均由人工给定（如 Grasp、Place、Insert），论文未讨论如何自动发现或切分关键阶段。对新的长时程任务，仍需领域知识介入，限制了“开箱即用”的自动化程度。
- **路由器依赖离线标注的阶段标签**：路由训练使用带策略标签的轨迹做监督学习，标签来自规则或人工划分。若真实任务中阶段边界模糊（如“对准”与“插入”连续过渡），标签噪声会直接影响路由质量，论文未评估标签噪声敏感性。
- **技能与 VLA 的耦合仍是单向的**：原子技能以 VLA 参考动作为输入并受其约束，但 VLA 本身保持冻结，技能学到的精细控制能力不会回流改进通用策略。长期看，这种“冻结主干 + 外挂技能”的范式可能受限于主干本身的能力上限。
- **切换机制的阈值与确认步数为固定超参**：τ=0.6、k=2 在所有任务上共用，未讨论自适应阈值或按任务调节的策略；对于阶段时长差异极大的任务，固定确认步数可能导致切换滞后或过于敏感。
- **RL Token 的重建目标偏通用**：以中间特征重建为自监督目标，虽然与具体技能无关、便于共享，但重建保真度与“对控制有用”之间并非等价，缺少对该表示是否保留任务关键信息的定量分析（如线性探测或可视化）。

### 8.2 实验层面
- **缺少与同类方法的直接数值对比**：LIBERO 上仅与自实现的 Frozen VLA、Monolithic RLT 及三种路由架构比较，未与 AtomicVLA、SMoDP、SWAP 等同样涉及技能分解/策略切换的工作做同协议对比，削弱了“相对 SOTA 的增益”这一结论的说服力。
- **真实机器人验证规模有限**：单一任务（Tube Transport）、单一机械臂与相机布局、固定源/目标架位置，未做物体位姿扰动、光照变化、相机外参偏移等鲁棒性测试，也未报告失败模式分类（如抓空、插入偏移、路由误切换各占多少）。
- **Monolithic RLT 基线的强度存疑**：该基线用同一 RL Token 与参考约束训练单一 Actor，但未说明其超参是否经过与 MARS 同等强度的调优；若基线偏弱，10.52 个百分点的提升可能被高估。
- **统计显著性缺失**：仅报告 3 个种子的均值 ± 标准差，未做显著性检验；在部分套件上方法间差距接近方差量级时，结论稳健性难以判断。
- **未报告推理开销**：Mamba 时序编码、历史窗口注意力、技能查询自/交叉注意力叠加在 VLA 推理之上，实时性（控制频率、单步延迟）对真机部署至关重要，但文中未给出时延或算力对比数据。
- **训练数据规模与来源披露不足**：各技能的预热轨迹数量、人工干预轨迹比例、在线交互步数等关键数据量信息不完整，影响可复现性与样本效率的评估。

### 8.3 可复现性
- 单卡 4090 的配置降低了复现门槛，超参与网络结构披露较完整，是加分项；但 RL Token 编码器的 Transformer 层数/维度、解码器结构、各技能的奖励函数具体形式（稀疏奖励的判定容差）等细节仍不够充分，完整复现存在一定障碍。

## 9. 启发与可借鉴点

- **“分解—专精—路由”是缓解长时程稀疏奖励的通用范式**：把一条长链路的信用分配问题拆成若干短链路，本质上缩短了奖励传播距离，这一思路可迁移到导航、装配、多步骤工具使用等任意长时程决策任务，不限于 VLA 操作。
- **共享状态表示、独立策略头**：一次训练 RL Token、多技能复用的做法，与多任务 RL 中的共享编码器 + 任务特定头思路一致，在算力受限时尤其实用，可作为“多技能 RL 后训练”的默认工程模板。
- **参考动作 + 输入 dropout 的正则化组合**：既借预训练先验稳定早期探索，又通过随机置零避免策略退化为“复制 VLA”，这一技巧对任何“以强先验模型为参考做 RL 微调”的场景（如扩散策略微调、LLM 智能体 RL）都有直接借鉴价值。
- **用技能描述文本作为查询、让路由具备语义泛化潜力**：相比把技能 ID 当作 one-hot 类别，语义查询使路由器在原则上能处理新增技能（只需提供描述），为后续扩展到开放技能集留出了接口。
- **“块级动作 + 逐步路由 + 队列清空”的协调设计**：解决了高层离散切换与低层动作块执行之间的时序错位，是分层控制落地时的常见工程痛点，其处理方式（队列空时才请求新块、切换即清空）值得在类似分层系统中复用。
- **评估体系的分层设计**：局部技能成功率 → 固定轨迹路由 Macro-F1 → 闭环任务 SR/SCR → 真机部署，四层指标各自回答不同问题，能有效定位性能瓶颈出现在“技能不行”还是“路由不行”，这一评估框架本身具有方法论价值。

## 10. 总体评价

- **定位**：本文属于“系统与工程贡献为主、方法创新为辅”的工作。核心贡献不在于提出全新的 RL 算法，而在于**把已有的组件（RL Token、TD3、参考动作约束、Mamba 时序建模、语义查询注意力）以一种合理且有细节考量的方式组装成一个可用的分层系统**，并用较完整的实验链条证明其有效性。
- **贡献强度**：从 Frozen VLA 20.04% → MARS 85.67%（仿真 Tube Transport）、12.00% → 74.00%（真机）的提升幅度相当可观，说明“关键阶段专精 + 动态路由”这一思路在精度敏感型多阶段任务上确有实效，而非仅靠调参堆出的边际收益。
- **主要短板**：缺少与同类技能分解/路由方法的同协议横向对比；真机验证的场景多样性不足；路由依赖人工阶段标签，自动化程度受限；推理开销未披露。这些短板不影响核心结论的方向，但会影响结论的普适性强度。
- **适用场景判断**：方法最适合**阶段结构清晰、关键阶段对精度要求高、且能获得阶段标签或可规则化划分阶段**的工业/实验室操作任务（插装、装配、精密搬运）。对于阶段边界模糊、任务种类高度开放的场景，其预定义技能集与监督式路由会成为主要瓶颈。
- **后续值得跟进的方向**：技能自动发现与在线增扩、路由的自监督/弱监督训练（摆脱阶段标签）、技能到 VLA 主干的反馈式联合优化、以及推理延迟的工程优化。
- **一句话总结**：MARS 用“共享 RL Token + 原子技能专精 + 语义-时序动态路由”把通用 VLA 的广度与专用策略的精度结合起来，在仿真与真机上均取得大幅提升，是一篇工程完成度高、实验链条完整、结论可信但横向对比与自动化程度仍有提升空间的分层 VLA-RL 后训练工作。
