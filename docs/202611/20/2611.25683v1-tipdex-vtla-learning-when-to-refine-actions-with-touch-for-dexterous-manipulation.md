## 摘要
即使物理状态保持不变，光照变化也可能在灵巧操作中引起动作漂移。尽管现有的视觉—触觉—语言—动作（VTLA）策略融入了触觉反馈，但在视觉条件变化时，触觉何时以及如何细化动作仍具有挑战性。我们提出 TipDex-VTLA，一种结合估计的视觉动作可靠性与触觉预测验证来调节执行时细化的 VTLA 策略。具体而言，视觉动作敏感性估计（VASE）从冻结参考策略对光照扰动的动作敏感性中学习视觉可靠性。执行期间的触觉预测与校正（TACE）在匹配时刻比较预测触觉与实测触觉，并将所得差异与视觉可靠性结合，以门控未执行动作的有界特征校正。这有效地有助于在具有挑战性的未见视觉条件下细化动作。我们在四个真实世界灵巧操作任务和 UniVTAC 仿真基准上评估 TipDex-VTLA。在正常视觉条件下采集的数据上训练的 TipDex-VTLA，在真实世界任务中于正常光照（相应地，具有挑战性的未见光照）下分别取得 87.5%（相应地，73.8%）的平均全任务成功率，显著优于一些最先进方法。我们将发布所采集的数据和源代码。

## Abstract
Changes in illumination can induce action drift in dexterous manipulation even when the physical state remains unchanged. Although existing vision--tactile--language--action (VTLA) policies incorporate tactile feedback, when and how touch refines actions under changing visual conditions remains challenging. We introduce \textbf{TipDex-VTLA}, a VTLA policy that combines estimated visual action reliability and tactile forecast verification to regulate execution-time refinement. Specifically, Visual Action Sensitivity Estimation (VASE) learns visual reliability from a frozen reference policy's action sensitivity to illumination perturbations. Tactile Anticipation and Correction during Execution (TACE) compares predicted and measured touch at matched times and combines the resulting discrepancy with visual reliability to gate bounded feature corrections for unexecuted actions. This effectively helps to refine actions under challenging unseen visual conditions. We evaluate TipDex-VTLA on four real-world dexterous manipulation tasks and the UniVTAC simulation benchmark. TipDex-VTLA trained on data collected under normal visual conditions, achieves average full-task success rates of 87.5% (resp. 73.8%) under normal (resp. challenging unseen) lighting in real-world tasks, significantly outperforming some state-of-the-art methods. We will release the collected data and source code.

## 1. 核心问题与研究动机

- **背景**：视觉—语言—动作（VLA）策略从图像和语言指令生成操作动作，但在接触密集的灵巧操作中，手部常遮挡交互区域，局部接触的起始与演化难以从视觉观察；同时视觉引导对光照高度敏感——即使物理场景不变，光照变化也会改变策略预测，导致“动作漂移”。
- **现有 VTLA 的不足**：已有视觉—触觉—语言—动作（VTLA）策略虽引入触觉反馈，但缺少一个关键判断：**在当前视觉条件下，原计划是否仍然可靠？触觉应在何时、以多强的方式修正动作？** 触觉预测校验只能回答“接触是否按当前计划演化”，无法回答“该计划在當前视觉条件下是否可信”。
- **核心洞察**：视觉可靠性与触觉预测一致性是两类互补信号，可组合为四种执行期细化情形：
  - 触觉与预测一致 + 视觉可靠性低 → 做视觉补偿；
  - 触觉一致 + 视觉可靠性高 → 保持原计划；
  - 触觉偏离 + 视觉可靠性低 → 更强的联合修正；
  - 触觉偏离 + 视觉可靠性高 → 仍偏向接触修正。
- **整体含义**：论文希望让 VTLA 策略在**仅在正常光照数据上训练**的前提下，于未见光照条件下按需调用触觉进行有界、可控的动作细化，而不是无条件依赖触觉或视觉。

## 2. 方法论

### 2.1 总体框架

- **基础策略 π_θ** 由三部分组成：预训练 VLM（编码图像、语言、本体状态的 prefix，得到上下文 c_t）、触觉编码器（聚合近期触觉历史为 F_t，保留 5 个指尖区 + 3 个掌心区）、flow-matching 动作专家（生成 H 步动作块 A_t）。
- **慢—快流生成**（沿用 T-Rex 思路）：慢更新缓存 c_t 与中间流状态 X_{τs}（0<τ_s<1）；快更新时从 τ_s 继续积分到 τ=1，复用缓存并注入当前触觉反馈。论文中 τ_s=0.6，即仅在最后 4 个流积分步施加触觉细化。
- **辅助触觉预测器 P** 与动作专家共享触觉编码器，输入 c_t 与执行上下文 ξ_t′（机器人状态、触觉特征、当前动作序列及执行时刻），预测未来 H 帧归一化触觉，缓存后用于后续校验。

### 2.2 VASE：视觉动作敏感性估计

- **目的**：为每个观测估计一个“动作相关”的视觉可靠性分数，而非图像质量分数。
- **监督构造**：对每条演示观测保留原始多视图图像 I_a，并对同一观测施加光照增强得到 I_b（低照度、强照度、光照方向改变、不均匀光照、不变光照五类各 20% 概率），保证视角与物理状态一致。
- **冻结参考策略**在语言、机器人状态、触觉历史、采样噪声与采样设置完全相同的条件下分别生成 â_a 与 â_b，其差异即参考策略对图像扰动的动作敏感性。
- **可靠性目标**：q′_v = exp(−MSE(â_a, â_b)/λ)，当两预测完全一致时为 1，差异越大越接近 0；λ 控制衰减尺度。作者明确说明这只是“动作一致性代理”，**不代表动作正确性或任务成功概率**。
- **估计头**：q_v = σ(h_ω(Pool(c_t)))，用 BCE 损失以 q′_v 监督；部署时只需当前 prefix，不需要配对参考图像，并在每次慢更新时缓存 q_v。

### 2.3 TACE：执行期触觉预测与校正

- **触觉校验**：在快更新 t′，取最近一次“在 t′ 之前、且与 intervening 已执行动作一致”的缓存预测 T̂_t′，计算与实测 T_t′ 的归一化平均绝对误差 e_t′；若无合格预测则令 e_t′=0，退化为仅用视觉分数（作者注明这不代表预测准确）。
- **执行分数**：q_t′ = G(q_v, e_t′)，要求 G 对 q_v 非减、对 e_t′ 非增，且 G(q_v,0)=q_v。即视觉可靠性是基线，触觉校验只能下调分数。
- **门控特征修正**：对每个可替换、未执行的动作位置 h，由共享 Refinement Network 及 Residual/Gate 两个头给出残差 R_ψ 与门控 logit S_ψ，修正为
  - g_{τ,h} = σ(S_ψ(U_{τ,h}, ξ_t′) − κ·logit(q_t′))
  - Ũ_{τ,h} = U_{τ,h} + g_{τ,h}·b·tanh(R_ψ(U_{τ,h}, ξ_t′))
  - 其中 b>0 逐分量限制残差幅度（实验中 b=0.1），κ>0 控制执行分数对门控的影响；视觉可靠性越低或校验差异越大，门控越倾向于放开，允许更强修正。
- **时序保持**：修正后的特征经剩余动作专家层生成更新动作块 Ã_t，**只替换可替换、未执行的动作命令，动作位置与原始执行时刻全部保持不变**。

### 2.4 两阶段训练

- **Stage 1**：用未增强图像演示联合训练 VTLA 主干与触觉预测器。对归一化专家动作块 a*，采样 ε~N(0,I)、τ~U(0,1)，构造 X_τ=(1−τ)ε+τa*；损失 L1 = E[‖v_θ(X_τ,τ|c_t,F_t) − (a*−ε)‖² + λ_T·L_T]，L_T 为预测与实测归一化触觉序列的 Huber 损失。训练后**冻结全部 Stage 1 参数**。
- **Stage 2**：仅优化 VASE 头 ω 与 TACE 模块 ψ。VASE 用配对光照观测与 q′_v 监督（BCE）；TACE 用同一冻结参考预测的带符号动作修正目标 Δa = â_a − â_b，并以 I_b 缓存同一名义轨迹的 X_{τs}，从 τ_s 续算到 1 得到细化动作块 â_b′，损失为
  - L_Q = E[BCE(q_v(I_b,ℓ,s_t), q′_v)]
  - L_R = E[MSE_M(â_b′ − â_b, Δa)]
  - L2 = λ_Q·L_Q + λ_R·L_R
  - M 仅选择可替换、未执行的动作坐标；无选中坐标的样本从 L_R 中剔除。
- **梯度隔离**：训练时门控使用 stop-gradient 的 sg(q_t′)，使 L_Q 只更新 ω，L_R 只经修正路径更新 ψ，主干始终冻结。

- **真实任务**：标准光照平均全任务成功率 **87.5%**（Egg 90 / Grape 95 / Tissue 75 / Beans 90），未见光照 **73.8%**（70 / 90 / 60 / 75），两种条件下均为四任务最高。
- **未见光照下的显著优势**：较 N0-VTLA（31.3%）高 **42.5

- **标准光照下的稳健性**：完整模型在 N 条件下仍优于带触觉的 T-Rex 与 N0-VTLA，说明 VASE/TACE 并未以牺牲正常条件性能为代价换取鲁棒性；其中纸巾抽取（Tissue）在两种光照下均为最低（75% / 60%），作者归因于可变形物接触状态本身难以从 364 个 taxel 的低维压阻信号中稳定刻画。

- **仿真结果**：在 UniVTAC 八个任务上，完整模型平均成功率最高，且在 Insert Hole、Insert HDMI、Insert Tube 等接触精度要求高的插入类任务上相对纯视觉基线的提升最明显；Grasp、Classify 等以抓取稳定性为主的任务上，各带触觉方法差距收窄。作者据此论证：触觉预测校验的收益随“接触几何精度要求”上升而增大。

  - 三组件同时缺失时性能低于纯视觉基线，提示错误的触觉注入可能比不用触觉更糟。

- **光照强度扫描（图 5）的机理发现**：
  - q_v 随曝光偏移（−3 EV 至 +3 EV）单调下降，与预测轨迹 RMSE 呈明显负相关，验证了“动作敏感性代理”确实能刻画与任务执行相关的视觉可靠性，而非单纯图像质量；
  - 去掉预测校验的变体在低光端 RMSE 上升更快，说明触觉校验在视觉最不可靠区间起到主要兜底作用；
  - 去掉特征修正的变体虽然 q_v 估计正常，但因无法实际改变动作，RMSE 几乎不随 q_v 下降而改善，形成“能诊断但不能治疗”的对照，反向证明门控修正通路的必要性；
  - 过曝端（+3 EV）性能退化整体小于低光端，作者推测与压阻触觉信号在强光下不受影响、而低光下视觉特征整体信噪比下降更彻底有关。

- **总体论断**：论文的核心贡献不是“用了触觉”，而是把触觉重新定位为**执行期的计划校验信号**，并与视觉可靠性分数组合成一个单调、有界、可解释的执行分数 q_t′，从而把“何时修、修多少”从隐式学习变成显式可控的门控变量。

## 7. 局限与批判性评价

- **理论层面的薄弱点**：
  - q′_v 被明确定义为“参考策略在配对光照扰动下的动作一致性”，作者也承认它不等于动作正确性；但整条门控链路（q_t′ → logit 偏置 → 残差幅度）默认“一致性高即可信”，在参考策略本身在某种光照下系统性错误但稳定时，q_v 会给出高分，此时系统不会调用触觉纠正。这是一个未被实验覆盖的失效模式。
  - 执行分数 G 只被约束为“对 q_v 非减、对 e_t′ 非增、G(q_v,0)=q_v”，函数形式与标定方式未给出，κ 的取值也缺少敏感性分析，导致“有界可控”的主张在定量上不够扎实。
  - 触觉校验使用归一化 MAE 作为偏离度量，对所有 taxel 等权，未区分指尖/掌心、接触/非接触区域的重要性差异，可能稀释关键接触点的偏离信号。

- **实验层面的局限**：
  - 真实实验每任务仅 20 次试验、成功率分辨率 5%，且未报告置信区间、方差或多随机种子，42.5 个百分点的差距虽大，但 20 次试验下单项对比的统计稳健性仍有限；未做显著性检验。
  - 仅单一机器人平台（RM75 + Inspire 灵巧手）与单一触觉模态（压阻阵列），未验证跨 embodiment、跨传感器（如光学触觉、电容）的迁移性；仿真部分虽用 UniVTAC 光学触觉，但那是适配而非原生验证。
  - 未见光照全部为受控室内设定（非对称光照、色温、低光、强光），未覆盖户外、动态阴影、相机自动曝光剧烈波动、镜头污损等更广的分布偏移，鲁棒性结论的外推范围有限。
  - Stage 2 需要为每条演示额外采集光照扰动副本并跑冻结参考策略生成配对监督，这一数据与算力开销未被量化，实际部署成本不清晰。
  - 缺少与 TacPAC、ReTouch、ResTacVLA、TouchWorld 等“触觉预测 + 执行期修正”同类方法的直接对比，仅在 Related Work 中定性区分，“优于 SOTA”的表述说服力被削弱。
  - 关键超参（λ、κ、b、τ_s=0.6、触觉历史长度、5 指尖 + 3 掌心区的分区方式）均无消融或敏感性曲线，读者难以判断方法对调参的敏感程度。

- **工程与可复现性**：
  - 未报告训练总时长、GPU 小时、推理频率/延迟与显存占用；对“快更新只作用于最后 4 个流积分步”这一实时性设计，缺少端到端控制频率的实测数据，而这对接触密集操作至关重要。
  - 代码、数据、模型权重是否开源未在正文中说明。

- **写作与呈现**：
  - 部分表述存在轻微过度归纳，例如把“触觉校验在标准光照下贡献更大”直接解释为机理结论，而消融中 N/U 差异也可能来自训练数据分布与任务难度的混杂。
  - 四个真实任务的难度与接触特性差异较大（易碎、易损、可变形、颗粒），但未做任务难度归一化，跨任务平均成功率的解释力有限。

## 8. 启示与可拓展方向

- **可借鉴的方法论范式**：把“传感器可靠性估计”与“跨模态一致性校验”解耦为两个独立可监督的子问题，再用一个单调门控函数组合，是一种可迁移到其他多模态策略（如视觉 + 力/力矩、视觉 + 音频）的通用执行期细化框架；其关键在于可靠性目标必须是**任务相关**的（动作敏感性）而非**信号质量相关**的（图像清晰度）。
- **可拓展方向**：
  1. 将 q_v 的监督从“参考策略动作一致性”升级为与任务成功/失败结果关联的校准目标，缓解“稳定地错”导致的漏检；
  2. 用注意力或可学习权重替代 taxel 等权 MAE，使触觉校验聚焦关键接触区；
  3. 引入在线自适应 κ、b（例如按 e_t′ 的时序趋势调整），把当前的固定门控升级为闭环控制；
  4. 在更多 embodiment 与触觉模态上验证，并补充跨传感器迁移实验；
  5. 补齐推理延迟与实时性实测，验证该方法能否满足接触密集任务的控制频率要求。
