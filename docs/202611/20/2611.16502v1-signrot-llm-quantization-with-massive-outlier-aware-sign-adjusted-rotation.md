## 摘要
量化虽能压缩LLM并加速推理，但离群激活会阻碍高效的低比特表示。尤其是，大规模离群值会造成显著的性能下降。尽管依赖随机Hadamard变换进行在线推理的旋转类方法旨在缓解这一问题，但当某个大规模离群值主导一个token的激活时，这类方法可能产生带有空bin的碎片化分布。这种碎片化会严重削弱均匀量化的性能。此外，大规模离群值集中在down-projection输入中，而其前面的非线性操作要求在推理时施加旋转。这一约束使得SpinQuant等基于训练的方法无法在该位置学习在线旋转，因为学习得到的稠密矩阵无法使用快速Walsh-Hadamard变换，并且在推理时需要完整的矩阵乘法。为解决这一问题，我们提出SignRot（符号调整旋转），它识别大规模离群值通道，并构造符号调整向量，使对应Hadamard行的符号统一，从而将双峰分布坍缩为适合量化的单峰形态。由于对齐后的离群值会使激活均值偏离零，我们将SignRot与非对称激活量化配对使用，其零点可吸收该偏移。作为一种轻量级、即插即用的改进，SignRot与任何基于Hadamard的量化方法兼容，仅需一次校准前向传播，并在推理时仅增加逐元素符号翻转，而无需额外的矩阵乘法。将SignRot应用于QuaRot后，在LLaMA3-70B模型上取得5.88的WikiText2困惑度和72.73的平均零样本推理准确率，超过SpinQuant。代码见 https://github.com/HYU-ARK-Lab/SignRot。

## Abstract
While quantization compresses LLMs and accelerates inference, outlier activations impede efficient low-bit representation. In particular, massive outliers cause substantial performance degradation. Although rotation-based methods that rely on randomized Hadamard transforms for online inference aim to mitigate this, they can produce fragmented distributions with empty bins when a massive outlier dominates a token's activation. This fragmentation severely undermines uniform quantization performance. Moreover, massive outliers concentrate in the down-projection input, where the preceding nonlinearity requires the rotation to be applied at inference time. This constraint prevents training-based approaches such as SpinQuant from learning the online rotation at this position, as a learned dense matrix cannot use the Fast Walsh-Hadamard Transform and would require a full matrix multiplication during inference. To address this, we propose SignRot (Sign-adjusted Rotation), which identifies massive outlier channels and constructs a sign adjustment vector that unifies the signs of the corresponding Hadamard row, collapsing the bimodal distribution into a unimodal profile amenable to quantization. Since the aligned outlier shifts the activation mean away from zero, we pair SignRot with asymmetric activation quantization, whose zero-point absorbs this shift. As a lightweight, drop-in improvement compatible with any Hadamard-based quantization method, SignRot requires only a single calibration forward pass and adds only element-wise sign flips at inference, without an additional matrix multiplication. Applying SignRot to QuaRot achieves a WikiText2 perplexity of 5.88 and an average zero-shot reasoning accuracy of 72.73, surpassing SpinQuant on the LLaMA3-70B model. Code is available at https://github.com/HYU-ARK-Lab/SignRot.

- **大背景**：LLM 规模急剧膨胀，量化（尤其是训练后量化 PTQ）成为压缩模型、加速推理的关键技术。但激活中的**巨量离群值（massive outliers）**会严重扭曲低比特均匀量化。

- **现有方法的矛盾**：
  - 为保持推理效率，在线旋转只能采用**随机 Hadamard 变换（RHT）**以利用快速 Walsh–Hadamard 变换（FWHT）。
  - 但基于训练的方法（如 SpinQuant）无法在此位置学习稠密旋转矩阵，因为稠密矩阵无法使用 FWHT，会引入完整矩阵乘法。
- **核心观察（论文的“病因诊断”）**：当某个 token 的激活被一个巨量离群值主导时，RHT 会把能量分散成**正负两簇、中间留空的碎片化双峰分布**（图 1）。空 bin 会**撑大激活量化范围、增大步长**，直接恶化量化误差。
- **整体含义**：论文提出一个**极轻量、免训练、即插即用**的符号调整方案，专门修复在线 Hadamard 旋转下的双峰碎片化问题，从而在几乎零额外推理开销的前提下提升 4-bit 量化性能。

## 2. 方法论（核心思想、技术细节与算法流程）

### 2.1 理论分析：双峰碎片化的成因

- 设 token 激活为 $x_t$，离群通道为 $c_{\max}$，其值 $M_t$。RHT 输出为 $y_t = x_t \cdot \text{diag}(r) \cdot H$，第 $j$ 维可分解为：
  $$y_{t,j} = M_t r_{c_{\max}} h_{c_{\max},j} + \sum_{i \neq c_{\max}} x_{t,i} r_i h_{i,j}$$
- 由于 $h_{c_{\max},j}$ 符号交替，离群项在输出中呈 **$\pm M_t/\sqrt{C_{in}}$ 的二值贡献**，叠加近似高斯的残差后形成**双高斯混合**。
- 推导出**双峰判据**：当且仅当离群通道能量超过其余所有通道能量之和，即
  $$M_t^2 > \sum_{i \neq c_{\max}} x_{t,i}^2$$
  分布才呈双峰（至多一个通道能满足）。该条件对应“主导巨量离群通道”。
- 量化误差界：$\text{MSE}_t \le \Delta_t^2/4$，双峰使逐 token 量化范围至少增大 $2|M_t|/\sqrt{C_{in}}$，从而抬高 $\Delta_t$ 与误差。

### 2.2 核心方法：SignRot（符号调整旋转）

- **识别离群通道**：用一次校准前向，取
  $$c_{\max} = \arg\max_c \left(\max_t |x_{t,c}|\right)$$
  依据是巨量离群通道在输入间高度稳定（首个离群层中同 token 能量占比 87–99.9%）。
- **构造符号调整向量**：
  $$n_j := \text{sign}(h_{c_{\max},j})$$
- **构造符号调整 Hadamard 矩阵**：
  $$H_{adj} = H \cdot \text{diag}(n)$$
  这样 $c_{\max}$ 行所有元素统一为 $+1/\sqrt{C_{in}}$，离群贡献从交替符号变为**恒定正偏移**，双峰坍缩为单峰。
- **等价嵌入线性层**：由于 $\text{diag}(n)$ 是对合矩阵，
  $$Y = XW = (X H_{adj})(H_{adj}^{-1} W)$$
  $\text{diag}(n)^{-1}$ 可**离线合并进权重 $W_d$**，推理时只需对中间激活 $X_d$ 做**逐元素符号翻转**（无额外矩阵乘法）。
- **非对称激活量化（关键配套）**：符号对齐后分布均值偏移，采用**非对称–对称矩阵乘（Asym–Symm matmul）**，用零点 $Z_X$ 吸收偏移：
  $$Y_{deq} = \Delta_X (X_q W_q - Z_X W_q)\Delta_W$$
  其中零点修正项 $z_X(1^\top W_q)$ 的列和可离线预计算，在线只增加 $O(TC_{out})$ 的秩-1 外积开销。

### 2.3 算法流程（一句话概括）

一次校准前向 → 找 $c_{\max}$ → 算 $n$ → 把 $\text{diag}(n)^{-1}$ 折进权重 → 推理时激活乘 $\text{diag}(n)$ 并做非对称量化。

## 6. 主要结论与发现

- **碎片化确实存在且有害**：RHT 在巨量离群主导时产生双峰、空 bin，撑大量化范围；首个巨量离群层是量化误差最大的层之一（单层 KL 达无离群层中位数的 2.3–3.6×）。
- **SignRot 有效修复**：在首个巨量离群层将单层 KL 降低 **36–61%**，且非离群 token 的 KL 也下降 31–64%（误差经 attention 传播）；逐 token 范围缩小 2.6–11.3×。
- **性能提升**：
  - LLaMA3-70B + GPTQ：QuaRot+SignRot 的 WikiText2 PPL 从 6.16 降到 **5.88**，平均零样本准确率从 72.28 升到 **72.73**，**超过 SpinQuant（6.38 / 71.15）**。
  - SpinQuant+SignRot 进一步把 PPL 从 6.38 降到 **5.45**，准确率从 71.15 升到 **73.52**。
  - LLaMA2-13B、LLaMA3-8B 等也普遍改善，并可与 DartQuant 叠加。
- **非对称量化是必要组成**：单独符号调整在对称量化下收益有限，配合非对称量化后增益显著（LLaMA3-8B 准确率 +0.99 分）。
- **开销极低**：端到端延迟仅增加 **0.43%**，峰值内存 +0.02%，仍保持相对 FP16 约 **1.65× 加速、3.19× 显存节省**。
- **通用性**：在 Mistral（稠密）与 Qwen3-30B-A3B（MoE）上同样有效。

## 7. 优点（亮点）

- **问题定位精准**：从“符号交替”这一被忽视的角度解释 RHT 碎片化，并给出可检验的能量主导判据，理论—现象—方法闭环。
- **方法极简且优雅**：仅一个 $\pm1$ 符号向量 + 对合矩阵性质，即可离线合并、在线只做逐元素翻转，**无额外矩阵乘法**。
- **即插即用**：兼容 QuaRot / SpinQuant / DartQuant 及任意 Hadamard 类方法，且同时适用于稠密与 MoE。
- **成本极低**：一次校准前向即可，量化时间与 QuaRot 持平，远快于 SpinQuant 的多 GPU 训练。
- **实验扎实**：多模型、多基线、多种子（部分）、控制变量严谨；额外提供延迟、内存、单层 KL 等实用性证据。
- **诚实披露**：对双峰判据的近似性、对单通道折叠的局限、对某些模型退化情形均有说明。

## 8. 不足与局限

- **每层仅折叠一个通道**：当 token 含多个巨量离群通道（如 LLaMA3-70B 首层 $M_2/M_1 \approx 0.34$）或后层主导通道随 token 变化（Mistral、Qwen3 末层）时，第二通道引起的分裂仍残留；作者将“按通道组分配独立 Hadamard + 符号向量”列为未来工作。
- **无巨量离群时的处理不明**：论文未说明在没有巨量离群值的层/场景下如何高效调整在线变换。
- **仅验证 Hadamard 类旋转**：对其他变换矩阵是否有效未知。
- **MoE 效率问题**：中间维度较小时 Hadamard 变换效率下降（Qwen3 专家下投影 $C_{in}=768$）。
- **实验覆盖的偏差风险**：
  - LLaMA3-70B 为单次运行，缺少方差；部分结论依赖特定裁剪比（70B 用 1.0）。
  - 校准仅用 WikiText2/C4 少量样本，虽做了敏感性分析，但下游任务分布差异未充分覆盖。
  - 主要评测为 PPL 与零样本准确率，缺少长上下文、生成质量、指令微调模型等场景。
- **理论近似性**：双峰阈值基于两高斯近似，作者自承“能量主导”是指示性判据而非精确检验；部分真实 token 不满足残差高斯条件。
- **应用限制**：依赖离群通道在输入间稳定的假设，对通道漂移严重的模型（部分末层）收益有限。
