## 摘要
现代大语言模型（LLMs）日益支持更长的上下文并服务更多并发请求，导致序列长度和批大小同时增加。这两种趋势都会增加推理期间的 KV 缓存大小和内存流量。KV 缓存量化可降低这些开销，近期方法使用基于码本的向量量化来实现极低比特宽度。然而，硬件限制码本大小，且大多数方法在注意力计算前将缓存重建为更高精度的浮点格式，从而限制了量化的计算收益。为解决这些局限，我们提出 MiSTiQ，一种可直接替换基于码本的向量量化器的方法，它将格状编码存储与微缩放（MX）格式相结合以实现低精度计算。我们将格状量化与束搜索结合，在无需大型码本的情况下于大重建空间上编码 KV 缓存。为支持 MX 计算，我们推导了 MX-Hash 函数，可直接在目标 MX 元素格式中生成重建值。这些函数利用块归一化高斯输入的尺度条件边缘分布。在 Llama3 和 Qwen3 上，MiSTiQ 在约 1.25 有效比特/元素时，在多种块缩放格式下相比所评估基线取得更低的 WikiText 困惑度和更高的 GSM8K 准确率。在 NVFP4 下，它还在两个模型上取得最高的 LongBench 平均值。

## Abstract
Modern large language models (LLMs) increasingly support longer contexts and serve more concurrent requests, increasing both sequence lengths and batch sizes. Both trends increase KV-cache size and memory traffic during inference. KV-cache quantization reduces these costs, with recent approaches using codebook-based vector quantization to achieve extremely low bit widths. However, hardware constraints limit codebook size, and most methods reconstruct the cache in higher-precision floating-point formats for attention, limiting the computational benefits of quantization. To address these limitations, we introduce MiSTiQ, a drop-in replacement for codebook-based vector quantizers that combines trellis-coded storage with microscaling (MX) formats for low-precision computation. We combine trellis quantization with beam search to encode the KV cache over large reconstruction spaces without large codebooks. To support MX computation, we derive MX-Hash functions that generate reconstruction values directly in the target MX element format. These functions use the scale-conditioned marginal distribution of block-normalized Gaussian inputs. On Llama3 and Qwen3, MiSTiQ achieves lower WikiText perplexity and higher GSM8K accuracy than the evaluated baselines across several block-scale formats at approximately 1.25 effective bits per element. With NVFP4, it also achieves the highest LongBench average on both models.

## 1. 核心问题与研究动机

- **背景压力**：LLM 支持更长上下文与更高并发，序列长度与批大小同时增长，导致 KV 缓存容量与内存带宽开销急剧上升；在投机解码、MLA、共享前缀等场景下，解码阶段甚至可能变成计算受限。
- **现有方案的两难**：
  - 码本向量量化（如 NSNQuant、VecInfer）能以极低比特压缩 KV 缓存，但**码本大小受硬件限制**，重建空间随维度指数增长；且大多数方法在注意力计算前需将缓存反量化回高精度浮点，**量化带来的计算收益被抵消**。
  - QTIP 用格状量化绕开显式码本，但针对权重压缩，且使用精确 Viterbi 搜索，编码开销大；尚未与微缩放（MX）计算格式结合。
- **核心问题**：如何在保持极低存储（<2 有效比特/元素）的同时，使 KV 缓存**直接重建为 MX 兼容格式**以支持低精度计算，并避免大型码本带来的硬件约束？
- **整体意义**：首次将「格状编码存储」与「MX 低精度计算」结合用于 KV 缓存量化，为码本向量量化提供即插即用替代方案，同时兼顾存储压缩与计算加速。

## 2. 方法论

### 2.1 核心思想
- **存储侧**：用 QTIP 式 bitshift 格状（trellis）编码替代显式码本，通过路径表示长向量，重建空间随格状长度而非码本规模增长。
- **计算侧**：将 MX 分块缩放（共享 scale + 低精度元素）前置于格状编码，使重建值直接落在 MX 元素网格（如 E2M1、E4M3）上，无需二次转换。
- **关键观察**：缩放与格状量化的**顺序影响误差**——先做 MX 分块缩放、再编码缩放后的值，优于先格状后 MX 转换。

### 2.2 关键技术细节
- **束搜索替代 Viterbi**：
  - 初始化 `{0,…,2^bstart−1}` 个假设（`bstart=0` 时固定初始状态为 0），每步对每个保留假设展开 `2^kV` 个后继，按累积失真保留至多 `B` 条最低成本路径。
  - 复杂度从 Viterbi 的 `O(2^L·T/V)` 降为 `O((2^bstart+(T/V−1)B)·2^kV)`，解码流程不变（仅状态恢复 + 哈希查表）。
  - 存储：分支标签 `c_t`（`kV` 比特）+ 初始状态（`bstart` 比特）。
- **MX-Hash（核心创新）**：
  - 假设输入近似高斯，推导**尺度条件 MX-Gaussian 分布**的逆 CDF `F⁻¹(p;s)`（公式 6），用逆变换采样把均匀比特映射到目标重建值。
  - 先经 **LCG + 位混合器**（XOR 移位 + 乘法）把格状状态 `u` 混合为均匀字，取符号位与幅值秩，再查逆 CDF 表，最后经 `Q_E` 量化到 MX 元素网格。
  - 支持两种变体：尺度条件版（初始尺度固定）与**Clipped MX-Hash**（尺度无关，输出随 scale 变化保持固定），后者用于联合尺度搜索。
  - 高效 LUT 实现：MX-Gaussian 约 7 KiB、Clipped 约 3 KiB（256 槽 × FP32 系数 + 共享 ierf 表），相对误差 <1%。
- **放松联合尺度搜索**：
  - 把量化块尺度 `s_b` 放松为连续变量 `a_b`，在束搜索每步用前缀统计量 `(R, W, D)` 闭式重拟合：`a* = (W + λ·s_ref)/(R + λ)`，块完成时令 `λ=0` 重拟合并舍入。
  - 正则项 `λ(a_b−s_ref)²` 防止短前缀导致尺度漂移；配合 Clipped Hash 使输出与尺度解耦。
- **混合精度 K/V**：
  - 键对量化更敏感，为 K/V 分配不同 transition-bit 预算（如高位配置 K/V = 8/6，低位 = 9/6）。
  - 增大向量长度 `V` 可让每比特变化对应 `1/V` 比特/元素，实现更细粒度分配（`V=4` 适合均匀载荷，`V=8` 适合极低比特下的非均匀分配）。
- **集成方式**：作为 NSNQuant / VecInfer 的码本量化器直接替换，保留其归一化与 Hadamard 变换；默认 `L=16, T=1024, B=128`。

## 8. 缺点与局限

- **模型与架构覆盖有限**：实验仅涉及 Llama-3.1-8B-Instruct 与 Qwen3-8B 两个同量级稠密模型，未验证更小（如 1B 级）或更大（70B+）模型，也未覆盖 MoE、MLA、GQA 变体等不同注意力结构；方法在 KV 头数、头维度、层间分布差异较大的架构上是否同样有效尚不清楚。
- **缺乏端到端系统实测**：论文主要在算法层面报告 PPL、LongBench、GSM8K，未给出实际解码延迟、吞吐、显存占用、内存带宽节省或能耗数据。MX 格式在现有 GPU（H100）上是否有原生/高效内核支持、Triton 实现的实际加速比如何，均未量化；因此“支持低精度计算”的收益仍停留在设计论证而非部署证据。
- **编码/校准开销未充分披露**：束搜索虽将复杂度从 Viterbi 的指数级降为 `O((2^bstart+(T/V−1)B)·2^kV)`，但相对简单 round-to-nearest 量化仍有明显编码成本；论文未报告单序列编码时间、校准总耗时，也未讨论在线/离线编码的适用边界。校准仅用 48 个候选、32 条训练向量，规模偏小，可能对分布偏移敏感。
- **高斯假设的稳健性存疑**：MX-Hash 的逆 CDF 推导基于输入近似高斯的假设（附录 C/D），而真实 KV 缓存常存在通道离群值、层间/头间分布差异及长尾现象。论文虽报告相对误差 <1%，但这是 LUT 逼近误差，不等于量化失真最优；分布失配时哈希映射可能次优，且缺少对非高斯输入的敏感性分析。
- **束搜索为启发式，非全局最优**：以束宽 `B=128` 保留最低成本路径，无法保证全局最优；`B`、`bstart`、`kV`、`V`、`T` 等超参对精度/开销的权衡缺少系统敏感性曲线（仅图 2 部分覆盖），实际部署时调参成本可能较高。
- **基线适配的公平性仍有争议**：作者承认基线码本拟合目标未纳入 MX 转换，虽为统一处理，但可能低估 NSNQuant/VecInfer 在 MX 网格上的潜力；同时未与 QTIP（权重压缩场景）、FP8/INT4 等非 MX 量化方案直接对比，优势边界不够清晰。
- **长上下文与动态场景验证不足**：LongBench 任务长度与真实 128K 级长上下文仍有差距；未测试 KV 缓存淘汰/分页、连续批处理、前缀共享动态变化等系统场景，而论文动机恰恰强调长上下文与高并发。
- **比特分配依赖人工/搜索**：K/V 混合精度（如 8/6、9/6）与 `V` 的选择由实验确定，非自适应；不同层、不同头、不同输入的最优分配可能不同，缺少自动化分配策略与理论指导。
- **缺少理论误差界**：论文给出分布推导与闭式尺度解，但未建立格状量化 + MX 哈希的端到端失真上界或收敛保证，方法优势更多是经验性的。

## 9. 改进方向与启示

- **分布自适应哈希**：用轻量在线统计（如 per-channel 均值/方差、混合高斯或 Student-t 拟合）替换固定高斯假设，或学习式校准逆 CDF 表，以提升非高斯 KV 的稳健性。
- **端到端内核与硬件协同**：在支持 MX 的新一代加速器上实现 fused decode 内核，实测延迟/吞吐/带宽；探索将哈希查表与注意力矩阵乘融合，减少中间反量化与内存往返。
- **自适应比特与尺度分配**：结合层敏感度、头重要性或在线误差反馈，自动分配 K/V 比特与 `V`；将联合尺度搜索扩展到跨块/跨层联合优化。
- **系统级集成**：与 PagedAttention、连续批处理、前缀缓存结合，评估动态缓存管理下的精度与开销；探索编码的增量/流式更新，降低长序列编码成本。
- **理论分析**：建立格状路径表示 + MX 网格量化的率失真界，给出束宽 `B` 与失真/复杂度的显式权衡，为超参选择提供依据。
- **更广验证**：扩展到 MoE、MLA、多模态 LLM 及 70B+ 模型，覆盖更多语言与长文档任务；与 FP8、INT4、QTIP 等在统一比特口径下对比。

## 10. 总体评价

MiSTiQ 的核心贡献在于提出了一条**“格状编码存储 + MX 兼容重建”**的新路径，针对码本向量量化的硬件约束与反量化开销两个痛点给出了可落地的替代方案：以束搜索降低编码复杂度，以 MX-Hash 将状态映射直接落到 MX 元素网格，并以联合尺度搜索缓解块尺度失配。方法设计完整、推导扎实、工程实现轻量（3–7 KiB LUT），在 ~1.25 有效比特的极低比特区间对 NSNQuant/VecInfer 形成稳定优势，且可作为 drop-in 组件集成。其主要不足在于评估仍以算法指标为主，缺少端到端系统实测与更广架构验证，高斯假设与启发式搜索的最优性也留有余地。总体而言，这是一项**问题定位清晰、方法新颖且具备部署潜力**的工作，若能在硬件实测、分布稳健性与自适应分配上进一步补强，影响力有望提升。
