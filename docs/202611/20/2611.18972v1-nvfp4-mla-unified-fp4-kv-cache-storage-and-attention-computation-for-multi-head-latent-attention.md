## 摘要
长上下文推理与智能体工作负载使键值（KV）缓存容量和注意力计算成为服务前沿大语言模型的主要成本。我们提出 NVFP4-MLA，这是首个将多头潜在注意力（MLA）的 KV 缓存存储与注意力计算同时推进到 FP4 的设计。NVFP4-MLA 将量化算法与注意力内核及缓存系统协同设计。选择性残差补偿仅对量化敏感通道添加 NVFP4 残差，从而保持模型精度。二维量化块使共享潜在缓存兼容两个注意力批量矩阵乘法（BMM）的不同归约方向，从而消除二者之间的重新量化。在 DeepSeek-R1 和 Kimi-K3 上，NVFP4-MLA 在九个基准上达到与 BF16 MLA 相当的平均准确率，同时将 MLA KV 缓存相对 BF16 MLA 分别压缩 3.20 倍和 3.05 倍。在 NVIDIA Rubin GPU 上，相比 FP8 MLA，NVFP4-MLA 在 DeepSeek-R1 和 Kimi-K3 上将注意力内核分别最高加速 2.82 倍和 2.71 倍，并将智能体多轮服务中的 p90 首 token 时延分别最高降低 3.5 倍和 2.1 倍。在分离式 DeepSeek-R1 服务中，它还将每 GPU 吞吐量最高提升 2.30 倍。

## Abstract
Long-context reasoning and agentic workloads make key-value (KV) cache capacity and attention computation the dominant costs of serving frontier large language models. We present NVFP4-MLA, the first design to push both KV-cache storage and attention computation of multi-head latent attention (MLA) to FP4. NVFP4-MLA co-designs the quantization algorithm with the attention kernel and the cache system. Selective residual compensation preserves model accuracy by adding NVFP4 residuals only to the quantization-sensitive channels. Two-dimensional quantization blocks make the shared latent cache compatible with the different reduction directions of the two attention batched matrix multiplications (BMMs), removing requantization between them. On DeepSeek-R1 and Kimi-K3, NVFP4-MLA matches BF16 MLA average accuracy across nine benchmarks while compressing the MLA KV cache by 3.20x and 3.05x relative to BF16 MLA. On NVIDIA Rubin GPUs, NVFP4-MLA speeds up the attention kernel over FP8 MLA by up to 2.82x on DeepSeek-R1 and 2.71x on Kimi-K3, and lowers p90 time to first token in agentic multi-turn serving by up to 3.5x and 2.1x, respectively. In disaggregated DeepSeek-R1 serving, it also raises per-GPU throughput by up to 2.30x.

# NVFP4-MLA 论文结构化总结

## 1. 核心问题与研究动机

- **背景压力**：长上下文推理与智能体（agentic）工作负载使 KV 缓存容量与注意力计算成为服务前沿大模型（DeepSeek-R1、Kimi-K3 等）的主要成本。MLA 通过低秩潜在空间压缩 KV 缓存，但缓存仍随序列长度与并发数增长，且每个解码步都要读取全部缓存，对显存容量和带宽构成双重压力。
- **智能体负载放大问题**：多轮会话与工具调用会持续复用增长的上下文，使 KV 缓存长期驻留；显存不足时需逐出并重算前缀，直接抬高首 token 时延（TTFT）。
- **计算侧压力**：MLA 所有查询头共享同一潜在缓存（不像 GQA 按组划分），每缓存字节承载的计算量更大；模型原生多 token 预测（MTP）进一步复用缓存、提高算术强度，使 MLA 解码转为**计算受限**（FP8 MLA 在 MTP=3 下算术强度 1,934 FLOP/B，远超 Rubin GPU 的 911 FLOP/B 拐点）。
- **核心命题**：仅压缩存储不足以加速，必须让 **KV 缓存存储与注意力计算同时进入 FP4**，利用 NVFP4 Tensor Core 原生的高算力，把"压缩"转化为真实推理加速。这是首个将 MLA 的 KV 存储与注意力计算统一推进到 FP4 的设计。

## 2. 方法论

### 2.1 总体思想
NVFP4-MLA 将量化算法、注意力内核与缓存系统**协同设计**，使共享潜在缓存直接作为两个注意力 BMM 的 FP4 操作数，全程无需反量化或重量化。

### 2.2 关键技术一：选择性残差补偿（Selective Residual Compensation）
- 白盒分析发现：MLA 缓存的 FP4 量化误差**高度集中在 RoPE 通道**（64/576 通道），其幅值达 NoPE 最大值的 3.9–125×，且随 token 剧烈波动。
- 方案：NoPE 保持单一 NVFP4 分量；仅对 RoPE 的量化误差**额外增加一个 NVFP4 残差分量**，两者各自带独立 block scale，在内核中沿 BMM1 归约维逻辑拼接并复制对应通道，单次归约即可完成。
- 收益：仅增加约 10% 的每层缓存开销，却避免混合精度；RoPE 残差的 NMSE 比 FP8 E4M3 低 7.9–11.2×。

### 2.3 关键技术二：二维量化块（16×16）
- 问题：MLA 的同一份潜在缓存被两个 BMM 以**不同方向归约**——BMM1（QK）沿通道归约，BMM2（PV）沿 token 归约。传统 1×16 一维块只对齐 BMM1，用于 BMM2 需反量化→转置→重量化，引入额外误差与同步开销。
- 方案：NoPE 采用 **16×16（token×channel）二维块**，每块单一 E4M3 scale，使块在任一归约方向上都有效；RoPE 仅参与 BMM1，仍用 1×16。
- 效果：一份缓存同时服务两个 BMM，消除重量化与高精度中间张量。

### 2.4 关键技术三：内核流水线与在线量化
- 对 Q、K、P（softmax 分数）、V 四类操作数全部量化；P 在 online softmax 中**在线量化**，使两个 BMM 都跑在 FP4 Tensor Core 上。
- 四项内核优化：
  1. **softmax 与 FP4 分数量化代数融合**：利用 $m_b \le m$ 保证 E2M1/E4M3 均不饱和，E2M1 值 $x_i$ 只依赖 $S_i$ 与 $m_b$、不依赖 $m$，可在跨块归约产生 $m$ 之前先行计算并打包，$m$ 就绪后只需补算 block scale。
  2. **分数构造与累加器重缩放的 warp group 均衡划分**：每组既构造自己分区的 FP4 分数，又在 running max 变化时重缩放互补分区的 BMM2 累加器，避免串行化。
  3. **BMM2 分数操作数跨输出 tile 复用**（Tensor Core operand-reuse 机制）。
  4. **形状自适应 CTA 调度**：cluster 内 CTA 切分 KV tile、经分布式共享内存交换 FP4 分数；长 KV 时再做 split-KV 归约。

### 2.5 关键技术四：端到端缓存系统
- 预填充阶段用融合 quantize-and-scatter 内核写入分页 NVFP4 存储；分离式服务只传输 E2M1 值 + scale + 未完成末块的 BF16 尾部。
- 解码阶段用融合 pre-attention 内核做 RoPE、维护 16-token BF16 环形缓冲、量化并写缓存；块填满后"定稿"为不可变 NVFP4 页，避免"反量化—追加—重量化"的二次误差。
- 投机解码（MTP）：写前快照 BF16 环、提交接受候选、回滚被拒位置；已定稿 NVFP4 页不回改，防止被拒 token 污染持久状态。
- 已集成进 TensorRT-LLM。

## 6. 主要结论与发现

- **精度**：NVFP4-MLA 在 9 基准平均精度上与 BF16 MLA 持平（R1：59.82 vs 59.80；K3：80.28 vs 80.27），而 Vanilla NVFP4 分别掉 5.71 / 16.48 个百分点；FP8 MLA 为 −0.06 / −0.33 pp。
- **缓存压缩**：相对 BF16 压缩 3.20×（R1，70,272→21,960 B/token）与 3.05×（K3，27,648→9,072 B/token），相对 FP8 为 1.60× / 1.52×；残差仅占每层缓存 10%。
- **内核加速**：所有 39 个形状均快于 FP8 MLA，R1 为 1.31–2.82×（几何均值 1.87×），K3 为 1.35–2.71×（几何均值 1.99×）；加速随 KV 长度增长（2K 时 1.3–1.5×，128K 时 2.2–2.8×）。
- **服务收益**：等 KV 预算下 AgentX p90 TTFT 分别最多降 3.5×（R1）与 2.1×（K3），源于更高前缀命中率（如 48 会话：77.0%→87.1%）；分离式 R1 服务每 GPU 吞吐平均 +26.7%（MLPerf）与 +39.9%（8K/16K），最高 2.30× / 2.25×。
- **机理性发现**：MTP 使 FP8 MLA 计算受限，因此"只压存储、计算仍用 FP8"的替代方案**无法快于** FP8 MLA；必须让计算本身进入 FP4 才能获益。

## 7. 优点

- **真正的软硬件协同设计**：量化算法（选择性残差、二维块）、内核（在线量化、warp group 均衡、operand reuse、形状自适应调度）与缓存系统（分页、环形缓冲、投机解码快照）三层贯通，而非单点优化。
- **二维量化块构思巧妙**：用 16×16 块一次性解决 MLA"共享潜在被双向归约"这一结构性问题，消除重量化误差与同步开销，是本文最具迁移价值的设计。
- **残差补偿极轻量且靶向精准**：基于白盒 NMSE 分析定位 RoPE 离群通道，仅 10% 存储开销即挽回精度，且比 FP8 编码更准，避免混合精度。
- **评估层次完整**：从下游精度→缓存字节→单核 microbenchmark→端到端 Pareto 前沿，形成完整证据链；并用 roofline 论证"存储型基线不可行"，逻辑闭环。
- **工程落地性**：已集成 TensorRT-LLM，投机解码回滚、分离式传输、分页存储等细节均有交代。
- **公平性处理较好**：等 KV 预算、相同并行布局、FP8 基线使用其每形状最优 split-KV 策略。

## 8. 不足与局限

- **模型覆盖窄**：仅 DeepSeek-R1 与 Kimi-K3 两个 MLA 模型，未验证其他 MLA 变体（如 LongCat-Flash）或非 MLA 架构，泛化性存疑；Kimi-K3 还有 2 层用 FP8，说明方法并非全层适用。
