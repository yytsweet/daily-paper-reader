## 摘要
视觉-语言-动作（VLA）策略必须在视觉推理仍在进行时做出反应。重叠计算与执行可减少等待，但会使感知记忆过时，并使连续动作块彼此脱节。我们提出 CauSyncVLA，一种异步双系统控制器，将感知记忆预测和轨迹校正与实际机器人执行对齐。因果潜在世界模型不预测像素或物理状态，而是根据延迟的视觉锚点和已执行的状态-动作历史预测当前感知记忆，并通过动作敏感蒸馏进行监督，以保留冻结专家的控制响应。以该更新后的记忆为条件，预测流热启动（PFWS）对齐未执行的动作时域，从而无需额外训练实现单步流校正。在 LIBERO-10 上，CauSyncVLA 以 5.04 倍推理吞吐量达到 93.8% 的成功率，提升了闭环鲁棒性和机器人运动平滑性。

## Abstract
Vision-Language-Action (VLA) policies must react while visual inference is still running. Overlapping computation and execution reduces waiting, yet leaves perceptual memory stale and successive action chunks disconnected. We present CauSyncVLA, an asynchronous dual-system controller that aligns perceptual-memory prediction and trajectory correction with actual robot execution. Rather than forecasting pixels or physical states, a Causal Latent World Model predicts current perceptual memory from delayed visual anchors and executed state-action history, supervised through action-sensitive distillation to retain the frozen expert's control response. Conditioned on this updated memory, Predictive Flow Warm-Starting (PFWS) aligns the unexecuted action horizon for single-step flow correction without extra training. On LIBERO-10, CauSyncVLA reaches 93.8% success at 5.04$\times$ inference throughput, improving closed-loop robustness and robot motion smoothness.

- **研究背景**：视觉–语言–动作（VLA）策略需将预训练多模态知识迁移至机器人操作，但物理部署时环境不会等待模型推理完成。重型视觉编码的延迟无法匹配快速物理执行，导致同步闭环反馈停滞。
- **现有方案的不足**：
  - 动作分块（action chunking）与异步执行虽可通过重叠计算摊销延迟，却使感知与动作在时间上错位。
  - 重放开环尾部或拼接边界，会让中间查询持续以**过时的感知记忆**为条件，接触状态在块中途变化时尤为危险。
  - 从高斯噪声重新采样轨迹还会引发跨块模式切换与多步开销。
- **核心矛盾**：异步控制需同时调和**反应性（reactivity）**、**感知新鲜度（perceptual freshness）**与**轨迹连续性（trajectory continuity）**这三个在失配的感知–控制时间尺度下相互冲突的目标。
- **论文主张**：实际机器人执行本身提供了一个共享时间参考——已观测状态转移与已施加命令记录了自最新视觉帧以来的物理演化，而未执行的动作尾部则提供了结构化的运动先验。据此应将异步控制建模为**同一物理时钟下的耦合感知记忆预测与轨迹校正**。

## 2. 方法论

### 2.1 核心思想：执行锚定的异步双系统控制

- **System 2（慢速视觉流）**：周期性将图像 $o_a$ 与指令 $\ell$ 编码为 KV 记忆锚点 $z_a = B_\phi(o_a,\ell)$，其采集时刻为 $a$，延迟为 $k=t-a$。
- **System 1（快速控制流）**：每执行 $C$ 条命令重规划一次，读取两类执行对齐记录：
  - 执行历史 $\mathcal{H}_{a:t}$：配对 $(s_a,s_t)$ 与已实现的转移 $(s_i-s_a,u_{i-1})$；
  - 轨迹先验 $Q_t$：将上一计划 $A_{t-C}$ 的未执行尾部与已消耗的 $C$ 条命令对齐。
- **闭环控制律**：$A_t = R_\psi\big(Q_t,\ W_\theta(z_a,\mathcal{H}_{a:t})\big)$，即先由世界模型更新感知条件，再精炼轨迹。

### 2.2 因果潜世界模型（Causal Latent World Model）

- **不预测像素或物理状态**，而是直接在冻结 VLM 的前缀 KV 空间中操作，通过锚点条件残差更新：
  $$\hat{z}_t = W_\theta(z_a,\mathcal{H}_{a:t}) = z_a + \mathbb{I}[k>0]\,\delta z_t$$
  其中年龄门控 $\mathbb{I}[k>0]$ 保证 $k=0$ 时锚点严格不变。
- **残差计算细节**：
  - 用逐层 RMS 尺度 $\sigma_{KV}$ 标准化 K/V，拼接 18 层特征并投影为 token；
  - 轨迹 MLP 编码归一化锚点年龄、端点、净位移、填充后的状态增量与原始坐标命令（输入维度 745）；
  - 6 个 AdaLN Transformer 块（384 维、4 头）通过自适应 LayerNorm 注入历史嵌入；
  - 输出投影恢复 post-RoPE KV 布局，零初始化使 $W_\theta$ 初始为恒等映射；
  - 历史容量 $K=48$，超限触发同步视觉刷新。

### 2.3 预测流热启动（PFWS）

- 将上一计划剩余 $H-C$ 步前移并重复末端动作 $C$ 次，形成先验 $Q_t = \text{ShiftRepeat}(A_{t-C}, C)$，并将状态相对坐标重定基到 $s_t$。
- 与高斯噪声在中间流时间 $\rho\in(0,1]$ 插值：
  $$x_\rho = (1-\rho)Q_t + \rho\epsilon,\qquad R_\psi(Q_t,z) = x_\rho - \rho\,v_\psi(x_\rho,\rho\,|\,z)$$
- 在 $\hat{z}_t$ 条件下用**冻结专家执行单步欧拉修正**，无需额外训练；$\rho=1$ 在回合起始退化为冷启动。
- $\rho$ 权衡连续性与反应性：较小 $\rho$ 抑制抖动，中等 $\rho$ 保留目标校正余量。

### 2.4 动作敏感蒸馏（Action-Sensitive Distillation）

- 复合损失：
  $$\mathcal{L}(\theta) = \underbrace{\left\|\frac{\hat{z}_t-z_t}{\sigma_\Delta}\right\|^2_m}_{\mathcal{L}_{KV}} + \lambda\underbrace{\left\|\hat{A}-A^\star\right\|^2_w}_{\mathcal{L}_{act}}$$
  其中教师目标 $A^\star = \text{sg}[D_\psi(z_t;x_\rho,\rho)]$ 被 detach，学生 $\hat{A}=D_\psi(\hat{z}_t;x_\rho,\rho)$ 共享同一 $(x_\rho,\rho)$ 与机器人状态。
- **理论解释**：对专家响应做一阶展开可得 $\mathcal{L}_{act}\approx\frac{1}{Hd_u}\|\Omega^{1/2}J_D e\|_2^2$，即等范数 KV 误差因雅可比敏感性不同而产生不等动作偏移；最小化 $\mathcal{L}_{act}$ 诱导出按控制影响加权的 pullback 度量 $J_D^\top\Omega J_D$，而 $\mathcal{L}_{KV}$ 则将零空间误差正则回新鲜 VLM 统计。
- 关键实证反转：加入动作蒸馏后**原始 KV 误差反而上升**（0.28461→0.31958），但动作 MSE 减半、成功率从 85.60% 升至 92.80%。

### 2.5 理论保证（附录）

- 因果可测性：$\hat{z}_t$ 与 $A_t$ 仅依赖已发布真实锚点与已实现转移，对 $\mathcal{F}_t$ 可测。
- 年龄为零时精确恒等；局部动作误差界 $\mathcal{L}_{act}\le L^2\|e\|_2^2/(7H)$。
- 单步欧拉离散误差界 $\|x_0^E-x_0\|\le\frac{1}{2}M\rho^2$。
- 外生场景不可辨识性：执行历史无法区分帧间独立外部运动，需下一次视觉刷新解决。
