## 摘要
智能体网络（agentic web）的兴起伴随着对端侧视觉语言模型（VLM）日益增长的需求，这些模型需要以更强的隐私保护和更低的延迟执行多样化的跨模态网络任务。混合专家（MoE）模型因其计算高效的扩展性而被现代 VLM 广泛采用，但其多专家架构因内存需求巨大而带来部署挑战。混合精度量化是一种有效的压缩技术，可在降低位宽的同时适应边缘设备的异构硬件预算；由于其固有的结构稀疏性导致专家间重要性不均衡，该技术尤其适合 MoE。尽管已有工作将量化应用于边缘端高效的 MoE 推理，但我们指出，在基于 MoE 的 VLM 中，视觉与文本 token 的模态特定特性会进一步影响专家量化。为解决该问题，我们提出 MoMoVL，一种面向基于 MoE 的 VLM 的模态感知自适应压缩框架，使视觉语言推理能够在端侧资源预算内实现。受我们对专家间模态引发差异的实证发现启发，MoMoVL 联合利用逐专家激活画像和逐模态量化敏感度来指导位宽分配。实验结果表明，相对于最先进的混合精度基线，MoMoVL 改善了精度-压缩权衡，并且相较于其均匀精度基线，在精度适度下降的情况下将内存占用最多降低 15.44%。我们的代码和数据已公开于 https://github.com/sco-edge/MoMoVL。

## Abstract
The rise of the agentic web has been accompanied by growing demand for on-device Vision-Language Models (VLMs) that perform diverse cross-modal web tasks with enhanced privacy and reduced latency. Mixture-of-Experts (MoE) models are widely adopted in modern VLMs for compute-efficient scalability, yet their multi-expert architecture poses deployment challenges due to substantial memory demands. Mixed-precision quantization is an effective compression technique that reduces bit-widths while adapting to the heterogeneous hardware budgets of edge devices, particularly well-suited for MoE due to its inherent structural sparsity, which causes imbalanced importance among experts. While prior work has applied quantization for efficient MoE inference at the edge, we point out that in MoE-based VLMs, the modality-specific characteristics of visual and text tokens further impact expert quantization. To address this issue, we present MoMoVL, a modality-aware adaptive compression framework for MoE-based VLMs that brings vision-language inference within reach of on-device resource budgets. Motivated by our empirical findings on modality-induced disparities across experts, MoMoVL jointly exploits the per-expert activation profile and per-modality quantization sensitivity to guide bit-width assignment. Experimental results show that MoMoVL improves the accuracy-compression trade-off relative to state-of-the-art mixed-precision baselines and reduces memory footprint by up to 15.44% with a modest drop in accuracy over its uniform-precision baseline. Our code and data are publicly available at https://github.com/sco-edge/MoMoVL.

## 1. 核心问题与研究动机

- **背景**：智能体网络（agentic web）兴起，网页智能体需要端侧部署的视觉语言模型（VLM）以保障隐私、降低延迟。MoE 架构因稀疏激活、计算高效而被现代 VLM 广泛采用（如 MolmoE-1B、DeepSeek-VL2-Tiny）。
- **核心矛盾**：MoE 的稀疏激活只节省计算，不节省内存——所有专家必须常驻内存，内存随**总参数**而非激活参数增长（MolmoE-1B 每 token 仅激活约 1.5B，却需驻留 7.2B）。专家参数占比极高（MolmoE-1B 为 89.21%）。
- **技术机会**：专家 FFN 对量化鲁棒（可压到 2-bit 甚至 1-bit），且专家间重要性天然不均衡（MolmoE-1B 前 4 热门专家占总激活 25.30%），因此**混合精度量化**特别适合 MoE，并能适配边缘设备异构的硬件预算。
- **被忽视的缺口**：现有 MoE 量化工作（EdgeMoE、MoE-APEX、Fate、MC-MoE、MxMoE 等）都面向**纯语言** MoE；面向 VLM 的量化（MASQuant、MBQ 等）多针对**稠密** VLM；VEQ 虽考虑 MoE 结构但只用固定均匀精度（3/4-bit）；MoPEQ 按专家重要性分配位宽但**无视模态差异**。
- **关键实证发现（两个 Insight）**：
  - **Insight 1**：专家激活跨模态高度分化，存在“视觉中心专家”与“文本中心专家”。视觉 token 路由更集中（前 8 专家占 51.49%），文本仅 29.63%；61 个视觉中心专家中仅 12 个对文本激活率超 25%。由于视觉 token 数量远多于文本（5~20 倍），**模态无关的激活画像会稀释文本中心专家的重要性**。
  - **Insight 2**：文本 token 数量少但信息密度高，文本中心专家对量化更敏感。在 INT2/INT4 混合设置下，优先给文本中心专家高精度，比优先视觉中心专家最多提升 **4.98%** 准确率。

## 2. 方法论（MoMoVL）

### 2.1 总体流程（三步）
1. **➊ 校准测量**：用小规模多模态校准集（ShareGPT4V 改进版 COCO caption，随机采样 128 图文对），分别统计每个专家在视觉/文本 token 上的激活画像，并测量逐模态量化敏感度。
2. **➋ 位宽分配**：在设备内存预算约束下，按组合重要性为每个专家分配位宽，输出 JSON 配置。
3. **➌ 量化部署**：用 HQQ 按配置量化并部署到目标设备。

### 2.2 逐模态激活画像（两种实现）
- **MoMoVL-Weight**：以 top-k 门控权重（路由概率）为统计量，权重越高对输出贡献越大。
- **MoMoVL-Index**：以 top-k 索引的出现频率（激活频次）为统计量，频次越高越重要。

### 2.3 逐模态量化敏感度
- 用 SFT loss 对 token 隐状态的梯度作为敏感度代理：
  - 式(2)：第 l 层第 t 个 token 的梯度 = 各隐藏维上 ∂L/∂h 的**绝对值均值**；
  - 式(3)：按模态（vis/text）对 token 梯度求和，再在校准集上取平均，得 `s̄_{l,vis}`、`s̄_{l,text}`；
  - 式(4)：归一化为 `ŝ_{l,vis} + ŝ_{l,text} = 1`，作为逐层模态缩放因子。
- **实测规律**：文本梯度显著高于视觉（最低 3.96×，几何平均 5.56×）；浅层依赖视觉、中层后视觉贡献下降；**最后一层视觉梯度完全消失**（prompt 被 loss mask 排除且无后续 attention），故最后一层仅按文本重要性分配。

### 2.4 组合重要性与位宽分配算法（Algorithm 1）
- **组合重要性**：`C[i] = ŝ_{l,vis}·m_{l,i,vis} + ŝ_{l,text}·m_{l,i,text}`，即用敏感度对逐模态激活画像加权。
- **分配流程**：
  1. 位宽选项按位宽降序排列（本文为 INT4、INT2）；
  2. 计算总重要性 `T = ΣC[i]`，为每个位宽设累积阈值 `Th[j] = T·Σ_{u≤j} r_u`（`r_u` 为该位宽的预算份额）；
  3. 专家按 `C` 降序排序，依次分配当前最高位宽；
  4. 当累计重要性超过当前阈值时降到下一档位宽，直至分配完毕。
- **量化设置**：HQQ（无需校准、支持多位宽），专家 INT2/INT4，shared experts 固定 INT4；仅量化 LLM backbone，其余 VLM 组件保持原精度。

## 6. 主要结论与发现

- **模态感知是必要的**：忽略模态会使位宽分配次优；文本中心专家应优先获得高精度，最多带来 4.98% 提升。
- **主结果**：
  - MolmoE-1B：MoMoVL-Weight 在多数任务上优于 MoE-APEX/Fate（ScienceQA、OCRBench 除外）；MoMoVL-Index（与 Fate 同为频率类统计）除 MMMU、ScienceQA 外更优。
  - DeepSeek-VL2-Tiny：MoMoVL-Index 取得最高 MMMU 与 RealWorldQA，但多个 benchmark 落后基线，作者归因于模型容量较小、吸收量化误差的能力弱。
- **压缩效果**：MoMoVL-Weight 相比 Uniform 全模型 INT4，内存再降 **15.44%**（MolmoE）/ **10.49%**（DeepSeek），精度仅小幅下降；在 MolmoE 的 RealWorldQA 上甚至超过该基线（尽管平均位宽更低）。
- **统计量类型的影响**：Top-K Weight 分布更集中，同阈值下 MoMoVL-Index 会分到更多 INT4 专家，整体分数更高；模态加权后重要性集中度降至 29.14%（对比单模态视觉 51.49%），说明平衡度量的有效性。
- **校准效率**：128 个样本后收益基本饱和，说明激活统计与敏感度收敛很快。
- **消融结论**：完整 MoMoVL 优于 w/o Visual、w/o Modality、w/o Scaling；仅用文本统计也优于模态无关统计（除个别项），印证“文本统计更关键、但两模态都不可少”。

- **模型规模与覆盖面有限**：仅验证 MolmoE-1B 与 DeepSeek-VL2-Tiny 两个 <10B 模型，且二者专家结构差异较大（有无 shared expert、top-k 不同），结论能否外推到更大 MoE-VLM（如 DeepSeek-VL2 完整版、更大规模开源 MoE-VLM）尚不明确；作者亦承认受 GPU 资源限制。
- **结果并非全面占优**：在 DeepSeek-VL2-Tiny 上多个 benchmark 落后于基线，作者归因于模型容量小、抗量化误差能力弱，但这一解释缺少直接证据（如逐层误差传播分析），也可能是分配算法在 shared expert 处理或小模型上的适配问题。
- **基线改造的公平性存疑**：MoE-APEX/Fate 被替换为真实门控输入后已非原始方法形态，且未报告其实际模型大小，导致“同内存预算下比精度”这一核心诉求无法严格对齐；INT4 阈值沿用基线原参数，也未针对 MoMoVL 做调优，双向都可能引入偏差。
- **敏感度代理的可靠性**：以 SFT loss 对隐状态的梯度均值作为量化敏感度代理，属于启发式近似，未与真实量化误差（如逐专家量化后的输出偏差）做相关性验证；最后一层视觉梯度消失的处理虽合理，但也说明该代理在边界情形下会退化。
- **量化方案较单一**：仅使用 HQQ，且专家只用 INT2/INT4 两档、shared expert 固定 INT4、非 LLM 组件不量化；未探索 INT3/INT1、权重+激活联合量化、或与 GPTQ/AWQ 等方法的组合，位宽粒度也较粗。
- **系统级收益未实测**：论文以“内存占用”为主要效率指标，缺少端侧真实延迟、吞吐、能耗的测量，而边缘部署的实际收益往往取决于这些指标；此外 JSON 配置在推理引擎中的调度开销也未讨论。

## 9. 启示与可延伸方向

- **模态感知应成为 MoE-VLM 量化的默认维度**：本文最核心的贡献是把“模态”引入专家重要性刻画，这一视角可自然迁移到剪枝、专家合并、专家卸载（offloading）等其他压缩手段——例如按模态决定哪些专家常驻内存、哪些放至外部存储。
- **预算抽象具备通用性**：将硬件约束抽象为“位宽档位 + 预算份额”的做法，可直接扩展到多设备异构协同、分层内存（HBM/DRAM/Flash）等更复杂的部署场景。
- **可结合输入自适应路由**：当前分配是静态的（离线一次），若与 MoE-APEX 类“跨层预测门控”的动态思路结合，或可在静态预算下进一步按输入调整精度，形成“静态预算 + 动态精度”的混合方案。
- **敏感度代理值得替换**：用真实量化误差或 Fisher 信息替代梯度均值，可能提升分配质量，尤其是在最后一层这类梯度退化的位置。
- **需要更系统的评测**：后续工作应补齐端侧延迟/能耗实测、更大模型验证、以及与原始（未改造）基线的同口径对比，才能更完整地支撑“边缘友好”的主张。

## 10. 总体评价

MoMoVL 是一篇**问题定位清晰、动机有实证支撑、方法轻量且工程可行**的工作。它准确抓住了 MoE-VLM 端侧部署中“内存随总参数增长”与“专家重要性跨模态分化”这两个关键矛盾，提出以逐模态激活画像 × 逐模态量化敏感度构造组合重要性，并在设备预算约束下做专家级混合精度分配。实验在 2 个模型、8 个 benchmark 上给出了较一致的收益（相对 Uniform INT4 再降 10%~15% 内存且精度损失有限），机制分析与消融也较扎实。其主要不足在于模型规模与基线公平性、敏感度代理的可靠性、以及缺少真实端侧系统指标；这些不影响核心论点的成立，但限制了结论的普适性与说服力上限。总体而言，作为“模态感知 MoE-VLM 量化”的开创性尝试，其思路价值大于当前的实验规模。
