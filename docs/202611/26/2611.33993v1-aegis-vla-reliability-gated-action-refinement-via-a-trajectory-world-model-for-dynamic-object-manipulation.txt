# Aegis-VLA: Reliability-Gated Action Refinement via a Trajectory World Model for Dynamic Object Manipulation 

Lennox Wei 1, Jiaqi Yao 1, Shixin Sun 1, Yuanzheng Zhang 2,Jianhua Han 3, Meng Tian 3,4, Shaohui Liu 1∗, Wangmeng Zuo 1

Abstract — Dynamic object manipulation requires maintain-ing spatial and temporal alignment with targets that continue to move during inference and execution. Although future prediction can inform action correction, an accurate forecast does not establish whether modifying an existing action would be beneficial. We present Aegis-VLA, a world-model-guided vision-language-action (VLA) framework that generates pre-dictive action corrections and separately determines whether and how strongly to apply them. A Trajectory World Model combines kinematic extrapolation with learned residual dy-namics to predict object motion and estimate positional uncer-tainty. Discrepancy-Guided Action Refinement uses differences between history-only and base-action-conditioned end-effector forecasts to propose bounded arm corrections. A Reliability Gate learns when to admit corrections based on demonstration-relative improvements over base actions, and regulates their application during inference using predictive uncertainty and anticipated object–end-effector proximity. Rejected corrections preserve the corresponding base actions. Aegis-VLA introduces only approximately 2.45M trainable parameters. On the simu-lated Dynamic Object Manipulation (DOM) benchmark, Aegis-VLA achieves 56.72% success over 1,800 evaluation trials, exceeding our reproduced DynamicVLA baseline of 45.44% by 11.28 percentage points. 

I. I NTRODUCTION 

Manipulating a moving object requires the robot and target to meet at the right place and time [1]–[3]. A grasp that is geometrically appropriate at planning time can become ineffective before contact if the object continues moving. The same observed position can demand different actions depending on whether the target is approaching, receding, or changing direction. Partial visibility obscures motion, while perception, inference, and physical execution introduce delays during which the scene evolves. Dynamic manipu-lation therefore requires maintaining spatial and temporal alignment between robot actions and target motion. Pretrained vision-language-action (VLA) and generalist robot policies provide increasingly capable foundations for language-conditioned manipulation [4]–[6]. World models offer information about how a scene may evolve beyond the latest observation. A forward adjustment may improve alignment when the base action trails the target. If the base action already compensates for that motion, how-ever, an additional adjustment may worsen alignment even with an accurate forecast. An apparently useful correction may also depend on an unreliable forecast. Useful refine-ment must therefore assess whether a proposed correction improves on the base action and whether the motion forecast is sufficiently reliable to justify the correction. Residual learning provides a way to adapt an existing con-troller or policy [19], [20], including observation-conditioned per-step action correction [21] and uncertainty-guided cor-rective exploration [22]. However, freezing backbone weights does not by itself preserve task performance once residuals alter the executed actions. Trajectory World Model. We combine kinematic ex-trapolation, learned residual dynamics, and positional uncertainty estimation to provide shared motion con-text for action refinement and predictive evidence for regulating corrections under uncertain target motion.  

> •

Discrepancy-Guided Action Refinement. We gener-ate bounded arm corrections from position and ori-entation discrepancies between history-only and base-action-conditioned end-effector forecasts, linking each proposal to the base action it modifies.  

> •

R ELATED WORK 

A. Dynamic Manipulation and Responsive Execution 

Vision-language-action (VLA) models and generalist robot policies provide reusable foundations for manipulation [4]– [6], [23], [24], leveraging temporally coherent action se-quences [25], [26] and efficient action generation [8], [27]. Dynamic manipulation additionally requires motion-aware perception and control [1], [2], [7], [28] together with responsive execution [9], [10], [29]. DynamicVLA [3] combines temporal observations, con-tinuous inference, and temporally aligned action streaming. Whereas A2C2 [21] corrects each action from recent ob-servations and base-action context, Aegis-VLA generates a bounded residual chunk from discrepancies between two predicted end-effector trajectories. 

B. World Models for Anticipatory Manipulation 

Video-based policies and world models connect predictive representations to action generation [11]–[13], [30]–[32]. For dynamic manipulation, PUMA [14] combines historical optical flow with auxiliary prediction of future object-centric features, while DynamicWAM [15] conditions joint video and action generation on flow and kinematic descriptors. AHEAD [16] supplies predicted visual tokens to a frozen VLA and uses uncertainty to adapt the rollout horizon. Aegis-VLA instead predicts object-coordinate trajectories and positional uncertainty from dual-view RGB and propri-oceptive history to support action-space refinement. Fore-casting supervision shapes the shared motion context, while explicit trajectories support proximity estimation. Its forecast horizon is fixed, and uncertainty regulates corrections. 

C. Prediction-Guided and Selective Action Refinement 

Residual policy learning adapts existing controllers through additive corrections [19], [20], [33]. Uncertainty-aware residual reinforcement learning regulates exploration using base-policy uncertainty [22]. Aegis-VLA instead uses uncertainty in predicted object motion to constrain correction application during inference. DreamTrajectory [17] ranks sampled action chunks, in-cluding the base proposal, whereas DynaWM [18] regener-ates complete chunks conditioned on a frozen VLA’s base actions and observation history. Unlike chunk-level rank-ing or regeneration, Aegis-VLA explicitly learns admission for individual corrections within a single bounded residual chunk. The residuals are generated directly from discrepan-cies between history-only and base-action-conditioned end-effector forecasts, without candidate search or additional sampling of action chunks from the backbone. Discrepancy-guided variants without A retain the shared history en-coder but remove object-prediction branches and losses. The encoder learns through end-effector and candidate-action objectives, with gate-dependent losses omitted for the refiner-only model. The plain adapter uses the same history-encoder architecture, training budget, optimizer and learning-rate schedule, residual bound, and candidate-action and temporal-difference loss weights as the full model. It predicts residuals from history features and base actions without trajectory pre-dictors, discrepancy inputs, or gating. Its success falls from the baseline’s 45 .44% to 22 .00% , showing that its learned corrections harm base-policy performance. The discrepancy-guided refiner instead exceeds the baseline by 2.67 points under the same ungated execution rule used for the adapter. Aegis-VLA therefore separates correction generation from admission, so a proposed correction is not automati-cally applied. Admission is learned from each candidate’s demonstration-relative improvement over its base action, while uncertainty and proximity constrain whether and how strongly the proposed correction is applied. The unchanged Long-horizon Sequencing score may re-flect the temporal scope of refinement. Corrections are generated from short-horizon end-effector forecasts without explicitly modeling task progress or subtask transitions. If later stages remain unsuccessful, better interception alone does not increase full-sequence success. Demonstration-relative improvement compares candidates with base actions against recorded demonstrations. Actions that differ from the demonstration may still lead to task success, and lower local action error need not improve contact timing or later task outcomes. The success drop when admission is bypassed supports the learned selector’s prac-tical benefit, although the task-level results do not establish whether every admitted correction is beneficial. The current evaluation is simulation-based, and smaller ablation differences warrant repeated runs. Future work will examine selective refinement on physical robots and under shifts in target motion, visibility, and execution dynamics, particularly when predictive evidence becomes less reliable. VI. C ONCLUSION 

Aegis-VLA integrates trajectory forecasting, discrepancy-guided arm refinement, and reliability gating for dynamic object manipulation. With approximately 2.45 M trainable parameters, it achieves 56 .72% DOM success, improving on the reproduced baseline by 11 .28 percentage points. Ablations show that the full framework further improves on an independently trained ungated refiner that already outper-forms the base policy.
