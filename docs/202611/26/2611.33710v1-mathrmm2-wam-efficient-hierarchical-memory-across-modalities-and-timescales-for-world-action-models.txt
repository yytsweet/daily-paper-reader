Abstract
Long-horizon robotic manipulation requires historical con-
text, yet retaining extensive visual histories incurs grow-
ing storage and retrieval costs, while aggressive compres-
sion risks losing fine-grained information needed for sub-
sequent decisions.
Moreover, executed action histories
capture intermediate behaviors that sparse visual obser-
vations may miss.
Preserving this complementary con-
text efficiently calls for modality-specific memory mech-
anisms that balance recent detail with long-term reten-
tion. To this end, we introduce M2-WAM, a world-action
model equipped with hierarchical visual and interaction

1. Introduction
Long-horizon robotic manipulation often requires reason-
ing beyond the current observation [22, 38, 52]. For exam-
ple, in a shell game task, a robot must track a target ob-
ject as it is occluded and moved beneath visually identical
cups, relying on historical observations to identify its loca-
tion [10, 13]. Such tasks are inherently non-Markovian with
respect to instantaneous observations, requiring policies to
reason over past observations and interactions [17]. Recent
world-action models (WAMs) have demonstrated promis-
ing capabilities by jointly modeling visual dynamics and
robot actions [19, 42, 44]. However, many WAMs still rely
on current observations or limited contexts, making it diffi-
cult to exploit information from earlier stages of execution.
Historical context must support ongoing decisions while
preserving information from earlier task stages. Recent ob-
servations provide spatial detail, whereas earlier observa-
tions may contain cues that remain relevant after they leave
view. As shown in Figure 1(a,b), a memoryless WAM lacks
access to earlier observations, whereas retaining full visual
history incurs storage and retrieval costs that grow with
episode length. A sliding window preserves recent detail
but discards older observations [37, 39]. Alternatively, com-
pact or recurrent memories reduce storage costs, but com-
pression can limit access to fine-grained historical informa-
tion [41, 49].
We argue for allocating memory capacity
across timescales: retaining recent observations explicitly
and consolidating older entries into a compact, persistent
state. This design preserves recent detail without compress-
ing all observations and extends historical coverage beyond
a fixed window, drawing inspiration from short- and long-
term memory [1] and complementary learning systems [26].
However, retaining history across timescales is only part
of the challenge: memory must also capture complementary
information from observations and executed actions. Visual
observations describe scene configurations and changes,
but may omit behavior between sampled frames. Denser
sampling increases visual encoding and storage costs for
the same duration. Executed action prefixes complement
these observations by recording the intervening actions,
providing compact, temporally denser behavioral context
[27, 50, 53]. This motivates modality-aware memory that
preserves both scene observations and executed actions. We
therefore adopt visual and interaction memories that pre-
serve spatial details and temporal action patterns, respec-
tively, within a common short- and long-term hierarchy.
Building on these considerations, we propose M2-
WAM, which augments a mixture-of-transformers (MoT)
architecture with complementary visual and interaction
memories across timescales, as illustrated in Figure 1(c).
The visual memory preserves an initial observation anchor
and recent observations as dense spatial key-value (KV)
representations, while consolidating older information into
fixed-size, layer-wise associative states through gated delta
updates [14, 40]. To accommodate robot image sequences,
we apply temporal decay once per observation according
to elapsed time, rather than repeatedly across its spatial to-
kens. We further replace channel-wise erasure with a scalar
erase gate per token and head to improve numerical stabil-
ity. In parallel, the interaction memory encodes executed
action prefixes into compact temporal representations and
maintains a shared associative state. These memories are
integrated into world-action modeling through layer-wise,
query-conditioned retrieval. By combining bounded short-
term memories with fixed-size associative states, M2-WAM
enables persistent history conditioning with online memory
storage and retrieval costs independent of episode length.
Our main contributions are as follows: 1) We propose
M2-WAM, a world-action model equipped with modality-
specialized hierarchical memory that jointly preserves vi-
sual observations and executed interactions across short and
long timescales.
2) We develop modality-specific mem-
ory representations and associative consolidation mecha-
nisms, together with complementary retrieval pathways that
incorporate historical information into world-action com-
putation with bounded online memory and retrieval costs.
3) We conduct extensive experiments on MIKASA-Robo
[10], RMBench [9], RoboTwin 2.0 [8], and three real-world
tasks, complemented by ablation studies and qualitative and
quantitative analyses. Results demonstrate improved per-
formance on memory-dependent tasks with bounded on-
line memory and retrieval costs, supporting the effective-
ness and efficiency of our method.

2.2. Memory-Augmented Robotic Policies
Memory-augmented robotic policies address partial observ-
ability through explicit memory banks, compressed visual
histories, and selective retrieval [6, 12, 21, 36, 37, 43].
MemoryVLA maintains perceptual and cognitive memory
streams, retrieving historical context with current tokens
and consolidating redundant entries [29]. MemoryVLA++
combines this memory with imagined future latents to con-
dition action generation [30].
BridgeVLA++ pairs tem-
poral memory of historical keyframes with spatial mem-
ory of the initial scene geometry, supporting task-progress
reasoning and localization under occlusion [20]. Memo-
ryWAM combines recent observations, anchor frames, and
historical gist tokens [41], whereas HiMem-WAM stores
compact task states at predicted skill boundaries [33]. To
retain history without accumulating tokens, recurrent ap-
proaches maintain fixed-size associative states using gated
delta updates [14, 40].
DRAM jointly incorporates to-
kens within each observation [49], while MemBodied com-
bines action summaries with their observed visual con-
sequences [27].
The latter also highlights the relevance
of behavioral history, explored through joint visual-action
representations in AEM and executed-action memory in
ActMem-VLA [50, 53].
M2-WAM organizes visual ob-
servations and executed action prefixes into separate path-
ways, each combining explicit short-term storage with as-
sociative long-term consolidation. Dense visual KV fea-
tures and compact temporal action representations are re-
tained and retrieved through modality-specific structures,
while entries evicted from each short-term window update
its corresponding fixed-size associative state.
3. Method
3.1. Problem Formulation and Architecture
We consider long-horizon robotic manipulation under par-
tial observability, where action generation may depend on
information beyond the current observation. At each replan-
ning step t, the robot receives an observation ot = (It, st),
comprising multi-view images and proprioceptive state, and
a task instruction ℓ. Given a bounded memory bank Mt
representing past observations and executed actions, the
policy predicts an action chunk At ∈RH×da:

As illustrated in Figure 2, M2-WAM builds on Fast-
WAM’s MoT backbone, comprising a video Diffusion
Transformer (DiT) [28] and an action DiT. During infer-
ence, the video DiT encodes the current observation into
layer-wise visual KV representations that condition itera-
tive action denoising in the action DiT, without generating
future video.
We augment this architecture with complementary visual
and interaction memories, each combining bounded short-
term memory (STM) with fixed-size associative long-term
memory (LTM). The action DiT directly retrieves historical
context from both memory streams during denoising.

3.3. Associative Long-Term Memory
When advancing a full FIFO, we consolidate its oldest en-
try into a fixed-size associative state before eviction. Vi-
sual LTM maintains an independent multi-head state at each
layer of the video DiT, while interaction LTM maintains one
multi-head state shared across layers of the action DiT. The
writers are independently parameterized and follow a com-
mon update rule. Below, we describe one head, omitting
modality and layer indices. Its state S ∈Rdk×dv, where
dk and dv are the per-head key and value dimensions, is
initialized to zero at the start of each episode.
Writing representations. For visual writes, we reuse the
video DiT’s native keys before rotary position embeddings
(RoPE) [31], together with its native values. The writer ap-
plies per-head ℓ2 normalization to the keys and predicts its
gates from normalized and projected value features. For in-
teraction writes, the action content tokens Zi are normalized
and projected into writer features, augmented with sinu-
soidal within-chunk phase encodings, and mapped to mem-
ory keys and values. The keys are also ℓ2-normalized. Gate
projection in Figure 2(c) predicts erase and write gates and
decay rates.
Gated delta update. We build on Gated DeltaNet-2 [14],
adapting its erase granularity and temporal decay to WAM
memory, as illustrated in Figure 2(c). We predict one scalar
erase gate per token and head, shared across key channels,
while retaining independent channel-wise writing. Scalar
erasure avoids the numerical instability we observe with
channel-wise erasure during training.
Spatial tokens from the same observation share a times-
tamp, so we apply temporal decay once per evicted entry
rather than once per spatial token. The same entry-level de-
cay applies to interaction memory. For each evicted entry e,
we first decay the memory state:

3.4. Memory-Augmented Action Generation
At each denoising iteration, the action DiT uses its features
to retrieve context from short- and long-term memories, as
shown in Figure 2(b). For visual memory, queries from
action features perform comparably to those from current-
observation features in our experiments. We choose the for-
mer because it avoids recursively encoding historical obser-
vations with memory and reduces training cost.

action sequence through the backbone’s MoT attention. A

tokens Zi every five layers of the action DiT. Relative-age
embeddings augment historical visual keys and interaction

During training, STM contains the preceding history
window, while LTM is reconstructed by replaying earlier
sampled history from the same episode under current pa-
rameters. We detach historical visual KV while keeping
memory writers, readers, and the executed-prefix encoder
trainable. Backpropagating through historical visual encod-
ing increases training time and GPU memory substantially,
with little performance change in our experiments.
Additionally, to discourage shortcuts from visual context
and action continuity, we randomly mask visual STM en-
tries at retrieval and add Gaussian noise to selected dimen-
sions of normalized executed prefixes before encoding.
Closed-loop inference.
During inference, the memory
bank Mt remains fixed throughout action denoising. Af-
ter generation, sampled observations enter the visual FIFO,
while action prefixes enter the interaction FIFO once exe-
cuted, with evicted entries consolidated into LTM. Imple-
mentation and training details are in Appendix A.

5. Conclusion
We present M2-WAM, a world-action model with hierarchi-
cal visual and interaction memories. The two pathways pre-
serve dense visual context and encode executed action pre-
fixes into compact temporal representations, respectively.
Recent entries are retained explicitly, while older ones
are consolidated into fixed-size associative states through
adapted gated delta updates.
Layer-wise retrieval brings
both memory levels into action generation with bounded on-
line storage and retrieval costs. Simulation and real-world
experiments show improved memory-dependent manipula-
tion while largely preserving general manipulation perfor-
mance. These findings support modality-specific memory
organization and retrieval across timescales as a promising
direction for memory-augmented world-action modeling.

A.2. Training and Online Memory Construction
Training memory construction. For each training sam-
ple at replanning step t, we construct memory from ear-
lier observations and demonstrated action prefixes in the
same episode. Each sampled observation is paired with the
subsequent action prefix, all of whose commands precede
the current prediction. The most recent N sampled entries
populate the visual and interaction FIFOs, with fewer en-
tries available near the episode start. Earlier entries are re-
played chronologically from zero-initialized LTM states un-
der the current model parameters. The first observation also
provides the permanent visual anchor. Memory is recon-
structed for each sample from its preceding history, rather
than carried across optimization steps.
Gradient handling. Historical observations are encoded
independently, and their visual KV representations are de-
tached before memory construction. Gradients propagate
through the memory writers, readers, executed-prefix en-
coder, and replayed LTM updates. Both DiTs are trained
through the current sample’s objectives, while historical vi-
sual encoding is excluded from the backward pass.
Memory augmentation. Visual STM dropout masks com-
plete observation entries at retrieval while retaining the per-
manent anchor. A common mask is used across layers and
heads. Stored entries and LTM writer inputs are unchanged.

A.4. Storage and Retrieval Complexity
We analyze persistent memory storage and history-
dependent computation for a single sample.
Model pa-
rameters and the backbone’s processing of current obser-
vations and actions are excluded from these complexity ex-
pressions. Let T denote the number of accumulated histori-
cal entries, Jv the number of spatial tokens per visual entry
across views, and R the number of action steps per executed
prefix. We retain N, H, and P for FIFO capacity, predic-
tion horizon, and tokens per encoded prefix. We hold layer
counts, head counts, and feature dimensions fixed through-
out the analysis.
Storage and retrieval. Let Bs(n) denote the storage for n
paired visual and interaction entries. Visual entries retain
layer-wise KV tensors, whereas interaction entries retain
normalized executed prefixes, giving Bs(n) = O(n(Jv +
R)) with fixed feature dimensions omitted.
After prefix
encoding, the readers attend to nJv visual tokens and nP
interaction tokens.
For H action queries, their history-
dependent retrieval cost per denoising iteration is
Cs(n) = O(Hn(Jv + P)) .
Each LTM head instead stores dkdv scalars and reads its
state in O(Hdkdv) operations.
Summing over the fixed
numbers of heads and reader layers gives LTM storage
Bl = O(1) and retrieval cost Cl = O(H), both indepen-
dent of T. The interaction reader’s computation is counted
at each insertion layer, although its parameters are shared.
Table 6 compares the four designs once the FIFO is
full; before then, N is replaced by min(T, N). The ex-
pressions suppress constant factors, including differences
in the KV tensors retained by each implementation. Full-
history memory grows linearly with T in both storage and
retrieval. The other designs have bounded costs for fixed
N and per-step input sizes. Compared with w/o-LTM, M2-
WAM adds fixed-size states to consolidate history beyond
the FIFO. Compared with w/o-STM, it retains recent detail
at a bounded additional cost. The w/o-STM variant writes
entries directly into LTM and retains the visual anchor with-
out maintaining historical FIFOs.
Preparation and updates.
Interaction prefixes are en-
coded once per replanning step, before denoising, with cost
O(n(R+P)) for fixed encoder dimensions. Their attention
KV projections are recomputed at each reader invocation.
Retrieval costs recur at every denoising iteration. Consoli-
dation processes the evicted entry’s Jv visual tokens and P
encoded interaction tokens, with each per-head state update
costing O(dkdv) per token. For M2-WAM, these prepara-
tion and update costs are bounded with respect to T because
the number of retained entries and the size of each evicted
entry are bounded. The bound applies to memory opera-
tions at each replanning step. Cumulative computation still
grows with the number of steps, and training-time LTM re-
construction depends on the replay length.
Empirical scaling. We measure the four implementations
on a PPU-ZW810E with batch size one, N = 16, H = 32,
R = 16, and Jv = 98, using the same pretrained pa-
rameters for corresponding modules.
We profile system
costs by cyclically replaying eight recorded observations
and executed prefixes with increasing timestamps, varying
T up to 128. Storage is the sum of unique persistent ten-
sor allocations: shared allocations are counted once, and
model weights and temporary tensors are excluded. Tim-
ing covers MoT attention and memory reads across all ac-
tion layers, including the backbone attention computation
within MoT. Instruction cross-attention, FFNs, prefix en-
coding, and memory updates fall outside the timed regions.
Each condition uses five rounds of 50 measurements after
20 warmup iterations per round; plotted values are the me-
dian of the round medians.
Figure 8 shows the predicted scaling trends. Full-history
memory exhibits linear storage growth and increasing read
latency, whereas M2-WAM reaches a storage plateau af-
ter the first FIFO eviction and maintains roughly stable
read latency as history grows. Removing either STM or
LTM reduces the measured overhead while omitting FIFO-
based recent context or associative consolidation, respec-
tively. The full hierarchy retains both at a bounded addi-
tional cost. These instrumented module measurements sup-
port the scaling comparison; end-to-end policy efficiency is
evaluated separately in Section 4.4.1.

B.2. Real-World Tasks and Protocols
We evaluate on Put Back Block, Shell Game, and Press But-
ton using the robot platform shown in Figure 3. Figure 9
illustrates the task procedures with representative demon-
stration frames.
Platform and policy inputs. Our platform consists of a 7-
DoF Franka Research 3 arm, a main-view RealSense D435i
camera, and a wrist-mounted RealSense D405 camera. For
M2-WAM, each RGB image is center-cropped to 640×640,
resized to 224 × 224, and concatenated horizontally with
the other view to form a 224 × 448 input.
The eight-
dimensional proprioceptive state contains the end-effector
position, quaternion orientation, and gripper width. Actions
comprise end-effector translation increments, relative rota-
tions represented by quaternions, and a binary gripper com-
mand. Press Button uses a fixed closed gripper, so its policy
predicts only the seven pose-increment components. We ap-
ply min–max normalization to actions and proprioception.
Demonstrations and training. We collected 50 demon-
stration trajectories per task using an Omega.7 teleopera-
tion device, shown in Figure 10, and trained a separate M2-
WAM policy for each task for up to 20,000 optimization
steps. Optimization and memory hyperparameters are listed
in Appendix A.1.
Put Back Block. The robot moves a block to the center of
the workspace and then returns it to its original location. It
must remember the initial placement and track whether the
intermediate move is complete. Success requires complet-
ing both stages in order.
Shell Game. Each trial begins with a five-frame observa-
tion phase, during which the robot waits while receiving the
initial scene observations. The program then pauses while a
human operator covers the block with a cup. After the pro-
gram resumes, the robot combines its memory of the initial
scene with the current observation to identify and lift the
cup covering the block. A trial succeeds when the robot
lifts the correct cup.
Press Button.
The scene contains three buttons, with a
number displayed in front of each of the first two. The robot
tracks its completed presses and must match both indicated
counts before pressing the third button to signal completion.
A trial succeeds when both counts are correct and the com-
pletion button is pressed last.
Deployment and evaluation. Inference runs on a single
NVIDIA RTX 3090 GPU, with control commands issued
at 15 Hz. M2-WAM predicts action chunks of length H =
32 and executes the first 16 commands before replanning
from the latest observation. Both M2-WAM and Fast-WAM
use precomputed text embeddings without loading the text
encoder during inference. We reset memory at the start of
each trial and evaluate each policy over 50 consecutive trials
per task. Trials exceeding 1,000 control steps are counted
as failures due to timeout.
B.3. Memory Variant Configurations
We train the five variants in Table 1 and Table 2 sepa-
rately, using the same training data and optimization budget
as the full model. All retain the permanent visual anchor,
current-observation conditioning, and benchmark-specific
action horizon and memory sampling stride.
Each vari-
ant uses its memory configuration during both training and
evaluation.
w/o-LTM. We remove both associative states and their writ-
ers and readers, while retaining the visual and interaction
FIFOs, each with capacity N. MoT attention reads visual
history, and interaction cross-attention reads encoded exe-
cuted prefixes. Evicted entries are discarded without con-
solidation.
w/o-STM. We remove both FIFOs while retaining the vi-
sual and interaction associative states. Each sampled ob-
servation is written directly into visual LTM before action
denoising, while its executed prefix is encoded and writ-
ten into interaction LTM after execution. The LTM readers
remain, while interaction STM cross-attention is removed.
Apart from the visual anchor, history is retained only in the
associative states.
Full-history memory. We retain all sampled visual KV en-
tries and executed prefixes from the episode, without evic-
tion or LTM consolidation. Action queries read the accu-
mulated visual history through MoT attention and the en-
coded prefixes through interaction cross-attention. Storage
and retrieval costs consequently grow with episode length,
as analyzed in Appendix A.4.
w/o modality separation. We retain the STM–LTM hierar-
chy but use a shared memory pathway for both modalities.
The prefix encoder produces P interaction tokens, which re-
ceive learned within-prefix position embeddings and layer-
specific projections into visual KV space. The projected
interaction keys and values are concatenated with their vi-
sual counterparts from the paired observation to form one
FIFO entry. Entries are committed after prefix execution
and evicted as a unit. On eviction, visual tokens followed
by interaction tokens update the same per-layer associative
state. Retrieval uses the visual STM and LTM pathways,
without separate interaction readers. The FIFO retains a ca-
pacity of N, and relative-age embeddings are shared by the
tokens within each entry.

B.4. Memory Retrieval Intervention Protocol
We assess the effect of memory retrieval using a fixed
checkpoint on ShellGameTouch, InterceptMedium, and Re-
memberColor3/5/9. For each task, all four retrieval condi-
tions use the same 30 environment seeds, yielding 30 roll-
outs per condition. Figure 6 reports their success rates.
Retrieval conditions. Full retrieval enables both STM and
LTM retrieval. STM read off disables retrieval from the vi-
sual and interaction FIFOs while retaining both LTM read-
ers. LTM read off disables both associative-state readouts
while retaining retrieval from the two FIFOs. Both reads
off combines these interventions. All four conditions retain
current-observation conditioning and access to the perma-
nent initial visual anchor.
The selected retrieval condition remains active through-
out each episode, across all denoising iterations and relevant
layers. FIFO storage, eviction, and LTM updates proceed
normally; only retrieval is masked.
Paired evaluation.
We reset memory at each episode
boundary and use the same task success criteria as in Ap-
pendix B.1. Matching seeds controls the initial task con-
ditions, while closed-loop actions and subsequent observa-
tions may diverge across retrieval conditions.

C.4. Effect of Decay Granularity
We compare applying temporal decay at every spatial to-
ken with our entry-level decay, which applies it once per
visual entry. The per-token variant is evaluated after 30,000
training steps on the five MIKASA-Robo tasks. Table 10
compares its success rates with the entry-level results from
Table 1.
Entry-level decay achieves higher success on all five
tasks, improving average success from 73.0% to 78.8%.
The largest gain is 19 percentage points on Remember-
Color3, compared with one and two points on ShellGa-
meTouch and InterceptMedium, respectively.
Spatial to-
kens within one observation share a timestamp, yet per-
token decay repeatedly attenuates the state as these tokens
are processed.
Our entry-level rule instead applies de-
cay once according to the elapsed source time, indepen-
dently of the number of spatial tokens, as detailed in Ap-
pendix A.3. These results support separating temporal de-
cay from within-frame spatial-token updates when adapting
gated delta updates to image sequences.

PressButton. With both memories enabled in Figure 16,

Fast-WAM backbone’s generalization and character recog-
nition, as discussed in Section 4.2.
ObserveAndPickup. In Figure 17, both memories are en-
abled, but the robot fails to pick up the blue bell matching
the initial reference. After the reference is occluded, the
left arm repeatedly operates near non-target objects, while
the right arm remains nearly stationary. The target remains
unmoved at the 250-step limit.
Across our experiments, the policy performs well on lay-
outs resembling the training data but fails more often on un-
familiar arrangements, even for the same target. This sensi-
tivity highlights limited generalization, consistent with Sec-
tion 4.2. We hypothesize that the policy relies too heavily
on the current scene, associating familiar layouts with tra-
jectories rather than consistently using the initial reference
to select the target.
BatteryTry. The task requires placing two batteries in their
slots with the correct orientations.

1,000-step limit. This case highlights difficulties in preserv-

errors.

Adaptive memory retrieval. Retrieval follows a prede-

retrieve and which modalities or memory levels to consult.

Memory use and generalization.
The failures in Ap-

consistently to unfamiliar layouts. Broader layout variation
and examples with similar current observations but different
historical cues and required actions could encourage more
reliable use of history.

alignment and manipulation precision.
