## 摘要
视觉-语言-动作（VLA）策略在固定指令的机器人操作基准上表现良好，但其在执行过程中适应指令变化的能力仍缺乏充分研究。我们提出动态任务更新基准（DTU-Bench），使用模拟机器人操作基准LIBERO，评估跨越七种更新类型和三个执行阶段的40项任务修订。我们比较在执行开始前与执行过程中给出新指令时的性能，并考察新任务指令是否被遵循。在13种代表性VLA配置中，原始物体操作任务的平均任务成功率为95.8%，而当指令在执行过程中改变要操作的物体时，成功率仅为1.6%。受控诊断表明，策略通常先完成原始任务再完成更新后的任务，且其响应取决于机器人的物理状态。我们进一步测试一个简单的脚本控制器——释放已抓取物体并将机械臂移回——是否有助于机器人响应指令变化。该方法将π0.5的成功率从2%提高到38%，将DM0.5的成功率从8%提高到48%，但可能造成不期望的物体运动。这些发现揭示了固定指令基准和仅凭任务成功率指标在评估机器人操作时可能忽视的局限性。项目页面：https://dtu-bench.github.io/

## Abstract
Vision-language-action (VLA) policies perform well on fixed-instruction robotic manipulation benchmarks, but their ability to adapt to instruction changes during execution remains understudied. We introduce the Dynamic Task Update Benchmark (DTU-Bench), evaluating 40 task revisions across seven update types and three execution stages using LIBERO, a simulated robotic manipulation benchmark. We compare performance when a new instruction is given before execution starts versus during execution, and examine whether the new task instructions are followed. Across 13 representative VLA configurations, average task success is 95.8% on the original object-manipulation tasks, compared with only 1.6% when the instruction changes which object to manipulate during execution. Controlled diagnostics show that policies often complete the original task before the updated one, and that their responses depend on the robot's physical state. We further test whether a simple scripted controller that releases the grasped object and moves the arm back helps robots respond to instruction changes. This improves success from 2% to 38% for π0.5 and from 8% to 48% for DM0.5, but can cause unwanted object motion. These findings reveal limitations that fixed-instruction benchmarks and task-success metrics alone can overlook in evaluating robotic manipulation. Project page: https://dtu-bench.github.io/

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）策略在 LIBERO、CALVIN 等固定指令基准上表现优异，但真实人机协作中，用户可能在机器人**执行途中**修改指令（换物体、换放置位置、撤销部分要求等）。
- **核心问题**：现有 VLA 能否在**不重置环境与机器人状态**的前提下，从已执行的部分原任务中转向新任务？固定指令基准与单一“任务成功率”是否会掩盖这一能力缺陷？
- **与已有工作的区别**：
  - DynamicVLA、TIC-VLA 主要应对动态观测/反应式控制，而非任务目标变更；
  - SwitchVLA、ReSteer 通过训练新策略或生成数据提升可切换性，而非系统评测；
  - LIBERO-Plus、LIBERO-Safety 关注扰动与安全，不关注执行中任务修订。
- **整体含义**：论文主张将“修订任务本身的能力”与“运行时切换能力”区分开，并指出“到达新目标”不等于“及时响应新指令并保持结果”。

## 2. 方法论

### 2.1 核心思想
- 构建 **DTU-Bench**：在 LIBERO 模拟环境中，于机器人执行原指令 $I_0$ 的过程中注入修订指令 $I_1$，从当时物理状态 $s_\tau$ 继续执行，系统评估运行时任务适应。
- 同时设置“原任务控制”“修订任务从初始状态执行控制”“运行时更新”三类条件，以分离任务难度与切换难度。

### 2.2 任务更新形式化
- 执行开始于 $I_0$（目标 $G_0$），在 $t=\tau$ 时系统处于中间状态 $s_\tau$，指令切换为 $I_1$（目标 $G_1$）：
  - $a_t \sim \pi(\cdot \mid o_t, I_0)$，当 $t<\tau$；
  - $a_t \sim \pi(\cdot \mid o_t, I_1)$，当 $t\ge\tau$。
- 更新后丢弃原指令下剩余动作，基于新指令与当前观测重新推理；给予 300 步动作预算，并继续执行以检查目标是否保持；部分实验延长至 600 步。

### 2.3 七类任务更新分类（4 大类）
- **Entity（实体）**：
  - Spatial referent（空间指代）：改变目标物体的关系性描述；
  - Object identity（物体身份）：改变被操作物体。
- **Goal（目标）**：
  - Destination（目的地）：改变放置位置；
  - Placement relation（放置关系）：改变物体—目的地关系；
  - Terminal state（终态）：改变环境所需最终状态。
- **Entity/Goal**：
  - Subgoal replacement（子目标替换）：替换一个必需子目标，保留其余子目标。
- **Multiple（多重）**：
  - Compound goal（复合目标）：同一指令中改变两个及以上独立要求。

### 2.4 执行阶段干预
- 按**任务进展事件**而非固定步数划分 **early / middle / late** 三阶段（如接近物体、抓取/抬起、移向目的地）。
- 若机器人未到达指定阶段，则该次更新记为“未交付”。

### 2.5 评估指标与诊断设计
- **三类条件**：original control、updated-from-start control、runtime update。
- **目标满足指标**：
  - **Ever**：$G_1$ 是否至少满足一次；
  - **Held-10**：是否连续 10 次观测满足；
  - **Final**：300 步结束时是否满足。
- **匹配状态行为诊断**：恢复同一干预状态，分别以 $I_0$ 与 $I_1$ 继续，均用 $G_1$ 评判，比较目标达成、物体交互及原/新目标满足的时序。
- **执行状态与可达性诊断**：改变机器人姿态、物体布局、视觉输入；并用基于几何路点的参考控制器独立尝试修订任务，以提供可达性证据（失败不证明不可行）。
- **统计分析**：按初始状态块重采样估计 95% 置信区间；任务簇 bootstrap 与留一任务分析检验任务组成敏感性。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- 基于 **LIBERO** 的四个套件：**Spatial、Object、GOAL、Long**。
- 构建 **40 个任务更新场景**，每个场景包含原指令—目标 $(I_0,G_0)$ 与更新指令—目标 $(I_1,G_1)$，环境不重置。
- 每个场景使用 **50 个官方初始状态**；完整设计为每策略配置 **10,000 次计划试验**（40 任务 × 50 状态 × 5 条件，两个 from-start 控制跨三阶段共享）。

### 3.2 对比的 VLA 配置（13 个）
- OpenVLA、OpenVLA-OFT、π0、π0.5、DM0.5、WorldVLA、RynnVLA-002、UniVLA、VLA-JEPA、InstructVLA、τ0-VLA、MolmoAct2、FlashVLA-π0.5。
- 覆盖自回归动作 token、连续回归、流匹配等不同动作生成机制；均使用公开 LIBERO checkpoint，**不额外训练**，保留各自原生观测输入、动作表示与推理接口。

### 3.3 受控诊断实验
- **Destination vs. Object 更新**：π0、π0.5，同一 GOAL 场景，5 个初始状态，approach 与 stable-grasp 两阶段，300 步延续。
- **指令、姿态与布局**：π0.5、DM0.5，2 个 Object 任务 × 5 状态，变化 instruction / posture / layout，共 **160 条延续**，600 步。
- **匹配指令延续**：**94 对**（π0.5 46 对、DM0.5 48 对），覆盖 Long、Object、Spatial。
- **推理时辅助**：Direct、Retreat、Release+Retreat 三种方式；10 个 Object 任务 + 5 个 GOAL destination 任务，5 状态 × 2 阶段；每策略每阶段 50 个 Object 试验与 25 个 Destination 试验。
- **轨迹分析**：自动提取首次手指—物体接触时间及原/新目标满足时间。
- 另有任务取消、无关指令、视觉输入敏感性等实验置于补充材料。
