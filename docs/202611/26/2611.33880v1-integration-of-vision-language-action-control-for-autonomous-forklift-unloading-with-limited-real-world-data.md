## 摘要
叉车在仓储和配送中发挥着关键作用，但现有自动化系统在处理需要序贯决策的复杂任务时仍存在局限。近来，视觉-语言-动作（VLA）模型作为一种颇具前景的方法出现，其通过从视觉观测和语言提示直接生成控制动作来实现多步决策。尽管基于VLA的控制已在机械臂上得到广泛研究，但据我们所知，其在叉车上的应用仍未被探索。因此，本研究展示了在有限真实世界数据下将VLA控制集成用于自主叉车卸货任务。此外，训练VLA模型通常需要大规模数据集。由于目前尚无公开的叉车操作数据集，我们使用主要基于机器人机械臂数据预训练的VLA模型，并通过仿真构建训练数据集，该数据集可以低成本扩展。随后，我们使用9.38小时的仿真数据和0.8小时的真实世界示范将预训练VLA模型适配到叉车控制，其中后者按持续时间计约占所收集叉车数据的8%。该集成系统通过四种模型变体下的72次真实世界试验进行了验证。结果表明，所提出的系统即使在有限真实世界数据下也能完成卸货任务。

## Abstract
Forklifts play a critical role in warehousing and distribution, but existing automation systems remain limited in handling complex tasks that require sequential decision-making. Recently, vision--language--action (VLA) models have emerged as a promising approach for multi-step decision-making by directly generating control actions from visual observations and language prompts. Although VLA-based control has been extensively researched for manipulators, to the best of our knowledge, its application to forklifts remains unexplored. Therefore, this study demonstrates the integration of VLA control for an autonomous forklift unloading task with limited real-world data. Moreover, training VLA models typically requires large-scale datasets. As there is currently no public dataset for forklift operations, we use a VLA model pretrained primarily on robotic manipulator data and construct a training dataset via simulation, which can be scaled up at low cost. We then adapt the pretrained VLA model to forklift control using 9.38 h of simulation data and 0.8 h of real-world demonstrations, with the latter accounting for approximately 8% of the collected forklift data by duration. The integrated system was validated through 72 real-world trials across four model variants. The results show that the proposed system can accomplish an unloading task even with limited real-world data.

## 2. 方法论

### 2.1 核心思想
- 采用 **两阶段迁移适配**：先在仿真数据上做 mid-training 以弥合"机械臂→叉车"的具身差距（embodiment gap），再用少量真实数据 post-training 适配目标平台与环境。
- 以 **π0.5** 为基础模型（PaliGemma 式 VLM：SigLIP 视觉编码 + Gemma，配合 flow matching 动作专家），绕过从零构建 VLA 的高昂成本。

### 2.2 模型输入输出与关键设计
- **观测**：$o_t = [I^l_t, I^r_t, \ell_t, q_t]$，即左/右相机图像（352×288 RGB，缩放至 224×224）、语言提示 $\ell_t$、车辆状态 $q_t$（速度、偏航角速度、货叉高度）。状态向量量化为 256 个 bin，以文本 token 形式输入。
- **动作**：$a_t \in \mathbb{R}^3$（油门 0–100%、转向舵机角度、目标货叉高度），与人工操作接口一致；预测未来 $H=20$ 步、步长 20 ms 的动作块。
- **联合预测**：VLM 分支做子任务分类（7 类：接近、拾取、倒车、右转搜索、向蓝/黄/红区放置），动作专家生成动作序列：
  $$\pi_\theta(a_t, c_t \mid o_t) = \pi_\theta(a_t \mid o_t)\,\pi_\theta(c_t \mid o_t)$$
  子任务预测不直接参与动作生成，但动作专家会 attend 到用于分类的 VLM 表示；分类损失反传经 VLM，作为**辅助语义监督**保留任务语义。
- **损失函数**：
  $$L(\theta) = \mathbb{E}[\ell_{fm}(\theta; o_t, a^*_{t:t+H})] + \lambda\,\mathbb{E}[-\log \pi_\theta(c^*_t \mid o_t)]$$
  默认 $\lambda=1$；$\lambda=0$ 即消融掉子任务预测。
- **状态随机化**：$\hat{q}_t = r_{mul} \odot q_t + r_{add}$，乘性增益噪声 + 正态加性偏置，提升对观测噪声的鲁棒性。
- **双提示设计**：将任务拆为"Pick up the pallet on the truck."与"Find the {color} zone and place the pallet there."，训练时在 pickup→backout 转换处切换；推理时以货叉高度阈值为触发条件自动切换——这是部署中**唯一的预定义逻辑**。
- **异步动作块执行**：VLA 单次推理约 100 ms，故以 $t_{inf}=0.2$ s 为周期推理，模型预测至观测后 400 ms 的动作，控制器跳过推理延迟对应部分、执行 200–400 ms 段的动作，保持观测—推理—运动的时间一致性。

## 3. 实验设计

- **平台**：1/14 比例平衡重式叉车（后轮转向、前轮驱动），左右双针孔相机，Raspberry Pi 4 + ROS 与推理 PC 通信；速度/偏航率由动捕系统提供，货叉高度由旋转编码器测得。
- **数据集**：
  - 仿真：Isaac Sim + CAD 模型 + 实景 3D 扫描背景，随机化光照、托盘/负载颜色、负载排布、相机位姿；由硬编码子任务管理器 + 利用特权信息（绝对位姿）的 Clothoid 路径规划与 Pure Pursuit 生成数据；1179 次任务、9.38 h、898 个成功回合。
  - 真实：两个环境（A/B，放置区背景差异显著）遥操作采集，58 次任务、0.8 h，真实数据按时长占比约 8%。
- **Benchmark 与对比方法**（均基于同一 π0.5 权重）：
  - **Proposed**：25,000 步仿真 + 5,000 步真实，共 30,000 步；
  - **Only real**：仅真实数据 10,000 步；
  - **Only sim.**：仅仿真数据 25,000 步；
  - **Proposed ($\lambda=0$)**：去掉子任务分类损失。
- **评估协议**：每个环境对 3 种颜色区各执行 3 次（共 9 次/环境，18 次/模型，4 模型共 **72 次真机试验**），三次试验间变化托盘负载摆放；成功判据为"未掉落负载且托盘中心落在目标区域内"。

## 6. 主要结论与发现

- **Proposed 方法在 18/18 次试验中全部成功（100%）**；"Only real" 为 50%，"Only sim." 为 **0%**，$\lambda=0$ 变体仅 39%（低于 Only real）。
- **仿真 mid-training 有效**：9.38 h 仿真数据可显著提升仅用 0.8 h 真实数据时的成功率，说明仿真数据能为新具身提供有效监督。
- **子任务辅助监督关键**：去掉分类损失后成功率大幅下降，最常见失败模式是**把托盘送到错误颜色区或非预期位置**，表明辅助语义监督有助于维持语言目标与生成动作的一致性（与 π0.5、知识隔离等相关工作结论一致）。
- **子任务识别精度高**：未参与训练的 5 段真实演示上帧级分类准确率达 **96.8%**。
- **"Only sim." 失败原因**：仿真数据由单一控制策略生成、多样性不足，难以覆盖真实条件。
- **系统级可行性**：VLA 推理 + 阶段预测 + 异步动作块执行 + 底层车辆控制的集成可在真实平台上闭环运行，仅依赖板载相机与最小传感配置。

## 7. 优点

- **首创性**：据作者所述，是首个将 VLA 端到端动作生成集成到真实叉车卸货任务的研究，填补了 VLA 在工业车辆上的应用空白。
- **低成本数据路线务实**：数字孪生仿真（含光照、颜色、负载、相机位姿、状态噪声多重随机化）+ 仅 0.8 h 真实遥操作数据，真实数据占比约 8%，显著降低数据采集门槛。

- **实验有对照、判据客观**：包含两个有意义的基线与一个消融变体，成功标准几何化、可复现。

## 8. 不足与局限

- **平台规模限制**：实验在 1/14 比例叉车上完成，未验证全尺寸叉车的车辆动力学、更强传感噪声、安全约束与数据采集问题；结论向真实工业部署的外推需谨慎。
- **环境与任务覆盖有限**：仅两个受控环境、固定颜色区布局，未证明对任意环境、托盘位姿、目标布局的开放式鲁棒性；语言指令仅两条固定提示，未测试开放语言泛化。
- **缺失实际作业中的关键技能**：未涵盖深度取货时的"先抬至车边、再深插货叉"等再抓取动作，也未涉及用货叉轻推托盘等接触丰富、高精度操作（作者建议未来用离线 RL 处理）。
- **预训练贡献未厘清**：高成功率展示了适配潜力，但**预训练权重本身的具体贡献尚未被消融或量化**。
- **模型能力边界**：单帧观测、无历史；子提示切换仍依赖一个硬编码阈值；缺乏对失败恢复与长时程纠错机制的讨论。
- **实验统计性偏弱**：每条件仅 3 次重复、无显著性检验；基线训练步数与真实数据预算不完全对齐；仿真数据多样性受限于单一生成策略，可能低估仿真路线的真实潜力或高估其局限。
- **算力信息不完整**：未报告训练 GPU 数量/型号与训练时长，复现成本难以评估。
- **数据可得性**：无公开叉车数据集，本文自建数据亦未说明是否开源，限制后续可比研究。
