## 摘要
嵌套式多精度量化通过仅读取每个权重的前导位，从单个检查点导出多种精度，这使其在不同内存与能耗预算下的端侧部署具有吸引力。然而，现有方法仅提供整数比特，导致相邻精度之间存在较大的精度差距，并在 2 比特时出现严重退化。为此，我们提出 Any-Rate，它从单个检查点提供 2-8 比特，并在 2-4 比特范围内以半比特为步长。Any-Rate 将某些位平面限制为 8 权重块中的扩展汉明码字（每权重 0.5 比特），跨精度共享每行一个 LUT，并联合编码所有精度且为每个精度设置单独目标，从而减少共享位平面带来的损失。在四个 LLM 上，Any-Rate 在 2 比特和 3 比特下取得了多精度方法中最先进的精度，在 2 比特下保持 FP16 精度的 69%，在 4 比特下与最佳方法相差不超过一个百分点。其解码速度与现有内核大致相当，且一个 LPDDR 能耗模型估计在同等精度下可减少高达 27% 的能耗。代码见 https://github.com/hoonki2002/Any-Rate。

## Abstract
Nested multi-precision quantization derives multiple precisions from a single checkpoint by reading only the leading bits of each weight, which makes it attractive for on-device deployment under varying memory and energy budgets. However, existing methods offer only integer bits, leaving large accuracy gaps between adjacent precisions and severe degradation at 2 bits. To address this, we propose Any-Rate, which serves 2-8 bits from one checkpoint, in half-bit steps over 2-4 bits. Any-Rate restricts some bit-planes to extended Hamming codewords in 8-weight blocks (0.5 bits per weight), shares one LUT per row across precisions, and encodes all precisions jointly with a separate target for each, reducing the loss from sharing bit-planes. Across four LLMs, Any-Rate achieves state-of-the-art accuracy among multi-precision methods at 2 and 3 bits, keeping 69% of FP16 accuracy at 2 bits, and is within one point of the best at 4 bits. It decodes about as fast as existing kernels, and an LPDDR energy model estimates up to 27% less energy at equal accuracy. Code is available at https://github.com/hoonki2002/Any-Rate.

### 1. 核心问题与整体含义
- **研究动机**：LLM 端侧部署受内存与能耗预算约束，且预算会随设备/运行时变化；推理主要是内存带宽受限，权重比特宽度直接决定延迟与能耗。理想方案是“单检查点、多精度、按需读取前缀位平面”。
- **现有问题**：嵌套多精度量化（AP、AB、MG 等）虽能从单一检查点读出多个精度，但仅支持整数比特，2–4 bit 间精度档位稀疏；2 bit 下 AP/AB 严重退化，MG 为兼顾 2 bit 会牺牲 4 bit 精度。
- **核心概念**：作者将“所有模式共享前导位平面”带来的额外重建损失称为 **nesting cost**。论文目标是：在保持前缀可解码的前提下，提供 2–4 bit 的半比特步进，并覆盖 2–8 bit，同时降低 nesting cost。
- **整体含义**：Any-Rate 试图让一个检查点在不同内存/能耗/精度预算下平滑切换，尤其改善低比特区间，从而提升端侧动态精度部署的可用性。

### 2. 方法论
- **核心思想**：
  - 用 **U/H 混合位平面布局** 实现半比特步进：U 为无约束位平面（1 bit/weight），H 为扩展 Hamming `[8,4,4]` 编码位平面（0.5 bit/weight）。
  - 采用 `UHHHHHH` 布局：读取前 3–7 个平面分别得到 2、2.5、3、3.5、4 bit 模式；5–8 bit 通过独立残差平面扩展。
  - 每行共享一个 LUT，各模式 LUT 由共享 LUT 按前缀平均导出，降低元数据开销。
  - 联合编码所有模式，但为每个模式保留独立误差反馈目标（per-mode targets），而非 MG 的加权平均目标。
- **关键技术细节**：
  - **H 平面**：每 8 个相邻权重为一组，其 8 个比特限制为扩展 Hamming 码的 16 个码字之一；每组存 4-bit message，故 0.5 bit/weight。解码时可由 message 通过 XOR 直接恢复索引位，无需显式展开码字。
  - **共享 LUT**：存储顶层共享 LUT `T`，模式 `m` 的 `T_k` 由共享 LUT 中具有相同 k-bit 前缀的项平均得到；固定索引时 LUT 拟合为加权最小二乘闭式解，编码与 LUT 重拟合交替进行。
  - **残差校正**：2–4 bit ladder 固定后，5–8 bit 使用独立 4-bit 残差索引 `ρ`（四个 U 平面）；`m` bit 模式重建为 `bw_m = bw_4 + δ_m[ρ >> (8-m)]`，其中 `δ_m` 为每行偏移表，避免共享 LUT 随平面数指数膨胀。
  - **联合编码目标**：层重建损失为 `L_layer_m = ||E_m X||_F^2 = tr(E_m Γ E_m^T)`，`Γ=XX^T`；联合最小化 `Σ_m λ_m tr(E_m Γ E_m^T)`。
  - **逐模式误差反馈**：每个模式维护独立目标 `τ_m`，用该模式自身量化误差更新；U 平面逐列选比特，H 平面按 8 列块联合选择码字。
  - **多模式块级搜索**：候选 `s` 固定各 H 平面码字后，逐列选择 U 比特使 `Σ_m λ_m(τ̃_{m,i}-q_{m,i})^2` 最小，并分别传播各模式误差；候选按加权损失评估。
  - **高效候选搜索**：利用 ladder 前缀结构，逐 H 平面扩展 16 个码字并保留 beam 宽度 `B` 个候选，最后对 top `K` 个候选做带误差反馈的精确评估；默认 `B=K=64`。
- **解码与存储**：
  - 前缀解码：每个模式只读取所需前导平面；切换模式无需重新量化或单独检查点。
  - 存储：U 平面 1 bit/weight，H 平面 0.5 bit/weight；Llama-3.1-8B-Instruct 上 UHHHHHH 的共享 LUT 约 0.21 bit/weight，残差偏移表约 0.09 bit/weight。
  - 2–4 bit ladder 约 4.21 bit/weight；2–8 bit 全模式约 8.30 bit/weight。
