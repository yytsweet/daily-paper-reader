## 摘要
动态物体操作需要在推理与执行过程中与持续运动的目标保持空间和时间对齐。尽管未来预测可以为动作修正提供依据，但准确的预测并不能确定修改现有动作是否有益。我们提出 Aegis-VLA，一个由世界模型引导的视觉-语言-动作（VLA）框架，它生成预测性动作修正，并单独决定是否应用以及以多强程度应用这些修正。轨迹世界模型将运动学外推与学习到的残差动力学相结合，以预测物体运动并估计位置不确定性。差异引导动作细化利用仅历史条件与基动作条件下的末端执行器预测之间的差异，提出有界机械臂修正。可靠性门基于相对于基动作的示教相对改进来学习何时接纳修正，并在推理期间利用预测不确定性和预期物体-末端执行器接近度来调节其应用。被拒绝的修正保留相应的基动作。Aegis-VLA 仅引入约 2.45M 个可训练参数。在模拟动态物体操作（DOM）基准上，Aegis-VLA 在 1,800 次评估试验中取得 56.72% 的成功率，比我们复现的 DynamicVLA 基线 45.44% 高出 11.28 个百分点。

## Abstract
Dynamic object manipulation requires maintaining spatial and temporal alignment with targets that continue to move during inference and execution. Although future prediction can inform action correction, an accurate forecast does not establish whether modifying an existing action would be beneficial. We present Aegis-VLA, a world-model-guided vision-language-action (VLA) framework that generates predictive action corrections and separately determines whether and how strongly to apply them. A Trajectory World Model combines kinematic extrapolation with learned residual dynamics to predict object motion and estimate positional uncertainty. Discrepancy-Guided Action Refinement uses differences between history-only and base-action-conditioned end-effector forecasts to propose bounded arm corrections. A Reliability Gate learns when to admit corrections based on demonstration-relative improvements over base actions, and regulates their application during inference using predictive uncertainty and anticipated object--end-effector proximity. Rejected corrections preserve the corresponding base actions. Aegis-VLA introduces only approximately 2.45M trainable parameters. On the simulated Dynamic Object Manipulation (DOM) benchmark, Aegis-VLA achieves 56.72\% success over 1,800 evaluation trials, exceeding our reproduced DynamicVLA baseline of 45.44\% by 11.28 percentage points.

- **应用背景**：动态物体操作（如抓取移动中的瓶子、滚动土豆）要求机器人在推理与执行延迟期间，始终与持续运动的目标保持空间—时间对齐。同一观测位置，目标靠近、远离或转向时，所需动作完全不同。
- **关键痛点**：现有 VLA/世界模型方法（如 DynamicVLA、PUMA、AHEAD、DynaWM、DreamTrajectory）能预测未来或修正动作，但**“预测准确”不等于“修改有益”**。
  - 若基动作已补偿目标运动，额外修正反而破坏对齐；
  - 修正本身可能建立在不可靠的预测之上。
- **核心命题**：有用的动作精修必须同时回答两个问题——(a) 该修正是否优于基动作；(b) 运动预测是否足够可靠以支撑该修正。
- **整体含义**：论文提出将“修正生成”与“修正准入”解耦的框架 Aegis-VLA，在冻结 VLA 主干的前提下，以极少量参数（约 2.45M）实现可靠性门控的动态操作动作细化。

## 2. 方法论

### 核心思想
- 以**冻结的 DynamicVLA** 为动作生成主干；仅训练三个轻量模块：轨迹世界模型（预测）、差异引导动作细化（提议）、可靠性门（准入与调节）。
- 修正以**有界残差**形式作用于机械臂动作；夹爪动作保持基动作不变；被拒绝的修正即 α=0，退化为基动作。

### 关键技术细节

**（1）轨迹世界模型（Trajectory World Model）**
- 输入：5 帧双视角 RGB + 末端位姿历史（25 Hz，跨度 0.32 s），经双视角共享 CNN 编码器 + 时序 GRU 得到运动上下文 \(z_t\)。
- 物体运动预测 = **常加速度运动学外推 + 学习残差动力学**：
  \(\hat p_{t,h} = \hat p_t + \hat v_t\delta_h + \tfrac12\hat a_t\delta_h^2 + \rho^{pos}_{t,h}\)，速度项同理；预测 16 步、0.64 s。
- 不确定性头输出有界对数标准差 \(\sigma_{t,h}\)（三坐标共享一个标量），用**异方差高斯 NLL** 训练：\(\mathcal L = \|\hat p - p^\star\|^2/(6\sigma^2) + \log\sigma\)。

**（2）差异引导动作细化（Discrepancy-Guided Action Refinement）**
- 两个预测器：仅历史 MLP 预测末端轨迹 \(\hat e^{hist}\)；额外以基动作前 M 步为条件的 GRU 预测 \(\hat e^{cond}\)。
- 二者差异经 wrap（位置恒等、欧拉角卷绕到 \([-\pi,\pi]\)）与端点对齐线性插值 \(T(\cdot)\) 映射到动作块索引，得差异特征 \(\tilde d_{t,i}\)。
- 残差生成：\(\Delta u_{t,i} = \zeta_{max}\tanh(F_{ref}([z_t; u^{base}_{t,i}; \tilde d_{t,i}]))\)，一次批量生成整个动作块。
- 无门控候选 \(u^{cand}=u^{base}+\Delta u\) 以示范动作为监督，并加一阶/二阶差分惩罚约束时序平滑。

**（3）可靠性门（Reliability Gate）**
- **学习准入**：Sigmoid MLP 输出选择分数 \(q_{t,i}\)，输入含运动上下文、基动作、残差绝对值/范数、位置差异范数、块内相对位置。
- 准入标签基于**示范相对改进**：\(\Delta E = E_{base} - E_{cand}\)，需同时满足绝对改进 \(\epsilon_{abs}\)、相对改进 \(\lambda_{rel}\) 与预测精度 \(ADE_t \le \epsilon_{ADE}\) 三重条件；负样本加权 BCE 训练，并加保留惩罚。
- **推理时调节**：不确定性衰减 \(r_t = \exp(-\bar\sigma_t/\sigma_0)\)，准入 \(\beta_{t,i} = \chi_t\cdot\mathbb 1[q\ge\tau]\cdot\mathbb 1[\bar\sigma\le\sigma_{veto}, r\ge r_{min}]\)，最终系数 \(\alpha_{t,i} = \alpha_{max}\beta_{t,i}r_t(1-\kappa\gamma_{t,i})\)，其中 \(\gamma\) 为物体—末端接近度分数（接近时抑制干预）。
- 输出：\(u^{out} = u^{base} + \alpha\Delta u\)，\(g^{out}=g^{base}\)。

## 8. 不足与局限

- **仅仿真验证**：全部结果来自 Isaac Sim 的 DOM 基准，未在真实机器人上验证，sim-to-real 迁移性未知。
- **统计严谨性不足**：每个设置仅单次完整运行，未报告方差、置信区间或多种子结果；小差异消融（如 −1.50 pp）结论稳健性存疑。
