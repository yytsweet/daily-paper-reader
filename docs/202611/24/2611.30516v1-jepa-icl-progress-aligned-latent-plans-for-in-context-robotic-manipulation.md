## 摘要
示范展示了任务可以如何完成，但具身形态、外观和执行速度的差异使得难以识别与机器人当前进度相关的引导信息。我们提出 JEPA-ICL，一个将预测性规划与示范学习耦合的视觉-语言-动作框架。该策略通过在 JEPA 特征空间中预测直至子任务完成的有序未来状态来学习规划，捕捉尚待完成的内容。这些计划引导动作生成，并在示范中定位相关阶段，其 JEPA 监督的内容特征提供进度对齐的上下文。反过来，从该上下文学习会更新产生计划与动作的共享策略。这种耦合将预判机器人自身执行与复用示范经验联系起来。在 Imitator Game 上，JEPA-ICL 在 C15 预训练下达到 80.0% 的已见任务成功率，比 Zero-WAM 高出 12.0 个百分点。在没有上下文示范的情况下，JEPA-ICL 优于未进行人类视频预训练的 VLA-JEPA 变体，将 LIBERO 上的成功率从 96.1% 提升至 97.6%，将 LIBERO-Plus 上的成功率从 62.9% 提升至 73.2%。在基于示范的训练和推理时上下文引导下，LIBERO-Plus 成功率进一步从 73.2% 提升至 75.2%。

## Abstract
Demonstrations show how a task can be completed, but differences in embodiment, appearance, and execution speed make it difficult to identify the guidance relevant to the robot's current progress. We introduce JEPA-ICL, a vision-language-action framework that couples predictive planning with demonstration learning. The policy learns to plan by predicting ordered future states in JEPA feature space up to subtask completion, capturing what remains to be accomplished. These plans guide action generation and locate relevant stages in demonstrations, whose JEPA-supervised content features provide progress-aligned context. Learning from this context, in turn, updates the shared policy that produces the plans and actions. This coupling connects anticipating the robot's own execution with reusing demonstrated experience. On the Imitator Game, JEPA-ICL achieves 80.0% seen-task success under C15 pretraining, outperforming Zero-WAM by 12.0 percentage points. Without contextual demonstrations, JEPA-ICL outperforms the VLA-JEPA variant without human-video pretraining, improving success rates from 96.1% to 97.6% on LIBERO and from 62.9% to 73.2% on LIBERO-Plus. With demonstration-based training and contextual guidance at inference, LIBERO-Plus success further increases from 73.2% to 75.2%.

## 1. 核心问题与整体含义

- **研究背景**：机器人通过人类示范（视频/遥操作）学习操作技能是重要范式，但示范与机器人自身执行之间存在**具身形态、外观、执行速度**三重差异，导致难以判断"示范中哪一段与机器人当前进度相关"。
- **现有方法的痛点**：
  - 按**时间索引**读取示范：长示范与短动作块推进节奏不一致，策略容易"照抄"或"忽略"示范；
  - 按**相似度**对齐：需要手工度量（如动作 DTW、DINO 特征）或额外的专用对应模型（HOST、Demo-JEPA）；
  - 匹配所用的表示与策略实际执行所用的表示**相互分离**，学到的对应关系无法反哺规划。
- **核心问题**：如何让"指导机器人自身动作的计划"同时成为"组织其使用示范经验的索引"？
- **整体含义**：论文主张用**"当前子任务完成前尚待发生的状态变化序列"**来刻画执行阶段——即用"还剩什么"而非"过了多久"来定义进度，从而把**自身执行预判**与**示范经验复用**统一到同一潜在空间。

## 2. 方法论

### 2.1 核心思想
- 在**冻结 V-JEPA 2.1 特征空间**中，让潜在计划 $Z_t$ 预测"当前子任务剩余区间内的有序未来状态"，该计划同时承担两个角色：
  1. 条件化动作生成；
  2. 作为**进度键**在示范中定位同一阶段，读取该阶段的内容特征作为上下文。

### 2.2 共享策略与查询 token
- 骨干为 VLM（Qwen3-VL-2B 或 π0.5），在序列后追加可学习查询：
  - **plan queries**（16 个）→ 潜在计划 $Z_t$；
  - **future queries**（64 个）→ 内容特征 $E_t$；
  - **action queries**（32 个）→ 特征 $h_t$，与本体状态 $s_t$ 一起送入 flow-matching 动作头；
  - **memory tokens** $M_t$（16 个）→ 来自示范上下文。
- **注意力掩码设计**：plan queries 只读观测与指令（$Z_t$ 不受上下文污染）；future/action queries 读 $Z_t$ 与 $M_t$；action queries **不读** future queries，保证计划是动作头唯一的预测信号来源。

### 2.3 Markov 监督的潜在计划
- **目标定义**：训练回合按子任务切分，$e_t$ 为当前子任务结束时刻，在剩余区间按 25%/50%/75%/100% 放置 $K=4$ 个 checkpoint：
  $$n_k = t + \tfrac{k}{K}(e_t - t),\quad S_k = S(o_{n_k})$$
  最后一个目标恒为子任务完成点，从而**消除固定时间视界**依赖。
- **预测方式**：世界模型 $W$ 从当前状态 $\hat S_0 = S(o_t)$ 出发，每步只看前一步状态与计划：
  $$\hat S_k = W(\hat S_{k-1}, Z_t),\ k=1,\dots,K$$
  四个步骤**共享同一个转移模型**，步间**梯度截断**（每步按一步预测训练）。
- **损失**：特征空间 L1，运动 patch 权重 0.8、静态 patch 权重 0.2：
  $$L_{plan} = \sum_{k=1}^{K} w_k \odot \|\hat S_k - S_k\|_1$$
- **关键论点**：$W$ 只能看到当前帧与 $Z_t$，因此当前帧未揭示的剩余过程必须由计划承载；监督所有中间 checkpoint（而非仅终点）迫使计划编码**剩余变化的顺序**。

### 2.4 进度对齐的示范上下文
- **定位阶段**：小型 indexer $g$ 嵌入计划，取余弦相似度最大帧：
  $$i_t = \arg\max_j \cos(g(Z_t), g(Z_j^D))$$
- **对齐监督** $L_{align} = L_{stage} + L_{cycle} + \omega L_{order}$：
  - $L_{stage}$：以子任务标注为正样本的对比损失（无标注帧被 mask 而非作负样本）；
  - $L_{order}$：用 soft-DTW 对整条匹配路径打分，保证匹配单调前进；
  - $L_{cycle}$：机器人与示范双向软匹配并惩罚往返时间距离。
- **内容特征**：future queries 预测固定偏移 $\Delta=16$ 后的状态，$L_{future} = d(\phi(E_t), S(o_{t+\Delta}))$，patch-wise 余弦距离——因此示范帧的 $E^D_j$ 描述的是"该帧的近未来"。
- **读取上下文**：对匹配阶段附近窗口 $\Omega=\{-7,0,7,14\}$ 帧的内容特征，经 memory adapter（两层 cross-attention + 16 个可学习 query）转为 $M_t$ 进入 VLM 序列。
- **动态更新**：$i_t$ 与 $M_t$ 每个新观测都重算，上下文跟随**进度**而非**时间**。

### 2.5 联合训练与执行
- **总目标**：$L = L_{action} + \beta L_{plan} + \gamma L_{future} + \lambda L_{align}$，其中 $L_{action}$ 为条件 flow matching。
- **闭环**：动作损失通过 $h_t$、$M_t$ 回传至共享骨干，即"计划 → 上下文 → 动作"的路径反过来更新产生计划的骨干。
- **训练流程**：先预训练世界模型 + teacher（压缩真实 checkpoint 成教师计划），策略 warm-up 阶段回归教师计划，之后替换为 $L_{plan}$；训练时 80% 样本附同任务异回合示范，其余 $M_t=0$ 以保证无示范可用；示范侧的键由周期性刷新的策略副本计算以稳定。
- **推理**：无示范时 $M_t=0$，仅增加查询 token 开销；有示范时其帧编码一次并缓存计划与内容特征，每个 chunk 做一次匹配 + 读取窗口。

## 6. 主要结论与发现

- **进度对齐的计划是有效的匹配键**：在 Imitator Game C15 上，进度对齐检索带来 +8.0（已见）/+6.5（P+FT 后未见）个百分点，显著优于视觉相似度检索（+2.0/+4.0）；而**时间打乱的示范反而比不给示范更差**（−4.0/−3.0），说明"在错误阶段读取示范会产生误导"。
- **计划本身即有价值**：LIBERO 平均 97.6%（vs 同策略无计划 96.8%）；LIBERO-Plus 73.2%（vs VLA-JEPA† 62.9%）；真实机器人 40% → 60%（仅加计划，无示范）。
- **长程任务收益最大**：LIBERO-10 上 95.8% vs 94.5%/94.0%，与"计划刻画剩余子任务"的动机一致。
- **训练时用示范 + 推理时读示范可叠加**：LIBERO-Plus 73.2% → 74.0%（仅训练）→ 75.2%（再给示范），7 个扰动维度全部提升。
- **真实部署场景的示范价值最高**：部署场景录制的示范使成功率从 65%（训练场景示范）升至 80%，且**不更新任何参数**，说明策略读取的是"每个阶段的部署环境外观"，而非复现轨迹。
- **失效模式前移**：加入计划与示范后，失败点从"底座未放置"逐步后移至"齿轮未啮合"，说明能力是渐进叠加而非突变。
- **局限现象**：在两物体放置任务中，机器人转向第二个物体后检索会**回退到第一个物体的示范段**，暴露重复操作间的阶段混淆。

## 7. 优点

- **表示复用的优雅性**：用于控制的计划直接充当匹配键，**无需手工度量、无需独立的对应模型**，只加一个小投影/indexer，是方法论上最核心的亮点。
- **"剩余过程"而非"固定视界"的目标设计**：以子任务完成点归一化时间，并对 25/50/75/100% 四个中间 checkpoint 全部监督，迫使计划编码**顺序**而非仅终点，这一设计对进度敏感任务有实质意义

这一设计对进度敏感任务有实质意义——因为若只监督终点，计划完全可以用"当前帧 + 一个标量剩余时间"近似满足，而中间 checkpoint 的加入让"先发生什么、后发生什么"成为必须编码的信息。

- **注意力掩码的因果纪律**：plan queries 不读示范上下文、action queries 不读 future queries，这两条约束从结构上保证了"计划不是被上下文污染的事后解释"，也保证"动作确实依赖计划"，使消融结论（去计划即掉点）具有可解释性，而不是被信息泄漏掩盖。
- **示范的使用是"可插拔"的**：无示范时 $M_t=0$，模型退化为纯计划条件策略；有示范时仅增加匹配与读取开销，帧特征可缓存复用。这种设计使同一套权重能覆盖"零示范 / 有示范 / 跨具身示范"三种部署形态，工程上友好。
- **匹配键与执行表示同源**：由于 indexer 嵌入的是策略自己产生的 $Z_t$，示范检索天然随策略能力演进而自适应，避免了"手工度量与策略脱节"的固有问题；示范侧的键用策略副本周期性刷新，也缓解了训练早期键质量差导致的匹配漂移。
- **实验叙事与论点严格对应**：核心主张（进度 > 时间 > 外观）由"无示范 / 时间打乱 / 视觉检索 / 进度检索"四条件直接检验，且"时间打乱比不给更差"这一反直觉结果被用作正面证据，论证链条闭合度较高。
- **真实机器人验证的诚实性**：作者明确报告部署场景不微调、仅换示范即从 65% 升至 80%，同时承认 20 trials 的噪声限制，没有把小幅差异包装成显著增益。

## 8. 局限与可改进方向

### 8.1 论文自身暴露的局限
- **重复性阶段的混淆**：两物体放置任务中，机器人转向第二个物体后检索回退到第一个物体的示范段。这说明进度键本质上是**"剩余状态变化"的相似性**，当两个阶段的变化模式高度同构（同为"抓取—移动—放置"）时，仅靠内容相似度无法区分"第几次"。
- **依赖子任务标注**：$L_{stage}$ 需要示范与回合的子任务边界标签，$L_{plan}$ 的目标 checkpoint 也以子任务结束点 $e_t$ 为锚。这限制了方法在无分段标注数据（如大规模无标注人类视频）上的直接扩展。
- **匹配粒度为帧级、单点**：$i_t$ 取 argmax 单帧，窗口 $\Omega$ 为固定偏移集合，对速度差异极大或示范本身含停顿/回退的情形可能不够稳健；虽然 $L_{order}$ 用 soft-DTW 约束了训练期路径单调性，但推理期并无显式单调约束。
- **固定偏移 $\Delta=16$ 的内容特征**：future queries 预测固定步长后的状态，若不同任务的动作节奏差异大（快任务 16 步已跨子任务，慢任务 16 步几乎无变化），该偏移的语义一致性存疑，论文未给出对 $\Delta$ 的敏感性分析。
- **评测统计强度不足**：单种子、单次评测、不报方差；真实机器人 20 trials 下的 5 个百分点差异难以支撑细粒度结论；LIBERO 已近饱和，主表区分度低，增益主要靠 LIBERO-Plus 与长程 suite 承担。
- **baseline 非同环境重跑**：跨系统比较的数字来源不一，作者虽声明增益归因依赖 within-method 对比，但读者仍难以完全剥离"实现质量/训练数据"与"方法本身"的贡献。
- **算力信息不透明**：仅给出单卡推理延迟，训练规模（GPU 数量、总时长）缺失，复现成本难以评估，也影响对"方法是否轻量"的判断。

### 8.2 可改进的方向
- **引入阶段身份或计数信号**：在计划中显式编码"第几个同类子任务"（如加入子任务索引 embedding，或在 indexer 输入中拼接历史匹配位置），可直接针对重复阶段回退问题。
- **软匹配与多候选读取**：将 argmax 替换为对候选帧的加权（top-k + 单调性约束），或用推理期 Viterbi/DTW 解码保证匹配路径不回退，与训练期的 $L_{order}$ 形成闭环。
- **弱化分段标注依赖**：用变化点检测或计划自身的预测误差峰值自动切分子任务，把 $e_t$ 从人工标注转为自监督估计，从而向无标注人类视频扩展。
- **自适应时间偏移**：让 $\Delta$ 随任务节奏或计划预测的不确定性调整，或改为"预测到下一个语义变化点"而非固定步数。
- **与长程记忆结合**：当前 memory tokens 只承载示范侧上下文，若再加入机器人自身的历史阶段轨迹，可同时解决"我在第几次"和"示范走到哪"两个问题。
- **统计严谨性**：多种子训练 + 报告置信区间，真实机器人增加 trials 数或采用配对试验设计，使小幅增益可判定。

## 9. 总体评价

- **定位**：这是一篇**方法论导向**的工作，其贡献不在新任务或新数据，而在于提出一个统一视角——"用自身执行预判作为组织示范经验的索引"，并用一个共享骨干、共享潜在空间、共享查询 token 的架构把该视角落地。
- **创新度**：核心创新（计划即键）概念简洁且具有可迁移性，属于"把两个原本分离的模块用同一表示缝合"的类型；其价值在于消解了手工度量与专用对应模型，而非提出全新的学习目标。相对而言，Markov 式多点监督与注意力掩码是支撑该创新的必要工程，单独看新意有限但组合得当。
- **证据强度**：覆盖 4 个仿真基准 + 1 个真实平台、2 种骨干，消融与控制实验针对性强，尤其"时间打乱劣于无示范"与"换部署示范即提升且不更新参数"两组结果，对核心论点支持力度较高。但受限于单种子、非同环境 baseline、部分设定非零样本，整体证据属于"方向可信、幅度待复核"。
- **实用性**：无示范退化路径干净、示范特征可缓存、推理开销仅增加查询 token，工程落地门槛较低；主要障碍是子任务标注依赖与重复阶段混淆。
- **一句话总结**：论文把"我还剩什么要做"变成"我该看示范的哪一段"，用同一潜在计划同时驱动动作与检索，在跨具身示范复用上给出了简洁、可解释且实验支撑较扎实的方案，其遗留问题（阶段歧义、标注依赖、统计强度）也清晰地指向了后续工作。
