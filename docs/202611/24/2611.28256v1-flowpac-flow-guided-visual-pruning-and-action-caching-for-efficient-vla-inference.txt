Abstract —Vision-Language-Action (VLA) models have emerged as a powerful paradigm for embodied AI, yet their high inference latency and memory footprint remain major barriers to edge deployment. Existing training-free acceleration techniques, such as visual token pruning and action caching, typically rely on static resource allocation. This mismatch with dynamic robotic interactions not only degrades control performance but also causes severe hardware inefficiencies, including fragmented KV-cache layouts and wasted compute on non-critical regions. To address this, we propose FlowPAC, a locality-aware framework that leverages task-aware optical flow as a shared physical signal to jointly optimize visual and action computation. Specifically, we introduce Direction-Aware Trajectory Propagation (DATP) and Locality-Aware Contiguous Token Selection (LACT) to jointly handle visual token dynamics and enforce spatial locality, re-ducing memory fragmentation and enabling efficient KV-cache compression. This is complemented by Flow-Conditioned Action-Block Refresh (FCAR) for adaptive action computation based on motion dynamics. Extensive closed-loop evaluations on LIBERO demonstrate that FlowPAC achieves a 2.13 × end-to-end speedup over the dense baseline while essentially maintaining the success rate with 30% visual-token retention. These results validate that aligning computation allocation with both physical dynamics and hardware constraints is essential for efficient VLA deployment on edge systems. 

Index Terms —vision-language-action models, robotic manipu-lation, token pruning, diffusion caching, inference acceleration 

I. I NTRODUCTION 

Vision-Language-Action (VLA) models have emerged as a promising solution to enhance generalization of robotic con-trol in embodied intelligence [1]–[4]. The mainstream VLA architecture pairs a pretrained VLM backbone with a dedicated action expert to unify visual, textual, and action information within a token-domain framework [5], [6]. While implementa-tions like the π series demonstrate strong generalization, they suffer from prohibitive end-to-end latency on device deploy-ment. Recent work on model efficiency spans quantization of VLA policies [7] and visual geometry transformers [8], layer skip-ping [9], knowledge distillation [10], visual token pruning [11], and action-head feature caching [12]. Efficient multimodal in-ference has also been explored in robotic perception, including training-free visual place recognition [13]. Among these, visual

token pruning and action caching have emerged as effective techniques for improving VLA inference efficiency, as they offer the distinct advantage of significantly reducing compu-tational and memory overheads without requiring costly model retraining or architectural modifications [14]–[16]. Visual token pruning reduces spatial redundancy by scoring patches with instruction-conditioned attention, action-decoding relevance, or recent action dynamics and retaining a compact token set under a prescribed budget, thereby reducing subsequent token processing and KV-cache storage [14], [17]. Caching-based methods reduce temporal redundancy either by reusing visual-token KV states across adjacent observations [15] or by retriev-ing intermediate action trajectories from similar multimodal contexts to warm-start iterative action generation [16]. How-ever, the holistic impact of these disjointed optimizations on the end-to-end VLA pipeline remains under-explored. Crucially, adapting these isolated optimizations to resource-constrained robotic platforms is non-trivial [18]–[20]. First, existing pruning methods typically decide which visual tokens to keep based on their importance in the current frame [14], [17]. However, a region that is unimportant in the current frame may become critical in the next few frames, for example, when the gripper moves toward it or approaches a contact boundary. Pruning decisions must be made before this future importance becomes directly observable. Premature pruning can therefore discard future-critical information and misallocate the compute budget, degrading control accuracy. Second, existing action-side caching methods typically use a fixed refresh rule, such as recomputing the action expert every few steps or when a predefined threshold is reached [16], [21]. Yet recomputa-tion needs vary throughout an interaction: frequent refreshes during smooth phases waste computation by repeating similar work, whereas infrequent refreshes during rapid or contact-rich transitions can reuse outdated action updates and introduce control lag. Fixed refresh rules thus fail to adapt computation to changing interaction dynamics. Both problems arise from the same limitation: the computational value of visual tokens and the freshness of cached action updates change with the interaction dynamics. • We propose DATP, which combines instruction-conditioned semantic relevance with signed optical flow to propagate semantic relevance toward future interaction regions and allocate visual tokens along predicted trajectories. 

• We introduce FCAR, which maps semantic-weighted dual-view motion to a causal, episode-calibrated refresh budget. FCAR selectively reuses action-expert residuals during stable solver steps without shortening the original flow-matching trajectory. 

• We develop LACT with deferred physical packing. LACT constructs an exact-budget, spatially coherent token mask, while deferred packing preserves early cross-token interac-tion and physically shortens the position-preserving visual prefix and its KV cache for subsequent layers. II. P ROFILING AND MOTIVATION 

As illustrated in the introduction, VLA systems typically consist of a VLM backbone and an action expert. To gain deeper insights into their execution efficiency, we profile π0.5

as our representative model. 

A. Profiling Setup 

To identify the computational and memory bottlenecks of flow-matching VLA inference, we profile the complete π0.5

policy inference under the same closed-loop rollout protocol used for evaluation. Our analysis targets three questions: (1) where execution time concentrates, (2) how the visual-prefix KV state scales with token count, and (3) whether optical-flow magnitude between consecutive observations varies across task phases. All measurements are taken on a single NVIDIA A100-PCIE-40GB GPU with BF16 precision and batch size one. The live tensor allocation of the visual-prefix KV state is captured at each retention setting. To construct the optical-flow magnitude trace, we compute dense optical flow between each pair of consecutive rollout frames and average the magnitudes of the top 15% of pixels within each frame pair. Here, the magnitude of a flow vector denotes its Euclidean norm, consistent with Sec. III-D. We show the raw trace together with an offline cen-tered moving-average trace to suppress frame-level noise and apply within-rollout percentile normalization for visualization. 

B. Bottleneck Analysis 

Panel I of Fig. 1(a) reveals two distinct resource imbalances between the sources of latency and persistent memory in dense 

π0.5 inference: action denoising dominates runtime (77.6%), while visual tokens dominate the prefix KV state (79.3%). As shown in panel II of Fig. 1(a), visual tokens account for 768 of the 968 prefix tokens (79.3%) and occupy 13.50 of the 17.02 MiB live KV state. Across the evaluated reten-tion settings, physical packing reduces the prefix KV state from 17.02 MiB to 9.81, 8.02, and 6.19 MiB, showing that physically shortening the prefix substantially reduces persistent KV storage. However, vision encoding and prefix computation together account for only 22.2% of policy-core latency, so even their idealized removal yields a visual-only speedup ceiling of 1/0.778 = 1 .29 ×. Visual pruning alone is therefore insufficient; repeated action denoising, the dominant latency component, must also be addressed. At each control query, the π0.5 action expert performs ten flow-matching denoising steps, consuming 236.3 ms, or 77.6% of the 304.6 ms policy-core latency. However, the action expert does not need to be recomputed at every step. When the in-teraction changes slowly, consecutive observations are similar, so the previous action update can be reused. During more dynamic interactions, such as grasping or contact, the scene changes more quickly and the cached update may no longer be accurate, requiring more frequent recomputation. Therefore, the key is to decide when the cached update can be reused and when it should be refreshed. As shown in the rightmost panel (III) of Fig. 1(a), the optical-flow magnitude also changes across different interaction phases, with larger values during more active interactions. This suggests that optical flow can provide a simple observable signal for deciding when to reuse the cached update and when to recompute the action expert. III. M ETHOD 

A. Overview 

FlowPAC jointly optimizes visual and action computation by using task-aware optical flow as a shared physical signal to coordinate two complementary axes: where visual computation is preserved and when action-expert computation is refreshed. As summarized in Fig. 1(b), the spatial branch comprises DATP, which predicts future-critical tokens using instruction-conditioned relevance and signed motion, and LACT, which converts the spatial score into an exact-budget, spatially co-herent mask followed by deferred physical packing. The tem-poral branch, FCAR, aggregates the same task-aware motion evidence into a causal refresh signal that adapts action-expert recomputation to the current dynamics of the interaction. Let Ivt denote the observation from view v ∈ { g, w } at control query t, where g and w denote the global and wrist camera views, respectively, and let x be the language instruc-tion. At each query, FlowPAC constructs per-view task-aware motion evidence from instruction-conditioned visual relevance and signed optical flow between consecutive observations. This shared signal drives both the spatial and temporal branches described below. 

B. Direction-Aware Trajectory Propagation

C. Locality-aware Contiguous Token Selection 

Common global Top-K selection often produces spatially fragmented masks, where selected tokens are scattered across the image. Here, one memory access refers to reading one contiguous span of selected patches in raster order during the packing gather; fragmented masks therefore require many sep-arate memory accesses, reducing the hardware benefit of token pruning. As shown in Fig. 3, LACT groups visual tokens into aligned b × b blocks and searches over one- or two-component block templates around high-score trajectory regions. Complete blocks are selected first to preserve spatial coherence, while the remaining budget is filled by a partial block drawn from adjacent high-score patches. In this way, LACT replaces the scattered token selection of global Top-K with the selection of spatially contiguous blocks. This makes the retained tokens easier to gather and physically compact, while the block budget is adjusted to keep exactly the same number of tokens as the original Top-K selection. The Bt refresh locations are distributed uniformly along the trajectory, including its two boundaries. At a refresh location, each action-expert layer performs its attention and feed-forward network (FFN) operations normally and caches the resulting residual updates. At a reuse location, both operators are skipped, and the most recently cached resid-uals are added to the current hidden state. Importantly, FCAR does not alter the flow-matching solver or reduce its integration steps: the action state and timestep embedding are updated at all D solver steps. FCAR therefore reduces computation by selectively reusing action-expert block evaluations while preserving the original solver trajectory. As a result, low task-conditioned motion leads to more aggressive reuse, whereas significant motion in either the global or wrist view automatically increases the refresh budget. This enables FCAR to allocate computation according to the instantaneous dynamics of the interaction rather than using a fixed temporal caching schedule. 

E. Joint Inference Procedure 

For every control query, DATP computes semantic and mo-tion evidence once and exposes it to both branches. LACT uses the spatial field to physically pack a future-aware visual prefix, while FCAR reduces action-expert recomputation according to the scalar dual-view motion risk. The modules are therefore coupled by a shared physical signal but optimize different axes: token packing reduces prefix length and KV storage, and action refresh reduces repeated temporal computation. IV. E VALUATION 

A. Experimental Setup 

We evaluate on the official π0.5 LIBERO checkpoint [22] with two active camera views and the original 10-step flow-matching solver. LIBERO comprises four suites (Spatial, Ob-ject, Goal, Long) with 10 tasks each; every success-rate entry averages 50 trials per task (2,000 episodes total). We compare against dense inference, FastV [23], VLA-ADP [17], and VLA-Cache [15] at matched 70%, 50%, and 30% control ratios. For pruning methods (FastV, VLA-ADP), the ratio denotes visual-token retention; for VLA-Cache, the complementary non-reuse ratio. All FlowPAC results share one fixed architecture (physical packing + FCAR) and differ only in retention. All measure-ments run on one NVIDIA A100-PCIE-40GB with BF16 and batch size one, using synchronized CUDA events over the full inference path. We report median (P50) and 95th-percentile (P95) latencies, corresponding to the values below which 50% and 95% of runs fall, respectively; speedup is computed from P50. 

B. End-to-End Results 

Table I reports the full success grid. Current-frame pruning methods such as FastV and VLA-ADP cannot reliably identify and preserve regions that become relevant in subsequent inter-actions. Discarding these future-critical visual tokens deprives the policy of visual evidence needed for later action generation, reducing task success; this limitation is particularly evident on the long-horizon LIBERO-Long suite. Under the tight 30% budget, FastV and VLA-ADP achieve only 71.2% and 83.2% success on LIBERO-Long, respectively, compared with 92.6% for dense inference. VLA-Cache retains all visual tokens but reaches only 89.2% on LIBERO-Long under aggressive visual-state reuse. In comparison, FlowPAC achieves 92.2% on the same suite and 97.15%, 96.15%, and 95.80% average success at 70%, 50%, and 30% retention, respectively. V. C ONCLUSION 

We presented FlowPAC, a training-free framework that uses task-aware optical flow to jointly optimize visual token selec-tion and action-expert refresh for VLA models. DATP predicts future-critical tokens via motion propagation, LACT enforces contiguous masks for physical packing, and FCAR adapts refresh to causal motion dynamics.
