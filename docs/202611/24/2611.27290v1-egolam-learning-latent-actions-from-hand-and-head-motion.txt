# Abstract 

Latent action models let a robot policy learn from video by turning the change between two frames into a training tar-get. In egocentric video, a cup can move across the image because a hand pushes it or because the wearer turns. Both changes help predict the next frame, but only the first de-scribes manipulation. During training, EgoLAM supervises the action code with measured wrist motion and supplies camera motion separately to the forward model. Even when the wearer turns while pushing a cup, the training target still describes how the hand pushed it. The action encoder pools object slots around each hand, and wrist translation and rotation can be decoded from the code in a common reference frame. Extracting a code then requires only two RGB frames. Alongside LARYBench classification and re-gression, we measure how much wrist motion a frozen code retains and how strongly it responds to a synthetic view or lighting change. EgoLAM has the highest hand-motion de-coding score among eight evaluated models. Across three LIBERO suites, policies pretrained on its codes and fine-tuned on expert demonstrations achieve 79.38% mean suc-cess, 28.73 points above expert behavior cloning and 9.76 points above the strongest other latent action model in each suite on average. 

# 1. Introduction 

Egocentric videos can teach bimanual manipulation even without recorded robot commands. Policies learn from these videos by predicting latent action labels from obser-vation history. The labels determine which changes a policy learns to imitate. 

Motivation. Applying existing latent action models to egocentric manipulation raises two problems for imitation. 

First, next-frame reconstruction can omit the motion the hand actually performs. LAPA reconstructs the later frame from the earlier frame and a latent action [25]. During a push, a code may suffice to reconstruct the scene yet omit some wrist translation or rotation. Accurate reconstruction supplies no separate signal to preserve that motion.

# 2. Related Work 

Inferring actions from observation transitions. A tran-sition between observations can supply an imitation target when expert commands are unavailable. BCO learns inverse dynamics through interaction and infers the demonstrator’s actions [22]. ILPO learns latent actions first and uses lim-ited interaction to map them to controls [3]. LAPO learns codes that explain transitions and trains a policy to predict them [18]. For a head-mounted camera, the transition also includes the observer’s motion. This makes the choice of what the code must predict particularly important. 

Training targets for video action models. Pixels, visual features and action labels place different demands on a code. LAPA learns from image reconstruction and Moto tokenizes motion for video pretraining [2, 25]. A change in appear-ance is informative for visual prediction even when it comes from a head turn. CLAM uses a continuous code with action decoding [10], and LAOM shows how action labels help un-der visual distraction [15]. GeoLAM instead uses a geome-try teacher to supervise displacement, residual image motion and orientation changes [24]. EgoLAM specifies whose mo-tion to preserve: its readout target is the wearer’s wrist mo-tion expressed in one reference frame. Related approaches use synchronized views [20] or progress toward a goal [13] to learn visual representations. 

Object-centric dynamics. Slots provide a way to follow the manipulated object through a cluttered scene. Slot At-tention groups image features [12], SAVi tracks slots over time [8], and SlotFormer predicts their dynamics [23]. DI-NOSAUR groups self-supervised visual features [1, 19]; our temporal training target follows VideoSAUR [26]. Closest to our work, Klepach et al. [9] select action-relevant slots and learn from their changes. Selecting the cup still leaves its apparent displacement ambiguous under a moving cam-era. EgoLAM uses hand queries to pool the interaction and measured camera motion to condition the prediction of fu-ture slots. 

Evaluating video representations. LARYBench mea-sures action classification and robot command regression separately from policy learning [14]. Something-Something labels temporal actions [5], while Ego4D and Ego-Exo4D cover first-person activities and skills across viewpoints [6, 7]. Recognizing a cup lift says little about its wrist trajectory. Section 4 therefore tests whether the wrist displacement and rotation can be decoded and how much the code changes when only the image is perturbed.

3.3. Stage 1: Slot pretraining 

Slot pretraining uses frozen visual features as targets. DI-NOv2 divides each frame into patches. Slot attention [12] pools patch features into K slots. A predictor initializes the next frame’s slots from the current ones, then the new features refine them. The decoder has two targets for each patch: its current feature and a distribution over patches in the next frame. A slot can reconstruct a cup in one frame without linking its features across frames. A second loss supplies that tem-poral signal. Lfeat is the mean squared error (MSE) against frozen DINO features. For a source patch i on the cup rim, destination patches j with similar frozen DINO keys receive more target probability pij . Several patches can share this mass. # 4. Egocentric diagnostics for LARYBench 

A code can score well on LARYBench action recognition while retaining little decodable wrist motion [14]. For ex-ample, a cup rising from a table may identify a lift even if the code omits which hand lifted it or how the wrist turned. In our results, LAOM reaches 70.56% human action accuracy but its wrist-motion readout achieves only R2 = 0 .0564 on the same checkpoint (Tables 1 and 2). Category recognition alone therefore does not tell us whether a code can label hand motion for imitation. Identifying which cue the model used requires an intervention. We use AD to measure recover-able motion and IC to measure responses to view or lighting changes at fixed action. LARYBench asks whether a frozen code identifies an ac-tion category or predicts a robot command [14]. Neither task separates two properties needed for egocentric imitation: re-taining human wrist motion and resisting a change in appear-ance when the hand stays still. We test the first by decoding hand motion and the second by perturbing an image. 44.1. Action decoding

5.3. Downstream tasks 

We compare latent action teachers within a common policy-training protocol on LIBERO [11]. For each task, all teach-ers label the same 24-frame-gap image pairs from the same 40 LIBERO training demonstrations. # 6. Discussion and conclusion 

A latent action for imitation must retain wrist motion even when the camera moves. EgoLAM uses hand poses to de-fine this motion in a common frame and gives camera mo-tion to the forward model separately. The paired motion-loss ablation supports the first choice, and the view-consistency ablation shows that training with warps reduces sensitivity to that intervention. The full model had the highest hand-motion decoding score among the eight evaluated check-points. After expert fine-tuning, mean success on three LIBERO suites reached 79.38%, a gain of 28.73 points over direct BC and 9.76 points over the strongest competing latent action teacher per suite, on average. EgoLAM could supply pretraining labels for first-person demonstrations without robot commands. Consider awearer who looks toward a shelf while lifting a cup. On independent head-mounted videos, we would match wrist motion to isolate the effect of real head turns, then fine-tune policies on matched demonstrations and measure real pick-and-place success. 8LLM Usage Statement
